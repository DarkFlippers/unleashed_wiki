# Official Unleashed links

These are the **authoritative** Unleashed Firmware resources, taken from the project's
[ReadMe](https://github.com/DarkFlippers/unleashed-firmware/blob/dev/ReadMe.md).

::: warning Only use official links
`DarkFlippers/unleashed-firmware` on GitHub is the **only** official home of the project. There are no paid,
"premium" or closed-source versions. If someone claims to be from the team and offers you something like that,
they are a scammer — block them.
:::
