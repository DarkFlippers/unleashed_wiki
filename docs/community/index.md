## About this wiki

This is a community project. It is **not affiliated with Flipper Devices** and is **not** an official Unleashed
resource — it is a how-to wiki written by reading the firmware source, the official documentation and the research
articles of the people credited here.

The wiki is **Unleashed-first**: where the Unleashed fork behaves differently from the stock firmware (extra
protocols, extra menus, extra apps), the difference is called out explicitly. Stock Flipper Zero knowledge is still
covered in full.

::: tip Every page credits its sources
Any page built from someone's article, channel post, documentation or firmware code carries a credits block at the
bottom listing the exact originals. If you think something is miscredited or missing, see
[Contributing](/community/contributing).
:::

::: warning For lawful use only
Everything here is for working with **your own** devices and for lawful research. Access control, rolling codes and
car keys are covered as a technical subject, not as an invitation to attack systems you do not own.
:::
