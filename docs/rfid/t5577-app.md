# T5577 app

The **T5577** app (by @mishamyte, shipped with Unleashed) works with a T5577 / ATA5577 blank at the **block level** —
the silicon, not the card it pretends to be. It can read the chip's blocks and save them, edit any block or compose its
configuration word, write a saved dump back, test which blocks accept writes, wipe the tag, clear its password, and
recover a password off the air by listening to a reader or cloner writing a tag.

Open it from `Main Menu → Apps → RFID → T5577` (installed as `/ext/apps/RFID/t5577.fap`). The 125 kHz RFID app also
launches it when you open a `.t5577` file from **Saved**.

::: tip Unleashed
This app does not exist in the stock firmware. Clear Password and the T5577 wipe used to be in the 125 kHz RFID app's
**Extra Actions**; they now live here.
:::

## Background: what is in a T5577

| Page / block | Contents |
|---|---|
| Page 0, block 0 | **Configuration**: modulation, bit rate, number of data blocks sent (max block), password bit and other flags |
| Page 0, blocks 1–6 | Data — the emulated card's frame |
| Page 0, block 7 | Password store (or ordinary data when no password is enabled) |
| Page 1, block 0 | Copy of the configuration |
| Page 1, blocks 1–3 | Traceability data from manufacture (blocks 1–2 locked on genuine chips) |

## Main menu

| Item | What it does |
|---|---|
| **Read Tag** | Read all blocks into a dump |
| **Test Tag** | Find out which blocks accept writes (backup first, then put back) |
| **Saved** | Open a saved `.t5577` dump |
| **Wipe Tag** | Reset the chip to blank |
| **Clear Password** | Remove a password: your word first, then the dictionary |
| **Sniff Password** | Listen to a reader / cloner and decode the commands it sends |
| **Passwords** | View the dictionaries and manage your own words |

## Read Tag

1. `T5577 → Read Tag`. Put the tag on the back of the Flipper and hold still (*Finding tag*, then `P0 block N…`).
2. The result screen **T5577 read** shows `Block 0: XXXXXXXX` and a summary like `RF/64, password set, inverted`.
   Buttons: **Save**, **Info**, **Retry**.
   - **Info** shows the decoded configuration (Modulation, Bit rate, Max block, flags PWD/AOR/ST/XM/POR, Password) and
     all blocks of Page 0 and Page 1; blocks that were not read are shown as dashes.
   - **Save** asks *Name the dump* and saves `/ext/lfrfid/<name>.t5577`.
3. **Read in part** means the tag stopped answering part way — the block it went quiet at is named. Hold it better and
   retry.
4. **Nothing found** — *Hold the tag still, or it needs a password*. Buttons **No pass** (retry plain) and
   **Password**.

::: danger Password reads can damage an open tag
Choosing **Password** shows *Only if it is protected — A password read writes block 0 of a tag that has no password
set*. The password-read frame is the same length as a write: sent to a tag that has **no** password it writes your
"password" into block 0 and the tag stops reading as anything. A badly held tag looks exactly like a protected one, so
always retry plainly first. If the app later finds the tag wanted no password, it warns *Tag wants no password — That
frame wrote block 0. Check it below, and wipe the tag if it reads wrong*.
:::

## Saved dumps

`T5577 → Saved` lists `.t5577` files. A dump opens a menu:

| Item | Action |
|---|---|
| **Info** | Decoded configuration and all blocks |
| **Write to Tag** | Write the dump back (asks *Write to tag* with the number of blocks) |
| **Edit** | Edit blocks |
| **Rename** / **Delete** | Manage the file (a dump can hold the tag's password — delete it if it shouldn't stay on the card) |

### Write to Tag

Writes only the blocks the dump really read, in the order Proxmark3 uses: page 0 blocks 1–7, page 1 blocks 1–3,
**block 0 last**. A zero block 0 is never written. Each block is read back afterwards. Results include **Written!**,
**Not written**, *Lost the tag at P0 block N*, *P0 block N differs*, *Tag wants a password this dump has not*, or
*P1 trace unchanged* (genuine chips refuse to change their traceability blocks — expected).

If block 0 describes a configuration the Flipper can't decode, you are warned before writing that *Nothing will read
back*.

### Edit

**Edit blocks** lists every block with its value. Pick a block to type a new 32-bit word. **Block 0** opens a
configuration editor with named fields:

- **Modulation**: Direct, PSK1, PSK2, PSK3, FSK1, FSK2, FSK1a, FSK2a, ASK/MC, Biphase, Diphase
- **Bit rate**: RF/8, RF/16, RF/32, RF/40, RF/50, RF/64, RF/100, RF/128
- **Data blocks** (max block), **Password bit** (On/Off), and **Word** — the raw hex.

When you leave, *Save changes — Write the edited blocks back to the file* asks whether to save. Declining also
discards the edit from memory, so it can't reach a tag by accident.

## Test Tag

Finds which of page 0 blocks 1–7 actually take a write. Asks *Do not move the tag — A backup is saved, then every block
is written and put back*.

- The full dump is read and saved as `/ext/lfrfid/t5577/T5577_before_test.t5577` before any write.
- Each block gets one bit flipped, is read back, and the original is written back and verified.
- Results: **Full T5577** (everything writable), **Nothing writeable**, *Stopped at block N*, *Lost tag at block N —
  Check it, then retry*, *Block N is not back* (restore it from the backup), **Tag has a password — Not supported yet**.
- If a previous test left a tag changed, the app warns *Unfinished test* before overwriting the backup.

## Wipe Tag

Confirm *Wipe T5577 — Erases all data. The tag stops working as a key. Hold still while running* → **Wipe**. Data
blocks are zeroed and a default configuration written, then the result is verified by reading back.

- **Wiped!** — done; write a new key from the 125 kHz RFID app.
- **Not wiped** — *No answer. Protected? Try Clear Password*, *The tag answered, but not as wiped*, or *Could not check
  what the tag holds*.

The wipe does **not** remove a password.

## Clear Password

1. `Clear Password` asks *Password to try first* — enter the tag's password if you know it (or leave the default).
2. Confirm *Apply tag to Flipper's back and don't move it while it runs* → **Start**.
3. The app first checks whether the tag is unprotected at all, then tries your password, then your **user dictionary**,
   then the **system dictionary** (`Pass N of M`). Only block 0 is written, with the password bit cleared — the same
   single write Proxmark3 uses.
4. Results: **Cleared!** (*Opened by this password* — with **Save** to add the word to your list), *The tag was asking
   for no password*, **Not cleared** (*No password matched, or no tag answered*), or dictionary/SD-card errors.

Block 7 keeps the old password value after clearing — only the protection bit is removed.

## Sniff Password

Recovers a password by **listening** while a reader or cloner talks to a tag. The Flipper sends nothing and does not
energise the field — safe to point at hardware you don't own.

1. `Sniff Password`. The screen shows *Listening* / *Hold on the cloner* and a live trace.
2. Put the Flipper's back on the cloner or reader, where the tag would go, and let the device do its write/read.
3. The capture ends after a complete command and silence; the result screen shows what was heard:
   - **Password** — *The cloner sent it* (a password-protected read/write was heard);
   - **New password** — *Written to block 7* (the cloner was installing a password);
   - **Maybe a password** — the 38-bit frame could be a password read or a write; both readings are under **More**;
   - **No password** / **Commands heard** — *None of them carried a password*;
   - **Too much noise**, **Can't decode**, **Nothing heard**.
4. **More** lists every decoded command (Reset, Read/Write with or without password, with block and data). **Save**
   stores a found password in your user dictionary (a reading deduced from neighbouring frames asks *Save a
   deduction?* first).

## Passwords

`T5577 Passwords` shows **System dict: N** and **User dict: N** with **Add** and **List** (select a word to delete it).

| File | Contents |
|---|---|
| `/ext/lfrfid/assets/t5577_dict.lfrfid` | System list (Proxmark3 passwords, overwritten on firmware update) |
| `/ext/lfrfid/assets/t5577_dict_user.lfrfid` | Your words — tried first by Clear Password, kept across updates |
