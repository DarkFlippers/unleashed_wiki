# Запис ключів 125 кГц на заготовки

Оригінальні карти та брелоки 125 кГц майже завжди доступні лише для читання. Щоб зробити фізичну копію, потрібна
**заготовка з можливістю запису** — «магічний» чип, який можна запрограмувати так, щоб він поводився як карта іншого
протоколу. Flipper Zero вміє записувати на таку заготовку будь-який збережений, прочитаний або доданий вручну ключ.

## На які заготовки можна писати

| Чип (як показано на екрані) | Типові назви на ринку | Записує | Типово |
|---|---|---|---|
| **T5577** | T5577, ATA5577, карти/брелоки/наліпки «5577» | усі протоколи | ON |
| **EM4305** | заготовки EM4305 / EM4205 | родина EM4100, Electra, FDX-B, Gallagher, GProxII, Jablotron, Radio Key (Securakey), Viking | ON |
| **8265** | ID8265 / H5 (клон Hitag Micro, типовий пароль) | родина EM4100 | ON |
| **8210** | ID8210 (той самий чип, пароль копіювальника FURUI) | родина EM4100 | ON |
| **H5.5** | iKey H5.5 (той самий чип, пароль iKey) | родина EM4100 | ON |
| **8268** | ID8268 (магічний чип Hitag S) | EM4100 лише на RF/64 | **OFF** |

::: tip Unleashed
Офіційна документація згадує тільки T5577. Підтримку Hitag Micro — **8265/H5, H5.5 та 8210** — додав до Unleashed
**@gromovyna**: ці чипи відрізняються лише паролем входу, тому Фліппер по черзі пробує кожен відомий пароль, а не
питає вас. Передісторія: [T5577 і Hitag Micro](/ua/rfid/t5577-hitag).
:::

::: warning 8268 — лише за вашим бажанням
Ціль **8268** (Hitag S) типово вимкнена. На відміну від інших режимів запису вона вибирає будь-яку мітку Hitag S, яка
відповіла, а на справжній Hitag S сторінки 4 і 5 містять дані застосунку — Фліппер не здатен відрізнити справжню
мітку від клона. Увімкніть цю ціль лише тоді, коли точно знаєте, що на котушці заготовка 8268.
:::

## Як записати ключ

1. Прочитайте мітку (`Read` → **More** → **Write**) або відкрийте збережену (`Saved` → ключ → **Write**).
2. Притуліть заготовку до задньої стінки Фліппера й **не рухайте її**. Світлодіод блимає пурпуровим.
3. На екрані буде **Writing**, протокол у квадратних дужках, назва файлу (або *Unsaved Tag*) і в круглих дужках —
   **чип, який пробується зараз**, наприклад:

   ```text
   Writing
   [EM4100]
   Office
   (T5577)
   ```

   ![Екран запису з протоколом [EM4100], назвою ключа і чипом, який пробується, — (T5577) у дужках](/screens/lfrfid/write.png)

4. Фліппер по черзі записує кожен увімкнений тип чипа і після кожної спроби **читає мітку назад**. Щойно зворотне
   читання збігається, він припиняє.
5. У разі успіху ви побачите **Success!** із назвою чипа, який насправді прийняв дані (наприклад, `T5577`, `EM4305`,
   `H5.5`), і застосунок повернеться до меню ключа.

![Запис у процесі: видно чип, який пробується](/img/remote/34b72cbd8417d74e.png)

![Результат запису з назвою чипа](/img/remote/3ca59457a78dad5b.png)

::: tip Навіщо показувати назву чипа?
Коли треба перебрати кілька типів чипів (а для Hitag Micro ще й три паролі), запис може тривати відчутно довше, і було
незрозуміло, що саме записалося. Показ чипа, який пробується, і кінцевого чипа — це UX-правка @gromovyna: технічно це
ринкова назва різновиду заготовки, а не протокол.
:::

## Settings → Write Chips

`Main Menu → 125 kHz RFID → Settings → Write Chips` показує всі цілі: **T5577**, **EM4305**, **8265**, **8210**,
**H5.5**, **8268** — кожну в стані **ON** / **OFF**.

- <kbd>OK</kbd>, <kbd>←</kbd> або <kbd>→</kbd> перемикає виділений чип.
- Вибір зберігається у `/ext/lfrfid/.lfrfid.settings`, коли ви покидаєте сторінку (<kbd>Back</kbd>).
- Якщо вимкнути чипи, якими ви ніколи не користуєтеся, запис пришвидшиться (кожен увімкнений чип, що не підходить,
  коштує одного запису + перевірки).
- CLI-команда `rfid write` використовує те саме налаштування.

Якщо сторінка не відкривається, ви побачите *Settings plugin failed to load* — оновіть ресурси на картці (ця сторінка
є окремим файлом плагіна). Запис усе одно користується тим, що збережено у файлі налаштувань.

## Write and set password {#write-and-set-password}

`Saved` → ключ → **Write and set password** записує ключ на **T5577** і вмикає його захист паролем, щоб ніхто не зміг
перезаписати мітку, не знаючи пароля.

1. Введіть 4-байтовий пароль у hex. Якщо пароля ще не було, поле заповнюється випадковим словом зі словника T5577.
2. Тримайте заготовку нерухомо. На екрані буде **Writing with password**, `[Protocol]` і поточний крок.
3. Спочатку записується й зчитується назад ключ, потім пароль іде в блок 7 і теж зчитується назад, і лише після цього
   в блоці 0 встановлюється біт пароля. **Запишіть пароль** — T5577, заблокований невідомим паролем, вже не
   використати.

Можливі результати:

| Екран | Що означає |
|---|---|
| **Success!** | Ключ записано, пароль збережено, захист увімкнено |
| **Error** — *This protocol cannot be written with a password* | Протоколу потрібні всі 7 блоків даних, тож блок 7 не може містити пароль |
| **Has a password** — *Clear it first: the T5577 app, Clear Password* | Мітка вже захищена |
| **Cannot read it** | На котушці щось є, але його блоки не читаються — спершу зітріть мітку або скиньте їй пароль |
| **Not written** | Один із блоків не прийняв ключ; мітка містить його частину й не має пароля |
| **Not protected** | Пароль не потрапив у блок 7, або мітка відмовилася вмикати захист |
| **Not confirmed** | Пароль на мітці, але підтвердити читанням, чи активний захист, не вдалося |
| **Still trying to write...** | Жодна мітка не відповідає — переконайтеся, що це T5577 з можливістю запису |

## Повідомлення про помилки звичайного запису

| Повідомлення | Що робити |
|---|---|
| *This protocol cannot be written* | Для нього немає кодування під жоден чип |
| *No write chips enabled. Enable one in Settings* | Усі цілі в стані OFF |
| *No enabled chip can write this protocol* | Наприклад, для HID-ключа увімкнено лише EM4305 — увімкніть T5577 |
| **Still Trying to Write...** *Make sure this card is writable and not protected* | З’являється приблизно через 10 с або після кількох невдалих перевірок. Мітка доступна лише для читання, захищена паролем, має непідтримуваний чип або погано розташована. Фліппер продовжує спроби, доки ви не натиснете <kbd>Back</kbd>. |

## Усунення проблем

- **На заготовці є пароль.** Багато дешевих копіювальників блокують заготовки T5577. Скористайтеся
  [застосунком T5577](/ua/rfid/t5577-app) → **Clear Password** (пробує ваш пароль, потім словник).
- **T5577 отримав сміттєву конфігурацію** (не читається взагалі). Застосунок T5577 → **Wipe Tag**.
- **Hitag Micro (8265/8210/H5.5) вимагає гарного розташування.** Запис на ці чипи триває довше й чутливий до
  положення; на LF Фліппер має лише передавач, тому успіх підтверджується тільки зворотним читанням мітки.
- **«Success» на карті лише для читання.** Якщо незаписувана мітка вже має такий самий ID, зворотне читання
  збігається і запис звітується як успішний.
- **Брелоки з металом або товстим корпусом.** Спробуйте різні місця: у брелоках котушка часто розташована не по
  центру.
