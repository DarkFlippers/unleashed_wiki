# Застосунок T5577

Застосунок **T5577** (від @mishamyte, постачається з Unleashed) працює із заготовкою T5577 / ATA5577 на **рівні
блоків** — тобто з самим кремнієм, а не з картою, якою той прикидається. Він умієпрочитати блоки чипа і зберегти їх,
відредагувати будь-який блок або скласти слово конфігурації, записати збережений дамп назад, перевірити, які блоки
приймають запис, стерти мітку, скинути їй пароль і дістати пароль «з повітря», підслухавши, як зчитувач або
копіювальник записує мітку.

Відкривається через `Main Menu → Apps → RFID → T5577` (встановлюється як `/ext/apps/RFID/t5577.fap`). Застосунок
125 kHz RFID теж запускає його, коли ви відкриваєте файл `.t5577` із **Saved**.

::: tip Unleashed
У стоковій прошивці цього застосунку немає. Clear Password і стирання T5577 раніше були в **Extra Actions** застосунку
125 kHz RFID; тепер вони живуть тут.
:::

## Трохи теорії: що є в T5577

| Сторінка / блок | Вміст |
|---|---|
| Сторінка 0, блок 0 | **Конфігурація**: модуляція, бітрейт, кількість блоків даних, що передаються (max block), біт пароля та інші прапорці |
| Сторінка 0, блоки 1–6 | Дані — кадр емульованої карти |
| Сторінка 0, блок 7 | Сховище пароля (або звичайні дані, якщо пароль не ввімкнено) |
| Сторінка 1, блок 0 | Копія конфігурації |
| Сторінка 1, блоки 1–3 | Заводські дані відстеження (на справжніх чипах блоки 1–2 заблоковані) |

## Головне меню

| Пункт | Що робить |
|---|---|
| **Read Tag** | Прочитати всі блоки в дамп |
| **Test Tag** | Дізнатися, які блоки приймають запис (спершу резервна копія, потім усе повертається) |
| **Saved** | Відкрити збережений дамп `.t5577` |
| **Wipe Tag** | Повернути чип у чистий стан |
| **Clear Password** | Зняти пароль: спочатку ваше слово, потім словник |
| **Sniff Password** | Підслухати зчитувач чи копіювальник і розшифрувати команди, які той надсилає |
| **Passwords** | Подивитися словники та керувати власними словами |

## Read Tag

1. `T5577 → Read Tag`. Покладіть мітку на задню стінку Фліппера й тримайте нерухомо (*Finding tag*, далі
   `P0 block N…`).
2. Екран результату **T5577 read** показує `Block 0: XXXXXXXX` і короткий опис на зразок `RF/64, password set,
   inverted`. Кнопки: **Save**, **Info**, **Retry**.
   - **Info** показує розшифровану конфігурацію (Modulation, Bit rate, Max block, прапорці PWD/AOR/ST/XM/POR,
     Password) і всі блоки сторінок Page 0 та Page 1; непрочитані блоки показані рисками.
   - **Save** запитує *Name the dump* і зберігає `/ext/lfrfid/<name>.t5577`.
3. **Read in part** означає, що мітка перестала відповідати на півдорозі — блок, на якому вона замовкла, названо.
   Притуліть її краще й повторіть.
4. **Nothing found** — *Hold the tag still, or it needs a password*. Кнопки **No pass** (повторити без пароля) і
   **Password**.

::: danger Читання з паролем може зіпсувати незахищену мітку
Якщо вибрати **Password**, з’явиться *Only if it is protected — A password read writes block 0 of a tag that has no
password set*. Кадр читання з паролем має таку саму довжину, як і запис: надісланий мітці **без** пароля, він запише
ваш «пароль» у блок 0, і мітка перестане читатися як щось узагалі. Погано притулена мітка виглядає точно так само, як
захищена, тому завжди спершу повторюйте спробу без пароля. Якщо згодом застосунок виявить, що мітка пароля не хотіла,
він попередить: *Tag wants no password — That frame wrote block 0. Check it below, and wipe the tag if it reads wrong*.
:::

## Збережені дампи

`T5577 → Saved` показує файли `.t5577`. Дамп відкривається з меню:

| Пункт | Дія |
|---|---|
| **Info** | Розшифрована конфігурація та всі блоки |
| **Write to Tag** | Записати дамп назад (запитує *Write to tag* із кількістю блоків) |
| **Edit** | Редагувати блоки |
| **Rename** / **Delete** | Керування файлом (дамп може містити пароль мітки — видаліть його, якщо він не має залишатися на картці) |

### Write to Tag

Записує лише ті блоки, які дамп справді прочитав, у порядку, який використовує Proxmark3: блоки 1–7 сторінки 0, блоки
1–3 сторінки 1, **блок 0 — останнім**. Нульовий блок 0 не записується ніколи. Після цього кожен блок читається назад.
Серед результатів бувають **Written!**, **Not written**, *Lost the tag at P0 block N*, *P0 block N differs*, *Tag
wants a password this dump has not* та *P1 trace unchanged* (справжні чипи не дають змінювати свої блоки відстеження —
це очікувано).

Якщо блок 0 описує конфігурацію, яку Фліппер не здатен розшифрувати, перед записом вас попередять, що *Nothing will
read back*.

### Edit

**Edit blocks** перераховує всі блоки з їхніми значеннями. Виберіть блок, щоб увести нове 32-бітове слово.
**Block 0** відкриває редактор конфігурації з іменованими полями:

- **Modulation**: Direct, PSK1, PSK2, PSK3, FSK1, FSK2, FSK1a, FSK2a, ASK/MC, Biphase, Diphase
- **Bit rate**: RF/8, RF/16, RF/32, RF/40, RF/50, RF/64, RF/100, RF/128
- **Data blocks** (max block), **Password bit** (On/Off) і **Word** — сире значення в hex.

Під час виходу з’явиться запит *Save changes — Write the edited blocks back to the file*. Якщо відмовитися, правка
також відкидається з пам’яті, тож випадково потрапити на мітку вона не може.

## Test Tag

Визначає, які з блоків 1–7 сторінки 0 насправді приймають запис. Запитує *Do not move the tag — A backup is saved,
then every block is written and put back*.

- Перед будь-яким записом повний дамп читається і зберігається як `/ext/lfrfid/t5577/T5577_before_test.t5577`.
- У кожному блоці перевертається один біт, блок читається назад, а потім оригінал записується назад і перевіряється.
- Результати: **Full T5577** (усе доступне для запису), **Nothing writeable**, *Stopped at block N*, *Lost tag at
  block N — Check it, then retry*, *Block N is not back* (відновіть його з резервної копії), **Tag has a password —
  Not supported yet**.
- Якщо попередній тест залишив мітку зміненою, застосунок попередить *Unfinished test*, перш ніж перезаписати резервну
  копію.

## Wipe Tag

Підтвердьте *Wipe T5577 — Erases all data. The tag stops working as a key. Hold still while running* → **Wipe**. Блоки
даних обнуляються, записується типова конфігурація, після чого результат перевіряється зворотним читанням.

- **Wiped!** — готово; запишіть новий ключ із застосунку 125 kHz RFID.
- **Not wiped** — *No answer. Protected? Try Clear Password*, *The tag answered, but not as wiped* або *Could not
  check what the tag holds*.

Стирання **не** знімає пароль.

## Clear Password

1. `Clear Password` запитує *Password to try first* — введіть пароль мітки, якщо ви його знаєте (або залиште типове
   значення).
2. Підтвердьте *Apply tag to Flipper's back and don't move it while it runs* → **Start**.
3. Застосунок спершу перевіряє, чи мітка взагалі захищена, потім пробує ваш пароль, далі ваш **користувацький
   словник**, а потім **системний словник** (`Pass N of M`). Записується лише блок 0 зі скинутим бітом пароля — той
   самий одиничний запис, який робить Proxmark3.
4. Результати: **Cleared!** (*Opened by this password* — із кнопкою **Save**, щоб додати слово до свого списку), *The
   tag was asking for no password*, **Not cleared** (*No password matched, or no tag answered*) або помилки
   словника / картки.

Після скидання блок 7 зберігає старе значення пароля — прибирається лише біт захисту.

## Sniff Password

Відновлює пароль, **підслуховуючи** розмову зчитувача або копіювальника з міткою. Фліппер нічого не надсилає й не
живить поле — тому його безпечно наводити на обладнання, яке вам не належить.

1. `Sniff Password`. На екрані буде *Listening* / *Hold on the cloner* і живий трейс.
2. Притуліть задню стінку Фліппера до копіювальника чи зчитувача — туди, де була б мітка, — і дайте пристрою виконати
   свій запис або читання.
3. Перехоплення завершується після повної команди й тишини; екран результату показує почуте:
   - **Password** — *The cloner sent it* (почуто захищене паролем читання чи запис);
   - **New password** — *Written to block 7* (копіювальник встановлював пароль);
   - **Maybe a password** — 38-бітний кадр може бути як читанням із паролем, так і записом; обидва трактування — під
     **More**;
   - **No password** / **Commands heard** — *None of them carried a password*;
   - **Too much noise**, **Can't decode**, **Nothing heard**.
4. **More** перераховує всі розшифровані команди (Reset, Read/Write з паролем або без, із блоком і даними). **Save**
   зберігає знайдений пароль у ваш користувацький словник (для трактування, виведеного зі сусідніх кадрів, спершу
   запитають *Save a deduction?*).

## Passwords

`T5577 Passwords` показує **System dict: N** і **User dict: N** із кнопками **Add** і **List** (виберіть слово, щоб
його видалити).

| Файл | Вміст |
|---|---|
| `/ext/lfrfid/assets/t5577_dict.lfrfid` | Системний список (паролі з Proxmark3, перезаписується під час оновлення прошивки) |
| `/ext/lfrfid/assets/t5577_dict_user.lfrfid` | Ваші слова — Clear Password пробує їх першими, і вони зберігаються між оновленнями |
