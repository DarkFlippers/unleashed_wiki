# Чипи для тварин (FDX-B, FDX-A)

Чипи для домашніх улюбленців — це RFID-транспондери розміром із рисове зерно, що імплантуються під шкіру. Коли
зчитувач подає на них живлення, вони передають ID, який можна знайти в базах розшуку тварин. Flipper Zero читає два
поширені LF-типи:

| Тип | Назва у Фліппері | Опис |
|---|---|---|
| **FDX-B** | `FDX-B` (ISO) | ISO 11784/11785, 15-значний ID; найпоширеніший тип; деякі чипи ще й повідомляють температуру тіла |
| **FDX-A** | `FDX-A` (FECAVA) | Старіші 10-значні чипи, що не відповідають ISO |

Більшість чипів для тварин працюють на **134,2 кГц**, тоді як антена Фліппера налаштована на 125 кГц, тому відстань
читання невелика — близько **1 см**. Чипи в діапазоні 110–140 кГц прочитати можна, але ще ближче.

::: tip Unleashed
Офіційна документація радить користуватися *Read ASK*. Unleashed створює для цих чипів справжнє поле **134,2 кГц**:
- **Read** тепер виконує третій прохід, **134kHz**, після ASK і PSK;
- `Extra Actions → Read FDX-B (Animals)` весь час тримається на 134,2 кГц — найкращий вибір для слабких чипів;
- назва країни для FDX-B шукається у `/ext/lfrfid/assets/iso3166.lfrfid`.
:::

## Як прочитати чип улюбленця

1. Відкрийте `Main Menu → 125 kHz RFID → Extra Actions → Read FDX-B (Animals)`. На екрані буде *Reading FDX-B*.
2. Знайдіть чип:
   - у собак і котів він зазвичай під шкірою **між лопатками**; у континентальній Європі часто **посередині лівого
     боку шиї**. Чипи можуть трохи зміщуватися;
   - обережно промацайте пальцями тверде зернятко, а потім приставте до нього центр задньої стінки Фліппера.
3. Тримайте Фліппер нерухомо близько **3 секунд** у кожній точці. Якщо нічого немає, рухайте його дрібними кроками по
   ділянці, потім поверніть Фліппер на 90° і повторіть.
4. Дивіться на світлодіод: жовтий або зелений означає, що сигнал ловиться — залишайтеся на цьому місці.
5. Після розшифрування з’явиться екран результату. <kbd>→</kbd> **More → Save**, щоб зберегти його.

## Що Фліппер показує для FDX-B

| Поле | Значення |
|---|---|
| `ID: CCC-NNNNNNNNNNNN` | 3-значний код країни (ISO 3166-1 numeric) або код виробника + 12-значний національний ID — саме цей 15-значний номер і шукають у базах |
| Country Code / Country | Код і його назва з таблиці ISO 3166 |
| Temperature | Для термочипів, у °C і °F; `---`, якщо його немає |
| Animal | Позначка застосування «тварина» |
| Visual Start Digit, Replacement Number, User Info, RFU | Поля заголовка ISO-кадру |
| Data Block | Present / Absent — додатковий блок даних (наприклад, температура) |
| RUDI Bit | Yes / No |

Для FDX-A показуються 10-значний hex `ID` і `Parity`.

::: warning
Температура з чипа не замінює справжній термометр.
:::

## Як знайти ID у базі

Введіть 15-значний ID у базу розшуку тварин, наприклад:
- [AAHA Pet Microchip Lookup](https://www.aaha.org/petmicrochiplookup) — США та Канада
- [Europetnet](https://www.europetnet.com/) — Європа
- [PETMAXX](http://www.petmaxx.com/) — по всьому світу

Або зверніться до місцевого ветеринара чи реєстру тварин.

## Якщо чип не знаходиться

- Він поза зоною дії — рухайтеся дрібнішими кроками і довше тримайте в кожній точці.
- Чип змістився — перевірте більшу ділянку.
- Поряд метал або електроніка — відійдіть від них.
- У тварини може бути чип на 13,56 МГц — спробуйте [NFC](/ua/nfc/read).
- Чип не підтримується — попросіть ветеринара просканувати його.

Ключі FDX-B також можна [емулювати або записати](/ua/rfid/write) (на заготовки T5577 та EM4305, які бувають і у
вигляді скляних капсул) — наприклад, щоб перевірити дверцята для тварин.
