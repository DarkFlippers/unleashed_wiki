# Читання, збереження та емуляція міток 125 кГц

Мітка 125 кГц — це транспондер, який, отримавши живлення від поля зчитувача, передає фіксований ID. Якщо мітка
використовує один із [підтримуваних протоколів](/ua/rfid/protocols), Flipper Zero розшифровує цей ID, показує його і
може зберегти на картку microSD, емулювати для зчитувача або [записати на заготовку](/ua/rfid/write).

**Коли це потрібно:** якщо ви хочете мати копію власного пропуску чи брелока на Фліппері, хочете дізнатися, що саме у
вас за мітка, або вам потрібен ID для системи контролю доступу, якою ви керуєте.

::: tip Insert an SD card
Збережені ключі, словники та налаштування лежать на картці microSD (`/ext/lfrfid/`). Встановлюйте прошивку з
вставленою карткою, щоб ресурси застосунку опинилися на місці.
:::

## Як прочитати мітку

1. Відкрийте `Main Menu → 125 kHz RFID → Read`.
2. Притуліть мітку до **задньої** стінки Фліппера, приблизно посередині, і тримайте нерухомо. На екрані буде
   *Don't move card*.
3. Фліппер послідовно виконує три проходи читання приблизно по 2 секунди кожен і показує активний як
   **Reading 1/3 … 3/3**: **ASK** (125 кГц), **PSK** (125 кГц) і **134kHz** (ASK на 134,2 кГц, для чипів тварин).

   ![Reading 1/3 з активним проходом ASK, під ним PSK і 134 кГц, а знизу «Don't move card»](/screens/lfrfid/read.png)

4. Дивіться на світлодіод: під час читання він блимає **блакитним**, стає **жовтим**, коли щось почув, і **зеленим**,
   коли кадри мітки почали розшифровуватися — так зручно знайти найкраще положення.
5. Коли мітку розшифровано, Фліппер пищить і показує екран результату:
   - заголовок: виробник і протокол, наприклад **EM-Micro EM4100**;
   - `Hex:` — сирі дані ключа (перші 7 байтів, довші ключі закінчуються на `...`);
   - розпізнані поля (facility code, номер карти тощо — див. [протоколи](/ua/rfid/protocols)).

   ![Результат читання: EM-Micro EM4100 з hex-даними, facility code, номером карти, DEZ 8 і DEZ 10, а знизу Retry і More](/screens/lfrfid/read_success.png)

6. Кнопки: <kbd>←</kbd> **Retry** (запитає *Retry Reading? All unsaved data will be lost*), <kbd>→</kbd> **More**,
   <kbd>Back</kbd> запитає, чи виходити, втративши незбережений результат.

::: tip Unleashed
Стокова документація описує лише перемикання ASK/PSK. Unleashed додає третій прохід на **134 кГц** (мітки FDX-A/FDX-B
налаштовані на 134,2 кГц, і слабкі відповідають лише там), а для EM4100 ще й показує **DEZ 8** та **DEZ 10** —
десяткові форми, надруковані на багатьох брелоках. Якщо EM4100 розшифровується як пропуск Casi-Rusco C10106,
з’являється додатковий рядок `or C10106: …`, а ключ Generic HIDProx перевіряється на відповідність відомим форматам
HID (H10304, H10302, S10401, H10306, Corp1000-35) з показом їхніх FC та номера карти.
:::

## Після читання: More

<kbd>→</kbd> **More** відкриває:

| Пункт | Дія |
|---|---|
| **Save** | Ввести назву (типовий префікс `RFID`), зберігається як `/ext/lfrfid/<name>.rfid` |
| **Emulate** | Відразу емулювати ключ, не зберігаючи його |
| **Write** | Записати ключ на заготовку — див. [Запис](/ua/rfid/write) |

## Читання з фіксованою модуляцією

Деяким міткам потрібно більше часу, ніж один 2-секундний прохід, а деякі надійно знаходяться лише з конкретним
демодулятором. `Main Menu → 125 kHz RFID → Extra Actions` пропонує:

| Пункт | Що читає |
|---|---|
| **Read ASK (Regular)** | Лише ASK на 125 кГц, доки не знайдеться мітка: EM4100, HID, AWID, Viking, Paradox… |
| **Read PSK (Indala)** | Лише PSK: Indala, Keri, Nexwatch, Idteck… |
| **Read FDX-B (Animals)** | Лише ASK на 134,2 кГц — чипи тварин, див. [Чипи для тварин](/ua/rfid/animal-microchips) |

У режимі Debug в тому самому меню є ще **Read RAW RFID data** і **Emulate RAW RFID data** — див. [RAW](/ua/rfid/raw).

## Збережені ключі

`Main Menu → 125 kHz RFID → Saved` відкриває файловий браузер у `/ext/lfrfid/`. Якщо вибрати ключ `.rfid`,
відкриється меню:

![Меню збереженої мітки з пунктами Emulate, Write, Write and set password та Edit](/screens/lfrfid/saved_menu.png)

| Пункт | Дія |
|---|---|
| **Emulate** | Видавати себе за цей ключ перед зчитувачем |
| **Write** | Записати його на заготовку ([Запис](/ua/rfid/write)) |
| **Write and set password** | Записати на T5577 і захистити паролем ([Запис](/ua/rfid/write#write-and-set-password)) |
| **Edit** | Змінити дані ключа в hex; зберігається під тією самою назвою |
| **Rename** | Змінити назву файлу |
| **Delete** | Видалити файл (з підтвердженням) |
| **Info** | Назва, протокол, повні hex-дані та всі розпізнані поля |

::: tip Unleashed
Браузер також показує дампи блоків **`.t5577`** (позначені іконкою T5577). Вибір такого дампа запускає
[застосунок T5577](/ua/rfid/t5577-app) з ним. Якщо застосунку немає, ви побачите *No T5577 app — It comes with the
firmware - install its resources to get it*.
:::

## Емуляція

1. Відкрийте збережений ключ (або щойно прочитаний через **More**) і виберіть **Emulate**.
2. На екрані буде *Emulating*, `[Protocol]` і назва ключа (або *Unsaved Tag*); світлодіод блимає пурпуровим.

   ![Екран емуляції з надписом «Emulating», протоколом [EM4100] і назвою ключа](/screens/lfrfid/emulate.png)

3. Притуліть Фліппер задньою стінкою впритул до зчитувача. Щоб припинити, натисніть <kbd>Back</kbd>.

## CLI

Через CLI по USB/serial (команда `rfid`):

```text
rfid read <optional: normal | indala | ask134>   - read in ASK/PSK mode
rfid <write | emulate> <key_type> <key_data>      - write or emulate a card
rfid raw_read <ask | ask134 | psk> <filename>     - read and save raw data to a file
rfid raw_emulate <filename>
rfid raw_analyze <filename>
```

`key_type` — це назва протоколу так, як вона зберігається у файлах `.rfid` (наприклад, `EM4100`, `H10301`), а
`key_data` — hex.

## Усунення проблем

- **Нічого не знаходиться.** Можливо, карта працює на 13,56 МГц — спробуйте [NFC](/ua/nfc/read). Багато «подвійних»
  карт містять і те, і те.
- **Читання крутиться по колу.** Спробуйте фіксований режим в **Extra Actions** — проходу в 2 с деяким міткам
  замало.
- **Слабкі мітки та маленькі брелоки.** Повільно рухайте мітку по задній стінці й слідкуйте за жовтим/зеленим
  світлодіодом. Не тримайте її в руці над металом.
- **Невідомий протокол.** Зробіть [RAW](/ua/rfid/raw)-запис і надішліть її розробникам.
- **Емуляцію не приймають.** Деякі зчитувачі вимогливі до відстані та орієнтації — тримайте Фліппер рівно, спробуйте
  кілька положень. Зчитувачі, які перевіряють щось більше за ID (наприклад, криптокарти), емуляцією не обдурити.
