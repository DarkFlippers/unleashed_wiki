# Мобільні та настільні застосунки

Flipper працює самостійно, але з комп'ютером чи смартфоном деякі речі робляться значно легше: встановлення й
оновлення прошивки, копіювання файлів, установлення застосунків, резервне копіювання ключів і пультів, дистанційне
керування Flipper.

| Інструмент | Працює на | Для чого зручний |
|---|---|---|
| [qFlipper](/ua/mobile/qflipper) | Windows, macOS, Linux | встановлення Unleashed із `.tgz`, файловий менеджер, резервне копіювання / відновлення, recovery |
| [Мобільний застосунок Flipper](/ua/mobile/mobile-app) | iOS, Android | оновлення через Bluetooth (у тому числі власним `.tgz`), архів ключів, каталог застосунків, дистанційне керування |
| [qUnleashed](/ua/mobile/qunleashed-app) | Android, iOS, Windows, macOS, Linux | власний застосунок Unleashed: оновлення прошивки через BLE або USB, архів, каталог застосунків, віддалений екран, CLI, відновлення Seed |
| [Вебінструменти](/ua/mobile/web-tools) | браузер | вебінсталятор, карта Sub-GHz і координат, карта Wi-Fi-вардрайвінгу, прошивальник ESP32, Flipper Lab |

::: tip Unleashed
Unleashed повністю сумісний з офіційним qFlipper і офіційним мобільним застосунком Flipper. Найшвидший спосіб
встановити або оновити Unleashed — [вебінсталятор](/ua/mobile/web-tools#unleashed-web-installer) у браузері на
Chromium.
:::

::: warning Одне підключення за раз
Послідовний USB-порт Flipper може використовувати лише одна програма. Закрийте qFlipper, перш ніж відкривати
Flipper Lab, вебінсталятор, термінал CLI або U2F, і тримайте відкритою лише одну вкладку Flipper Lab.
:::
