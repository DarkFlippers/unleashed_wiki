# Офіційні посилання Unleashed

Це **достовірні** ресурси прошивки Unleashed, узяті з
[ReadMe](https://github.com/DarkFlippers/unleashed-firmware/blob/dev/ReadMe.md) проєкту.

::: warning Користуйтеся тільки офіційними посиланнями
`DarkFlippers/unleashed-firmware` на GitHub — **єдиний** офіційний дім проєкту. Жодних платних, «преміальних»
чи закритих версій не існує. Якщо хтось видає себе за члена команди й пропонує вам щось подібне, це шахрай —
блокуйте його.
:::

## Супутні застосунки та вебінструменти

| Інструмент | Що робить | Посилання |
|---|---|---|
| **qUnleashed** | Керування Flipper зі смартфона або ПК (супутній застосунок Unleashed) | [github.com/DarkFlippers/qUnleashed](https://github.com/DarkFlippers/qUnleashed) |
| **Карта вардрайвінгу** | Показує на карті ваші файли Sub-GHz-вардрайвінгу та будь-які файли з координатами | [map.unleashedflip.com](https://map.unleashedflip.com) |
| **Карта WiGLE** | Об'єднує й відображає записи у форматі WiGLE з ESP32 Marauder та інших пристроїв | [wdmap.unleashedflip.com](https://wdmap.unleashedflip.com) |
| **ESP flasher** | Прошиває популярні модулі ESP32 повністю у браузері | [espflasher.unleashedflip.com](https://espflasher.unleashedflip.com) |
