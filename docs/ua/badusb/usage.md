# Використання Bad USB

На цій сторінці розглянуто запуск скрипта через USB і через Bluetooth та описано кожен пункт меню **Config**.
Підписи меню та повідомлення наведені точно так, як вони виглядають у прошивці.

::: warning
Запускайте скрипти лише на комп'ютерах, які вам належать або які вам дозволено тестувати. Прочитайте скрипт перед
запуском: він зробить усе, що в ньому написано, з правами вашого користувача.
:::

## Перед початком

- Потрібна картка microSD із ресурсами прошивки. Без неї застосунок показує *«No SD card or app data found.
  This app will not work without required files.»*
- Покладіть свій скрипт (`.txt`) у `/ext/badusb/` (підтеки допускаються).
- **Режим USB забирає USB-порт Flipper собі.** Якщо через USB підключений qFlipper або [CLI](/ua/dev/cli),
  застосунок показує *«Connection Is Active! Disconnect from PC or phone to use this function.»* Спочатку закрийте
  qFlipper.

## Головний екран

1. Відкрийте `Main Menu → Bad USB`.
2. Виберіть скрипт у файловому браузері. Відкриється екран скрипта.

Верхній рядок показує назву скрипта, під ним у дужках — розкладку клавіатури, `(default)` або, наприклад,
`(de-DE)`, і час від початку, а в режимі BLE — PIN-код спарювання. Малюнок у центрі показує USB-штекер або символ
Bluetooth.

![Екран скрипта Bad USB: завантажено demo_windows, 0/34 рядків, підказки Config / Run / BLE](/screens/badusb/script_ready.png)

| Стан | Текст на екрані | <kbd>OK</kbd> | <kbd>←</kbd> | <kbd>→</kbd> |
|---|---|---|---|---|
| Очікування / Done / немає з'єднання | прогрес або *Connect to device* | **Run** | **Config** | перемкнути на **BLE** / **USB** |
| Очікування з'єднання після Run | *Will run on connect* | **Cancel** | | |
| Виконується або в `DELAY` | `рядок/усього`, відсотки, `Delay Ns` | **Stop** | | **Pause** |
| Пауза | *Paused* | **End** | | **Resume** |
| Очікування на `WAIT_FOR_BUTTON_PRESS` | | **Press to continue** | | |
| Помилка | *ERROR:* + `line N` + повідомлення | | | |

Якщо натиснути **Run** до того, як хост розпізнає Flipper, застосунок чекає (*«Will run on connect»*) і запускає
скрипт автоматично **через 1,5 с після встановлення з'єднання**, щоб хост мав час установити клавіатуру.

Поки хост не підключений, замість прогресу показуються пісочний годинник і *Connect to device*:

![Bad USB чекає на USB-хост, на екрані написано Connect to device](/screens/badusb/not_connected.png)

<kbd>Back</kbd> виходить з екрана скрипта й повертає до файлового браузера.

## Запуск через USB

1. Закрийте qFlipper на комп'ютері.
2. `Main Menu → Bad USB` → виберіть скрипт.
3. Переконайтеся, що на екрані зображено **USB**; якщо ні, натисніть <kbd>→</kbd> **USB**.
4. За бажанням: <kbd>←</kbd> **Config → Keyboard Layout (global)**, щоб розкладка відповідала розкладці
   комп'ютера (типово `en-US`).
5. Підключіть Flipper до комп'ютера USB-кабелем.
6. Натисніть <kbd>OK</kbd> **Run**. Прогрес `рядок/усього` дійде до 100 %.

![Bad USB виконує скрипт: 32 %, рядок 12 з 34, підказки Stop і Pause](/screens/badusb/script_running.png)

![Bad USB у режимі USB](/img/remote/d49323518c0b4b18.jpg)

## Запуск через Bluetooth (BLE)

1. Переконайтеся, що Bluetooth на Flipper увімкнений (`Settings → Bluetooth`).
2. `Main Menu → Bad USB` → виберіть скрипт.
3. Натисніть <kbd>→</kbd> **BLE**; з'явиться символ Bluetooth. Flipper почне рекламувати себе як клавіатуру.
4. На комп'ютері чи смартфоні відкрийте налаштування Bluetooth і підключіться до
   **`BadUSB <ім'я вашого Flipper>`** (типове ім'я).
5. Підтвердьте спарювання на обох пристроях. У типовому режимі спарювання на обох екранах показується однаковий
   PIN; підтвердьте, що він збігається. PIN також видно на екрані скрипта.
6. Натисніть <kbd>OK</kbd> **Run**.
7. Щоб згодом прибрати спарювання: <kbd>←</kbd> **Config → Remove BLE Pairing**, а потім забудьте пристрій і на
   хості.

![Bad USB у режимі BLE](/img/remote/083420027c3f836c.jpg)

::: tip Окрема ідентичність і окреме спарювання
У режимі BLE Flipper використовує **власну MAC-адресу** (похідну від MAC Flipper) і власне сховище спарювань,
окреме від звичайного профілю Bluetooth. Тому спарювання комп'ютера з Bad USB не ламає спарювання з Flipper
Mobile App. Коли ви виходите із застосунку, звичайний профіль Bluetooth відновлюється.
:::

## Скрипти, які самі перемикають режим

Якщо **перший рядок** скрипта — команда `ID` (USB) або `BLE_ID` / `BT_ID` (Bluetooth), застосунок автоматично
перемикається у відповідний режим під час відкриття скрипта й застосовує задану ідентичність. Перемкнути режим
вручну через <kbd>→</kbd> все одно можна. Див.
[Формат скриптів → Device ID](/ua/badusb/script-format#device-id).

## Меню Config

<kbd>←</kbd> **Config** доступне лише тоді, коли скрипт не виконується. Вміст залежить від поточного режиму
з'єднання.

### Спільні пункти

| Пункт | Значення | Що робить |
|---|---|---|
| **Keyboard Layout (global)** | файловий браузер | Вибирає файл `.kl` із `/ext/badusb/assets/layouts/`. Діє для кожного скрипта, який не задає власну розкладку через `DUCKY_LANG`. Див. [Розкладки клавіатури](/ua/badusb/layouts). |
| **Connection** | `USB` / `BLE` | Те саме, що <kbd>→</kbd> на головному екрані. Перелік нижче змінюється відповідно. |

### Режим BLE

| Пункт | Значення | Що робить |
|---|---|---|
| **Persist Pairing** | `ON` / `OFF` | ON (типово): створює зв'язок із хостом і запам'ятовує його, тому підключення відновлюється без повторного спарювання. OFF: спарювання щоразу. |
| **Pairing Mode** | `YesNo`, `PIN Type`, `PIN Y/N` | `YesNo`: спарювання без PIN. `PIN Type`: Flipper показує PIN, який ви вводите на хості. `PIN Y/N` (типово): обидва показують PIN; підтвердьте, що він збігається. |
| **Set Device Name** | текст | Ім'я Bluetooth (*«Set BLE device name»*). Порожнє = `BadUSB <ім'я Flipper>`. |
| **Set MAC Address** | 6 байтів | *«Set BLE MAC address»*. |
| **Randomize MAC Address** | дія | Генерує випадкову статичну MAC-адресу, показує **Done**. Зручно, щоб виглядати як «нова» клавіатура. |
| **Restore BLE Defaults** | дія | Очищає ім'я та MAC, ставить Persist Pairing ON і Pairing Mode `PIN Y/N`. |
| **Remove BLE Pairing** | дія | *«Unpair the Device?»* → **Unpair** забуває всі хости, спаровані з Bad USB. |

### Режим USB

| Пункт | Значення | Що робить |
|---|---|---|
| **Set Manufacturer Name** | текст | Рядок виробника USB (*«Set USB manufacturer name»*). |
| **Set Product Name** | текст | Рядок назви продукту USB (*«Set USB product name»*). |
| **Set VID and PID** | 4 байти | *«Set USB VID:PID»*. Дає Flipper представлятися із заданими ID виробника/продукту. |
| **Randomize VID and PID** | дія | Випадкові VID і PID, показує **Done**. |
| **Restore USB Defaults** | дія | Очищає VID/PID та назви: використовується типова клавіатурна ідентичність Flipper. |

Усе це, разом із вибраною розкладкою та режимом, зберігається у `/ext/badusb/.badusb.settings`. Рядок
`ID` / `BLE_ID` у скрипті перевизначає ідентичність лише для цього скрипта.

## Якщо не працює

| Проблема | Що спробувати |
|---|---|
| Набраний текст — мішанина (`z` і `y` помінялися, не ті символи) | Розкладка хоста не збігається з розкладкою застосунку. Виберіть правильну розкладку в Config або додайте `DUCKY_LANG` до скрипта. На ПК із кількома мовами введення перемкніть хост на мову розкладки перед запуском (наприклад, на англійську, а не українську). |
| Частина символів пропадає | Хост надто повільний. Додайте `DEFAULT_STRING_DELAY 10` (або більше) і довші `DELAY` після відкриття вікон. |
| Скрипт починається до того, як вікно відкрилося | Збільште `DELAY` після `GUI r`, `ENTER` і подібних команд. |
| *ERROR: line N* | У рядку невідома команда, друкарська помилка, хибне число або текст не з ASCII. Команди **чутливі до регістру** (`STRING`, а не `string`). Див. [Формат скриптів](/ua/badusb/script-format). |
| *Native .kl supports ASCII, not UTF-8* | `STRING` містить символи не з ASCII (діакритика, кирилиця…). Скористайтеся `ALTSTRING`/`ALTCHAR` у Windows або введіть такий текст іншим способом. |
| *Connection Is Active!* | Відключіть qFlipper / CLI від USB-порту. |
| macOS відкриває *Keyboard Setup Assistant* | Скористайтеся рядком `ID` із VID/PID клавіатури Apple (див. приклад `demo_macos.txt`) або просто закрийте помічника. |
| BLE-хост не знаходить Flipper | Увімкніть Bluetooth на Flipper, залишайтеся на екрані скрипта в режимі BLE, приберіть старі спарювання з обох боків (`Remove BLE Pairing`). |
