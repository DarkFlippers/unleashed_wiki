# Небезпечні налаштування: розширений діапазон Sub-GHz

Unleashed може змусити радіомодуль CC1101 працювати **за межами офіційного діапазону частот**. На цій сторінці —
що робить це налаштування, чому воно вам майже напевно не потрібне і як його все-таки увімкнути, якщо потрібне.

::: danger Прочитайте перед тим, як щось робити
1. Не робіть цього, якщо не розумієте точно, що саме робите.
2. Для майже будь-якого сценарію розширений діапазон не потрібен.
3. Передавання за межами специфікації обладнання **може пошкодити ваш пристрій**.
4. Ні команда Flipper Devices, ні розробники Unleashed не відповідають за будь-які пошкодження, спричинені
   кастомною прошивкою чи розширенням діапазону частот.
:::

## Найімовірніше, воно вам не потрібне: регіональних обмежень немає

::: tip Unleashed
В Unleashed **усі регіональні обмеження на передавання прибрані типово**. Будь-яка частота в межах діапазону, який
підтримує чип, передається без додаткових дій. Не використовуйте небезпечне налаштування, щоб «розблокувати свій
регіон» — для цього воно не потрібне.
:::

Якщо передавання на якійсь частоті заблоковано, спершу перевірте, чи вона входить до звичайного діапазону передавання
(таблиця нижче). Поза ним прошивка пише в журнал `Frequency blocked - outside default range`.

## Діапазони частот

| | Діапазони |
|---|---|
| Документація на CC1101 | 300–348 МГц, 386–464 МГц, 778–928 МГц |
| Типовий діапазон **передавання** в Unleashed | ≈ 300–350 МГц, 387–467,75 МГц, 779–928 МГц (розширено, щоб охопити 350 МГц і 467 МГц) |
| Передавання з увімкненим `dangerous_settings` | **281–361 МГц, 378–481 МГц, 749–962 МГц** |

Розширений діапазон збігається з розширеним діапазоном YARD Stick One (так зазначено у вихідному коді прошивки).
За межами діапазонів з документації чип працює поза специфікацією, і передавання там може його пошкодити.

## Як увімкнути

1. Вийміть картку microSD або під’єднайтеся через qFlipper чи будь-який інший файловий менеджер.
2. Відкрийте файл **`/ext/subghz/assets/dangerous_settings`**. Він виглядає так:
   ```text
   # Do you want to damage your flipper CC1101 radio chip by using Frequencies that outside HW specs?
   # CC1101 Frequency range specs: 300-348 MHz, 386-464 MHz, and 778-928 MHz
   # This setting will extend to: 281-361 MHz, 378-481 MHz, and 749-962 MHz
   yes_i_want_to_destroy_my_flipper: false
   ```
3. Прочитайте коментарі й замініть `false` на `true`:
   ```text
   yes_i_want_to_destroy_my_flipper: true
   ```
4. Збережіть файл і перезавантажте Фліппер. Налаштування читається під час запуску.

Щоб повернути все як було, поставте значення `false` і перезавантажте пристрій.

::: warning Оновлення
Цей файл — частина ресурсів прошивки. Оновлення може перезаписати його типовим значенням `false`. Якщо ви покладаєтеся
на це налаштування, перевіряйте файл після кожного оновлення.
:::
