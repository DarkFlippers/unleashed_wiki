# Керування

У Flipper Zero є п’ятипозиційний джойстик і окрема кнопка <kbd>BACK</kbd>.

| Кнопка | Що робить |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | Переміщення по меню та віртуальних клавіатурах. <kbd>←</kbd>/<kbd>→</kbd> змінюють значення вибраного параметра |
| <kbd>OK</kbd> | Запуск застосунку, підтвердження вибору. Довге натискання часто відкриває додаткові дії |
| <kbd>BACK</kbd> | Повернення назад або вихід із застосунку. Довге натискання на робочому столі відкриває екран вимкнення |

У списку стрілки переміщують рамку по пунктах, а <kbd>OK</kbd> відкриває вибраний:

![Головне меню з рамкою на пункті Sub-GHz](/screens/mainmenu/subghz.png)

У цій вікі «утримувати» або «довге натискання» означає натиснути кнопку й тримати приблизно секунду. Підказки внизу
екрана (наприклад, `◀ Cancel` або `Save ▶`) показують, що саме на цьому екрані роблять <kbd>←</kbd>, <kbd>OK</kbd>
та <kbd>→</kbd>.

## Режим для лівші

**Main Menu → Settings → System → Hand Orient → `Lefty`**

Екран перевертається на 180°, а кнопки перепризначаються — тепер Фліппер зручно тримати в лівій руці.

## Гарячі клавіші

| Дія | Як |
|---|---|
| Увімкнення | Утримуйте <kbd>BACK</kbd> близько 3 с |
| Вимкнення | Утримуйте <kbd>BACK</kbd> на робочому столі → **Power Off** (<kbd>→</kbd>) |
| Перезавантаження (пристрій зависнув) | Утримуйте <kbd>←</kbd> + <kbd>BACK</kbd> близько 5 с |
| Жорстке перезавантаження (скидання живлення) | Від’єднайте USB, утримуйте <kbd>BACK</kbd> близько 30 с |
| Перезавантаження в DFU (відновлення) | Утримуйте <kbd>←</kbd> + <kbd>BACK</kbd>, відпустіть <kbd>BACK</kbd>, тримайте <kbd>←</kbd>, доки не засвітиться синій світлодіод |

Усі комбінації скидання та входу в DFU, а також що робити, коли вони не допомагають, —
на сторінці [Комбінації кнопок](/ua/start/key-combos).

## Ярлики робочого стола

| Кнопка | Коротке натискання | Довге натискання |
|---|---|---|
| <kbd>OK</kbd> | Main Menu | Улюблений застосунок (OK Long) |
| <kbd>↑</kbd> | Lock Menu | **Блокування Фліппера** (з PIN-кодом, якщо він заданий) |
| <kbd>↓</kbd> | Archive | Інформація про пристрій / службовий екран |
| <kbd>←</kbd> | Улюблений застосунок (Left Short), типово — меню Apps | Улюблений застосунок (Left Long) |
| <kbd>→</kbd> | Passport (або призначений застосунок) | Улюблений застосунок (Right Long) |
| <kbd>BACK</kbd> | — | Екран вимкнення |

Застосунки призначаються в **Settings → Desktop → Favorite App - …**. Докладніше — на
сторінці [Робочий стіл](/ua/start/desktop).

::: tip Unleashed
Утримування <kbd>↑</kbd> на робочому столі одразу блокує пристрій (з PIN-кодом, якщо він заданий). У стоковій
прошивці заблокувати Фліппер можна лише через `Lock Menu`.
:::

Коротке натискання <kbd>↑</kbd> відкриває Lock Menu:

![Lock Menu: вибрано Turn Bluetooth On, нижче Mute і Dummy Mode](/screens/desktop/lock_menu.png)

Якщо задано PIN-код, Фліппер запитає його перед розблокуванням. Стрілки вводять код, <kbd>BACK</kbd> стирає
введене, а <kbd>OK</kbd> підтверджує:

![Enter PIN: чотири введені цифри показані зірочками, п’ята клітинка порожня, підказка про стирання та кнопка OK](/screens/desktop/pin_input.png)

Довге натискання <kbd>↓</kbd> відкриває інформаційний екран пристрою — час роботи, ревізія апаратної платформи,
ім’я Фліппера, версія прошивки й дата збірки, коміт, версія API та прапорець Debug. Довге натискання
<kbd>OK</kbd> на цьому екрані вмикає або вимикає Debug:

![Інформаційний екран пристрою: Uptime 1h23m45s, апаратна платформа 13.F7B9C6 R00, прошивка unlshd-080 від 21-11-2026 і D:ON](/screens/desktop/debug.png)

## Відгук на натискання

**Main Menu → Settings → Input**

| Пункт | Значення | Що означає |
|---|---|---|
| Buttons Vibro | `OFF`, `1`…`9` | Коротка вібрація на кожну подію кнопки. Чим більше число, тим довша вібрація |
| Vibro Trigger | `Press`, `Release`, `Both` | Коли саме спрацьовує вібрація |

## Введення тексту

На віртуальній клавіатурі переміщуйтеся стрілками й натискайте <kbd>OK</kbd>, щоб ввести вибраний символ. Утримуйте
<kbd>OK</kbd> на літері, щоб ввести її у верхньому регістрі. Для підтвердження виберіть клавішу `⏎` / **Save**.
<kbd>BACK</kbd> видаляє останній символ або закриває клавіатуру.

::: tip Unleashed
У полі введення тексту є **курсор**, тому текст можна правити в середині, а не лише з кінця. У шістнадцятковому полі
**введення байтів** (наприклад, коли ключ додають вручну) кілька разів натисніть <kbd>↑</kbd>, доки не з’явиться
**міні-редактор нібблів** — він дає змогу змінювати по півбайта за раз.
:::
