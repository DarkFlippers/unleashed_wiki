# Картка microSD

Картка microSD не є чимось необов'язковим. На ній зберігаються ваші збережені ключі, картки й пульти, усі
застосунки `.fap` (включно з вбудованими застосунками Unleashed), бази даних, пакет оновлення, а в актуальній
прошивці — навіть **внутрішнє сховище**.

## Вибір картки

- **Обсяг:** 16–32 ГБ цілком достатньо. Підтримуються картки до 256 ГБ, але великі монтуються довше.
- **Файлова система:** FAT12, FAT16, FAT32 або exFAT.
- **Якість:** беріть **брендову** картку (SanDisk, Kingston…). Flipper спілкується з карткою через **SPI**, а не
  через швидкий режим SDIO, яким користуються смартфони й ПК. Не кожна картка добре працює по SPI, навіть якщо в
  інших пристроях вона поводиться нормально. Погана картка робить Flipper повільним, може швидше розряджати
  акумулятор (до ~50 мА замість ~30 мА) і може пошкодити дані.
- Читання по SPI досягає майже 600 КіБ/с, і цього достатньо для всього, що робить Flipper.

## Встановлення

1. Слот розташований у нижній частині Flipper.
2. Тримайте картку **контактами догори** й вставляйте, доки вона не клацне.
3. У рядку стану з'явиться піктограма SD.

## Якщо картка не розпізнається

З'являється повідомлення про SD-картку або піктограма в рядку стану стає перекресленою. Можливі причини:

| Причина | Що робити |
|---|---|
| Хибна файлова система або її відсутність | Форматувати картку (див. нижче) |
| Пил у слоті | Обережно продути стисненим повітрям |
| Картка не підтримує SPI | Взяти іншу картку |
| Картка пошкоджена | Взяти іншу картку |

## Settings → Storage

**Main Menu → Settings → Storage**

| Пункт | Що робить |
|---|---|
| **About Internal Storage** | Назва, тип `Virtual (/.int on SD)`, загальний і вільний обсяг, вільна флеш-пам'ять |
| **About SD Card** | Мітка, тип файлової системи, загальний і вільний обсяг, виробник і серійний номер |
| **Unmount SD Card** / **Mount SD Card** | Безпечно відмонтувати перед вийманням або змонтувати знову. Монтування може коротко знімати живлення із зовнішніх модулів |
| **Format SD Card** | Форматує картку. **Усі дані буде втрачено!** |
| **Benchmark SD Card** | Перевіряє швидкість запису/читання в режимі SPI |
| **Factory Reset** | Стирає внутрішнє сховище (налаштування, спарювання, дельфіна). Див. [Відновлення](/ua/start/recovery#factory-reset) |

### Форматування

1. **Settings → Storage → Format SD Card**.
2. Підтвердьте клавішею <kbd>→</kbd> **Format**.
3. Дочекайтеся `Formatted` і натисніть **Finish**.

Якщо форматування на Flipper не вдається (`Cannot Format SD Card`), відформатуйте картку на ПК у FAT32/exFAT або
спробуйте іншу картку.

### Безпечне виймання

1. **Settings → Storage → Unmount SD Card** → <kbd>→</kbd> **Unmount**.
2. Коли побачите `SD Card Unmounted` / `You can remove SD card now.`, натисніть на картку, щоб вона вийшла, і
   витягніть її.

Виймання картки, поки Flipper на неї пише, може пошкодити файли або файлову систему.

### Benchmark

Benchmark записує тестовий файл `/ext/rwfiletest.bin` і показує рядки на кшталт `4096b : W 300K R 600K`: розмір
блоку, далі швидкість запису й читання в КіБ/с. Для нормальної роботи картка мусить писати **щонайменше
~260 КіБ/с**. Результати відрізняються від бенчмарків на ПК, бо тест виконується в режимі SPI. Запустіть його
кілька разів, щоб отримати справедливу картину.

## Структура тек

`/ext` — це корінь картки. Основні теки:

| Тека | Вміст |
|---|---|
| `/ext/subghz/` | Файли `.sub` для Sub-GHz. У `assets/` лежать `dangerous_settings`, `setting_user.example` (шаблон для власного переліку частот), сховище ключів KeeLoq `keeloq_mfcodes` |
| `/ext/subghz_remote/` | Розкладки Sub-GHz Remote |
| `/ext/nfc/` | Файли `.nfc` для NFC. У `assets/` лежать словники ключів |
| `/ext/lfrfid/` | Файли `.rfid` для RFID 125 кГц |
| `/ext/ibutton/` | Файли `.ibtn` для iButton |
| `/ext/infrared/` | ІЧ-пульти `.ir`. У `assets/` лежать бібліотеки універсальних пультів |
| `/ext/badusb/` | Скрипти Bad USB (`.txt`). У `assets/layouts/` лежать розкладки клавіатури (`.kl`) |
| `/ext/apps/` | Застосунки `.fap` за категоріями (вбудовані застосунки й пакети застосунків) |
| `/ext/apps_data/` | Дані й налаштування застосунків |
| `/ext/dolphin/` | `name.settings` (власне ім'я) та анімації |
| `/ext/update/` | Розпаковані пакети оновлення |
| `/ext/.int/` | Файли, що лежать за внутрішнім сховищем (`/int`). Не редагуйте їх вручну |

::: tip
Час від часу робіть резервну копію всієї картки (qFlipper може завантажити файли, або скопіюйте їх на ПК). Ваші
ключі й пульти існують лише на картці.
:::

## macOS: приховані файли й сортування {#macos-hidden-files-and-sorting}

macOS залишає на картці файли `._*` і `.DS_Store`. Приберіть їх:

```bash
sudo dot_clean -mn /Volumes/Flipper\ SD
```

Замініть `Flipper\ SD` на назву своєї картки.

Файловий браузер виводить перелік файлів швидше, коли каталог FAT відсортований. На macOS (із
[Homebrew](https://brew.sh)):

```bash
brew install fatsort
diskutil list                         # find the card, e.g. disk4s1
diskutil unmount /Volumes/Flipper\ SD
sudo fatsort -n /dev/disk4s1          # use your own disk id
```

`fatsort` доступний і для Linux.
