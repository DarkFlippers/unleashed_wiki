# Комбінації кнопок

Іноді Фліппер перестає реагувати через програмну помилку. Ці комбінації кнопок скидають його на апаратному рівні
або запускають у режимі DFU (оновлення прошивки) — без участі завислої прошивки.

## Коротка довідка

| Мета | Комбінація | USB |
|---|---|---|
| Перезавантажити завислий Фліппер | <kbd>←</kbd> + <kbd>BACK</kbd>, ~2–5 с | будь-як |
| Скидання живлення | <kbd>BACK</kbd>, 30 с | **від’єднано** |
| DFU через завантажувач Фліппера (з індикацією) | <kbd>←</kbd> + <kbd>BACK</kbd>, відпустити <kbd>BACK</kbd>, тримати <kbd>←</kbd> до синього світлодіода | будь-як |
| DFU через завантажувач ST (без індикації) | <kbd>←</kbd> + <kbd>BACK</kbd> + <kbd>OK</kbd>, відпустити <kbd>BACK</kbd> і <kbd>←</kbd> | будь-як |
| Екран скидання PIN-коду / налаштувань | утримувати <kbd>↑</kbd> під час завантаження | — |

## Базові комбінації

### Апаратне скидання

1. Натисніть і тримайте <kbd>←</kbd> та <kbd>BACK</kbd> кілька секунд.
2. Відпустіть обидві кнопки.

Так лінія скидання мікроконтролера притягується до нуля. Шлях: кнопки → DD8 (NC7SZ32M5X, елемент OR) →
DD1 (STM32WB55, мікроконтролер).

**Не працює, якщо:** активний блок налагодження мікроконтролера й він утримує лінію скидання зсередини.

### Апаратне скидання живлення

1. Від’єднайте кабель USB і будь-яке зовнішнє живлення. Переконайтеся, що USB справді від’єднано.
2. Натисніть і тримайте <kbd>BACK</kbd> **30 секунд**. Це працює лише з від’єднаним USB.
3. Відпустіть <kbd>BACK</kbd>.

Так лінія живлення SYS вимикається й знову вмикається через мікросхему заряджання DD6 (bq25896).

**Не працює, якщо:** живлення подається по USB або на 5V_ext.

### Програмний DFU

Утримуйте <kbd>←</kbd> під час завантаження Фліппера. Він увійде в режим DFU через **завантажувач Фліппера**.

**Не працює, якщо:** завантажувач Фліппера пошкоджений або відсутній.

### Апаратний DFU

Утримуйте <kbd>OK</kbd> під час завантаження Фліппера. Він увійде в режим DFU через **завантажувач ST**, вбудований
у мікроконтролер.

**Не працює, якщо:** Option Bytes пошкоджені або налаштовані ігнорувати кнопку <kbd>OK</kbd>.

## Комбінації для DFU

### Апаратне скидання + програмний DFU

1. Тримайте <kbd>←</kbd> + <kbd>BACK</kbd> кілька секунд.
2. Відпустіть <kbd>BACK</kbd>.
3. Пристрій входить у DFU **з індикацією**: синій світлодіод і екран DFU.
4. Відпустіть <kbd>←</kbd>.

**Не працює, якщо:** блок налагодження мікроконтролера утримує лінію скидання або завантажувач Фліппера пошкоджений
чи відсутній.

### Апаратне скидання + апаратний DFU

1. Тримайте <kbd>←</kbd> + <kbd>BACK</kbd> + <kbd>OK</kbd> кілька секунд.
2. Відпустіть <kbd>BACK</kbd> і <kbd>←</kbd>.
3. Пристрій входить у DFU **без індикації**. Екран залишається порожнім — це нормально.

**Не працює, якщо:** блок налагодження мікроконтролера утримує лінію скидання або Option Bytes пошкоджені чи
налаштовані ігнорувати <kbd>OK</kbd>.

### Апаратне скидання живлення + програмний DFU

1. Від’єднайте USB та будь-яке зовнішнє живлення.
2. Тримайте <kbd>BACK</kbd> + <kbd>←</kbd> 30 секунд.
3. Відпустіть <kbd>BACK</kbd>.
4. Пристрій входить у DFU з індикацією (синій світлодіод + екран DFU).
5. Відпустіть <kbd>←</kbd>.
6. Під’єднайте USB.

**Не працює, якщо:** живлення подається по USB або на 5V_ext, або завантажувач Фліппера пошкоджений чи відсутній.

### Апаратне скидання живлення + апаратний DFU

1. Від’єднайте USB та будь-яке зовнішнє живлення.
2. Тримайте <kbd>BACK</kbd> + <kbd>OK</kbd> 30 секунд.
3. Відпустіть <kbd>BACK</kbd> і <kbd>OK</kbd>.
4. Пристрій входить у DFU без індикації.
5. Під’єднайте USB.

**Не працює, якщо:** живлення подається по USB або на 5V_ext, або Option Bytes пошкоджені чи налаштовані
ігнорувати <kbd>OK</kbd>.

## Що робити в режимі DFU

Під’єднайте Фліппер до комп’ютера. Він визначиться як **DFU in FS Mode** (Windows/macOS) або
**STMicroelectronics STM Device in DFU Mode** (`lsusb` у Linux). Далі відновіть прошивку через qFlipper:
[Відновлення](/ua/start/recovery#firmware-recovery).

## Якщо ніщо не допомагає {#if-nothing-helps}

- Переконайтеся, що акумулятор заряджений: залиште пристрій на зарядці на годину.
- Від’єднайте й знову під’єднайте акумулятор (потрібно розібрати корпус).
- Прошийте пристрій через ST-Link або інший SWD-програматор.

Якщо після всього цього пристрій усе одно не працює, проблема **не програмна**.
