# Відновлення

Що робити, якщо Фліппер зависає, не оновлюється, не показує нічого на екрані або ви забули PIN-код. Виконуйте кроки
по порядку — від найобережнішого до найрадикальнішого.

## 1. Спершу перезавантаження

- **Зависло:** утримуйте <kbd>←</kbd> + <kbd>BACK</kbd> близько 5 секунд.
- **Усе ще зависло:** від’єднайте USB і тримайте <kbd>BACK</kbd> 30 секунд (скидання живлення).
- **Розряджений акумулятор:** зарядіть кілька хвилин (або годину) і спробуйте знову.
- Якщо Фліппер працює: **Settings → Power → Reboot → Reboot Flipper**.

Усі комбінації — на сторінці [Комбінації кнопок](/ua/start/key-combos).

## 2. Відновлення прошивки з режиму DFU {#firmware-recovery}

Потрібне, коли прошивка пошкоджена: оновлення зривається, на екрані сміття або порожньо, кнопки не реагують.
Завантажувач USB DFU прошиває пристрій без участі його власної системи.

### Крок 1: перевести Фліппер у режим DFU (відновлення)

**Якщо Фліппер ще працює, але не оновлюється нормально:**
1. **Main Menu → Settings → Power → Reboot → Firmware Upgrade**.
2. Підтвердьте `Reboot to DFU Mode?` кнопкою <kbd>→</kbd> **Reboot**.

*або:* утримуйте <kbd>←</kbd> + <kbd>BACK</kbd> 5 с, відпустіть <kbd>BACK</kbd> і тримайте <kbd>←</kbd>, доки не
засвітиться **синій світлодіод**.

**Якщо екран порожній і кнопки не реагують:**
1. **Від’єднайте кабель USB.**
2. Тримайте <kbd>OK</kbd> + <kbd>BACK</kbd> **30 секунд**. Порожній екран тут — це нормально.

Після цього під’єднайте Фліппер до комп’ютера кабелем USB.

### Крок 2: переконатися, що комп’ютер бачить DFU-пристрій

| ОС | Де дивитися | Назва |
|---|---|---|
| Windows | Диспетчер пристроїв | **DFU in FS Mode** |
| macOS | Меню Apple → About This Mac → System Report → Hardware → USB (або `system_profiler SPUSBDataType`) | **DFU in FS Mode** |
| Linux | `lsusb` | **STMicroelectronics STM Device in DFU Mode** |

Не визначається? Спробуйте інший кабель. Під’єднуйтеся безпосередньо до порту USB на материнській платі, а не через
хаб чи адаптер. Або вийміть картку, зарядіть пристрій годину й під’єднайте без картки.

### Крок 3: відновлення

Підійде будь-який із двох застосунків. Обидва повністю перепрошивають Фліппер по USB.

**[qUnleashed](/ua/mobile/qunleashed-app)** — Android, Windows, macOS і Linux (на iOS USB немає):

1. Під’єднайте Фліппер у режимі DFU по USB.
2. Відкрийте **Repair from DFU mode** і запустіть відновлення.

**qFlipper** — Windows, macOS і Linux:

1. Запустіть **qFlipper** — він виявить DFU-пристрій.
2. Натисніть **Repair**. qFlipper повністю встановить **офіційну** прошивку.

Далі встановіть Unleashed знову: [Встановлення Unleashed](/ua/start/install).

::: tip Unleashed
Кнопка **Repair** у qFlipper завжди відновлює офіційну прошивку. Це нормально: ви отримуєте чисту основу. Після
відновлення поставте Unleashed через qUnleashed, Web Installer або **Install from file**. Файли на картці
відновлення не чіпає.
:::

### Якщо qFlipper не може відновити пристрій

- Перевірте, чи правильно встановлений qFlipper. Для Windows дивіться розділ про драйвери в довідці qFlipper.
- Від’єднайте USB, перезавантажте пристрій комбінацією <kbd>←</kbd> + <kbd>BACK</kbd> і повторіть спробу.
- Зробіть скидання живлення (<kbd>BACK</kbd> 30 с з від’єднаним USB) і повторіть спробу.
- Запустіть qFlipper від імені адміністратора.
- Скористайтеся портом USB безпосередньо на материнській платі.
- Останній варіант: прошивання через SWD за допомогою ST-Link
  (див. [Комбінації кнопок](/ua/start/key-combos#if-nothing-helps)).

## 3. Відновлення внутрішнього сховища / скидання до заводських налаштувань {#factory-reset}

Якщо оновлення зриваються через переповнене або пошкоджене внутрішнє сховище, скиньте Фліппер до заводського стану.
Це стирає **внутрішнє сховище**: налаштування, Bluetooth-парування, PIN-код, рівень дельфіна.
**Файли на картці залишаються.**

::: info Внутрішнє сховище в сучасній прошивці
У сучасній прошивці внутрішнє сховище (`/int`) **віртуальне** й лежить у прихованій папці `/ext/.int/` на картці.
Пункт **Settings → Storage → About Internal Storage** показує `Type: Virtual (/.int on SD)`.
:::

### Спершу резервна копія (необов’язково)

qFlipper → **Advanced controls** → **BACKUP** → виберіть папку → **BACKUP**. Так внутрішнє сховище збережеться
у файл `.tgz`. Картка в копію не входить, тож скопіюйте її окремо.

### Скидання на самому пристрої

1. **Main Menu → Settings → Storage → Factory Reset**.
2. Екран запитає `Confirm Factory Reset?`: *«Internal storage will be erased, data and settings will be lost!»*
3. Натисніть <kbd>→</kbd> **Erase** **5 разів**. Екран показує, скільки натискань залишилося.
4. Фліппер перезавантажиться й відформатує внутрішнє сховище.

### Скидання через qFlipper

**Advanced controls** → **ERASE** → **ERASE** → після завершення **CONTINUE**.

### Відновлення з копії

qFlipper → **Advanced controls** → **RESTORE** → виберіть файл копії `.tgz` → **RESTORE** → **CONTINUE**.

Якщо після скидання оновлення все одно зривається, зробіть скидання ще раз **без** відновлення копії або виконайте
[відновлення прошивки](#firmware-recovery).

## 4. Скидання забутого PIN-коду {#reset-pin}

Якщо Фліппер заблокований PIN-кодом, якого ви не пам’ятаєте:

1. **Від’єднайте кабель USB.**
2. Вимкніть Фліппер: утримуйте <kbd>BACK</kbd> → **Power Off**. Якщо не вдається, виконуйте наступний крок, але
   тримайте кнопки 30–40 секунд.
3. Тримайте <kbd>↑</kbd> + <kbd>BACK</kbd> близько 5 секунд. Фліппер запуститься із затиснутою <kbd>↑</kbd> і покаже
   **екран скидання PIN-коду**.
4. **Утримуйте <kbd>→</kbd>**, доки смужка прогресу не заповниться, щоб підтвердити скидання. Натисніть <kbd>↓</kbd>,
   щоб вийти без скидання.
5. Фліппер перезавантажиться.

Так скидається користувацька конфігурація (регістри RTC, внутрішнє сховище з налаштуваннями та PIN-кодом) до
заводського стану. **Користувацькі файли на картці microSD залишаються.**

## 5. Усе одно не оживає?

- Зарядіть пристрій годину й спробуйте знову.
- Від’єднайте та знову під’єднайте акумулятор (потрібно розібрати корпус).
- Прошийте пристрій через SWD за допомогою ST-Link або іншого програматора.

Якщо нічого з цього не допомогло, проблема апаратна, а не програмна.
