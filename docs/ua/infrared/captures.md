# Як надіслати свої ІЧ-записи до універсальних пультів

Якщо [універсальний пульт](/ua/infrared/universal-remotes) не працює з вашим пристроєм, ви можете записати свій
оригінальний пульт і додати його до бібліотеки, щоб він працював для всіх. Тут описано, як робити **чисті**
записи: короткі, декодовані там, де це можливо, і названі точно так, як очікує універсальний пульт.

Методика взята з посібника Unleashed від **@amec0e** (який підтримує ІЧ-ресурси Unleashed) і базується на
оригінальній документації *UniversalRemotes* від @gsurkov, @skotopes, @knrn-ai, @DrZlo13 та @ahumeniy.

## Назви кнопок у кожній бібліотеці {#button-names-per-library}

Універсальний пульт використовує лише сигнали, чиє `name:` точно відповідає одній із його кнопок (регістр має
значення). Будь-яку з них можна пропустити, якщо у вашого пристрою її немає.

| Бібліотека | Файл | Назви сигналів |
|---|---|---|
| Телевізори | `tv.ir` | `Power`, `Mute`, `Vol_up`, `Vol_dn`, `Ch_next`, `Ch_prev` |
| Аудіо | `audio.ir` | `Power`, `Mute`, `Play`, `Pause`, `Prev`, `Next`, `Vol_up`, `Vol_dn` |
| Проєктори | `projectors.ir` | `Power`, `Mute`, `Vol_up`, `Vol_dn`, `Play`, `Pause` |
| Світлодіодні стрічки | `leds.ir` | `Power_on`, `Power_off`, `Brightness_up`, `Brightness_dn`, `Red`, `Green`, `Blue`, `White` |
| Вентилятори | `fans.ir` | `Power`, `Mode`, `Speed_up`, `Speed_dn`, `Rotate`, `Timer` |
| Кондиціонери | `ac.ir` | `Off`, `Dh`, `Cool_hi`, `Cool_lo`, `Heat_hi`, `Heat_lo` |

На багатьох аудіопультах `Play` і `Pause` — та сама кнопка: запишіть її як `Play` і пропустіть `Pause`.

## Телевізори, аудіо, проєктори, вентилятори, світлодіодні стрічки

1. Спрямуйте пульт на ІЧ-приймач Flipper.
2. Запустіть `Infrared → Learn New Remote` для першої кнопки або виберіть `+` у пульті для наступних.
3. **Коротко натисніть** кнопку пульта й збережіть сигнал під відповідною назвою з таблиці вище.
4. Повторіть кроки 2-3 для всіх кнопок.
5. Перевірте кожну збережену кнопку на реальному пристрої: кожна мусить робити те, що вказано в її назві.

::: warning Не тримайте кнопку
Затиснута кнопка пульта дає довгі записи з багатьма повторами. Вони довше надсилаються й уповільнюють увесь
універсальний пульт для всіх.
:::

### Parsed проти RAW

**Parsed** — найкращий результат: протокол розпізнано, і зберігаються лише протокол, адреса та команда.

```text
name: EXAMPLE
type: parsed
protocol: NEC
address: 07 00 00 00
command: 02 00 00 00
```

Завади від інших пристроїв поряд (лампи, підсвітка телевізора, інші пульти) можуть перевести запис у **RAW**,
навіть якщо протокол відомий. Якщо для поширеного пульта ви отримали RAW, натисніть **Retry** на Flipper кілька
разів, доки не отримаєте чистий розібраний запис.

**RAW** цілком годиться, коли пульт справді використовує невідомий протокол. Намагайтеся отримати *найменшу
кількість семплів*, яка все ще працює на пристрої: коротке натискання, зазвичай **близько 100 семплів**. Ідеальний
запис одного натискання виглядає так:

```text
name: EXAMPLE
type: raw
frequency: 38000
duty_cycle: 0.330000
data: 2410 597 1189 599 592 600 1186 602 589 603 1183 606 595 597 593 598 1208 605 596 596 594 597 593 599 592 25604 2403 604 1182 606 595 597 1189 599 591 601 1185 603 618 573 617 575 1211 602 588 603 588 605 596 596 594 25605 2402 604 1192 596 594 597 1189 599 592 601 1185 628 593 598 593 600 1186 602 589 603 588 604 597 595 596
```

## Кондиціонери {#air-conditioners}

Пульти кондиціонерів працюють інакше: пульт сам тримає стан (режим, температуру, обдув, жалюзі) на своєму дисплеї
й кожне натискання надсилає **увесь стан** одразу. Тому кожна «кнопка» кондиціонера насправді є повним станом,
який потрібно записати цілком.

Для кожного сигналу **крім `Off`**:

1. Натисніть **Power** на пульті, щоб на його дисплеї кондиціонер був у стані ON.
2. Виставте режим і температуру з таблиці нижче. Усе інше (швидкість обдуву, жалюзі) за можливості залиште на
   **AUTO**.
3. Натисніть **Power** на пульті, щоб перевести його у стан OFF.
4. На Flipper запустіть запис (`Learn New Remote` для першого сигналу, `+` для решти).
5. Спрямуйте пульт на Flipper і натисніть **Power** ще раз (це і є кадр «увімкнутися в цьому режимі»).
6. Збережіть сигнал під назвою з таблиці.
7. Повторіть для кожного рядка.

| Сигнал | Режим | Температура | Примітка |
|:---:|:---:|:---:|---|
| `Dh` | Осушення | — | |
| `Cool_hi` | Охолодження | найнижча | найнижча доступна температура в режимі охолодження |
| `Cool_lo` | Охолодження | 23 °C | |
| `Heat_hi` | Нагрівання | найвища | найвища доступна температура в режимі нагрівання |
| `Heat_lo` | Нагрівання | 23 °C | |

Потім запишіть **`Off`**:

1. Переконайтеся, що на дисплеї пульта кондиціонер у стані ON.
2. Запустіть запис на Flipper і спрямуйте на нього пульт.
3. Натисніть **Power**, щоб пульт показав OFF.
4. Збережіть сигнал як `Off`.

У результаті ви отримаєте до 6 сигналів. Перевірте їх усі на реальному кондиціонері.

## Підготовка файлу та надсилання

1. Скопіюйте файл `.ir` з `/ext/infrared/` на комп'ютер через [qFlipper](/ua/mobile/qflipper) (або мобільний
   застосунок) і відкрийте його в текстовому редакторі.
2. Поставте перед своїми сигналами коментар із моделлю, щоб бібліотека залишалася впорядкованою:
   ```text
   # Model: <your brand and model>
   ```
   Порядок сигналів усередині блоку не має значення.
3. Зробіть форк [репозиторію Unleashed](https://github.com/DarkFlippers/unleashed-firmware) і **додайте** свій
   блок **у кінець** відповідного файлу в
   `applications/main/infrared/resources/infrared/assets/`.
4. Відкрийте pull request зі зміненим файлом. Після перевірки він увійде в наступну збірку для всіх.

Формат файлу описано у [Форматі ІЧ-файлів](/ua/infrared/file-format#library-files). Великі колекції готових
пультів від спільноти: [Flipper-IRDB](https://github.com/Lucaslhm/Flipper-IRDB) та офіційна
[flipperdevices/IRDB](https://github.com/flipperdevices/IRDB), яку використовує
[мобільний застосунок](/ua/infrared/mobile).
