# Запис і надсилання ІЧ-сигналів

Flipper Zero може по одній скопіювати кнопки ІЧ-пульта й зберегти їх як **віртуальний пульт** — файл `.ir` у
`/ext/infrared/`. Це зручно, коли оригінальний пульт загубився, зламався або просто лежить в іншій кімнаті, а
також коли універсальний пульт не знаходить ваш пристрій.

Сигнали [відомих протоколів](/ua/infrared/protocols) декодуються й зберігаються в компактній *розібраній* формі
(протокол + адреса + команда). Усе інше зберігається як **RAW**-тайминги, які теж нормально відтворюються.

## Запис нового пульта

1. Перейдіть до `Main Menu → Infrared → Learn New Remote`.
2. На екрані з'явиться **«Point the remote at IR port and push the button»**. Тримайте пульт за кілька
   сантиметрів від верхнього торця Flipper, у межах прямої видимості ІЧ-вікна.

   ![Learn New Remote в очікуванні сигналу: «Point the remote at IR port and push the button»](/screens/infrared/learn.png)

3. Натисніть кнопку на пульті **коротко**. Не тримайте її: затиснута кнопка дає довгий запис, повний повторів.
4. З'явиться екран запису:
   - декодований сигнал показує назву протоколу та адресу/команду, наприклад `NECext`, `A: 0x87EE`, `C: 0xA05D`;
   - невідомий сигнал показує **Unknown** і кількість семплів, наприклад `150 samples`.

   ![Екран запису: декодований протокол NEC з адресою й командою, а внизу Retry, Send і Save](/screens/infrared/learn_success.png)

5. Виберіть, що робити далі:
   - <kbd>OK</kbd> **Send**: відтворює записаний сигнал, доки кнопка натиснута, щоб перевірити його одразу;
   - <kbd>←</kbd> **Retry**: запитує *«Retry Reading? All unsaved data will be lost!»*, після чого <kbd>←</kbd>
     Exit викидає запис і слухає знову, а <kbd>→</kbd> Stay повертає назад;
   - <kbd>→</kbd> **Save**: перейти до введення назви.
6. Введіть назву кнопки в **«Name the button»** (не більше 23 символів) і підтвердьте. Типова назва генерується з
   сигналу: перші 4 літери протоколу й команда (наприклад, `NECe_A05D`) або `RAW_<samples>` для RAW.
7. З'явиться **«Success!»**, і новий пульт відкриється. Перший пульт зберігається як `/ext/infrared/Remote.ir`;
   якщо таке ім'я вже зайняте — `Remote1.ir`, `Remote2.ir` і так далі.

![Записаний сигнал на екрані](/img/remote/a62fc8f9d738534b.png)

::: tip Перейменуйте пульт
Новий пульт завжди називається `Remote`. Перейменуйте його одразу через `Edit → Rename Remote` (див. нижче),
інакше у вас накопичаться `Remote`, `Remote1`, `Remote2`…
:::

### Додавання кнопок

У списку кнопок пульта прокрутіть до кінця й виберіть **`+`**. Знову відкриється екран запису. Запишіть сигнал,
натисніть **Save**, назвіть кнопку — і ви отримаєте **«Saved»**: кнопка додається до того самого файлу.

Натискання <kbd>Back</kbd> на екрані запису запитує *«Exit to Infrared Menu?»* (або *«Exit to Remote Menu?»*, якщо
ви додаєте кнопку до наявного пульта): якщо вибрати Exit, незбережені дані буде втрачено.

## Надсилання збереженої кнопки {#send-a-saved-button}

1. Перейдіть до `Main Menu → Infrared → Saved Remotes` і виберіть файл `.ir`.
2. Спрямуйте верхній торець Flipper на пристрій.
3. Виберіть кнопку клавішами <kbd>↑</kbd> / <kbd>↓</kbd> і натисніть <kbd>OK</kbd>.

Сигнал надсилається **доки ви тримаєте** <kbd>OK</kbd>: одне натискання для окремої команди, утримання — для дій
на кшталт «натиснути й тримати», як-от плавна зміна гучності. Під час передавання блимає світлодіод.

![Надсилання збереженого сигналу](/img/remote/d20ed673954c3711.png)

::: tip Улюблене й Archive
Збережені пульти також з'являються в **Archive** (`Main Menu → Archive → Infrared`), і там їх можна додати до
улюбленого. У Flipper Mobile App вони доступні в **Archive → Infrared**, див.
[Пульти в мобільному застосунку](/ua/infrared/mobile).
:::

## Редагування пульта

Відкрийте пульт і виберіть **Edit** у самому кінці списку кнопок. У меню Edit є:

| Пункт | Що робить |
|---|---|
| **Add Button** | Записати ще одну кнопку (те саме, що `+`). |
| **Rename Button** | Вибрати кнопку й ввести нову назву. |
| **Move Button** | Екран *«Select a Button to Move»*: виберіть кнопку, натисніть <kbd>OK</kbd>, щоб «узяти» її (вона зсунеться праворуч), перемістіть клавішами <kbd>↑</kbd> / <kbd>↓</kbd> і натисніть <kbd>OK</kbd> ще раз, щоб покласти. |
| **Delete Button** | Вибрати кнопку. Підтвердження *«Delete Button?»* показує її назву й протокол / адресу / команду (або `RAW` і кількість семплів). <kbd>←</kbd> Cancel, <kbd>→</kbd> Delete. |
| **Rename Remote** | Перейменовує пульт і файл. Якщо така назва вже є, додається номер. |
| **Delete Remote** | Підтвердження *«Delete Remote?»* із кількістю кнопок. Видаляє файл `.ir`. |

Назви обмежені **23 символами** і для кнопок, і для пультів. Більші правки (злиття файлів, видалення багатьох
кнопок) простіше робити на ПК: завантажте файл через [qFlipper](/ua/mobile/qflipper) і відредагуйте його як
текст, див. [Формат ІЧ-файлів](/ua/infrared/file-format).

::: warning Файли бібліотек — не пульти
Якщо спробувати відкрити файл із `/ext/infrared/assets/` через Saved Remotes, ви отримаєте
*«Library file … can't be opened as a remote»*. Файли бібліотек (`Filetype: IR library file`) використовуються
лише [універсальними пультами](/ua/infrared/universal-remotes).
:::

## Додаткові можливості в режимі Debug {#debug-mode-extras}

З увімкненим `Settings → System → Debug` у меню Infrared з'являються ще два пункти:

- **Learn New Remote RAW**: той самий процес, що й Learn, але декодер вимкнений, і кожен сигнал зберігається як
  RAW. Корисно, коли декодер розпізнає протокол, але відтворення декодованого сигналу не працює на вашому
  пристрої.
- **Debug RX**: екран *«INFRARED monitor»*, який у реальному часі показує, що приймає приймач.

## Якщо не працює

| Проблема | Що спробувати |
|---|---|
| Нічого не відбувається під час натискання на пульті | Перевірте батарейки пульта (подивіться на його світлодіод через камеру смартфона). Підійдіть ближче й спрямуйте пульт прямо на верхній торець. Уникайте прямого сонячного світла та люмінесцентних і світлодіодних ламп поблизу. |
| Сигнал записується як **Unknown / RAW**, хоча пульт поширений | Завади можуть змусити записати RAW. Скористайтеся **Retry** кілька разів, доки не отримаєте декодований сигнал. Якщо протокол справді невідомий, RAW цілком годиться. |
| Величезні RAW-записи (сотні семплів) | Ви тримали кнопку. Натискайте коротко; для одного натискання типово близько 100 семплів. Дуже довгі записи відтворюються повільно. RAW-сигнал може містити щонайбільше 1024 тайминги. |
| Пристрій не реагує на збережену кнопку | Підійдіть ближче, спрямуйте Flipper прямо на ІЧ-вікно пристрою. Спробуйте надіслати сигнал кілька разів або потримати <kbd>OK</kbd> довше. Для великих відстаней скористайтеся [зовнішнім ІЧ-модулем](/ua/infrared/external-ir). |
| Кондиціонер реагує неправильно | Пульти кондиціонерів надсилають увесь стан (режим, температуру, обдув) у кожному натисканні. Запишіть кожний потрібний стан окремою кнопкою, див. [Як надіслати свої записи](/ua/infrared/captures#air-conditioners). |
| «Failed to load …» під час надсилання | Файл `.ir` пошкоджений або неправильно відредагований вручну. Перевірте його за [форматом файлів](/ua/infrared/file-format). |
