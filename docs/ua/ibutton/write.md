# Запис ключів iButton на заготовки

Оригінальні ключі iButton мають заводський ID, який неможливо змінити. Щоб скопіювати такий ключ, потрібна
**заготовка** — перезаписуваний ключ із програмованим ID. У Flipper Zero є два режими запису:

- **Write ID** — записує ID (ROM / код) на заготовку. Це звичний сценарій «зробити копію домофонного ключа».
- **Full Write on Same Type** — лише для DS1992, DS1996 і DS1971: копіює вміст **пам’яті** на інший справжній ключ
  того самого типу (DS1992 → DS1992). Цільовий ключ зберігає власний ID.

## Підтримувані заготовки

| Заготовка (як у Settings) | Що записує | Примітки |
|---|---|---|
| **RW1990.1** | ID DS1990, DS1420 | Заготовки типу RW1990; цей варіант записує біти інвертовано |
| **RW1990.2** | ID DS1990, DS1420 | Заготовки типу RW1990, неінвертований варіант |
| **TM2004** | ID DS1990, DS1420, DS1992, DS1996, DS1971 та універсального 1-Wire | Заготовки RW2004/TM2004; записується лише ID, хоча заготовка має пам’ять |
| **TM01x** | ID DS1990, **Cyfral**, **Metakom** | Заготовки TM01/TM01x |

Заготовки, які продають як RW1990, TM1990 або TM08v2, обслуговують варіанти RW1990; Flipper пробує обидва, тож знати
заздалегідь, яка саме заготовка у вас, не потрібно.

::: tip Unleashed
- У **Settings → Write Blanks** можна вмикати та вимикати типи заготовок (типово увімкнені всі).
- На екрані запису видно, яка заготовка пробується, а на екрані успіху пишеться, наприклад, *Written to TM2004!*
- **Cyfral і Metakom** можна записувати на заготовки **TM01x**.
:::

::: warning TM01x для Cyfral / Metakom — незворотно
Для Cyfral і Metakom заготовку TM01x записують, зчитують назад для порівняння, а потім **фіналізують** у режим Cyfral
або Metakom. Фіналізацію неможливо скасувати: заготовка більше не відповідає як пристрій 1-Wire і її не можна
перезаписати — навіть як ключ Dallas. Якщо перевірка не пройшла, заготовка не фіналізується й залишається доступною
для запису. ID Dallas, записаний на TM01x, не фіналізується.

Ключі Metakom із хибною парністю записувати не можна (*Refusing to write a key with odd parity*).
:::

## Write ID

1. Відкрийте ключ: `Saved` → ключ → **Write ID** (або **More → Write ID** після читання).

   ![Меню збереженого ключа: Emulate, Write ID, Edit і Rename](/screens/ibutton/saved_menu.png)

2. На екрані з’явиться **Writing ID**, `[Protocol]`, назва ключа (або *Unsaved Key*), а в дужках — тип заготовки, який
   пробується зараз, наприклад `(RW1990.1)`.

   ![Екран Writing ID: протокол [DS1990], назва ключа і заготовка, яка пробується, (RW1990.1)](/screens/ibutton/write.png)

3. Прикладіть заготовку до **плоскої частини** майданчика (лівий пін даних + середня земля), як і під час читання.
   Тримайте нерухомо.
4. Flipper пробує кожну ввімкнену заготовку, яка підтримує цей протокол, і зчитує результат назад.
5. **Written to RW1990.2!** (або *Successfully written!*) — готово.

## Full Write on Same Type

1. `Saved` → ключ DS1992 / DS1996 / DS1971 → **Full Write on Same Type**.
2. На екрані — **Full Writing**. Прикладіть справжній ключ **того самого** типу.
3. Пам’ять буде записано; власний ID цільового ключа залишиться. Цей режим не використовує налаштування Write Blanks.

## Settings → Write Blanks

`Main Menu → iButton → Settings → Write Blanks` містить пункти **RW1990.1**, **RW1990.2**, **TM2004**, **TM01x** зі
значеннями **ON**/**OFF**. Перемикайте їх кнопками <kbd>OK</kbd>/<kbd>←</kbd>/<kbd>→</kbd>; під час виходу
налаштування зберігається у файл `/ext/ibutton/.ibutton.settings`. Команда CLI `ikey write` використовує те саме
налаштування.

Якщо сторінка повідомляє *Settings page missing. Update the SD resources*, перевстановіть прошивку зі вставленою
карткою microSD.

## Помилки

| Екран | Що означає |
|---|---|
| **Cannot Write** — *No blanks enabled. Enable one in Settings* | Усі типи заготовок вимкнені |
| **Cannot Write** — *No enabled blank can write this key* | Наприклад, для ключа Metakom увімкнено лише RW1990 |
| **Cannot Write** — *This key cannot be written* (або причина від протоколу) | Дані ключа непридатні для запису |
| Екран запису не змінюється, блимає світлодіод | Заготовку ще не виявлено — перевірте контакт або тип заготовки не підтримується |

## Усунення проблем

- **Контакт.** Центр заготовки має торкатися піна даних, а її обідок — піна землі.
- **Невідомий тип заготовки.** Спробуйте ввімкнути всі типи. Деякі дешеві заготовки належать до типів, які Flipper не
  вміє програмувати.
- **Запис «успішний», але зчитувач не приймає копію.** Деякі зчитувачі відфільтровують заготовки (перевіряють
  поведінку, характерну для перезаписуваних ключів) — тут Flipper нічим не допоможе.
- **Витрачена TM01x.** Заготовку TM01x, фіналізовану як Cyfral/Metakom, повторно використати не вдасться.
