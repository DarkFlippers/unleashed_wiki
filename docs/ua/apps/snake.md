# Snake

Класична гра «Змійка» з офіційної прошивки, яку Unleashed постачає як системний застосунок.

`Main Menu → Apps → Games → Snake Game`

![Snake на початку гри: змійка в лівій частині поля, фрукт посередині](/screens/apps/snake.png)

## Як грати

1. Запустіть гру. Змійка рухається сама.
2. Керуйте кнопками <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd>. Їжте фрукти, щоб рости; кожен фрукт додає очок.
3. Не вріжтеся у стіну чи у власний хвіст. Чим довша змійка, тим швидше вона рухається.
4. На екрані `Game Over` показано ваш результат (`Score`). Натисніть <kbd>OK</kbd>, щоб почати нову гру.
5. <kbd>Back</kbd> виходить із гри будь-коли.

::: tip Unleashed
Більше ігор є в [наборах застосунків](/ua/apps/catalog#base-and-extra-packs), а Dummy Mode на робочому столі має
власні мініігри: натисніть або утримуйте будь-яку кнопку-стрілку (див. [Робочий стіл](/ua/start/desktop)).
:::
