# Clock

Годинник біля ліжка: великі цифри часу, дата й рівень заряду акумулятора, керування яскравістю екрана з червоним
світлодіодним нічником, секундомір і щоденний будильник. Створений на основі FlipperNightStand від @nymda, разом із
@Willy-JL, @mishamyte та @xMasterX (версія застосунку 1.3).

`Main Menu → Clock`

![Clock: дата над великим часом і рівень заряду акумулятора під ним](/screens/apps/clock.png)

::: tip Unleashed
В Unleashed Clock — це застосунок із головного меню, що має будильник і нічник. Якщо потрібен лише час на робочому
столі, замість цього увімкніть `Settings → Desktop → Show Clock`.
:::

## Кнопки на екрані годинника

| Кнопка | Дія |
|---|---|
| <kbd>↑</kbd> / <kbd>↓</kbd> | яскравість екрана більше / менше (смужка з’являється і зникає через 3 с після останнього натискання) |
| <kbd>↓</kbd> за яскравості 0 | увімкнути / вимкнути тусклий червоний світлодіодний нічник |
| <kbd>OK</kbd> | секундомір Start / Stop |
| <kbd>←</kbd> | скинути секундомір |
| <kbd>→</kbd> | налаштування будильника |
| <kbd>Back</kbd> | вихід |

Час показується у системному форматі: 12-годинному з AM/PM або 24-годинному — залежно від
`Settings → System → Time Format`.

## Секундомір

1. Натисніть <kbd>OK</kbd>, щоб запустити; час відлічується у вигляді `MM:SS`.
2. Натисніть <kbd>OK</kbd> ще раз, щоб зупинити, і ще раз — щоб продовжити.
3. Натисніть <kbd>←</kbd> (**Reset**), щоб скинути показання.

## Щоденний будильник

1. На екрані годинника натисніть <kbd>→</kbd>.
2. Переведіть **Alarm** у стан **ON** кнопками <kbd>←</kbd> / <kbd>→</kbd>.
3. Оберіть **Set time** і натисніть <kbd>OK</kbd>.
4. У полі вибору `Alarm time`: <kbd>←</kbd> / <kbd>→</kbd> перемикають години, хвилини (і AM/PM у 12-годинному
   режимі), <kbd>↑</kbd> / <kbd>↓</kbd> змінюють значення (утримуйте для швидкої зміни). <kbd>OK</kbd> або
   <kbd>Back</kbd> зберігає.
5. Натисніть <kbd>Back</kbd>, щоб повернутися до годинника. Час будильника видно на екрані годинника.

Коли будильник спрацьовує, на екрані блимає `! ALARM !` з написом `Press any key to stop`, грає мелодія разом із
вібрацією та червоним світлодіодом. Натисніть будь-яку кнопку, щоб зупинити. Будильник залишається увімкненим і
спрацює наступного дня в той самий час.

::: warning
Будильник дзвенить лише доки відкритий застосунок Clock. Залиште Flipper на ніч на зарядці із запущеним Clock.
:::

Будильник і рівень яскравості зберігаються у `/ext/apps_data/clock/` і відновлюються наступного разу, коли ви
відкриєте застосунок.
