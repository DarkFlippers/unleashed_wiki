# Archive (файловий менеджер)

**Archive** — це файловий менеджер Flipper. Він показує збережені ключі, карти, пульти та скрипти, дозволяє одразу
їх запускати й виконує базові дії з файлами: закріплення в улюблених, перейменування, копіювання, переміщення,
створення папок і видалення.

**Як відкрити:** на робочому столі натисніть <kbd>↓</kbd>.

![Archive на вкладці Sub-GHz: папка Garage і збережені сигнали .sub, вибрано Barrier](/screens/apps/archive.png)

## Вкладки

Натискайте <kbd>←</kbd> / <kbd>→</kbd>, щоб перемикати вкладки. Кожна вкладка показує одну папку з фільтром за типом
файлів:

| Вкладка | Папка | Які файли показує |
|---|---|---|
| Favorites | ваші закріплені файли | усе, що ви закріпили (`/ext/favorites.txt`) |
| Sub-GHz | `/ext/subghz` | `.sub` |
| SubRem | `/ext/subghz_remote` | `.txt` (карти [Sub-GHz Remote](/ua/subghz/remote)) |
| RFID LF | `/ext/lfrfid` | `.rfid` і дампи T5577 |
| NFC | `/ext/nfc` | `.nfc` |
| Infrared | `/ext/infrared` | `.ir` |
| iButton | `/ext/ibutton` | `.ibtn` |
| Bad USB | `/ext/badusb` | `.txt` |
| Phone | `/ext/phonebook` | `.phone` (телефонна книга [SIM800](/ua/gpio/sim800)) |
| U2F | внутрішня пам’ять | запис застосунку U2F |
| Apps | `/ext/apps` | `.fap` і `.js` |
| Internal | внутрішня флеш-пам’ять | усе (лише з увімкненим режимом Debug) |
| Browser | уся SD-карта | усе |

Archive відкривається на вкладці **Favorites**.

::: tip Unleashed
Unleashed додає вкладку **SubRem** для карт Sub-GHz Remote і вкладку **Phone** для телефонної книги SIM800 (запис
`.phone` відкривається прямо в застосунку SIM800), показує дампи T5577 поряд із ключами в **RFID LF** і виводить
скрипти `.js` у **Apps**.
:::

## Кнопки у списку

| Кнопка | Дія |
|---|---|
| <kbd>↑</kbd> / <kbd>↓</kbd> | рух по списку (утримуйте для швидкого прокручування) |
| <kbd>←</kbd> / <kbd>→</kbd> | попередня / наступна вкладка |
| <kbd>OK</kbd> на файлі | відкрити його меню |
| <kbd>OK</kbd> на папці | увійти до папки |
| утримувати <kbd>OK</kbd> на папці | відкрити меню папки |
| <kbd>OK</kbd> у Favorites | одразу запустити файл |
| утримувати <kbd>OK</kbd> у Favorites | відкрити меню |
| утримувати <kbd>OK</kbd> у порожній папці | відкрити меню (Paste / NewDir) |
| <kbd>Back</kbd> | на папку вище або вихід |

## Меню файлу: Actions і Manage

Меню має дві сторінки. У його заголовку видно, яка з них відкрита: **Actions** чи **Manage**. Натисніть <kbd>←</kbd>
або <kbd>→</kbd> всередині меню, щоб перемикатися між ними (не працює на вкладці Favorites). <kbd>↑</kbd> /
<kbd>↓</kbd> вибирають пункт, <kbd>OK</kbd> виконує його, <kbd>Back</kbd> закриває меню.

**Actions** (для файлу, який прошивка вміє відкривати):

- **Run**: відкрити файл у його застосунку (емулювати ключ, надіслати сигнал, запустити скрипт…).
- **Pin** / **Unpin**: додати до Favorites або прибрати звідти.
- **Info**: назва й розмір файлу.
- **Show**: подивитися файл як текст (для текстових форматів).

Для невідомого типу файлу Actions пропонує лише **Info**, а для текстових файлів — ще й **Show**.

**Manage:**

- **Cut** / **Copy**, а потім **Paste** у цільовій папці.
- **NewDir**: створити папку.
- **Rename**: ввести нову назву.
- **Delete**: спершу запитує підтвердження.

На вкладці **Favorites** меню складається з **Run**, **Unpin**, **Show** (якщо доступно) та **Move**. Move дозволяє
змінити порядок улюблених: натискайте <kbd>↑</kbd> / <kbd>↓</kbd>, щоб зсунути пункт, і <kbd>OK</kbd>, щоб зберегти
нову позицію (<kbd>Back</kbd> скасовує).

## Типові задачі

### Закріпити файл у Favorites

1. Робочий стіл → <kbd>↓</kbd>, щоб відкрити Archive.
2. Перейдіть на потрібну вкладку кнопками <kbd>←</kbd> / <kbd>→</kbd> й виберіть файл.
3. Натисніть <kbd>OK</kbd> → **Pin**. Тепер файл є на вкладці Favorites.

### Перейменувати збережений ключ або сигнал

1. Виберіть файл і натисніть <kbd>OK</kbd>.
2. Натисніть <kbd>→</kbd>, щоб перемкнути меню на **Manage**.
3. Виберіть **Rename**, введіть назву, підтвердьте.

### Видалити файли, щоб звільнити місце

1. Виберіть файл, <kbd>OK</kbd>, <kbd>→</kbd> до **Manage**.
2. Виберіть **Delete** і підтвердьте.

Щоб очистити цілу папку, скористайтеся вкладкою **Browser**: виберіть папку, утримуйте <kbd>OK</kbd>,
**Manage → Delete**.

### Перемістити файл в іншу папку

1. Виберіть файл, <kbd>OK</kbd>, **Manage → Cut**.
2. Перейдіть до цільової папки (вкладка **Browser** дає доступ до будь-якої папки на картці).
3. Натисніть <kbd>OK</kbd> на будь-якому файлі (або утримуйте <kbd>OK</kbd> у порожній папці) → **Paste**.

## Усунення проблем

- **«Empty»** означає, що в папці немає файлів того типу, який показує ця вкладка. Перевірте розширення файлу: файл
  `.ir` у `/ext/nfc` не з’явиться ні на одній з цих вкладок, але його покаже вкладка Browser.
- **Немає вкладки Internal**: вона видима лише коли `Settings → System → Debug` увімкнено (ON).
- **Зник закріплений файл**: записи, чий файл більше не існує (переміщений, перейменований або видалений поза
  Archive), прибираються зі списку. Закріпіть файл знову на новому місці.
- **Delete** завжди запитує `Delete <name>?` з кнопками **Cancel** / **Delete**, тому ніщо не видаляється одним
  випадковим натисканням.
