# Усунення проблем із застосунками

Коли застосунок не може запуститися, Flipper показує `Error: <name>` з короткою підказкою та посиланням
`r.flipper.net/err_0X`. Ця сторінка розбирає кожне повідомлення в тому вигляді, в якому воно з’являється в Unleashed.

::: tip Unleashed
Unleashed не блокує застосунки, зібрані під іншу версію API. Замість стокових помилок **Outdated App** /
**Outdated Firmware** він показує попередження й дає вам вирішити самим, див.
[App Too Old / App Too New](#app-too-old-app-too-new).
:::

## App Too Old / App Too New

```
App Too Old
APP:86 < FW:88
This app might not work
Continue anyways?
```

**Мажорна версія API** застосунку відрізняється від версії прошивки: **App Too Old** означає, що застосунок зібрано
під старіший API, **App Too New** — під новіший.

- Натисніть **Continue** (<kbd>→</kbd>), щоб усе одно спробувати. Багато застосунків працюють, але той, що викликає
  змінену функцію, може впасти.
- Натисніть <kbd>Back</kbd>, щоб скасувати.
- Справжнє рішення: оновити застосунок (узяти його з поточного набору Unleashed або перезібрати під актуальний SDK)
  або, у випадку **App Too New**, оновити прошивку.

## Error: App Not Found (err_01)

`Update firmware or app`

| Причина | Що робити |
|---|---|
| файл застосунку видалено з SD-карти | перевстановіть застосунок або перевстановіть прошивку (для системних застосунків) |
| старий чи бета-версія мобільного застосунку відкрила застосунок з каталогу, якого немає на картці | встановіть офіційний мобільний застосунок Flipper з App Store / Google Play і перевстановіть застосунок |

Схоже повідомлення **SD card needed** / `Install SD card to run this app` означає, що застосунок із меню лежить на
SD-карті, а картку не вставлено. **Update needed** / `Update firmware to run this app` означає, що картка на місці,
але файлу застосунку немає: перевстановіть прошивку зі вставленою карткою.

## Error: Invalid File (err_02)

`Update the app`. Файл `.fap` пошкоджений: зіпсований заголовок ELF, неповний файл (копіювання перервалося) або
секції, які не вдається завантажити. Скопіюйте чи встановіть застосунок знову.

## Error: Invalid Manifest (err_03)

`Update firmware or app`. Не вдається прочитати маніфест (спеціальну секцію ELF з версією API та інформацією про
застосунок). Файл пошкоджений або застосунок і прошивка занадто далеко розійшлися. Оновіть застосунок; якщо він
новіший за вашу прошивку — оновіть прошивку.

## Error: Missing Imports (err_04)

`Update firmware or app`. Застосунок викликає функції, яких ваша прошивка не експортує.

| Причина | Що робити |
|---|---|
| застосунок зібрано під новішу прошивку | оновіть Unleashed |
| застосунок зібрано під інший форк (він використовує власні функції того форка) | знайдіть збірку застосунку для Unleashed або перезберіть його з SDK Unleashed |

## Error: HW Target Mismatch (err_05)

`App not supported`. Застосунок зібрано під іншу апаратну платформу Flipper. На цьому пристрої він працювати не може.

## Error: Out of Memory

`Not enough RAM to run the app. Please reboot the device`. FAP завантажується в оперативну пам’ять; якщо купа
фрагментована або запущено надто багато (наприклад, фоновий BLE-маячок чи великий застосунок), він не вміщується.
Натисніть **Reboot** і запустіть застосунок одразу після завантаження.

## Усе одно не працює

1. Оновіться до останнього релізу Unleashed, див. [Оновлення](/ua/start/updating).
2. Перевстановіть застосунок із поточного [набору застосунків](/ua/apps/catalog#base-and-extra-packs) або з каталогу
   ([Застосунки на SD-карті](/ua/apps/sd-card-apps)).
3. Якщо застосунок підвішує Flipper, перезавантажте його комбінацією <kbd>←</kbd> + <kbd>Back</kbd>; якщо пристрій
   більше не вмикається, див. [Відновлення](/ua/start/recovery).
4. Спитайте в чатах спільноти, див. [FAQ](/ua/start/faq).
