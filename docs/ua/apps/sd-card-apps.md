# Застосунки на SD-карті (.fap)

Майже кожен застосунок, який ви запускаєте з `Main Menu → Apps`, — це **FAP** (Flipper App Package): виконуваний
файл `.elf` із додатковими метаданими (назва, піктограма, категорія, потрібна версія API) і необов’язковими
вбудованими ресурсами. FAP лежать на картці microSD, тому **застосункам потрібна SD-карта**, щоб запускатися.

## Де лежать застосунки

| Шлях | Що там |
|---|---|
| `/ext/apps/<Category>/*.fap` | встановлені застосунки, по папці на категорію (`Sub-GHz`, `NFC`, `RFID`, `GPIO`, `USB`, `Bluetooth`, `Games`, `Tools`, …) |
| `/ext/apps_data/<appid>/` | дані й налаштування, які кожен застосунок зберігає для себе |
| `/ext/apps_data/loader/plugins/` | плагіни завантажувача, наприклад [стилі головного меню](/ua/apps/menu-styles) |

`Main Menu → Apps` просто показує папки з `/ext/apps`. Вкладка **Apps** в [Archive](/ua/apps/archive) показує ту саму
папку, а ще й скрипти `.js`.

## Як Flipper запускає FAP

MCU не може виконувати код безпосередньо із зовнішнього сховища. Коли ви запускаєте застосунок, **App Loader**:

1. читає FAP із SD-карти й перевіряє його цілісність і маніфест;
2. перевіряє, що **мажорна версія API** застосунку відповідає мажорній версії API прошивки;
3. копіює секції коду й даних в оперативну пам’ять і виправляє адреси під нове розташування (релокація);
4. розв’язує кожну функцію, яку імпортує застосунок, через **таблицю символів** прошивки;
5. запускає застосунок.

Оскільки застосунок працює з оперативної пам’яті, великий застосунок залишає менше купи для всього іншого.
Завантажуються лише код і дані, тому використана пам’ять менша за розмір самого файлу `.fap`.

::: tip Unleashed
Unleashed зберігає офіційний API (поточну версію API друкують на початку кожного changelog, наприклад
`Current API: 88.27`), тому більшість застосунків з офіційного каталогу працюють як є. Якщо мажорна версія API
відрізняється, Unleashed не відмовляє навідріз: він показує **App Too Old** або **App Too New** з обома версіями
(наприклад, `APP:86 < FW:88`) і кнопкою **Continue**, тож ви все одно можете спробувати запустити. Див.
[Усунення проблем із застосунками](/ua/apps/troubleshoot).
:::

## Встановлення застосунків

### З наборів застосунків

Найпростіший спосіб — вибрати збірку прошивки, яка вже містить набір (типова або збірка `e`), див.
[Застосунки у складі Unleashed](/ua/apps/catalog).

Обидва набори лежать у репозиторії [xMasterX/all-the-plugins](https://github.com/xMasterX/all-the-plugins). Щоб додати набір вручну:

1. Завантажте `.zip` зі [сторінки релізів](https://github.com/xMasterX/all-the-plugins/releases/latest).
2. Розпакуйте архів.
3. Скопіюйте теки застосунків до теки `apps` на SD-карті (`/ext/apps/`), зберігаючи їхні папки-категорії.
4. Перевірте, що версія API набору збігається з версією прошивки (`Current API:` на початку changelog).

### З офіційного каталогу {#installing-from-the-official-catalog}

Офіційний каталог застосунків є у [Flipper Lab](https://lab.flipper.net/apps) (Chrome, Edge та інші браузери на
Chromium із підтримкою Web Serial) і на вкладці **Apps** у [мобільному застосунку Flipper](/ua/mobile/mobile-app).

1. Закрийте qFlipper і будь-яку іншу вкладку Flipper Lab (послідовний USB-порт може тримати лише одна програма).
2. Під’єднайте Flipper через USB (Flipper Lab) або Bluetooth (мобільний застосунок).
3. Відкрийте **Apps**, знайдіть застосунок за категорією або через пошук.
4. Натисніть **Install** на картці застосунку чи на його сторінці й дочекайтеся, поки він завантажиться.
5. На Flipper відкрийте `Main Menu → Apps → <категорія> → <застосунок>`.

Щоб оновити або видалити застосунки з каталогу, відкрийте **Apps → Installed** і натисніть **Update** або
піктограму видалення (кошик).

Якщо встановлення не вдається: перевірте з’єднання, звільніть місце на SD-карті (видаліть файли в
[Archive](/ua/apps/archive)) і переконайтеся, що прошивка актуальна.

### Вручну (будь-який `.fap`)

1. Завантажте `.fap`, зібраний під вашу прошивку (збірку для Unleashed або для OFW з відповідною версією API).
2. Скопіюйте його до `/ext/apps/<Category>/` через [qFlipper](/ua/mobile/qflipper), файловий менеджер мобільного
   застосунку або картрідер.
3. Запустіть його з `Main Menu → Apps` або відкрийте файл в [Archive](/ua/apps/archive) й виберіть **Run**.

::: warning
Застосунки, зібрані під інший форк прошивки, можуть імпортувати функції, яких Unleashed не експортує, і тоді впадуть
з **Missing Imports**. Беріть застосунки з наборів Unleashed або перезбирайте їх із SDK Unleashed.
:::

## Збірка власного FAP

FAP розробляються так само, як вбудовані застосунки. Коротко:

1. Покладіть папку свого застосунку в `applications_user/` у клоні прошивки.
2. У його `application.fam` вкажіть `apptype=FlipperAppType.EXTERNAL` (див.
   [Маніфести застосунків](/ua/dev/app-manifests)).
3. Зберіть одним із варіантів:

```bash
./fbt fap_{APPID}                                     # build one app
./fbt launch APPSRC=applications_user/path/to/app     # build, upload over USB and run
./fbt build APPSRC=applications_user/path/to/app      # build without uploading
./fbt faps                                            # build all FAPs (or ./fbt fap_dist)
```

У типовому профілі VS Code `launch` — це дія **Launch App on Flipper**
(<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd>).

**Ресурси.** Покладіть зображення у підпапку застосунку й вкажіть її у `fap_icon_assets`; далі напишіть
`#include "{APPID}_icons.h"` і користуйтеся ними так само, як піктограмами з `assets_icons.h`.

**Версіонування API.** Не кожна функція прошивки доступна застосункам: перелік експортованих лежить у
`api_symbols.csv` апаратної платформи. Мажорна версія зростає на зворотно несумісних змінах (видалено функцію чи
змінну, змінено сигнатуру), мінорна — на доповненнях. `fbt` керує цим автоматично: нові символи з’являються з `?`,
і кожен потрібно позначити `+` (експортований) або `-` (прихований), перш ніж прошивка збереться.

**Налагодження.** `fbt` завантажує `debug/flipperapps.py` у gdb, тож FAP можна налагоджувати так само, як код
прошивки. Зберіть і прошийте прошивку (`./fbt`, `./fbt flash`), запустіть свій FAP, а потім під’єднайтеся через
`./fbt debug`. Прошивка спиняється на точці зупинки одразу після завантаження FAP, тож у ньому можна ставити власні
точки зупинки. Тип збірки прошивки й застосунку (debug/release) має збігатися, а відповідна збірка — бути
злінкованою як `build/latest`.

[Першому застосунку на C](/ua/dev/first-app-c).
