# Remote Analyzer

**Remote Analyzer** (від @xMasterX) декодує по одному пульту за раз на внутрішньому CC1101 і показує всі поля, які здатен визначити. На відміну від `Sub-GHz → Read`, він **не веде історії** — на екрані лише останній сигнал — і **ніколи не зберігає** файл `.sub`. Це інструмент для відповіді на питання «що це за пульт?».

::: tip Unleashed
Remote Analyzer — вбудований системний застосунок Unleashed. Крім усіх протоколів, які знає застосунок Sub-GHz, він має власні протоколи лише для декодування: **Crypt**, **Crypt Lite**, **Hormann BiSecur**, **KCE6xxx**, **Life Fido**, **Nero Intro II** і **PC4**.
:::

**Коли це знадобиться:** швидко впізнати невідомий пульт, побачити, фіксований у нього код чи динамічний, або перевірити пульт, який основний застосунок декодувати не може. Щоб записати сигнал і відтворити його, користуйтеся [Read](/ua/subghz/read) або [Read RAW](/ua/subghz/read-raw).

## Головне меню

`Main Menu → Apps → Sub-GHz → Remote Analyzer`:

- `Read` — декодування в реальному часі
- `Decode RAW File` — пропустити збережений RAW-запис через ті самі декодери
- `Frequency Analyzer` — знайти частоту пульта
- `How to use` — вбудована інструкція

## Зчитування пульта

1. Відкрийте `Read`. На екрані буде `Waiting for a signal`.
2. Натисніть <kbd>←</kbd> (`Config`) і задайте **Frequency** та **Modulation** (або увімкніть **Hopping**).
3. Піднесіть пульт близько до Flipper і натисніть його кнопку.
4. З'явиться результат:
   - піктограма зліва вгорі показує, код **fixed** (фіксований) чи **rolling** (динамічний);
   - рядок під назвою протоколу й кількістю бітів вказує, чи знає цей протокол також застосунок Sub-GHz, чи він **analyzer only**;
   - `xN` праворуч угорі показує, скільки разів цей код було отримано;
   - смужка під рядком — рівень сигналу.
5. <kbd>↑</kbd> / <kbd>↓</kbd> прокручують результат, який не вмістився, <kbd>→</kbd> (`Reset`) очищає його.

**Світлодіод:** фіолетовий — слухає; жовтий — в ефірі щось є, але нічого не декодувалося; зелений — код пройшов.

## Config

| Пункт | Що робить |
|---|---|
| Frequency | частота приймання (ігнорується, поки увімкнений Hopping) |
| Modulation | пресет: AM270, AM650, FM238, FM476, FM12K і будь-які користувацькі пресети |
| Hopping | `OFF` або рівень від `-90dB` до `-40dB` |
| Sound | відтворювати демодульований сигнал через динамік |
| Mod. sweep | пробувати інші модуляції, коли нічого не декодується |
| Notify | один вібровідгук на код, що відрізняється від попереднього |
| Reset to default | повернути типові значення |

**Hopping.** Якщо рівень заданий, застосунок обходить частоти **315, 390, 430,5, 433,92, 434,42 і 868,35 МГц**, поки в ефірі тихо, і зупиняється на першому діапазоні, де носійна досягає цього рівня. Успішне декодування тримає діапазон дві секунди, після чого обхід продовжується. Вибір частоти у Frequency Analyzer вимикає hopping. Цей самий рівень визначає, що sweep і світлодіод вважають «сигналом», тому він має значення навіть із hopping у стані `OFF`.

**Mod. sweep.** Коли пульт явно передає, але нічого не декодується, застосунок обходить інші модуляції, приблизно по секунді кожну. Знак `~` біля модуляції означає, що спроби тривають, — **тримайте кнопку пульта натиснутою**. Перше успішне декодування фіксує модуляцію, і `~` зникає; якщо дві секунди нічого не декодується, обхід починається знову з цього місця. `Unknown remote` означає, що цілий круг нічого не дав; поки кнопку тримають, він іде по колу знову.

**Notify.** Затиснутий пульт повторює один код, тому це лише блимає світлодіодом; новий, інший код ще й подає вібровідгук.

## Decode RAW File

1. Виберіть `Decode RAW File` і вкажіть RAW-файл `.sub` із `/ext/subghz`.
2. Смужка прогресу показує, як далеко пройдено файл.
3. Кожний знайдений окремий код потрапляє до переліку; натисніть <kbd>OK</kbd> на ньому, щоб побачити повний результат.

Семпли містить лише RAW-запис — збережений файл ключа відкидається. Якщо нічого не декодувалося (або файл відкинуто), звучить помилка, а світлодіод залишається червоним.

## Frequency Analyzer

Утримуйте кнопку пульта біля Flipper, а потім **утримуйте** <kbd>OK</kbd>, щоб перенести знайдену частоту в `Read`. <kbd>←</kbd> / <kbd>→</kbd> змінюють рівень спрацьовування. Працює так само, як [аналізатор в основному застосунку](/ua/subghz/frequency-analyzer).

## Усунення проблем

- **Постійно `Waiting for a signal`** — хибна частота; запустіть Frequency Analyzer або увімкніть Hopping.
- **Жовтий світлодіод, але декодування немає** — увімкніть `Mod. sweep` і тримайте кнопку, або запишіть сигнал через [Read RAW](/ua/subghz/read-raw) і спробуйте `Decode RAW File`.
- **Протокол лише для аналізатора** — основний застосунок Sub-GHz не може ні зберегти, ні надіслати його; Remote Analyzer тільки впізнає його.
- **Хочете зберегти сигнал** — скористайтеся [Read](/ua/subghz/read); цей застосунок файлів не пише.
