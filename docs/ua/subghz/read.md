# Read (зчитування)

**Read** слухає одну частоту (або перебирає кілька), **декодує** сигнали відомих протоколів і виводить їх списком.
Декодований сигнал можна зберегти у файл-ключ і надіслати знову. Це основний спосіб скопіювати пульт зі
**статичним (фіксованим) кодом** — ворота, шлагбауми, дзвінки, розетки — і з'ясувати, який протокол використовує пульт.

Якщо Read не розпізнає пульт, скористайтеся [Read RAW](/ua/subghz/read-raw). Для пультів із динамічним кодом
**перед будь-яким надсиланням** прочитайте [Динамічні коди](/ua/subghz/rolling-codes).

::: tip Unleashed
Порівняно зі стоковою прошивкою Unleashed додає: десятки додаткових протоколів
([повний список](/ua/subghz/supported-systems)), збереження та надсилання багатьох протоколів із **динамічним кодом**,
**кастомні кнопки** на стрілках під час надсилання, хопінг із порогом RSSI, фільтри `Ignore …`,
`Delete old signals when memory is full`, **утримання <kbd>→</kbd> видаляє** сигнал зі списку, час приймання біля
кожного сигналу та запам'ятовування останніх налаштувань.
:::

## Як зчитати пульт

1. Якщо частота невідома, спочатку визначте її: [Frequency Analyzer](/ua/subghz/frequency-analyzer)
   (довге натискання <kbd>OK</kbd> там одразу відкриває Read на знайденій частоті).
2. Відкрийте `Main Menu → Sub-GHz → Read`. На екрані з'явиться `Fixed scan...` (або `Hopper scan...` з увімкненим
   хопінгом), а внизу — поточна частота й модуляція.

   ![Екран Read в очікуванні сигналу: Fixed scan на 433.92 МГц, AM650](/screens/subghz/read.png)

3. Піднесіть пульт до лівого боку Flipper і натисніть його кнопку на 1–2 секунди.
4. Декодований сигнал з'явиться у списку як `назва протоколу` + час приймання. Лічильник унизу показує, скільки
   сигналів у списку.

   ![Список Read із трьома прийнятими сигналами: Princeton, CAME 12bit і KL: DoorHan](/screens/subghz/read_list.png)

5. Виберіть його клавішами <kbd>↑</kbd> <kbd>↓</kbd> і натисніть <kbd>OK</kbd>, щоб побачити подробиці (ключ,
   кількість біт, серійник, кнопку, лічильник, виробника для KeeLoq тощо).

   ![Подробиці сигналу: Princeton 24bit із ключем, серійником і кнопкою, кнопки Send і Save](/screens/subghz/signal_info.png)

6. Натисніть <kbd>→</kbd> **Save**, введіть назву та підтвердьте. Файл потрапить до `/ext/subghz/`.
7. Або натисніть <kbd>OK</kbd> **Send**, щоб передати сигнал одразу.

Збережені сигнали лежать у `Main Menu → Sub-GHz → Saved` (див. [нижче](#saved-signals)).

## Кнопки на екрані Read

| Кнопка | Дія |
|---|---|
| <kbd>←</kbd> | **Config** — налаштування приймача |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Переміщення у списку прийнятих сигналів |
| <kbd>OK</kbd> | Відкрити вибраний сигнал |
| утримання <kbd>→</kbd> | Видалити вибраний сигнал зі списку |
| <kbd>Back</kbd> | Вийти з Read. Якщо є незбережені сигнали, з'явиться **Exit to Sub-GHz Menu?** — `Exit` / `Stay` |

Залежно від розміру переданих даних у списку може поміститися до 128 прийнятих сигналів.

## Config {#config}

Натисніть <kbd>←</kbd> **Config** на екрані Read:

![Меню Read Config: Frequency, Modulation, Hopping і Bin RAW](/screens/subghz/read_config.png)

| Пункт | Значення | Що робить |
|---|---|---|
| `Frequency` | список зі сторінки [Частоти](/ua/subghz/frequencies) | Фіксована частота приймання. Поки увімкнено хопінг, показує ` -----` |
| `Modulation` | `AM270`, `AM650`, `FM238`, `FM476`, `FM12K` + користувацькі пресети | Пресет демодуляції. `AM650` підходить для більшості пультів |
| `Hopping` / `Hopping RSSI` | `OFF`, `-90dBm` … `-40dBm` | Перебирає список хопінгу (315, 390, 430.5, 433.92, 434.42, 868.35 МГц). Значення — це рівень RSSI, за якого перебір зупиняється на частоті |
| `Bin RAW` | `OFF` / `ON` | Додатково збирає невідомі статичні сигнали як **BinRAW** (повторюваний шаблон із відновленим бітрейтом). Тримайте кнопку пульта трохи довше, щоб накопичилося достатньо даних |
| `Ignore ReversRB2` | `OFF` / `ON` | Ховає сигнали Revers RB-2(M) |
| `Ignore Alarms` | `OFF` / `ON` | Ховає протоколи вело- й мотосигналізацій (Hollarm, GangQi) |
| `Ignore Sensors` | `OFF` / `ON` | Ховає датчики та подібний радіошум: Magellan, Honeywell, Honeywell WDB і дзвінки Legrand, Doorbell32, KeyFinder/KeyFinder2, Feron |
| `Ignore Princeton` | `OFF` / `ON` | Ховає Princeton (PT2262 і клони) — корисно там, де дешеві пульти заповнюють ефір |
| `Ignore Nice Flor-S / Nice One` | `OFF` / `ON` | Ховає Nice Flor-S / Nice One |
| `Delete old signals when memory is full` | `OFF` / `ON` | Коли список заповнений, видаляє найстаріші сигнали замість того, щоб зупинитися. Лічильник тоді показує `!` |
| `Sound` | `OFF` / `ON` | Виводить усе, що приймає радіо, на динамік |
| `Reset to default` | — | Повертає 433.92 МГц AM650, вимкнений хопінг, усі фільтри вимкнені, Bin RAW вимкнено, потужність TX `Preset` |
| `Lock Keyboard` | — | Блокує кнопки під час сканування (у кишені). **Розблокування: тричі натисніть <kbd>Back</kbd>** |

Усі налаштування Read зберігаються й відновлюються під час наступного запуску застосунку.

::: tip Яке значення хопінгу вибрати
З увімкненим `Hopping` приймач залишається на частоті лише тоді, коли сигнал сильніший за вибраний рівень.
`-90dBm` — найчутливіший; підніміть значення, якщо перебір постійно зупиняється на завадах. Для надійного приймання
краще вибрати **фіксовану частоту**, знайдену аналізатором, — сигнали, надіслані під час перемикання частоти,
губляться.
:::

## Надсилання сигналу

Відкрийте сигнал (зі списку Read або з `Saved → <файл> → Emulate`). На екрані передавання показані дані ключа,
частота, модуляція і `R: Int` / `R: Ext` (яке радіо виконуватиме передавання).

- **Натисніть** <kbd>OK</kbd> (**Send**) — одноразове натискання надсилає повний пакет даних сигналу (зазвичай із 1–3
  повторами для надійності). **Утримання** кнопки викликає безперервне повторення передавання, доки кнопку не
  відпустять (це корисно на великій відстані від приймача або за сильних завад). Для динамічних протоколів утримання
  кнопки **не** збільшує лічильник (див. також [спеціальні режими лічильника](/ua/subghz/counter-mode)) — сигнал
  передається з тим самим лічильником, доки кнопку не відпустять і не натиснуть знову.
- <kbd>Back</kbd> — вийти.

### Кастомні кнопки (Unleashed)

::: tip Unleashed
Для багатьох протоколів клавіші-стрілки надсилають **той самий пульт з іншим кодом кнопки** — тому один збережений
файл працює як цілий пульт. Підтримуються, зокрема: KeeLoq, Alutech AT-4N, Nice Flor-S, Somfy Telis/Keytis,
Security+ 2.0, CAME Atomo, FAAC SLH, BelKorn, Beninca ARC, Ditec GOL4, Jarolift, KingGates Stylo 4k, V2 Phoenix,
Prastel, Roger, Nord ICE, Princeton, Proteco, Dooya, Hay21, GangQi, Hollarm. Поки стрілка натиснута, код кнопки,
що надсилається, показується біля правого краю екрана. Яка стрілка якій кнопці відповідає, залежить від протоколу —
див. [Динамічні коди](/ua/subghz/rolling-codes) і [Програмування нового пульта](/ua/subghz/remote-prog).
:::

## Збережені сигнали {#saved-signals}

`Main Menu → Sub-GHz → Saved` показує файли з `/ext/subghz/`. Виберіть один — і ви отримаєте:

- `Emulate` — відкрити екран передавання;
- `Rename`;
- `Delete`;
- `Signal Settings` — **лише в режимі Debug** (`Settings → System → Debug`): змінити `Counter Mode`, `Edit Counter`,
  `Edit Button` файлу з динамічним кодом. Див. [Режими лічильника](/ua/subghz/counter-mode).

RAW-файли відкриваються натомість на екрані Read RAW — див. [Read RAW](/ua/subghz/read-raw#playback).

Імена файлів генеруються автоматично (дата й час), якщо в [Radio Settings](/ua/subghz/settings) не ввімкнено
`Protocol Names` — тоді перед позначкою часу додається назва протоколу.

## Статичні та динамічні коди

- **Статичний код** (Princeton, CAME 12/24 bit, Nice Flo, Marantec, Roger, Gate TX…): кожне натискання надсилає той
  самий код. Збережена копія працює скільки завгодно довго паралельно з оригіналом.
- **Динамічний код** (KeeLoq, Nice Flor-S, CAME Atomo, FAAC SLH, Somfy, Security+…): кожне натискання несе нове
  значення лічильника. Unleashed уміє зберігати й надсилати чимало таких протоколів, **але надсилання копії
  розсинхронізовує оригінальний пульт**. Прочитайте [Динамічні коди](/ua/subghz/rolling-codes) і краще створіть
  *новий* пульт через [Add Manually](/ua/subghz/add-manually).

::: danger Автомобільні брелоки
Не експериментуйте з ключем від авто. Відтворення автомобільного брелока (через Read або Read RAW) може
розсинхронізувати оригінальний ключ або внести його до чорного списку, а для повторного прив'язування часто
потрібне дилерське обладнання. Використовуйте Flipper лише з власним обладнанням і для законних досліджень.
:::

## Якщо не працює

- **Нічого не з'являється** — хибна частота або модуляція. Скористайтеся аналізатором і пробуйте різні модуляції
  (`AM650`/`FM238`/`FM476`/`FM12K`). Перевірте, чи не ховає протокол якийсь фільтр `Ignore …`.
- **Сигнал приймається, але не декодується** — протокол невідомий: увімкніть `Bin RAW` (для статичних пультів) або
  запишіть сигнал через [Read RAW](/ua/subghz/read-raw). Спробуйте також застосунок
  [Remote Analyzer](/ua/subghz/remote-analyzer).
- **KeeLoq показує виробника `Unknown`** — ключа виробника немає в базі або пульт потребує Seed (BFT, Erreka,
  FAAC SLH). Див. [KeeLoq](/ua/subghz/keeloq) і [Seed Capturer](/ua/subghz/seed-capturer).
- **Немає кнопки `Send`** — протокол працює лише на приймання (наприклад, iDo) або це пакет Nice O-Code без коду
  інсталятора (скористайтеся застосунком [Nice O-Code](/ua/subghz/nice-o-code)).
- **Список заповнюється шумом** — увімкніть потрібні параметри `Ignore` або
  `Delete old signals when memory is full`.
