# Read RAW (запис сирого сигналу)

**Read RAW** записує демодульований сигнал «як є», без декодування — наче диктофон. Запис можна відтворити,
зберегти, декодувати пізніше або відредагувати. Користуйтеся ним, коли:

- **Read** не розпізнає пульт (невідомий протокол);
- потрібно зафіксувати сигнал для аналізу або щоб повідомити розробникам про новий протокол;
- потрібне точне відтворення статичного сигналу, протокол якого Flipper не знає.

Запис виконується з вибраними **частотою та модуляцією** — Flipper не SDR. Із хибною частотою або модуляцією ви
запишете лише шум.

::: warning Динамічні коди
Відтворення RAW-запису пульта з динамічним кодом — те саме, що й клон: воно просуває лічильник приймача й може
розсинхронізувати ваш оригінал. **Ніколи не робіть цього з автомобільним ключем** — ключ може потрапити до чорного
списку. Подробиці: [Динамічні коди](/ua/subghz/rolling-codes).
:::

## Запис

1. Якщо частота невідома, визначте її через [Frequency Analyzer](/ua/subghz/frequency-analyzer).
2. Відкрийте `Main Menu → Sub-GHz → Read RAW`.
3. Натисніть <kbd>←</kbd> **Config** і задайте `Frequency`, `Modulation` та `RSSI Threshold:` (див. нижче).
   Натисніть <kbd>Back</kbd>, щоб повернутися.

   ![Read RAW готовий до запису: порожня осцилограма, кнопки Config і REC](/screens/subghz/read_raw.png)

4. Натисніть <kbd>OK</kbd> **REC**. Осцилограма почне прокручуватися, праворуч показується RSSI.
5. Натисніть кнопку на пульті (тримайте 1–2 с).

   ![Read RAW під час запису: два пакети сигналу на осцилограмі, лічильник семплів і кнопка Stop](/screens/subghz/read_raw_recording.png)

6. Натисніть <kbd>OK</kbd> **Stop**.
7. Тепер є три варіанти:
   - <kbd>←</kbd> **Erase** — відкинути запис і почати спочатку;
   - <kbd>OK</kbd> **Send** — відтворити запис (утримуйте, щоб повторювати);
   - <kbd>→</kbd> **Save** — ввести назву (стандартно `RAW_<дата-час>`) і зберегти до `/ext/subghz/`.

## Config у Read RAW

Меню конфігурації RAW коротше, ніж у Read:

| Пункт | Значення | Що означає |
|---|---|---|
| `Frequency` | список частот | Частота приймання |
| `Modulation` | `AM270`, `AM650`, `FM238`, `FM476`, `FM12K` + користувацькі | Пресет демодуляції |
| `Sound` | `OFF` / `ON` | Виводить прийнятий сигнал на динамік |
| `RSSI Threshold:` | `-----`, `-85.0` … `-40.0` | Записує тільки поки сигнал вище цього рівня. `-----` = записувати все |

::: tip Коли використовувати поріг
З порогом у файл потрапляють лише пакети вашого пульта, а не секунди шуму між натисканнями — файли виходять значно
меншими й чистішими. Для записів, які ви надсилаєте розробникам, лишайте `-----` (повний запис).
:::

## Відтворення збереженого RAW {#playback}

1. `Main Menu → Sub-GHz → Saved` і виберіть RAW-файл. Він відкриється на екрані Read RAW.
2. <kbd>OK</kbd> **Send** — надсилає весь запис один раз; тримайте <kbd>OK</kbd>, щоб повторювати
   (**Hold to repeat**).
3. <kbd>←</kbd> **New** — почати новий запис.
4. <kbd>→</kbd> **More**:
   - `Decode` — прогнати запис через усі декодери застосунку Sub-GHz; знайдені сигнали можна зберегти як звичайні
     файли-ключі;
   - `Edit` — відкрити файл у застосунку [Sub-GHz RAW Edit](/ua/subghz/raw-editor) (пункт показується лише тоді,
     коли цей застосунок встановлено в сумісній версії); після виходу з редактора Sub-GHz відкривається знову;
   - `Rename`, `Delete`.

::: tip Unleashed
`More → Decode` і `More → Edit` — додатковий функціонал Unleashed. За допомогою `Edit` можна знайти справжній сигнал у
шумному записі, обрізати його, склеїти файли й декодувати лише вибрану ділянку.
:::

Довгі щільні RAW-файли під час надсилання читаються потоком просто з SD-картки. Якщо йдеться про дуже короткі імпульси
(менше 10 мкс), а картка повільна, передавання може зупинитися до кінця файлу — використовуйте якісну картку.

## Запис пульта для заявки на новий протокол

Саме цю процедуру просять виконати розробники Unleashed, коли потрібно зібрати зразки невідомого сигналу для подальшого розшифрування й додавання до списку підтримуваних протоколів:

1. Знайдіть частоту аналізатором. У Read спробуйте `AM650`, `FM238`, `FM476`, `FM12K` — якщо нічого не декодується,
   продовжуйте.
2. У Read RAW виставте цю частоту та **`RSSI Threshold: -----`**.
3. Зробіть **по одному RAW на кожну модуляцію**: `AM650`, `FM238`, `FM476`, `FM12K`.
4. Для кожного запису: натисніть **REC**, потім натисніть одну кнопку пульта **5 разів, тримаючи 1–2 с**, а далі
   **5 разів, тримаючи близько 5 с**. Зупиніть запис і збережіть.
5. Якщо на пульті кілька кнопок, запишіть кожну кнопку так само. Назвіть кожен файл за кнопкою.
6. Скопіюйте файли на комп'ютер, запакуйте в архів і створіть issue в
   [репозиторії прошивки](https://github.com/DarkFlippers/unleashed-firmware/issues) або передайте запит команді
   будь-яким зручним способом ([Офіційні посилання](/ua/community/links) — чати в Telegram, [Discord](https://discord.unleashedflip.com)).
   Додайте якісні фото пульта (за можливості й зсередини), модель і виробника.

## Якщо не працює

- **Запис плоский / тільки шум** — хибна частота чи модуляція або пульт надто далеко. Тримайте його близько.
- **Величезні файли** — задайте `RSSI Threshold`.
- **Відтворення не працює** — пульт використовує динамічний код (приймач відкидає старі лічильники), модуляція була
  хибною або в записі лише частина сигналу. Записуйте довші натискання.
- **Передавання обривається посередині** — повільна SD-картка з довгим щільним файлом. Обріжте файл у
  [RAW Edit](/ua/subghz/raw-editor) або візьміть швидшу картку.
- **У `More` немає `Edit`** — застосунок Sub-GHz RAW Edit не встановлено або він застарілий.
