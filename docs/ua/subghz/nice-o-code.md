# Застосунок Nice O-Code

**Nice O-Code** (від @xMasterX) відновлює 16-бітний **код інсталятора (IC)** пульта Nice O-Code і зберігає пульт у файл `.sub` — або як звичайний клон, або як **новий пульт** тієї самої інсталяції, який можна прописати в приймач.

## Передісторія

Nice O-Code — це Nice FloR-S, зашифрований кодом інсталятора: одним значенням, спільним для всіх пультів інсталяції. Приймач приймає лише той пульт, який несе його код інсталятора. Одного зчитаного натискання недостатньо, щоб знайти код, а **чотирьох або більше натискань** того самого пульта достатньо: лише з правильним кодом кожне натискання декодується в той самий серійник. Застосунок збирає натискання й перебирає всі 65 536 кодів просто на Flipper.

Частина пультів O-Code несе також **сертифікат** приймача (довший 112-бітний пакет, який надсилається лише під час перших двадцяти використань пульта). Коли застосунок бачить його, він знімає маскування після того, як IC стає відомим, і показує його як `Cert`.

::: tip Unleashed
Nice O-Code — вбудований системний застосунок Unleashed, а застосунок Sub-GHz уміє декодувати й надсилати пульти O-Code, коли у файлі є IC. В `Add Manually` є відповідні записи `Nice O-Code`, `Nice O-Code One` і `Nice O-Code+Crt` — див. [Add Manually](/ua/subghz/add-manually) і [Програмування нового пульта](/ua/subghz/remote-prog).
:::

::: warning
Користуйтеся цим лише з власною інсталяцією. Клон має спільний лічильник з оригінальним пультом, і вони будуть конфліктувати (див. [Динамічні коди](/ua/subghz/rolling-codes)).
:::

## Що потрібно

- Файл ключів Nice FloR-S `/ext/subghz/assets/nice_flor_s` на SD-картці (він постачається з прошивкою). Без нього застосунок повідомляє `No rainbow table`.
- Робочий пульт O-Code цієї інсталяції. Застосунок слухає на **433,92 МГц AM650**, через внутрішній або [зовнішній](/ua/subghz/external-cc1101) радіомодуль (`Int` / `Ext` у заголовку).

## Зчитування пульта

1. Відкрийте `Main Menu → Apps → Sub-GHz → Nice O-Code`.
2. Виберіть `Capture remote`. У стані показується `Listening 433.92`.
3. Натисніть кнопку пульта **4 чи більше разів — короткими натисканнями, не затискайте її**. Кожне нове натискання показує `Press N: …`; рядок `Presses n/4  Xpkt` і смужка прогресу заповнюються. Якщо пульт має сертифікат, рядок завершується на `+Crt`.
4. Коли зібрано 4 натискання, з'являється `Solve` — натисніть <kbd>OK</kbd>.
5. На екрані буде `Trying installer codes` з лічильником до 65536. <kbd>←</kbd> (`Cancel`) зупиняє перебір.
6. При успіху ви побачите `IC XXXX`, `Serial XXXXXXX` і, якщо він є, `Cert XXXXXX`.

Стани, які можуть з'являтися під час зчитування:

| Стан | Що означає |
|---|---|
| `Not O-Code, ignored` | пакет не належить до O-Code (наприклад, звичайний пульт FloR-S) |
| `Same press, ignored` | повтор уже збереженого натискання |
| `Need 4+ packets` | натискань недостатньо для розв'язку |
| `Ambiguous, capture more` | підходить кілька кодів — натисніть пульт ще кілька разів і розв'яжіть знову |
| `No code fits, not O-Code?` | жодний код інсталятора не підходить — імовірно, це не пульт O-Code або змішалися натискання різних пультів |

## Збереження

На екрані результату:

- <kbd>OK</kbd> (`Save`) — **клон** зчитаного пульта (типове ім'я `NiceO`). Зручно для перевірок, але він конфліктує з вашим оригіналом через лічильник.
- <kbd>→</kbd> (`New`) — **новий пульт**: той самий код інсталятора, кнопка й сертифікат, але власний серійник і лічильник (типове ім'я `NiceO_new`). Саме його й треба прописувати в приймач. Лічильник встановлюється близько до значення вашого робочого пульта й трохи нижче за нього.

Обидва записуються в `/ext/subghz/` після того, як ви дасте їм ім'я (`Name the .sub file`). Відкривайте їх у `Sub-GHz → Saved`.

Щоб прописати новий пульт, виконайте процедуру для Nice FloR-S зі сторінки [Програмування нового пульта](/ua/subghz/remote-prog). Пульт із сертифікатом прописує себе сам: натискайте його кнопку приблизно раз на секунду, **10–15 разів підряд** — ворота відкриваються десь на десятому натисканні.

## Decode RAW file

`Decode RAW file` виконує те саме відновлення на RAW-файлі `.sub`, який ви записали раніше через [Read RAW](/ua/subghz/read-raw) (запишіть 4+ окремих натискань). Файл ключа відкидається з повідомленням `Not a RAW capture`. Смужка прогресу показує, як далеко пройдено файл.

## Усунення проблем

- **`No rainbow table`** — немає `/ext/subghz/assets/nice_flor_s`; перевстановіть прошивку з вставленою SD-карткою або відновіть теку assets.
- **Натискання не рахуються** — робіть окремі короткі натискання; затиснута кнопка повторює те саме натискання.
- **Новий приймач із заводу ігнорує пульт O-Code** — у незайманого приймача немає коду інсталятора; пропишіть замість цього звичайний пульт `Nice One` / `Nice FloR-S` через кнопку (див. [Програмування нового пульта](/ua/subghz/remote-prog)).
- **Приймач відкидає новий пульт** — тримайте лічильник близько до значення свого робочого пульта; не скидайте його в нуль.
