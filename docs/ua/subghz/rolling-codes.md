# Динамічні коди

Пульти Sub-GHz бувають двох типів:

- **Статичний (фіксований) код** — кожне натискання надсилає абсолютно той самий пакет (Princeton, CAME 12/24 bit,
  Nice Flo, Marantec, Roger, Gate TX…). Копія ідентична оригіналу; обидва працюють як завгодно довго й у будь-якому
  порядку. Достатньо [Read](/ua/subghz/read) і зберегти.
- **Динамічний код** — кожне натискання надсилає новий пакет, побудований на основі **лічильника**, який
  збільшується на одиницю за кожне натискання (KeeLoq, FAAC SLH, Nice FloR-S, CAME Atomo, Somfy, Security+,
  Alutech AT-4N…). Лічильник зазвичай зашифрований, тож наступний код можна обчислити лише тоді, коли прошивка
  знає ключ протоколу.

::: tip Unleashed
Unleashed умієить декодувати, зберігати **й надсилати** багато протоколів із динамічним кодом, створювати для них
нові пульти через [Add Manually](/ua/subghz/add-manually), надсилати інші кнопки пульта клавішами-стрілками
([кастомні кнопки](#custom-buttons)) та регулювати крок лічильника
([Counter Incr.](#counter-increment), [Режими лічильника](/ua/subghz/counter-mode)). Стокова прошивка декодує
більшість із них, але не передає.
:::

## Як приймач перевіряє лічильник

Приймач зберігає останній прийнятий лічильник **для кожного пульта** (одне значення на пульт, а не на кнопку):

- лічильник **дорівнює очікуваному наступному / у межах вікна вперед** → прийнято, ворота відчиняються;
- лічильник **далеко попереду** → багато приймачів виконують ресинхронізацію: перше натискання запам'ятовується,
  наступне послідовне вже працює;
- лічильник **позаду** збереженого значення → ігнорується. Деякі приймачі після кількох «старих» кодів взагалі
  відв'язують пульт.

## Конфлікт лічильників

*Чому не можна просто зловити власний пульт із динамічним кодом у Read і користуватися ним із Flipper?*
(адаптовано з [@how2flipper_rus](https://t.me/how2flipper_rus/7))

Уявіть:

1. Ви натискаєте оригінальний пульт — він надсилає лічильник `0002`.
2. Ви зберегли цей сигнал на Flipper; коли ви його надсилаєте, Flipper надсилає `0003`.
3. Приймач вважає, що ви просто знову натиснули оригінал, і відчиняє.
4. Але оригінальний пульт досі на `0002`; його наступне натискання — `0003`, значення, яке приймач уже бачив,
   тому **він не відчиняє**.

Не панікуйте — пульт не відв'язаний. Натисніть його ще раз: `0004` обганяє Flipper, і оригінал знову працює. Проте
такі «перегони» можуть розвести лічильники на 100+ натискань, і тоді оригінал уже не повернути без повторного
прив'язування до приймача.

Варіанти виходу:

- **Найкращий: створити новий пульт** на Flipper (`Sub-GHz → Add Manually`) і зареєструвати його в приймачі. Він
  має власний серійник і лічильник і ніколи не конфліктує з оригіналами. Див.
  [програмування пульта](/ua/subghz/remote-prog).
- Вирішити, чим ви користуєтеся — Flipper **або** оригіналом, — і користуватися лише цим.
- Користуватися обома, але не давати лічильникам розійтися далеко (натисніть кілька разів на тому, що відстав).
- Експериментально: для деяких приймачів спеціальні [режими лічильника](/ua/subghz/counter-mode) дають клону й
  оригіналу співіснувати.

::: danger Автомобілі
Не клонуйте автомобільний брелок. Його відтворення (навіть через Read RAW) може розсинхронізувати ключ або
внести його до чорного списку, а для повторного прив'язування часто потрібне дилерське обладнання.
:::

## Кастомні кнопки {#custom-buttons}

Коли підтримуваний файл із динамічним (або деякі зі статичним) кодом відкрито в `Emulate`:

- <kbd>OK</kbd> (`Send`) надсилає кнопку, яку було записано / згенеровано;
- <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> надсилають **інші коди кнопок** того самого пульта з
  правильно збільшеним лічильником, поки їх утримують. Поки використовується стрілка, початковий код кнопки
  показується маленькою шістнадцятковою цифрою праворуч на екрані.

Яка стрілка якій кнопці відповідає, залежить від протоколу; приховані / програмувальні кнопки (наприклад, `0xF` у
BFT Mitto, `Prog` у Somfy) теж доступні цим способом — повна таблиця є на сторінці
[програмування пульта](/ua/subghz/remote-prog) (довідник прихованих кнопок).

Протоколи з кастомними кнопками в поточній прошивці (число = скільки додаткових кодів можуть надіслати стрілки):

| Ditec GOL4 | 4 | Dooya | 4 |
| Princeton | 4 | Somfy Telis | 3 |

## Крок лічильника {#counter-increment}

`Sub-GHz → Radio Settings → Counter Incr.` задає, на скільки зростає лічильник за одне передавання: `+1`
(стандартно), `+2`, `+3`. З увімкненим **режимом Debug** (`Settings → System → Debug`) список розширюється до `+4`,
`+5`, `+10`, `+50`, `OVFL`, `OFEX`, `No`, `-1` … `-50` — це інструменти для розробки протоколів; не застосовуйте їх
на реальній установці. Див. [Налаштування](/ua/subghz/settings).

## Програмування нового пульта в приймач

Звичайний, безконфліктний спосіб використовувати Flipper із воротами на динамічному коді:

1. Зчитайте свій оригінальний пульт (`Sub-GHz → Read`), щоб дізнатися протокол, частоту та модуляцію.
2. `Sub-GHz → Add Manually` → ваша система → той самий діапазон → зберегти.
3. Переведіть приймач у режим навчання (кнопкою на платі або з робочого пульта — Flipper надсилає приховану
   кнопку «програмування» однією зі стрілок).
4. Відкрийте новий файл і утримуйте <kbd>OK</kbd>.

Процедури для кожного виробника: **[Flipper як новий пульт](/ua/subghz/remote-prog)**.

## Якщо не працює

- **Спрацювало один раз, потім перестало** — ви користуєтеся клоном. Натисніть кілька разів підряд для
  ресинхронізації або натомість створіть новий пульт.
- **Оригінальний пульт перестав працювати** — Flipper забіг уперед. Натисніть оригінал кілька разів; якщо розрив
  надто великий, перереєструйте його в приймачі.
- **Стрілки нічого не роблять** — протокол не має кастомних кнопок або файл статичний і без поля кнопки.
- **`KL: Unknown` після Read** — ключ виробника невідомий, надіслати сигнал не вийде. Див.
  [KeeLoq](/ua/subghz/keeloq).

::: warning
Користуйтеся цими можливостями лише з власним обладнанням або з дозволу власника.
:::
