# Security+ PIN

**Security+ PIN** (від @xMasterX) працює зі зчитаним сигналом **клавіатури Security+ 2.0** — 86-бітним пакетом, який надсилають бездротові клавіатури Chamberlain / LiftMaster. PIN-код клавіатури лежить усередині цього пакета. Застосунок дозволяє задати PIN вручну або перебрати `0000`–`9999`, передає кожний варіант, а коли ви знайшли потрібний — записує PIN назад у файл.

::: tip Unleashed
Security+ 2.0 Keypad (86 бітів, 315 / 390 / 868 МГц) декодується застосунком Sub-GHz в Unleashed, а цей вбудований системний застосунок редагує його PIN. Звичайні 62-бітні пульти Security+ 2.0 не є пакетами клавіатури, і їх застосунок відкидає.
:::

::: warning
Лише для вашого власного приводу гаражних дверей і вашої клавіатури.
:::

## Перед початком

1. Зчитайте свою клавіатуру через `Sub-GHz → Read` на її частоті (див. [Read](/ua/subghz/read)) і збережіть сигнал. У збереженому файлі мусить бути `Security+ 2.0` з `Bit: 86`.
2. Файл лежить у `/ext/subghz/`.

## Користування застосунком

1. Відкрийте `Main Menu → Apps → Sub-GHz → Security+ PIN`.
2. Виберіть `Open .sub file` і вкажіть запис клавіатури. Після завантаження в стані показуються частота й `ready` (наприклад, `315MHz  ready`). Якщо у файлі вже є `Pin`, його буде показано.
3. На екрані чотири цифри PIN-коду, активна цифра обведена рамкою:
   - <kbd>←</kbd> / <kbd>→</kbd> — перехід між цифрами
   - <kbd>↑</kbd> / <kbd>↓</kbd> — зміна PIN-коду
   - <kbd>OK</kbd> (`Send`) — передати поточний PIN (`Sending 1234...` → `Sent 1234`)
   - утримання <kbd>OK</kbd> — **перебір**: надсилає всі PIN-коди, починаючи з поточного; смужка прогресу показує `N of 9999`. Коротке <kbd>OK</kbd> або <kbd>←</kbd> (Back) зупиняє його з повідомленням `Stopped at NNNN`
   - утримання <kbd>←</kbd> — **зберегти** поточний PIN у файл (`Saved PIN NNNN`)
   - <kbd>Back</kbd> — назад до меню

Рядок підказки на екрані підсумовує все це: `hold OK sweep   < save`.

Збереження змінює відкритий файл на місці: записуються поля `Pin`, `Key` і `Secplus_packet_1`. Після цього файл можна надсилати як завжди з `Sub-GHz → Saved`.

## Повідомлення

| Повідомлення | Що означає |
|---|---|
| `Not Security+ 2.0: …` | файл належить іншому протоколу |
| `Not an 86-bit keypad` | це пульт Security+ 2.0, а не пакет клавіатури |
| `Missing packet 1` / `No Key value` | неповний запис — зчитайте клавіатуру ще раз |
| `Unsupported preset …` / `Bad custom preset` | пресет із файла використати не вдається |
| `NNNMHz TX blocked` / `TX blocked, sweep stopped` | передавання на цій частоті не дозволене (див. [Частоти](/ua/subghz/frequencies)) |
| `TX failed` | радіомодуль не зміг передати |

## Усунення проблем

- **Перебір повільний** — кожний PIN передається окремо з короткою паузою, тому повний перебір триває довго. Починайте з імовірного значення й зупиняйтеся, щойно двері зреагують.
- **Двері зреагували, але ви не побачили PIN** — перебір зупиняється на показаному числі; поверніться на крок назад клавішею <kbd>↓</kbd>, надішліть окремі PIN-коди клавішею <kbd>OK</kbd>, щоб підтвердити, а потім утримуйте <kbd>←</kbd>, щоб зберегти.
- **Хибний файл відкидається** — зчитуйте саму клавіатуру, а не кишеньковий пульт.
