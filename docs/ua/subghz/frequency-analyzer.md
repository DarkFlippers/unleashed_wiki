# Frequency Analyzer

Frequency Analyzer підказує, **на якій частоті передає пульт**. Він перебирає частоти зі списку Sub-GHz, вимірює
силу сигналу (RSSI) і показує найсильнішу. Користуйтеся ним перед **Read** або **Read RAW**, коли частота пульта
невідома.

::: tip Unleashed
В Unleashed є перероблений аналізатор (спочатку від ClusterM) з історією на 4 записи, регульованим тригером,
вибором способу сповіщення (звук / вібро / тиша) та **прямим переходом до Read**: коротке натискання
<kbd>OK</kbd> запам'ятовує частоту для Read / Read RAW, довге — запам'ятовує й одразу відкриває Read.
:::

## Золоте правило

Аналізатор розрахований на роботу **лише за кілька сантиметрів від антени Flipper, на внутрішньому радіо**.
Антена розташована на лівому боці, поряд із чорним вікном ІЧ-порту. Його налаштування існують, щоб відфільтрувати
шум, а не щоб ловити сигнали здалеку. З надто низьким тригером аналізатор просто показує випадкові завади й власний
шум Flipper замість вашого пульта. Щоб справді *приймати* сигнали, використовуйте [Read](/ua/subghz/read) і
[Read RAW](/ua/subghz/read-raw).

::: warning Зовнішні модулі
У розширеній версії Unleashed (`E`) можна використовувати Frequency Analyzer із зовнішніми модулями — для цього
застосунок потрібно запускати з `Apps → Sub-GHz` (замість головного меню Sub-GHz). Майте на увазі, що із зовнішнім
модулем зростає чутливість до шуму й завад, які можна помилково прийняти за корисний сигнал.
:::

## Екран

![Frequency Analyzer показує 433.920 МГц, записи історії та шкалу RSSI](/screens/subghz/frequency_analyzer.png)

| Елемент | Що означає |
|---|---|
| Піктограма праворуч угорі | Сповіщення про спійманий сигнал: динамік = вібро + звук, маленький динамік = лише вібро, перекреслений = тиша |
| Велике число в центрі | Поточна (основна) частота. Поки приймається сигнал вище тригера, вона показується **інверсно, у чорній рамці** |
| Чотири записи нижче | Історія: округлена частота й кількість разів, коли її спіймано (`x3`). Допомагає зі слабкими пультами та з пультами, частота яких «пливе» |
| Шкала `RSSI` внизу | Сила сигналу в реальному часі з позначкою тригера |
| `T-` / `+T` | Кнопки рівня тригера |

## Кнопки

| Кнопка | Дія |
|---|---|
| <kbd>←</kbd> / <kbd>→</kbd> | Переміщує тригер (від −97 дБм до −60 дБм, крок 1 дБм). Ліворуч = чутливіше, праворуч = менш чутливо |
| <kbd>↑</kbd> | Перемикає режим сповіщення: вібро + звук → тиша → вібро → … |
| <kbd>↓</kbd> | Вибирає запис в історії (навколо нього з'являється рамка) |
| коротке <kbd>OK</kbd> | Зберігає вибрану частоту для Read / Read RAW |
| довге <kbd>OK</kbd> | Зберігає частоту й одразу відкриває **Read** |
| <kbd>Back</kbd> | Вихід (тригер і режим сповіщення запам'ятовуються) |

Яку частоту бере <kbd>OK</kbd>:

- якщо сигнал приймається **саме зараз** (основна частота в чорній рамці) — цю частоту, навіть якщо вибрано запис
  з історії;
- якщо нічого не приймається і вибрано запис з історії — вибраний запис;
- в інших випадках — останню частоту, що перетнула тригер, тому пульт не потрібно тримати натиснутим.

::: warning Округлення
Збережена частота завжди **округлюється до найближчої частоти зі списку**
([Частоти](/ua/subghz/frequencies)). Якщо ваш пульт далеко від усіх стандартних значень, додайте його частоту до
`setting_user`. Тоді основне число показуватиме реальну частоту, але після переходу до Read / Read RAW її
доведеться виставити вручну в `Config`.
:::

Збереження частоти з аналізатора також **вимикає Hopping**, тому Read стартує саме на цій частоті.

## Як визначити частоту пульта

1. Відійдіть від імпульсних блоків живлення, зарядок та іншої «шумної» електроніки.
2. Відкрийте `Main Menu → Sub-GHz → Frequency Analyzer`.
3. Тримайте пульт щільно до лівого боку Flipper (біля чорного вікна).
4. Натисніть і тримайте кнопку на пульті. Поки сигнал приймається, основна частота показується інверсно.
5. Відпустіть кнопку й дочекайтеся, поки частота потрапить до історії.
6. Натисніть <kbd>OK</kbd>, щоб її запам'ятати, або утримуйте <kbd>OK</kbd>, щоб відразу перейти до **Read**.

Більшість пультів передають приблизно на 315, 433.92 або 868.35 МГц. У Read усе одно спробуйте кілька модуляцій,
якщо нічого не декодується (спершу `AM650`, далі `FM238`, `FM476`, `FM12K`).

## Налаштування тригера

Стандартно тригер стоїть на −93 дБм — це положення працює в більшості випадків, тож зазвичай його не чіпають.
Налаштовуйте його лише тоді, коли пульт не ловиться навіть упритул або коли навколо багато шуму:

1. Не натискаючи пульт, переміщуйте позначку клавішами <kbd>←</kbd> / <kbd>→</kbd>, доки Flipper не перестане ловити
   будь-що (ні шуму, ні випадкових спрацювань). Крайнє ліве положення — найчутливіше: воно ловить і сигнали, *і*
   внутрішній шум Flipper, і будь-які завади; крайнє праве — найменш чутливе до всього.
2. Притисніть пульт до лівого краю Flipper і натисніть його кнопку.
3. Якщо нічого не ловиться, посувайте тригер **ліворуч** крок за кроком, доки не з'явиться сигнал.
4. Під час налаштування натискайте й відпускайте кнопку пульта кілька разів — переривчастий сигнал дає змогу
   знайти правильне положення легше, ніж безперервний.

## Якщо не працює

- **Постійно з'являються випадкові частоти** — тригер надто низький або поряд є шум. Посуньте його праворуч,
  відійдіть від блоків живлення.
- **Пульт не ловиться взагалі** — тримайте його ближче, перевірте батарейку, посуньте тригер ліворуч. Деякі пульти
  надсилають дуже короткі пакети: натискайте кілька разів.
- **На знайденій частоті Read нічого не показує** — хибна модуляція. Змініть її в `Read → Config`. Якщо нічого не
  декодується, запишіть сигнал через [Read RAW](/ua/subghz/read-raw).
- **Частота відрізняється від написаної на пульті** — це нормально; дешеві пульти «пливуть». Орієнтуйтеся на
  кількість спрацювань в історії та беріть найчастіше значення.
