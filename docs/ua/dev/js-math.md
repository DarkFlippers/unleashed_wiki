# Модуль math

Математичні функції та константи. Спочатку завантажте модуль:

```js
let math = require("math");
```

::: tip
`math` — найбільший JS-модуль: після завантаження він займає близько 21 КБ RAM. Якщо вам потрібно лише округлити невід’ємне число вниз, `x | 0` робить те саме, що й `math.floor(x)`, без завантаження модуля.
:::

## Константи

| Константа | Значення |
|---|---|
| `PI` | π = 3.14159265358979323846264338327950288 |
| `E` | e (число Ейлера) = 2.71828182845904523536028747135266250 |
| `EPSILON` | Найменше число, для якого 1.0 + EPSILON != 1.0; EPSILON = 2.2204460492503131e-16 |

## Методи

### abs()
`abs(x)`: абсолютне значення `x`. Якщо `x` від’ємне (зокрема -0), повертає `-x`, інакше — `x`. Результат завжди додатний або 0.

```js
math.abs(-5); // 5
```

### acos()
`acos(x)`: арккосинус у радіанах. `x` — від -1 до 1 включно (косинус кута). Повертає кут від 0 до π включно. Якщо `x` менше за -1 або більше за 1, повертає `NaN`.

```js
math.acos(-1); // 3.141592653589793
```

### acosh()
`acosh(x)`: гіперболічний арккосинус. `x` ≥ 1.

```js
math.acosh(1); // 0
```

### asin()
`asin(x)`: арксинус у радіанах. `x` — від -1 до 1 включно. Повертає кут від -π/2 до π/2 включно.

```js
math.asin(0.5); // 0.5235987755982989
```

### asinh()
`asinh(x)`: гіперболічний арксинус.

```js
math.asinh(1); // 0.881373587019543
```

### atan()
`atan(x)`: арктангенс у радіанах, від -π/2 до π/2 включно.

```js
math.atan(1); // 0.7853981633974483
```

### atan2()
`atan2(y, x)`: кут у радіанах (від -π до π включно) між додатною піввіссю x і променем з (0, 0) до точки (x, y).

- `y`: координата y точки;
- `x`: координата x точки.

```js
math.atan2(90, 15); // 1.4056476493802699
```

### atanh()
`atanh(x)`: гіперболічний арктангенс. `x` — від -1 до 1 включно.

```js
math.atanh(0.5); // 0.5493061443340548
```

### cbrt()
`cbrt(x)`: кубічний корінь.

```js
math.cbrt(2); // 1.2599210498948732
```

### ceil()
`ceil(x)`: округлення вгору; найменше ціле, не менше за `x`. Те саме, що `-math.floor(-x)`.

```js
math.ceil(-7.004); // -7
math.ceil(7.004);  // 8
```

### clz32()
`clz32(x)`: кількість старших нульових бітів у 32-бітному двійковому представленні `x`.

```js
math.clz32(1);    // 31
math.clz32(1000); // 22
```

### cos()
`cos(x)`: косинус кута в радіанах, від -1 до 1 включно.

```js
math.cos(math.PI); // -1
```

### exp()
`exp(x)`: e у степені `x` (результат невід’ємний).

```js
math.exp(0); // 1
math.exp(1); // 2.718281828459045
```

### floor()
`floor(x)`: округлення вниз; найбільше ціле, не більше за `x`. Те саме, що `-math.ceil(-x)`.

```js
math.floor(-45.95); // -46
math.floor(-45.05); // -46
math.floor(-0); // -0
math.floor(0); // 0
math.floor(45.05); // 45
math.floor(45.95); // 45
```

### log()
`log(x)`: натуральний логарифм, ln(x).

```js
math.log(1); // 0
math.log(3); // 1.0986122886681098
```

### isEqual()
`isEqual(a, b, tolerance)`: `true`, якщо різниця між `a` і `b` менша за `tolerance`, інакше — `false`.

```js
math.isEqual(1.4, 1.6, 0.2);      // false
math.isEqual(3.556, 3.555, 0.01); // true
```

### max()
`max(a, b)`: більше з двох чисел.

```js
math.max(10, 20);   // 20
math.max(-10, -20); // -10
```

### min()
`min(a, b)`: менше з двох чисел.

```js
math.min(10, 20);   // 10
math.min(-10, -20); // -20
```

### pow()
`pow(base, exponent)`: `base` у степені `exponent`.

```js
math.pow(7, 2);  // 49
math.pow(7, 3);  // 343
math.pow(2, 10); // 1024
```

### random()
`random()`: псевдовипадкове число з рухомою комою від 0 (включно) до 1 (не включно), розподілене приблизно рівномірно. Масштабуйте його до потрібного діапазону самостійно.

```js
let num = math.random();
```

### sign()
`sign(x)`: -1, якщо `x` менше за 0, інакше — 1.

```js
math.sign(3);  // 1
math.sign(0);  // 1
math.sign(-3); // -1
```

### sin()
`sin(x)`: синус кута в радіанах, від -1 до 1 включно.

```js
math.sin(math.PI / 2); // 1
```

### sqrt()
`sqrt(x)`: квадратний корінь, `x` ≥ 0. Якщо `x` < 0, скрипт **завершується з помилкою**.

```js
math.sqrt(25); // 5
```

### trunc()
`trunc(x)`: ціла частина `x` — дробові розряди відкидаються.

```js
math.trunc(-1.123); // -1
math.trunc(0.123);  // 0
math.trunc(13.37);  // 13
math.trunc(42.84);  // 42
```
