# Ваш перший застосунок на JavaScript

У цьому посібнику ви напишете крихітний скрипт, який виводить числа із затримкою, а потім запустите його на Flipper Zero двома способами: з меню пристрою і з ПК через CLI. Знадобляться Flipper Zero, комп’ютер і USB-кабель.

## Крок 1. Створіть скрипт

Створіть текстовий файл з назвою `first_app.js` і таким вмістом:

```js
print("start");
delay(1000);
print("1");
delay(500);
print("2");
delay(500);
print("3");
delay(500);
print("end");
```

Що він робить:

- виводить **start** і чекає 1 секунду;
- виводить **1**, **2** і **3**, роблячи паузу 0,5 секунди після кожного;
- виводить **end**.

`print()` виводить текст, а `delay()` робить паузу на задану кількість мілісекунд (1000 мс = 1 с). Обидві функції **вбудовані**, тому жодного модуля завантажувати не потрібно. Повний перелік — на сторінці [Вбудовані функції](/ua/dev/js-builtin).

## Крок 2. Скопіюйте файл на Flipper Zero

1. Підключіть Flipper Zero до комп’ютера через USB.
2. Відкрийте [qFlipper](/ua/mobile/qflipper).
3. Перейдіть на вкладку **File manager** і відкрийте `SD Card/apps/Scripts/`.
4. Перетягніть `first_app.js` у вікно qFlipper.

Файл можна скопіювати і через картрідер. Головне — він має опинитися в `/ext/apps/Scripts/`.

## Крок 3. Запустіть скрипт

### З меню Flipper

1. Відкрийте `Main Menu → Apps → Scripts`. У списку будуть скрипти з `SD Card/apps/Scripts/`.
2. Виберіть `first_app`.
3. Натисніть <kbd>OK</kbd>, щоб запустити.

![Скрипт працює на Flipper Zero](/img/dev/js_first_app_on_fz.jpg)

Рядки з’являються на екрані Flipper із затримками, заданими у скрипті.

### З CLI

Запуск через [CLI](/ua/dev/cli) зручний для налагодження: ви правите й перевіряєте скрипт, не торкаючись пристрою.

1. Підключіть Flipper Zero через USB.
2. Відкрийте CLI (наприклад, через вкладку CLI у qFlipper, послідовний термінал або `./fbt cli`).
3. Виконайте `js` і вкажіть шлях до скрипта:

```sh
js /ext/apps/Scripts/first_app.js
```

![Вивід скрипта в CLI](/img/dev/js_first_app_on_cli.jpg)

Якщо скрипт запущено з CLI, усе, що виводить `print()`, потрапляє в CLI, а не на екран Flipper.

## Усунення проблем

- **Скрипта немає в списку.** Перевірте, що файл має розширення `.js` і лежить у `/ext/apps/Scripts/` (вкладені папки теж працюють — просто зайдіть у них).
- **Скрипт завершується з помилкою.** mJS підтримує лише підмножину JavaScript (без замикань, стрілкових функцій і класів). Запустіть його з CLI, щоб побачити текст помилки й номер рядка.
