# Командний рядок (CLI)

Фліппер віддає текстову консоль через USB-serial. З неї можна читати й надсилати сигнали, запускати застосунки,
працювати з файлами, дивитися журнал, керувати GPIO та світлодіодом, спілкуватися з іншими Фліпперами через Sub-GHz
і багато іншого — зручно для скриптів, налагодження та розробки застосунків.

## Підключення до CLI

::: warning Спершу закрийте qFlipper
Послідовний порт Фліппера одночасно може використовувати лише одна програма. Закрийте **qFlipper** (а також
Flipper Lab та інші термінали), перш ніж підключатися.
:::

Швидкість передачі — **230400** бод (для USB CDC це значення здебільшого ігнорується, але деякі термінали
вимагають його вказати).

### Варіант 1: Flipper Lab (браузер)

Працює в Chrome, Edge або іншому браузері на Chromium із підтримкою Web Serial.

1. Під’єднайте Фліппер через USB.
2. Відкрийте [lab.flipper.net](https://lab.flipper.net/) → **CLI**.

### Варіант 2: вебтермінал послідовного порту (браузер)

1. Під’єднайте Фліппер через USB, відкрийте браузер на Chromium.
2. Перейдіть до [вебтерміналу послідовного порту](https://googlechromelabs.github.io/serial-terminal/).
3. Поставте **Baud rate** на **230400**, натисніть **Connect**, виберіть свій Фліппер і натисніть **Connect**.

### Варіант 3: термінал — macOS

1. Знайдіть порт:

   ```sh
   ls /dev/cu.*
   ```

   Фліппер з’являється як `/dev/cu.usbmodemflip_NAME`, де `NAME` — ім’я вашого Фліппера.
2. Підключіться через **screen**:

   ```sh
   screen /dev/cu.usbmodemflip_NAME
   ```

   Вихід: <kbd>Ctrl</kbd>+<kbd>A</kbd>, далі <kbd>K</kbd>, далі <kbd>Y</kbd>.
3. …або через **minicom** (встановлюється з [Homebrew](https://brew.sh/): `brew install minicom`):

   ```sh
   minicom -D /dev/cu.usbmodemflip_NAME
   ```

   Вихід: <kbd>Esc</kbd>+<kbd>Z</kbd>, далі <kbd>X</kbd>, далі <kbd>Return</kbd>.

### Варіант 3: термінал — Linux

1. Знайдіть порт:

   ```sh
   ls /dev/serial/by-id/
   ```

   Шукайте `usb-Flipper_Devices_Inc._Flipper_NAME_flip_NAME-if00`. Якщо послідовний пристрій у вас лише один, це
   зазвичай ще й `/dev/ttyACM0`; назву порту показує й qFlipper.
2. Підключіться:

   ```sh
   screen /dev/serial/by-id/usb-Flipper_Devices_Inc._Flipper_NAME_flip_NAME-if00
   # or
   minicom -D /dev/ttyACM0
   ```

   Вихід зі screen: <kbd>Ctrl</kbd>+<kbd>A</kbd>, <kbd>K</kbd>, <kbd>Y</kbd>. Вихід з minicom:
   <kbd>Ctrl</kbd>+<kbd>A</kbd>, <kbd>X</kbd>, <kbd>Return</kbd>.

::: tip
Якщо в Linux ви отримуєте «permission denied», додайте себе до групи `dialout` (у деяких дистрибутивах — `uucp`)
і увійдіть у систему заново.
:::

### Варіант 3: термінал — Windows

1. Встановіть [PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html).
2. Під’єднайте Фліппер; у **Device Manager → Ports (COM & LPT)** подивіться його COM-порт (від’єднайте та
   під’єднайте знову, щоб побачити, який саме з’являється).
3. У PuTTY виберіть **Connection type: Serial**, у **Serial line** вкажіть, наприклад, `COM3`, у **Speed** —
   `230400`, і натисніть **Open**.

### З дерева джерельного коду прошивки

Якщо у вас є джерельний код прошивки, сесію CLI одразу відкриває `./fbt cli`; з uFBT — `ufbt cli`.

**Очікуваний результат:** ASCII-банер Фліппера, рядок «Welcome to Flipper Zero Command Line Interface!», рядок із
версією прошивки і запит `>:`.

## Вбудовані та зовнішні команди

Команда `help` або `?` виводить список команд, доступних на вашому пристрої.

::: tip Unleashed / нова архітектура CLI
Більшість команд для радіо та периферії (`subghz`, `nfc`, `ir`, `rfid`, `ikey`, `onewire`, `bt`, `crypto`, `js`,
`gpio`, `led`, `vibro`, `buzzer`, `i2c`, `neofetch`, …) — це **зовнішні плагіни CLI**, які завантажуються з папки
на SD-карті `/ext/apps_data/cli/plugins` (файли з префіксом `cli_`). Без SD-карти або з пошкодженою карткою
залишаються лише базові команди. Після копіювання чи оновлення плагінів не перезавантажуйте пристрій — виконайте
`reload_ext_cmds`.
:::

|---|---|

| `?`, `help` | Список доступних команд |
| `bt` | Тестовий інструмент радіоядра (BLE) — версія HCI, а в режимі налагодження ще й тести несучої та пакетів |

| `exit` | Вийти з оболонки (корисно у вкладених оболонках, як-от `nfc`) |

| `ikey` | Читати, емулювати й записувати ключі iButton |
| `info` | Докладна інформація про пристрій і живлення |
| `input` | Показувати події кнопок, надсилати натискання |

| `led` | Керувати RGB-світлодіодом і підсвічуванням дисплея |

| `log` | Дивитися системний журнал |
| `neofetch` | Інформація про систему, як `neofetch` у Linux |
| `nfc` | Вкладена оболонка NFC: dump, emulate, raw, APDU, scanner |
| `onewire` | Просканувати шину 1-Wire (виводи iButton) |
| `power` | Вимкнення, перезавантаження, перезавантаження в DFU, 5 В / 3,3 В на GPIO |
| `reload_ext_cmds` | Перечитати список зовнішніх команд із SD-карти |
| `rfid` | Читати, записувати, емулювати карти 125 кГц; інструменти RAW |
| `sleep` | Чекати вказаний час, наприклад `sleep 5s` (корисно у скриптах) |
| `start_rpc_session` | Перевести CLI у режим protobuf RPC (використовується qFlipper та застосунками; зазвичай не потрібно) |

| `subghz` | Інструменти Sub-GHz: rx/tx, RAW, декодування, чат |
| `sysctl` | Системні налаштування: режим налагодження, відслідковування купи |
| `top` | Живий список потоків (як `top` у Linux); вихід — <kbd>Ctrl</kbd>+<kbd>C</kbd> |
| `update` | Встановити пакет оновлення, зробити резервну копію / відновити внутрішнє сховище |
| `uptime` | Час із моменту останнього запуску |
| `vibro` | Увімкнути/вимкнути вібромотор |

## Читання журналу {#reading-logs}

1. Підключіться до CLI.
2. Запустіть журналювання на потрібному рівні:

   | Команда | Що показує |
   |---|---|
   | `log` | Поточний рівень із системних налаштувань |
   | `log error` | Лише критичні помилки та важливі повідомлення |
   | `log warn` | Попередження й некритичні помилки, а також `error` |
   | `log info` | Некритичну інформацію, а також `warn` |
   | `log default` | Типовий системний рівень (= `info`) |
   | `log debug` | Налагоджувальну інформацію, а також `info` (впливає на швидкодію) |
   | `log trace` | Системні трасування, а також `debug` (впливає на швидкодію) |

   Команда `log ?` виводить цей список на самому пристрої.
3. Користуйтеся Фліппером — повідомлення з’являються в терміналі.
4. Для припинення натисніть <kbd>Ctrl</kbd>+<kbd>C</kbd>.

## Чат через Sub-GHz

Кілька Фліпперів на одній частоті можуть спілкуватися через CLI.

1. Кожен учасник підключається до CLI свого Фліппера.
2. Виконує `subghz chat <frequency_in_hz> <device>`, наприклад:

   ```
   subghz chat 868150000 0
   ```

   - частота в Гц у межах 299999755–348000000, 386999938–464000000 або 778999847–928000000;
   - пристрій `0` = внутрішній CC1101, `1` = зовнішній модуль CC1101.
3. Наберіть повідомлення й натисніть <kbd>Enter</kbd>.
4. Вихід — <kbd>Ctrl</kbd>+<kbd>C</kbd>.

::: tip Unleashed
Стокова прошивка передає лише на частотах, дозволених у вашому регіоні; Unleashed знімає регіональні обмеження на
передачу. Дотримуйтеся місцевих правил використання радіочастот.
:::

## Довідник команд

### bt

| Команда | Опис |
|---|---|
| `bt hci_info` | Інформація Bluetooth HCI |
| `bt tx_carrier <channel:0-39> <power:0-6>` | *Лише в режимі налагодження.* Запустити тест передачі несучої |
| `bt rx_carrier <channel:0-39>` | *Лише в режимі налагодження.* Запустити тест приймання несучої |
| `bt tx_packet <channel:0-39> <pattern:0-5> <datarate:1-2>` | *Лише в режимі налагодження.* Запустити тест передачі пакетів |
| `bt rx_packet <channel:0-39> <datarate:1-2>` | *Лише в режимі налагодження.* Запустити тест приймання пакетів |

### buzzer

| Команда | Опис |
|---|---|
| `buzzer freq <frequency_in_hz> <duration>` | Відтворити тон |
| `buzzer note <note> <duration>` | Відтворити ноту; `s` означає дієз, наприклад `cs3` = C♯3; бемолі не підтримуються |

Тривалість приймає `ms`, `s`, `m`, `h`, наприклад `buzzer note cs3 500ms`.

### crypto

Шифрує й розшифровує ключами, що зберігаються в захищеному анклаві MCU.

| Команда | Опис |
|---|---|
| `crypto encrypt <key_slot> <iv_hex>` | Зашифрувати текст за AES256-CBC, вивід у hex |
| `crypto decrypt <key_slot> <iv_hex>` | Розшифрувати hex назад у текст |
| `crypto has_key <key_slot>` | Перевірити, чи є в слоті (1–100) ключ |
| `crypto store_key <key_slot> <key_type> <key_size> <key_data_hex>` | **Необоротно!** Записати ключ — видалити його потім неможливо |

- `key_slot`: слоти 1–11 уже заповнені ключами, якими користується прошивка.
- `iv_hex`: 16-байтовий вектор ініціалізації у hex.
- `key_type`: `master`, `simple` або `encrypted`; `key_size`: `128` чи `256`.

### gpio

| Команда | Опис |
|---|---|
| `gpio mode <pin_name> <0/1>` | Перевести вивід на вхід (0) або вихід (1) |
| `gpio set <pin_name> <0/1>` | Задати значення виводу |
| `gpio read <pin_name>` | Прочитати значення виводу |

Назви виводів: `PA7`, `PA6`, `PA4`, `PB3`, `PB2`, `PC3`, `PC1`, `PC0` — див. [розпіновку GPIO](/ua/gpio/pinout).

### ikey

| Команда | Опис |
|---|---|
| `ikey read` | Прочитати ключ iButton |
| `ikey emulate <key_type> <key_data>` | Емулювати ключ |
| `ikey write Dallas <key_data>` | Записати 8 байтів на заготовку, сумісну з Dallas |

Типи ключів і довжина даних (hex): `Dallas` — 8 байтів, `Cyfral` — 2 байти, `Metakom` — 4 байти (має містити
правильну парність).

### info

| Команда | Опис |
|---|---|
| `info device` | Інформація про пристрій (прошивка, апаратна частина, радіостек, …) |
| `info power` | Інформація про систему живлення |
| `info power_debug` | Докладна інформація про живлення |

### input

| Команда | Опис |
|---|---|
| `input dump` | Виводити події кнопок |
| `input send <key> <type>` | Надіслати подію; `key`: `up`, `down`, `left`, `right`, `back`, `ok`; `type`: `press`, `release`, `short`, `long` |

Повне коротке натискання — це три команди, інакше введення відкидається:

```
input send ok press
input send ok short
input send ok release
```

Для довгого натискання замість `short` використовуйте `long`.

### ir

| Команда | Опис |
|---|---|
| `ir rx` | Приймати й декодувати ІЧ-сигнали |
| `ir rx raw` | Приймати у форматі RAW |
| `ir tx <protocol> <address> <command>` | Надіслати команду; адреса й команда у hex |
| `ir tx RAW F:<frequency> DC:<duty_cycle> <sample0> <sample1>...` | Надіслати RAW-дані: частота 10000–56000, коефіцієнт заповнення 0–100, максимум 512 відліків |
| `ir decode <input_file> [<output_file>]` | Декодувати файл із RAW-сигналами |
| `ir universal list <remote_name>` | Перелічити сигнали універсального пульта |
| `ir universal <remote_name> <signal_name>` | Надіслати сигнал з універсального пульта |

Протоколи: `NEC`, `NECext`, `NEC42`, `NEC42ext`, `Samsung32`, `RC6`, `RC5`, `RC5X`, `SIRC`, `SIRC15`, `SIRC20`,
`Kaseikyo`, `RCA`, `Pioneer`.

::: tip Unleashed
Назви універсальних пультів беруться з файлів у `/ext/infrared/assets/`. Unleashed постачає `tv`, `audio`, `ac`,
`projectors`, `fans` і `leds` (у стоковій прошивці їх менше). Щоб побачити припустимі назви сигналів, виконайте
`ir universal list tv`.
:::

### js

| Команда | Опис |
|---|---|
| `js <path>` | Виконати файл JavaScript і вивести його консольний вивід — див. [JavaScript](/ua/dev/js-about) |

### led

| Команда | Опис |
|---|---|
| `led r <0-255>` / `led g <0-255>` / `led b <0-255>` | Яскравість червоної / зеленої / синьої складової світлодіода |
| `led bl <0-255>` | Яскравість підсвічування дисплея (`128` ≈ 50%) |

Для чистого червоного: `led r 255`, `led g 0`, `led b 0`.

### loader

| Команда | Опис |
|---|---|
| `loader list` | Перелічити доступні застосунки |
| `loader open <Application Name> [args]` | Відкрити застосунок за назвою, за потреби з аргументами |
| `loader info` | Показати стан завантажувача застосунків |
| `loader close` | Закрити запущений застосунок |
| `loader signal <signal> [arg_hex]` | Надіслати сигнал із необов’язковим аргументом у hex |

Аргументи з пробілами можна брати в лапки:

```
loader open subghz "/ext/subghz/Some File.sub"
```

### nfc

`nfc` відкриває **вкладену оболонку**. Усередині: `help` / `?` виводить список команд, `<command> -h` показує
подробиці, `exit` виходить.

| Команда | Опис |
|---|---|
| `dump -f <path>` | Зчитати фізичну карту у файл `.nfc`. Параметри: `-k <key>`, `-p <protocol>`, `-t <timeout_ms>` |
| `emulate -f <path>` | Емулювати файл `.nfc` |
| `field` | Увімкнути поле 13,56 МГц; припинити — <kbd>Ctrl</kbd>+<kbd>C</kbd> |
| `scanner` | Перелічити всі протоколи, які підтримує мітка; `-t` показує дерево протоколів |
| `raw -p <protocol> -d <data>` | Надіслати «сирі» байти. Параметри: `-t <timeout>` (у періодах несучої), `-k` не вимикати поле, `-c` додати CRC, `-s` спершу виконати активацію/антиколізію |
| `apdu -d <data> [<data2> ...]` | Надіслати APDU до міток ISO14443-4A/4B або ISO15693-3; `-p 4a`/`4b`/`15` задає протокол примусово |
| `mfu info` | Базова інформація про мітку MIFARE Ultralight |
| `mfu rdbl -b <block>` | Прочитати блок |
| `mfu wrbl -b <block> -d <data>` | Записати 4-байтовий блок |

Протоколи для `dump -p`: `14_3a`, `14_3b`, `14_4a`, `14_4b`, `15` (ISO 15693-3), `felica`, `mfu`, `mfc`, `mfp`,
`des`, `slix`, `st25`, `ntag4` (NTAG 4xx), `t4t` (Type 4 Tag).
Протоколи для `raw -p`: `14a` / `iso14a`, `14b` / `iso14b`, `15`, `felica`.

### rfid

### subghz

| Команда | Опис |
|---|---|
| `subghz chat <frequency> <device>` | Чат з іншими Фліпперами |
| `subghz tx <3-byte_key_hex> <frequency> <te_us> <repeat> <device>` | Передати ключ (Princeton) |
| `subghz rx <frequency> <device>` | Приймати й декодувати |
| `subghz rx_raw <frequency>` | Приймати в RAW |
| `subghz decode_raw <path_to_raw_file>` | Декодувати RAW-файл `.sub` і вивести результати |
| `subghz tx_from_file <path> <repeat> <device>` | Передати збережений файл `.sub` |

Лише в режимі налагодження:

| Команда | Опис |
|---|---|
| `subghz tx_carrier <frequency>` | Передавати немодульовану несучу |
| `subghz rx_carrier <frequency>` | Приймати несучу (RSSI) |
| `subghz encrypt_keeloq <decrypted_file> <encrypted_file> <iv_16_bytes_hex>` | Зашифрувати файл виробничих ключів KeeLoq |
| `subghz encrypt_raw <decrypted_file> <encrypted_file> <iv_16_bytes_hex>` | Зашифрувати RAW-дані |

`device`: `0` — внутрішній CC1101, `1` — зовнішній CC1101 ([зовнішній модуль](/ua/subghz/external-cc1101)).
`te_us` — базова довжина імпульсу в мкс.

Приклад — передати збережений файл тричі через внутрішнє радіо:

```
subghz tx_from_file /ext/subghz/gate.sub 3 0
```
