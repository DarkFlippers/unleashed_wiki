# Link ufficiali di Unleashed

Queste sono le risorse **ufficiali** di Unleashed Firmware, prese dal
[ReadMe](https://github.com/DarkFlippers/unleashed-firmware/blob/dev/ReadMe.md) del progetto.

::: warning Usa solo i link ufficiali
`DarkFlippers/unleashed-firmware` su GitHub è l'**unica** casa ufficiale del progetto. Non esistono versioni a
pagamento, "premium" o closed source. Se qualcuno dichiara di far parte del team e ti offre qualcosa del genere, è un
truffatore: bloccalo.
:::
