# App T5577

L'app **T5577** (di @mishamyte, fornita con Unleashed) lavora su una vergine T5577 / ATA5577 a **livello di blocco** —
sul silicio, non sulla tessera che il chip finge di essere. Può leggere i blocchi del chip e salvarli, modificare
qualunque blocco o comporne la parola di configurazione, riscrivere un dump salvato, verificare quali blocchi
accettano le scritture, eseguire il wipe del tag, cancellarne la password e recuperare una password via radio
ascoltando un lettore o un cloner mentre scrive un tag.

La apri da `Main Menu → Apps → RFID → T5577` (installata come `/ext/apps/RFID/t5577.fap`). Anche l'app RFID 125 kHz
la avvia quando apri un file `.t5577` da **Saved**.

::: tip Unleashed
Questa app non esiste nel firmware di serie. Clear Password e il wipe del T5577 si trovavano in precedenza in
**Extra Actions** dell'app RFID 125 kHz; ora risiedono qui.
:::

## Premessa: cosa contiene un T5577

| Pagina / blocco | Contenuto |
|---|---|
| Pagina 0, blocco 0 | **Configurazione**: modulazione, bit rate, numero di blocchi dati inviati (max block), bit della password e altri flag |
| Pagina 0, blocchi 1–6 | Dati — il frame della tessera emulata |
| Pagina 0, blocco 7 | Archivio della password (o dati ordinari quando non è attiva alcuna password) |
| Pagina 1, blocco 0 | Copia della configurazione |
| Pagina 1, blocchi 1–3 | Dati di tracciabilità impostati in fabbrica (i blocchi 1 e 2 sono bloccati sui chip autentici) |

## Menu principale

| Voce | Funzione |
|---|---|
| **Read Tag** | Legge tutti i blocchi in un dump |
| **Test Tag** | Scopre quali blocchi accettano le scritture (prima un backup, poi il ripristino) |
| **Saved** | Apre un dump `.t5577` salvato |
| **Wipe Tag** | Riporta il chip allo stato vergine |
| **Clear Password** | Rimuove una password: prima la tua parola, poi il dizionario |
| **Sniff Password** | Ascolta un lettore / cloner e decodifica i comandi che invia |
| **Passwords** | Mostra i dizionari e gestisce le tue parole |

## Read Tag

1. `T5577 → Read Tag`. Appoggia il tag sul retro del Flipper e tienilo fermo (*Finding tag*, poi `P0 block N…`).
2. La schermata dei risultati **T5577 read** mostra `Block 0: XXXXXXXX` e un riepilogo come `RF/64, password set,
   inverted`. Pulsanti: **Save**, **Info**, **Retry**.
   - **Info** mostra la configurazione decodificata (Modulation, Bit rate, Max block, flag PWD/AOR/ST/XM/POR,
     Password) e tutti i blocchi di Page 0 e Page 1; i blocchi non letti sono indicati da trattini.
   - **Save** chiede *Name the dump* e salva `/ext/lfrfid/<name>.t5577`.
3. **Read in part** significa che il tag ha smesso di rispondere a metà strada — viene indicato il blocco in cui è
   rimasto in silenzio. Posizionalo meglio e riprova.
4. **Nothing found** — *Hold the tag still, or it needs a password*. Pulsanti **No pass** (nuovo tentativo normale) e
   **Password**.

::: danger Le letture con password possono danneggiare un tag non protetto
Scegliendo **Password** compare *Only if it is protected — A password read writes block 0 of a tag that has no password
set*. Il frame di lettura con password ha la stessa lunghezza di una scrittura: inviato a un tag che **non** ha
password, scrive la tua "password" nel blocco 0 e il tag smette di essere leggibile come qualunque cosa. Un tag tenuto
male sembra esattamente un tag protetto, quindi riprova sempre prima la lettura normale. Se in seguito l'app scopre che
il tag non voleva alcuna password, avverte *Tag wants no password — That frame wrote block 0. Check it below, and wipe
the tag if it reads wrong*.
:::

## Dump salvati

`T5577 → Saved` elenca i file `.t5577`. Un dump apre un menu:

| Voce | Azione |
|---|---|
| **Info** | Configurazione decodificata e tutti i blocchi |
| **Write to Tag** | Riscrive il dump sul tag (chiede *Write to tag* indicando il numero di blocchi) |
| **Edit** | Modifica i blocchi |
| **Rename** / **Delete** | Gestisce il file (un dump può contenere la password del tag — eliminalo se non deve restare sulla tessera) |

### Write to Tag

Scrive solo i blocchi che il dump ha effettivamente letto, nell'ordine usato da Proxmark3: pagina 0 blocchi 1–7,
pagina 1 blocchi 1–3, **blocco 0 per ultimo**. Un blocco 0 pari a zero non viene mai scritto. Ogni blocco viene poi
riletto. Tra i risultati: **Written!**, **Not written**, *Lost the tag at P0 block N*, *P0 block N differs*, *Tag
wants a password this dump has not* oppure *P1 trace unchanged* (i chip autentici rifiutano di modificare i blocchi di
tracciabilità — comportamento previsto).

Se il blocco 0 descrive una configurazione che il Flipper non riesce a decodificare, prima della scrittura vieni
avvisato che *Nothing will read back*.

### Edit

**Edit blocks** elenca ogni blocco con il suo valore. Seleziona un blocco per digitare una nuova parola a 32 bit. Il
**blocco 0** apre un editor di configurazione con campi nominati:

- **Modulation**: Direct, PSK1, PSK2, PSK3, FSK1, FSK2, FSK1a, FSK2a, ASK/MC, Biphase, Diphase
- **Bit rate**: RF/8, RF/16, RF/32, RF/40, RF/50, RF/64, RF/100, RF/128
- **Data blocks** (max block), **Password bit** (On/Off) e **Word** — l'esadecimale grezzo.

All'uscita, il messaggio *Save changes — Write the edited blocks back to the file* chiede se salvare. Rifiutando, la
modifica viene scartata anche dalla memoria, così non può finire su un tag per sbaglio.

## Test Tag

Individua quali dei blocchi 1–7 della pagina 0 accettano effettivamente una scrittura. Chiede *Do not move the tag — A
backup is saved, then every block is written and put back*.

- Il dump completo viene letto e salvato in `/ext/lfrfid/t5577/T5577_before_test.t5577` prima di qualunque scrittura.
- Per ogni blocco viene invertito un bit, il blocco viene riletto e poi l'originale viene riscritto e verificato.
- Risultati: **Full T5577** (tutto scrivibile), **Nothing writeable**, *Stopped at block N*, *Lost tag at block N —
  Check it, then retry*, *Block N is not back* (ripristinalo dal backup), **Tag has a password — Not supported yet**.
- Se un test precedente ha lasciato un tag modificato, l'app avverte con *Unfinished test* prima di sovrascrivere il
  backup.

## Wipe Tag

Confermando *Wipe T5577 — Erases all data. The tag stops working as a key. Hold still while running* → **Wipe**. I
blocchi dati vengono azzerati e viene scritta una configurazione predefinita, poi il risultato viene verificato con una
rilettura.

- **Wiped!** — operazione completata; scrivi una nuova chiave dall'app RFID 125 kHz.
- **Not wiped** — *No answer. Protected? Try Clear Password*, *The tag answered, but not as wiped* oppure *Could not
  check what the tag holds*.

Il wipe **non** rimuove la password.

## Clear Password

1. `Clear Password` chiede *Password to try first* — inserisci la password del tag se la conosci (oppure lascia il
   valore predefinito).
2. Conferma *Apply tag to Flipper's back and don't move it while it runs* → **Start**.
3. L'app verifica prima se il tag è davvero protetto, poi prova la tua password, quindi il tuo **dizionario utente** e
   infine il **dizionario di sistema** (`Pass N of M`). Viene scritto solo il blocco 0, con il bit della password
   azzerato — la stessa singola scrittura che usa Proxmark3.
4. Risultati: **Cleared!** (*Opened by this password* — con **Save** per aggiungere la parola al tuo elenco), *The tag
   was asking for no password*, **Not cleared** (*No password matched, or no tag answered*) oppure errori relativi al
   dizionario o alla scheda SD.

Dopo la cancellazione il blocco 7 conserva il vecchio valore della password — viene rimosso solo il bit di
protezione.

## Sniff Password

Recupera una password **ascoltando** mentre un lettore o un cloner dialoga con un tag. Il Flipper non trasmette nulla e
non alimenta il campo — si può puntare senza rischi su hardware che non è tuo.

1. `Sniff Password`. Lo schermo mostra *Listening* / *Hold on the cloner* e una traccia in tempo reale.
2. Appoggia il retro del Flipper sul cloner o sul lettore, dove andrebbe il tag, e lascia che il dispositivo esegua la
   sua scrittura/lettura.
3. La cattura termina dopo un comando completo seguito dal silenzio; la schermata dei risultati mostra ciò che è stato
   udito:
   - **Password** — *The cloner sent it* (è stata udita una lettura/scrittura protetta da password);
   - **New password** — *Written to block 7* (il cloner stava installando una password);
   - **Maybe a password** — il frame a 38 bit potrebbe essere una lettura con password o una scrittura; entrambe le
     interpretazioni sono sotto **More**;
   - **No password** / **Commands heard** — *None of them carried a password*;
   - **Too much noise**, **Can't decode**, **Nothing heard**.
4. **More** elenca ogni comando decodificato (Reset, Read/Write con o senza password, con blocco e dati). **Save**
   memorizza una password trovata nel tuo dizionario utente (un'interpretazione dedotta dai frame vicini chiede prima
   *Save a deduction?*).

## Passwords

`T5577 Passwords` mostra **System dict: N** e **User dict: N** con **Add** e **List** (seleziona una parola per
eliminarla).

| File | Contenuto |
|---|---|
| `/ext/lfrfid/assets/t5577_dict.lfrfid` | Elenco di sistema (password di Proxmark3, sovrascritto agli aggiornamenti del firmware) |
| `/ext/lfrfid/assets/t5577_dict_user.lfrfid` | Le tue parole — provate per prime da Clear Password, conservate tra gli aggiornamenti |
