# Snake

The classic Snake game from the official firmware, shipped with Unleashed as a system app.

`Main Menu → Apps → Games → Snake Game`

![Snake at the start of a game: the snake on the left of the playing field and the fruit in the middle](/screens/apps/snake.png)

## How to play

1. Start the game. The snake moves on its own.
2. Steer with <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd>. Eat the fruit to grow; each fruit raises the score.
3. Don't run into the wall or into your own tail. The snake speeds up as it grows.
4. On `Game Over` the screen shows your `Score`. Press <kbd>OK</kbd> to start a new game.
5. <kbd>Back</kbd> quits at any time.

::: tip Unleashed
More games are in the [app packs](/apps/catalog#base-and-extra-packs), and Dummy Mode on the desktop has its own
mini-games: press or hold any arrow button (see [Desktop](/start/desktop)).
:::
