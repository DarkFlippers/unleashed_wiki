# Snake

Le classique jeu du serpent issu du firmware officiel, fourni avec Unleashed comme application système.

`Main Menu → Apps → Games → Snake Game`

![Snake au début d'une partie : le serpent à gauche du terrain de jeu et le fruit au milieu](/screens/apps/snake.png)

## Comment jouer

1. Lancez le jeu. Le serpent avance tout seul.
2. Dirigez-le avec <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd>. Mangez les fruits pour grandir ; chaque fruit
   augmente le score.
3. Ne foncez pas dans le mur ni dans votre propre queue. Le serpent accélère à mesure qu'il grandit.
4. À l'écran `Game Over`, votre `Score` s'affiche. Appuyez sur <kbd>OK</kbd> pour commencer une nouvelle partie.
5. <kbd>Back</kbd> quitte à tout moment.

::: tip Unleashed
D'autres jeux se trouvent dans les [packs d'applications](/fr/apps/catalog#base-and-extra-packs), et le mode Dummy du
bureau a ses propres mini-jeux : appuyez sur n'importe quelle flèche, ou maintenez-la (voir
[Bureau](/fr/start/desktop)).
:::
