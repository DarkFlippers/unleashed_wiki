# Application T5577

L’application **T5577** (de @mishamyte, fournie avec Unleashed) travaille sur un support vierge T5577 / ATA5577 au
**niveau des blocs** — c’est-à-dire sur la puce elle-même, pas sur la carte qu’elle imite. Elle sait lire les blocs de
la puce et les enregistrer, modifier n’importe quel bloc ou composer son mot de configuration, réécrire un dump
enregistré, tester quels blocs acceptent l’écriture, effacer le tag, supprimer son mot de passe, et récupérer un mot de
passe « en l’air » en écoutant un lecteur ou un cloneur en train d’écrire un tag.

Ouvrez-la depuis `Main Menu → Apps → RFID → T5577` (installée sous `/ext/apps/RFID/t5577.fap`). L’application 125 kHz
RFID la lance également quand vous ouvrez un fichier `.t5577` depuis **Saved**.

::: tip Unleashed
Cette application n’existe pas dans le firmware d’origine. Clear Password et l’effacement du T5577 se trouvaient
auparavant dans les **Extra Actions** de l’application 125 kHz RFID ; ils résident désormais ici.
:::

## Contexte : ce que contient un T5577

| Page / bloc | Contenu |
|---|---|
| Page 0, bloc 0 | **Configuration** : modulation, débit binaire, nombre de blocs de données émis (max block), bit de mot de passe et autres indicateurs |
| Page 0, blocs 1–6 | Données — la trame de la carte émulée |
| Page 0, bloc 7 | Emplacement du mot de passe (ou données ordinaires si aucun mot de passe n’est activé) |
| Page 1, bloc 0 | Copie de la configuration |
| Page 1, blocs 1–3 | Données de traçabilité issues de la fabrication (blocs 1–2 verrouillés sur les puces authentiques) |

## Menu principal

| Élément | Rôle |
|---|---|
| **Read Tag** | Lire tous les blocs dans un dump |
| **Test Tag** | Déterminer quels blocs acceptent l’écriture (sauvegarde d’abord, puis restauration) |
| **Saved** | Ouvrir un dump `.t5577` enregistré |
| **Wipe Tag** | Réinitialiser la puce à l’état vierge |
| **Clear Password** | Supprimer un mot de passe : votre mot d’abord, puis le dictionnaire |
| **Sniff Password** | Écouter un lecteur / cloneur et décoder les commandes qu’il envoie |
| **Passwords** | Consulter les dictionnaires et gérer vos propres mots |

## Read Tag

1. `T5577 → Read Tag`. Posez le tag sur le dos du Flipper et ne bougez plus (*Finding tag*, puis `P0 block N…`).
2. L’écran de résultat **T5577 read** affiche `Block 0: XXXXXXXX` et un résumé du type `RF/64, password set, inverted`.
   Boutons : **Save**, **Info**, **Retry**.
   - **Info** affiche la configuration décodée (Modulation, Bit rate, Max block, indicateurs PWD/AOR/ST/XM/POR,
     Password) et tous les blocs des pages 0 et 1 ; les blocs non lus sont représentés par des tirets.
   - **Save** demande *Name the dump* et enregistre `/ext/lfrfid/<name>.t5577`.
3. **Read in part** signifie que le tag a cessé de répondre en cours de route — le bloc où il s’est tu est indiqué.
   Tenez-le mieux et réessayez.
4. **Nothing found** — *Hold the tag still, or it needs a password*. Boutons **No pass** (réessayer sans mot de passe)
   et **Password**.

::: danger Une lecture avec mot de passe peut endommager un tag non protégé
Choisir **Password** affiche *Only if it is protected — A password read writes block 0 of a tag that has no password
set*. La trame de lecture avec mot de passe a la même longueur qu’une écriture : envoyée à un tag qui n’a **aucun** mot
de passe, elle écrit votre « mot de passe » dans le bloc 0 et le tag ne se lit plus du tout. Un tag mal positionné
ressemble exactement à un tag protégé : réessayez donc toujours d’abord sans mot de passe. Si l’application découvre
ensuite que le tag ne voulait pas de mot de passe, elle avertit *Tag wants no password — That frame wrote block 0. Check
it below, and wipe the tag if it reads wrong*.
:::

## Dumps enregistrés

`T5577 → Saved` liste les fichiers `.t5577`. Un dump ouvre un menu :

| Élément | Action |
|---|---|
| **Info** | Configuration décodée et tous les blocs |
| **Write to Tag** | Réécrire le dump (demande *Write to tag* avec le nombre de blocs) |
| **Edit** | Modifier les blocs |
| **Rename** / **Delete** | Gérer le fichier (un dump peut contenir le mot de passe du tag — supprimez-le s’il ne doit pas rester sur la carte) |

### Write to Tag

N’écrit que les blocs réellement lus par le dump, dans l’ordre utilisé par le Proxmark3 : page 0 blocs 1–7, page 1
blocs 1–3, **bloc 0 en dernier**. Un bloc 0 à zéro n’est jamais écrit. Chaque bloc est ensuite relu. Les résultats
possibles sont **Written!**, **Not written**, *Lost the tag at P0 block N*, *P0 block N differs*, *Tag wants a password
this dump has not*, ou *P1 trace unchanged* (les puces authentiques refusent de modifier leurs blocs de traçabilité —
c’est normal).

Si le bloc 0 décrit une configuration que le Flipper ne sait pas décoder, vous êtes averti avant l’écriture que
*Nothing will read back*.

### Edit

**Edit blocks** liste chaque bloc avec sa valeur. Sélectionnez un bloc pour saisir un nouveau mot de 32 bits. Le
**bloc 0** ouvre un éditeur de configuration à champs nommés :

- **Modulation** : Direct, PSK1, PSK2, PSK3, FSK1, FSK2, FSK1a, FSK2a, ASK/MC, Biphase, Diphase
- **Bit rate** : RF/8, RF/16, RF/32, RF/40, RF/50, RF/64, RF/100, RF/128
- **Data blocks** (max block), **Password bit** (On/Off) et **Word** — l’hexadécimal brut.

En quittant, *Save changes — Write the edited blocks back to the file* demande si vous voulez enregistrer. Refuser écarte
aussi la modification de la mémoire, pour qu’elle ne puisse pas atteindre un tag par accident.

## Test Tag

Détermine lesquels des blocs 1–7 de la page 0 acceptent réellement une écriture. Demande *Do not move the tag — A
backup is saved, then every block is written and put back*.

- Le dump complet est lu et enregistré sous `/ext/lfrfid/t5577/T5577_before_test.t5577` avant toute écriture.
- Un bit est inversé dans chaque bloc, le bloc est relu, puis la valeur d’origine est réécrite et vérifiée.
- Résultats : **Full T5577** (tout est inscriptible), **Nothing writeable**, *Stopped at block N*, *Lost tag at block
  N — Check it, then retry*, *Block N is not back* (restaurez-le depuis la sauvegarde), **Tag has a password — Not
  supported yet**.
- Si un test précédent a laissé un tag modifié, l’application avertit *Unfinished test* avant d’écraser la sauvegarde.

## Wipe Tag

Confirmez *Wipe T5577 — Erases all data. The tag stops working as a key. Hold still while running* → **Wipe**. Les
blocs de données sont mis à zéro et une configuration par défaut est écrite, puis le résultat est vérifié par
relecture.

- **Wiped!** — c’est fait ; écrivez une nouvelle clé depuis l’application 125 kHz RFID.
- **Not wiped** — *No answer. Protected? Try Clear Password*, *The tag answered, but not as wiped*, ou *Could not check
  what the tag holds*.

L’effacement ne supprime **pas** de mot de passe.

## Clear Password

1. `Clear Password` demande *Password to try first* — saisissez le mot de passe du tag si vous le connaissez (ou laissez
   la valeur par défaut).
2. Confirmez *Apply tag to Flipper’s back and don’t move it while it runs* → **Start**.
3. L’application vérifie d’abord si le tag n’est pas tout simplement non protégé, puis essaie votre mot de passe, puis
   votre **dictionnaire utilisateur**, puis le **dictionnaire système** (`Pass N of M`). Seul le bloc 0 est écrit, avec
   le bit de mot de passe effacé — exactement la même écriture unique que celle du Proxmark3.
4. Résultats : **Cleared!** (*Opened by this password* — avec **Save** pour ajouter le mot à votre liste), *The tag was
   asking for no password*, **Not cleared** (*No password matched, or no tag answered*), ou des erreurs de
   dictionnaire / de carte SD.

Après la suppression, le bloc 7 conserve l’ancienne valeur du mot de passe — seul le bit de protection est retiré.

## Sniff Password

Récupère un mot de passe en **écoutant** un lecteur ou un cloneur dialoguer avec un tag. Le Flipper n’émet rien et
n’alimente pas le champ — sans risque pour du matériel qui ne vous appartient pas.

1. `Sniff Password`. L’écran affiche *Listening* / *Hold on the cloner* et une trace en direct.
2. Posez le dos du Flipper sur le cloneur ou le lecteur, à l’emplacement où irait le tag, et laissez l’appareil faire
   son écriture/lecture.
3. La capture s’arrête après une commande complète suivie d’un silence ; l’écran de résultat indique ce qui a été
   entendu :
   - **Password** — *The cloner sent it* (une lecture/écriture protégée par mot de passe a été entendue) ;
   - **New password** — *Written to block 7* (le cloneur était en train d’installer un mot de passe) ;
   - **Maybe a password** — la trame de 38 bits peut être une lecture avec mot de passe ou une écriture ; les deux
     interprétations figurent sous **More** ;
   - **No password** / **Commands heard** — *None of them carried a password* ;
   - **Too much noise**, **Can’t decode**, **Nothing heard**.
4. **More** liste chaque commande décodée (Reset, Read/Write avec ou sans mot de passe, avec bloc et données). **Save**
   enregistre un mot de passe trouvé dans votre dictionnaire utilisateur (une interprétation déduite des trames
   voisines demande d’abord *Save a deduction?*).

## Passwords

`T5577 Passwords` affiche **System dict: N** et **User dict: N** avec **Add** et **List** (sélectionnez un mot pour le
supprimer).

| Fichier | Contenu |
|---|---|
| `/ext/lfrfid/assets/t5577_dict.lfrfid` | Liste système (mots de passe du Proxmark3, écrasée à chaque mise à jour du firmware) |
| `/ext/lfrfid/assets/t5577_dict_user.lfrfid` | Vos mots — essayés en premier par Clear Password, conservés d’une mise à jour à l’autre |
