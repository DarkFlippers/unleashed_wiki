# Liens officiels d'Unleashed

Voici les ressources **de référence** du firmware Unleashed, reprises du
[ReadMe](https://github.com/DarkFlippers/unleashed-firmware/blob/dev/ReadMe.md) du projet.

::: warning N'utilisez que les liens officiels
`DarkFlippers/unleashed-firmware` sur GitHub est le **seul** dépôt officiel du projet. Il n'existe aucune version
payante, « premium » ou à code fermé. Si quelqu'un prétend faire partie de l'équipe et vous propose ce genre de chose,
c'est un escroc : bloquez-le.
:::
