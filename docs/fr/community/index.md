# Communauté

Le firmware Unleashed et ce wiki existent grâce à une vaste communauté de développeurs, de chercheurs et de
passionnés. Cette section est la partie « humaine » du wiki : qui a réalisé tout cela, où trouver les ressources
officielles du projet, et comment vous pouvez contribuer à améliorer les pages que vous lisez.

## À propos de ce wiki

Il s'agit d'un projet communautaire. Il n'est **pas affilié à Flipper Devices** et ce n'est **pas** une ressource
officielle d'Unleashed : c'est un wiki de guides pratiques rédigé en lisant le code source du firmware, la
documentation officielle et les articles de recherche des personnes créditées ici.

Le wiki est **orienté Unleashed** : chaque fois que le fork Unleashed se comporte différemment du firmware d'origine
(protocoles supplémentaires, menus supplémentaires, applications supplémentaires), la différence est signalée
explicitement. Les connaissances propres au Flipper Zero d'origine restent couvertes intégralement.

::: tip Chaque page crédite ses sources
Toute page construite à partir de l'article, du message de canal, de la documentation ou du code de firmware de
quelqu'un porte un bloc de crédits en bas de page qui liste les originaux exacts. Si vous estimez qu'un crédit est
erroné ou manquant, voyez [Contribuer](/fr/community/contributing).
:::

::: warning Pour un usage légal uniquement
Tout ce qui figure ici est destiné à travailler sur **vos propres** appareils et à la recherche légale. Le contrôle
d'accès, les codes tournants et les clés de voiture sont traités comme un sujet technique, et non comme une invitation
à attaquer des systèmes qui ne vous appartiennent pas.
:::
