# Snake

Klasična igra Snake iz službenog firmvera, uključena u Unleashed kao sistemska aplikacija.

`Main Menu → Apps → Games → Snake Game`

![Snake na početku igre: zmija s lijeve strane polja za igru i voćka u sredini](/screens/apps/snake.png)

## Kako igrati

1. Pokrenite igru. Zmija se kreće samostalno.
2. Upravljajte tipkama <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd>. Pojedite voćku kako biste rasli; svaka voćka povećava rezultat.
3. Nemojte udariti u zid niti u vlastiti rep. Zmija se ubrzava kako raste.
4. Na zaslonu `Game Over` prikazuje se vaš `Score`. Pritisnite <kbd>OK</kbd> za početak nove igre.
5. Tipka <kbd>Back</kbd> izlazi iz igre u bilo kojem trenutku.

::: tip Unleashed
Više igara nalazi se u [paketima aplikacija](/hr/apps/catalog#base-and-extra-packs), a Dummy Mode na radnoj površini ima vlastite mini-igre: pritisnite ili držite bilo koju tipku sa strelicom (pogledajte [Radna površina](/hr/start/desktop)).
:::
