# Aplikacija T5577

Aplikacija **T5577** (autor @mishamyte, isporučuje se uz Unleashed) radi s praznom karticom T5577 / ATA5577 na **razini blokova** —
sa samim silicijem, a ne s karticom koju oponaša. Može pročitati blokove čipa i spremiti ih, urediti bilo koji blok ili sastaviti njegovu
konfiguracijsku riječ, zapisati spremljeni ispis natrag, ispitati koji blokovi prihvaćaju pisanje, obrisati oznaku, ukloniti njezinu lozinku te
oporaviti lozinku iz etera prisluškivanjem čitača ili klonera dok piše na oznaku.

Otvorite je iz `Main Menu → Apps → RFID → T5577` (instalirana kao `/ext/apps/RFID/t5577.fap`). Aplikacija 125 kHz RFID također je
pokreće kada otvorite `.t5577` datoteku iz **Saved**.

::: tip Unleashed
Ova aplikacija ne postoji u tvorničkom firmveru. Clear Password i brisanje T5577 čipova nekada su se nalazili u izborniku
**Extra Actions** aplikacije 125 kHz RFID; sada se nalaze ovdje.
:::

## Pozadina: što je u čipu T5577

| Stranica / blok | Sadržaj |
|---|---|
| Page 0, block 0 | **Konfiguracija**: modulacija, brzina prijenosa bitova, broj poslanih podatkovnih blokova (max block), bit lozinke i ostale zastavice |
| Page 0, blocks 1–6 | Podaci — okvir (frame) emulirane kartice |
| Page 0, block 7 | Pohrana lozinke (ili obični podaci kada lozinka nije omogućena) |
| Page 1, block 0 | Kopija konfiguracije |
| Page 1, blocks 1–3 | Podaci o sljedivosti iz proizvodnje (blokovi 1–2 zaključani na izvornim čipovima) |

## Glavni izbornik

| Stavka | Što radi |
|---|---|
| **Read Tag** | Čitanje svih blokova u ispis (dump) |
| **Test Tag** | Otkrivanje koji blokovi prihvaćaju pisanje (najprije sigurnosna kopija, zatim vraćanje) |
| **Saved** | Otvaranje spremljenog `.t5577` ispisa |
| **Wipe Tag** | Vraćanje čipa na prazno stanje |
| **Clear Password** | Uklanjanje lozinke: najprije vaša riječ, zatim rječnik |
| **Sniff Password** | Prisluškivanje čitača / klonera i dekodiranje naredbi koje šalje |
| **Passwords** | Pregled rječnika i upravljanje vlastitim riječima |

## Read Tag

1. `T5577 → Read Tag`. Postavite oznaku na stražnju stranu Flippera i držite mirno (*Finding tag*, zatim `P0 block N…`).
2. Zaslon rezultata **T5577 read** prikazuje `Block 0: XXXXXXXX` i sažetak poput `RF/64, password set, inverted`.
   Tipke: **Save**, **Info**, **Retry**.
   - **Info** prikazuje dekodiranu konfiguraciju (Modulation, Bit rate, Max block, zastavice PWD/AOR/ST/XM/POR, Password) i
     sve blokove stranica Page 0 i Page 1; blokovi koji nisu pročitani prikazani su crticama.
   - **Save** pita *Name the dump* i sprema `/ext/lfrfid/<name>.t5577`.
3. **Read in part** znači da je oznaka prestala odgovarati na pola puta — naveden je blok kod kojeg je utihnula. Držite je bolje i
   pokušajte ponovno.
4. **Nothing found** — *Hold the tag still, or it needs a password*. Tipke **No pass** (ponovno obično čitanje) i
   **Password**.

::: danger Čitanje s lozinkom može oštetiti nezaštićenu oznaku
Odabirom **Password** prikazuje se *Only if it is protected — A password read writes block 0 of a tag that has no password
set*. Okvir za čitanje s lozinkom jednake je duljine kao i pisanje: pošalje li se oznaci koja **nema** lozinku, upisuje vašu
„lozinku“ u blok 0 i oznaka se više ne očitava ni kao što. Loše držana oznaka izgleda potpuno jednako kao zaštićena, stoga
uvijek najprije pokušajte obično čitanje. Ako aplikacija kasnije utvrdi da oznaka nije tražila lozinku, upozorit će *Tag wants no password — That
frame wrote block 0. Check it below, and wipe the tag if it reads wrong*.
:::

## Spremljeni ispisi (Saved dumps)

`T5577 → Saved` prikazuje popis `.t5577` datoteka. Odabir ispisa otvara izbornik:

| Stavka | Radnja |
|---|---|
| **Info** | Dekodirana konfiguracija i svi blokovi |
| **Write to Tag** | Zapisivanje ispisa natrag (pita *Write to tag* s brojem blokova) |
| **Edit** | Uređivanje blokova |
| **Rename** / **Delete** | Upravljanje datotekom (ispis može sadržavati lozinku oznake — obrišite ga ako ne bi trebao ostati na kartici) |

### Write to Tag

Zapisuje samo blokove koje je ispis doista pročitao, redoslijedom koji koristi Proxmark3: stranica 0 blokovi 1–7, stranica 1 blokovi 1–3,
**blok 0 na kraju**. Nulti blok 0 nikada se ne zapisuje. Svaki se blok nakon toga ponovno očitava. Rezultati uključuju **Written!**,
**Not written**, *Lost the tag at P0 block N*, *P0 block N differs*, *Tag wants a password this dump has not* ili
*P1 trace unchanged* (izvorni čipovi odbijaju promijeniti svoje blokove sljedivosti — očekivano).

Ako blok 0 opisuje konfiguraciju koju Flipper ne može dekodirati, prije zapisivanja dobit ćete upozorenje da *Nothing will read
back*.

### Edit

**Edit blocks** prikazuje svaki blok s njegovom vrijednošću. Odaberite blok za upis nove 32-bitne riječi. **Block 0** otvara
uređivač konfiguracije s imenovanim poljima:

- **Modulation**: Direct, PSK1, PSK2, PSK3, FSK1, FSK2, FSK1a, FSK2a, ASK/MC, Biphase, Diphase
- **Bit rate**: RF/8, RF/16, RF/32, RF/40, RF/50, RF/64, RF/100, RF/128
- **Data blocks** (max block), **Password bit** (On/Off) i **Word** — sirova heksadekadska vrijednost.

Pri izlasku *Save changes — Write the edited blocks back to the file* pita želite li spremiti. Odbijanjem se
uređivanje odbacuje i iz memorije, tako da ne može slučajno dospjeti na oznaku.

## Test Tag

Otkriva koji od blokova 1–7 na stranici 0 doista prihvaćaju pisanje. Pita *Do not move the tag — A backup is saved, then every block
is written and put back*.

- Prije bilo kakvog pisanja očitava se cijeli ispis i sprema kao `/ext/lfrfid/t5577/T5577_before_test.t5577`.
- Svakom bloku preokrene se jedan bit, zatim se ponovno pročita, a izvorna se vrijednost vraća i provjerava.
- Rezultati: **Full T5577** (u sve je moguće pisati), **Nothing writeable**, *Stopped at block N*, *Lost tag at block N —
  Check it, then retry*, *Block N is not back* (vratite ga iz sigurnosne kopije), **Tag has a password — Not supported yet**.
- Ako je prethodni test ostavio oznaku izmijenjenom, aplikacija upozorava *Unfinished test* prije prepisivanja sigurnosne kopije.

## Wipe Tag

Potvrdite *Wipe T5577 — Erases all data. The tag stops working as a key. Hold still while running* → **Wipe**. Podatkovni
blokovi postavljaju se na nule i zapisuje se zadana konfiguracija, zatim se rezultat provjerava ponovnim čitanjem.

- **Wiped!** — gotovo; zapišite novi ključ iz aplikacije 125 kHz RFID.
- **Not wiped** — *No answer. Protected? Try Clear Password*, *The tag answered, but not as wiped* ili *Could not check
  what the tag holds*.

Brisanje **ne** uklanja lozinku.

## Clear Password

1. `Clear Password` pita *Password to try first* — unesite lozinku oznake ako je znate (ili ostavite zadanu vrijednost).
2. Potvrdite *Apply tag to Flipper's back and don't move it while it runs* → **Start**.
3. Aplikacija najprije provjerava je li oznaka uopće nezaštićena, zatim isprobava vašu lozinku, potom vaš **korisnički rječnik**,
   pa **sistemski rječnik** (`Pass N of M`). Zapisuje se samo blok 0, s očišćenim bitom lozinke — isto
   jednostruko pisanje koje koristi Proxmark3.
4. Rezultati: **Cleared!** (*Opened by this password* — uz **Save** za dodavanje riječi na vaš popis), *The tag was asking
   for no password*, **Not cleared** (*No password matched, or no tag answered*) ili pogreške rječnika/SD kartice.

Blok 7 nakon čišćenja zadržava staru vrijednost lozinke — uklanja se samo bit zaštite.

## Sniff Password

Oporavlja lozinku **prisluškivanjem** dok čitač ili kloner komunicira s oznakom. Flipper ništa ne odašilje i ne
pobuđuje polje — siguran je za usmjeravanje prema hardveru koji nije vaš.

1. `Sniff Password`. Zaslon prikazuje *Listening* / *Hold on the cloner* i trag uživo.
2. Prislonite stražnju stranu Flippera uz kloner ili čitač, na mjesto gdje bi išla oznaka, i pustite uređaj da obavi pisanje/čitanje.
3. Snimanje završava nakon potpune naredbe i tišine; zaslon rezultata prikazuje što je uhvaćeno:
   - **Password** — *The cloner sent it* (uhvaćeno je čitanje/pisanje zaštićeno lozinkom);
   - **New password** — *Written to block 7* (kloner je postavljao lozinku);
   - **Maybe a password** — 38-bitni okvir mogao bi biti čitanje s lozinkom ili pisanje; oba su tumačenja pod **More**;
   - **No password** / **Commands heard** — *None of them carried a password*;
   - **Too much noise**, **Can't decode**, **Nothing heard**.
4. **More** prikazuje popis svih dekodiranih naredbi (Reset, Read/Write sa ili bez lozinke, s blokom i podacima). **Save**
   sprema pronađenu lozinku u vaš korisnički rječnik (tumačenje izvedeno iz susjednih okvira najprije pita *Save a
   deduction?*).

## Passwords

`T5577 Passwords` prikazuje **System dict: N** i **User dict: N** uz **Add** i **List** (odaberite riječ za brisanje).

| Datoteka | Sadržaj |
|---|---|
| `/ext/lfrfid/assets/t5577_dict.lfrfid` | Sistemski popis (lozinke za Proxmark3, prepisuje se pri ažuriranju firmvera) |
| `/ext/lfrfid/assets/t5577_dict_user.lfrfid` | Vaše riječi — Clear Password ih isprobava prve, čuvaju se kroz ažuriranja |
