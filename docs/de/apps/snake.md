# Snake

Das klassische Spiel Snake aus der offiziellen Firmware, das Unleashed als System-App mitbringt.

`Main Menu → Apps → Games → Snake Game`

![Snake am Spielanfang: die Schlange links im Spielfeld und die Frucht in der Mitte](/screens/apps/snake.png)

## So wird gespielt

1. Starte das Spiel. Die Schlange bewegt sich von selbst.
2. Steuere mit <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd>. Friss die Frucht, um zu wachsen; jede Frucht
   erhöht die Punktzahl.
3. Lauf nicht in die Wand oder in deinen eigenen Schwanz. Die Schlange wird schneller, je größer sie wird.
4. Bei `Game Over` zeigt der Bildschirm deinen `Score`. Drücke <kbd>OK</kbd>, um ein neues Spiel zu starten.
5. <kbd>Back</kbd> beendet jederzeit.

::: tip Unleashed
Weitere Spiele stecken in den [App-Packs](/de/apps/catalog#base-and-extra-packs), und der Dummy Mode auf dem Desktop
hat seine eigenen Minispiele: drücke oder halte eine beliebige Pfeiltaste (siehe [Desktop](/de/start/desktop)).
:::
