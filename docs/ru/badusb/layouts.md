# Раскладки клавиатуры для Bad USB

USB-клавиатура отправляет не символы, а **позиции клавиш**. Компьютер превращает их в символы по *своей*
раскладке. Чтобы набрать `z` на немецком (QWERTZ) ПК, Флиппер должен нажать клавишу, которая на американской
клавиатуре — `y`. **Файл раскладки** (`.kl`) сообщает Bad USB, какая клавиша (и модификатор) даёт каждый символ в
целевой раскладке.

::: tip Unleashed
Раскладки для Bad USB сделаны [rien / dummy-decoy](https://github.com/dummy-decoy/flipperzero_badusb_kl) и входят в
Unleashed. Команда `DUCKY_LANG` для выбора раскладки в скрипте — новинка Unleashed (PR #1224).
:::

::: warning Для русскоязычных пользователей
Раскладка в приложении должна совпадать с **текущим языком ввода на хосте**. Если на ПК включён русский язык,
`STRING notepad` наберёт `тщеузфв`. Перед запуском переключите хост на английский (или на язык выбранной
раскладки). Набрать кириллицу через `STRING` нельзя; в Windows можно использовать `ALTCHAR` с кодами нужной кодовой
страницы, а `ALTSTRING` работает только с печатными ASCII-символами.
:::

## Выбор раскладки

**Глобально** (для всех скриптов): на экране скрипта нажмите <kbd>←</kbd> **Config → Keyboard Layout (global)** и
выберите `.kl`-файл. Выбор сохраняется в `/ext/badusb/.badusb.settings` и показывается на экране скрипта в скобках,
например `(de-DE)`. Если сохранённый файл отсутствует или повреждён, используется `en-US`.

![Меню Config в Bad USB, первый пункт — Keyboard Layout (global)](/screens/badusb/config.png)

**Для скрипта**: поставьте `DUCKY_LANG <имя>` в начало скрипта:

```text
DUCKY_LANG fr-FR
STRINGLN bonjour
```

- `<имя>` — имя файла без `.kl`. Псевдонимы: `en` = `en-US`, `de` = `de-DE`, `fr` = `fr-FR`.
- Действует с этой строки и сбрасывается на глобальную раскладку в начале каждого запуска.
- Неизвестное или неверное имя — откат на встроенную `en-US` без остановки скрипта.

## На что раскладка НЕ влияет

- Через раскладку проходят только текст `STRING` / `STRINGLN` и односимвольные клавиши (`CTRL c`, `HOLD a`…).
  Именованные клавиши (`ENTER`, `F5`, стрелки…) везде одинаковы.
- `ALTCHAR` / `ALTSTRING` раскладку вообще не используют: они вводят символы по коду через `ALT`+Numpad, поэтому в
  Windows работают при любой раскладке.

## Формат файла (`.kl`)

Файл `.kl` — двоичная таблица ровно из **256 байт**: 128 записей по 2 байта (`uint16`, little-endian), по одной на
каждый ASCII-код 0-127.

- **Младший байт** — HID-код клавиши, которую нужно нажать (например, `0x1F` — клавиша `2`).
- **Старший байт** — биты модификаторов, которые надо удерживать вместе с ней:

| Бит (старший байт) | Модификатор |
|---|---|
| `0x01` | Левый Ctrl |
| `0x02` | Левый Shift |
| `0x04` | Левый Alt |
| `0x08` | Левый GUI |
| `0x10` | Правый Ctrl |
| `0x20` | Правый Shift |
| `0x40` | Правый Alt (AltGr) |
| `0x80` | Правый GUI |

Пример из `de-DE.kl`: запись для `"` (ASCII 34) — `1F 02`, то есть Shift + `2`, именно там двойная кавычка на
немецкой клавиатуре.

Поскольку записей всего 128, **набирать можно только ASCII**; `STRING` с любым байтом ≥ 128 (UTF-8: диакритика,
кириллица, эмодзи) останавливает скрипт с *«Native .kl supports ASCII, not UTF-8»*. Имя файла может содержать
буквы, цифры, `-` и `_` (до 32 символов перед `.kl`).

Чтобы сделать свою раскладку, следуйте инструкции в
[dummy-decoy/flipperzero_badusb_kl](https://github.com/dummy-decoy/flipperzero_badusb_kl) и скопируйте полученный файл
в `/ext/badusb/assets/layouts/`.
