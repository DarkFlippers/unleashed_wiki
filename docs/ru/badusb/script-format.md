# Формат скриптов Bad USB (DuckyScript)

Bad USB выполняет текстовые скрипты на **расширенном DuckyScript**. Классические скрипты USB Rubber Ducky 1.0
работают как есть; сверху Флиппер добавляет свою USB/BLE-идентичность, ввод через `ALT`+Numpad, `SYSRQ`,
мультимедийные клавиши, управление мышью, ожидание нажатия кнопки и многое другое. Справочник сверен с таблицей
команд в прошивке (`helpers/ducky_script_commands.c`, `ducky_script_keycodes.c`).

## Правила файла

- Обычный текст, расширение **`.txt`**, компилировать не нужно. Переводы строк `\n` или `\r\n`.
- Одна команда на строку. Пустые строки пропускаются; отступы пробелами или табами допустимы.
- Команды пишутся **ЗАГЛАВНЫМИ и чувствительны к регистру**: `STRING`, а не `string`.
- Команда и аргумент разделяются одним пробелом.
- Комментарии — целые строки, начинающиеся с `REM`. Комментариев в конце строки нет.
- Набираемый текст (`STRING`, `STRINGLN`) должен быть **ASCII**. Не-ASCII символы останавливают скрипт с
  *«Native .kl supports ASCII, not UTF-8»*.
- При ошибке скрипт останавливается, на экране — *ERROR:*, номер строки и причина.

## Краткий справочник

| Команда | Аргумент | Действие |
|---|---|---|
| `REM` | текст | Комментарий, игнорируется. |
| `ID` | `VID:PID [Manufacturer:Product]` | USB-идентичность, **только первая строка**. |
| `BLE_ID` / `BT_ID` | `MAC Имя` | Bluetooth-идентичность, **только первая строка**. |
| `DELAY` | мс | Однократная пауза. |
| `DEFAULT_DELAY` / `DEFAULTDELAY` | мс | Пауза перед каждой следующей командой. |
| `STRING` | текст | Набрать текст. |
| `STRINGLN` | текст | Набрать текст и нажать Enter. |
| `STRING_DELAY` / `STRINGDELAY` | мс | Пауза между нажатиями только для **следующего** `STRING`. |
| `DEFAULT_STRING_DELAY` / `DEFAULTSTRINGDELAY` | мс | Пауза между нажатиями для **всех** `STRING`. |
| `REPEAT` | n | Повторить предыдущую команду ещё n раз. |
| `DUCKY_LANG` | имя раскладки | Сменить раскладку до конца скрипта (Unleashed). |
| `HOLD` | клавиша / кнопка мыши | Нажать и держать. |
| `RELEASE` | клавиша / кнопка мыши | Отпустить удерживаемую клавишу. |
| `ALTCHAR` | код | Набрать один символ через `ALT`+Numpad. |
| `ALTSTRING` / `ALTCODE` | текст | Набрать текст через `ALT`+Numpad. |
| `SYSRQ` | символ | Комбинация Magic SysRq. |
| `MEDIA` | мультимедийная клавиша | Клавиша consumer control (громкость, play…). |
| `GLOBE` | клавиша | Fn/Globe + клавиша (Mac/iPad). |
| `WAIT_FOR_BUTTON_PRESS` | нет | Ждать нажатия <kbd>OK</kbd> на Флиппере. |
| `LEFTCLICK`, `RIGHTCLICK`, `MIDDLECLICK`… | нет | Клики мыши. |
| `MOUSEMOVE` / `MOUSE_MOVE` | x y | Сдвинуть мышь. |
| `MOUSESCROLL` / `MOUSE_SCROLL` | delta | Прокрутка колесом. |
| сочетание клавиш | напр. `CTRL-ALT DELETE` | Нажать и отпустить клавиши вместе. |

## Комментарии

```text
REM Эта строка игнорируется
```

## Паузы

| Команда | Параметр | Примечание |
|---|---|---|
| `DELAY` | мс | Однократная пауза. |
| `DEFAULT_DELAY` | мс | Добавляется перед каждой следующей командой. То же, что `DEFAULTDELAY`. |

```text
DEFAULT_DELAY 50
DELAY 1000
```

Паузы — главный инструмент надёжности: хосту нужно время, чтобы открыть окна, поэтому ставьте `DELAY` после
`GUI r`, `ENTER` в окне запуска и т. д. Длинные паузы показываются на экране как `Delay Ns`.

## Ввод текста

| Команда | Параметр | Примечание |
|---|---|---|
| `STRING` | текст | Набирает текст как есть, через активную раскладку. |
| `STRINGLN` | текст | То же, затем Enter. |
| `STRING_DELAY` | мс | Пауза между нажатиями только для следующего `STRING`/`STRINGLN`. То же, что `STRINGDELAY`. |
| `DEFAULT_STRING_DELAY` | мс | Пауза между нажатиями для всех последующих строк. То же, что `DEFAULTSTRINGDELAY`. |

```text
DEFAULT_STRING_DELAY 10
STRINGLN Hello World!
```

Без задержки текст уходит максимально быстро, и некоторые хосты/программы теряют символы. Встроенные
демо-скрипты используют `DEFAULT_STRING_DELAY 10`.

::: warning Раскладка важна
`STRING` отправляет *позиции клавиш*, пересчитанные через выбранную [раскладку](/ru/badusb/layouts). Если у хоста
другая раскладка, чем в приложении, получатся не те символы. Текст — только ASCII. Кириллицу `STRING` набрать не
может.
:::

## Клавиши и сочетания

Строка, которая не команда, читается как нажатие клавиши: ноль или больше **модификаторов**, затем одна
**клавиша**. Модификаторы разделяются пробелами или дефисами. Клавиша — имя специальной клавиши или один символ.

```text
ENTER
GUI r
CTRL c
CTRL-SHIFT ESC
CTRL ALT DELETE
ALT F4
SHIFT TAB
```

### Модификаторы

| Имя | Примечание |
|---|---|
| `CTRL`, `CONTROL` | |
| `SHIFT` | |
| `ALT` | |
| `GUI`, `WINDOWS` | Клавиша Windows / Command / Super |

### Специальные клавиши

| Имя | Примечание |
|---|---|
| `DOWNARROW` / `DOWN`, `LEFTARROW` / `LEFT`, `RIGHTARROW` / `RIGHT`, `UPARROW` / `UP` | Стрелки |
| `ENTER` | |
| `DELETE` | Delete (вперёд) |
| `BACKSPACE` | |
| `END`, `HOME`, `INSERT`, `PAGEUP`, `PAGEDOWN` | |
| `ESCAPE` / `ESC` | |
| `CAPSLOCK`, `NUMLOCK`, `SCROLLLOCK` | |
| `PRINTSCREEN` | |
| `BREAK`, `PAUSE` | Pause/Break |
| `SPACE`, `TAB` | |
| `MENU`, `APP` | Клавиша контекстного меню |
| `F1` … `F24` | Функциональные клавиши (прошивка знает и F13-F24) |

## Повтор

```text
DOWN
REPEAT 9
```

`REPEAT n` выполняет **предыдущую команду** ещё n раз (в примере стрелка вниз нажимается 10 раз). `n` ≥ 1.

## Удержание и отпускание

| Команда | Параметр | Примечание |
|---|---|---|
| `HOLD` | специальная клавиша, модификатор, один символ или кнопка мыши | Нажать и держать до `RELEASE`. |
| `RELEASE` | то же | Отпустить эту клавишу. |

```text
HOLD SHIFT
DOWN
REPEAT 4
RELEASE SHIFT
```

Одновременно можно держать не больше **6** клавиш/кнопок (размер HID-отчёта клавиатуры); больше — ошибка *«Too many
keys are held»*. `RELEASE`, когда ничего не удерживается, — *«No keys are held»*. В официальном документе написано 5,
проверка в прошивке допускает 6.

## Ввод через ALT + Numpad

В Windows (и некоторых Linux-окружениях) любой символ можно ввести, удерживая `ALT` и набирая его код на цифровой
клавиатуре. Это **не зависит от раскладки**, поэтому удобно на незнакомых машинах.

| Команда | Параметр | Примечание |
|---|---|---|
| `ALTCHAR` | код символа | Набирает один символ: держит ALT, вводит цифры на Numpad. |
| `ALTSTRING` | текст | Набирает каждый печатный ASCII-символ (32-126) текста по его ALT-коду. |
| `ALTCODE` | текст | То же, что `ALTSTRING` (такое имя встречается в некоторых реализациях DuckyScript). |

Перед ALT-вводом NumLock включается автоматически.

```text
ALTCHAR 7
ALTSTRING This works with any keyboard layout
```

## SysRq

```text
SYSRQ b
```

Отправляет `ALT`+`PRINTSCREEN`+клавиша — комбинацию Linux [Magic SysRq](https://en.wikipedia.org/wiki/Magic_SysRq_key).
Осторожно: некоторые клавиши SysRq сразу перезагружают или останавливают систему.

## Мультимедийные клавиши

`MEDIA <клавиша>` нажимает клавишу consumer control:

| Клавиша | Примечание |
|---|---|
| `POWER`, `REBOOT`, `SLEEP`, `LOGOFF` | Система |
| `EXIT`, `HOME`, `BACK`, `FORWARD`, `REFRESH` | Навигация в браузере / приложениях |
| `SNAPSHOT` | Сделать фото в приложении камеры |
| `PLAY`, `PAUSE`, `PLAY_PAUSE`, `NEXT_TRACK`, `PREV_TRACK`, `STOP`, `EJECT` | Воспроизведение |
| `MUTE`, `VOLUME_UP`, `VOLUME_DOWN` | Громкость |
| `FN` | Клавиша Fn/Globe на клавиатурах Mac |
| `BRIGHT_UP`, `BRIGHT_DOWN` | Яркость дисплея |

```text
MEDIA VOLUME_UP
REPEAT 5
```

## Клавиша Fn / Globe (Mac, iPad)

```text
GLOBE e
```

`GLOBE <клавиша>` держит Fn/Globe, нажимает клавишу и отпускает обе (специальная клавиша или один символ).

## Ожидание нажатия кнопки

```text
WAIT_FOR_BUTTON_PRESS
```

Скрипт встаёт на паузу без ограничения по времени; Флиппер показывает **Press to continue**. Нажмите <kbd>OK</kbd>,
чтобы продолжить. Удобно, чтобы синхронизироваться с ручными действиями (вход в систему, разблокировка экрана…).

## Мышь

| Команда | Параметр | Примечание |
|---|---|---|
| `LEFTCLICK` / `LEFT_CLICK` | нет | Левый клик |
| `RIGHTCLICK` / `RIGHT_CLICK` | нет | Правый клик |
| `MIDDLECLICK` / `MIDDLE_CLICK` / `WHEELCLICK` / `WHEEL_CLICK` | нет | Средний клик (колесо) |
| `MOUSEMOVE` / `MOUSE_MOVE` | `x y` (целые) | Относительное перемещение; отрицательные — влево / вверх |
| `MOUSESCROLL` / `MOUSE_SCROLL` | `delta` (целое) | Прокрутка; знак задаёт направление |

Кнопки мыши работают с `HOLD`/`RELEASE`, например для перетаскивания:

```text
HOLD LEFTCLICK
MOUSEMOVE 100 0
RELEASE LEFTCLICK
```

## Device ID

Можно задать идентичность, с которой Флиппер представляется хосту. Команда должна стоять **в самой первой строке**;
она применяется при открытии скрипта, до запуска, и приложение **переключается в соответствующий режим
подключения** (вручную переключиться обратно всё равно можно). В других строках эти команды игнорируются.

| Команда | Параметры | Пример | Режим |
|---|---|---|---|
| `ID` | `VID:PID Manufacturer:Product` | `ID 1234:abcd Flipper Devices:Flipper Zero` | USB |
| `BLE_ID` | `MAC Имя устройства` | `BLE_ID AA:BB:CC:DD:EE:FF Smart Fridge` | Bluetooth |
| `BT_ID` | `MAC Имя устройства` | `BT_ID AA:BB:CC:DD:EE:FF Smart Fridge` | то же, что `BLE_ID` |

- `ID`: VID и PID (hex) обязательны; строки производителя и продукта необязательны (до 31 символа каждая).
- `BLE_ID` / `BT_ID`: обязательны и 6-байтовый MAC, и имя устройства.

## Раскладка для скрипта: `DUCKY_LANG`

::: tip Unleashed
`DUCKY_LANG` — новинка Unleashed (PR #1224 от @ANTONiO-eagle).
:::

```text
DUCKY_LANG de-DE
STRING Hallo Welt
```

- Загружает `/ext/badusb/assets/layouts/<имя>.kl` и использует её с этой строки, вместо глобальной раскладки из
  Config. Короткие псевдонимы: `en` → `en-US`, `de` → `de-DE`, `fr` → `fr-FR`.
- Имя может содержать буквы, цифры, `-` и `_`, и после него в строке ничего не должно быть.
- Отсутствующий файл или неверное имя **не останавливают скрипт**: молча используется встроенная `en-US`.
- Каждый новый запуск снова начинается с глобальной раскладки, поэтому ставьте `DUCKY_LANG` в начало.

Список имён раскладок — на странице [Раскладки клавиатуры](/ru/badusb/layouts).
