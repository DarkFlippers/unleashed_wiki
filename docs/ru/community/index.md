# Сообщество

Прошивка Unleashed и эта вики существуют благодаря большому сообществу разработчиков, исследователей и
энтузиастов. Этот раздел — «человеческая» часть вики: кто всё это сделал, где искать официальные ресурсы проекта и
как помочь улучшить страницы, которые вы читаете.

## Об этой вики

Это общественный проект. Он **не связан с Flipper Devices** и **не** официальный ресурс Unleashed — это
практическая вики, написанная по исходникам прошивки, официальной документации и исследовательским статьям людей,
указанных в благодарностях.

Вики ориентирована **на Unleashed**: там, где форк Unleashed ведёт себя иначе, чем сток (лишние протоколы, меню,
приложения), это явно отмечается. Знания про стоковый Flipper Zero при этом раскрыты полностью.

::: tip Каждая страница указывает источники
Любая страница, построенная на чьей-то статье, посте, документации или коде прошивки, содержит внизу блок
благодарностей с точными ссылками на оригиналы. Если считаете, что что-то указано неверно или пропущено — см.
[Как помочь](/ru/community/contributing).
:::

::: warning Только для законного использования
Всё здесь — для работы со **своими** устройствами и законных исследований. СКУД, динамические коды и автоключи
разбираются как технический предмет, а не как призыв атаковать чужие системы.
:::
