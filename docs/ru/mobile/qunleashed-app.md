# Приложение-компаньон qUnleashed

::: tip Unleashed
**qUnleashed** — собственное приложение-компаньон команды Unleashed для телефона и компьютера. Оно
написано с нуля на Flutter как альтернатива официальному мобильному приложению Flipper, то есть это не
форк qFlipper. Лицензия GPL-3.0 или новее, исходники и сборки — в репозитории
[DarkFlippers/qUnleashed](https://github.com/DarkFlippers/qUnleashed).
:::

Приложение сделано под Unleashed, но работает и с другими прошивками. Текущая стабильная версия —
**0.17.2**.

## Пойдёт ли на вашем устройстве {#requirements}

| Система | Нужно |
|---|---|
| Android | 10 (API 29) или новее |
| iOS | 15 или новее |
| macOS | 12 или новее |
| Windows | 10 или новее, 64 бита |
| Linux | GLib 2.72 и glibc 2.35 — Ubuntu 22.04, Debian 12, Mint 21 или новее |

На более старом Linux бинарник просто не запустится.

## Установка {#install}

Выберите сборку для своей системы на
[странице релизов](https://github.com/DarkFlippers/qUnleashed/releases). Ни в магазинах приложений, ни в
виде установочного скрипта приложение не распространяется.

## Подключение {#connecting}

Bluetooth работает на всех пяти системах. USB-порт (serial) — на Android, Windows, macOS и Linux. На iOS
подключения по USB нет вообще: Apple не даёт приложениям работать с USB-serial.

Приложение запоминает Флипперы, с которыми вы уже работали, и переподключается само. Если один из них
воткнут в USB, он важнее последнего Bluetooth-устройства. На Android фоновая служба держит
Bluetooth-соединение, пока приложение свёрнуто.

## Прошивка {#firmware}

- **Обновление** по каналам release и dev со списком изменений. Прошивка скачивается и ставится прямо из
  приложения: базовая сборка Unleashed, сборка с дополнительными приложениями, компактная сборка, а
  также официальные каналы.
- **Repair from DFU mode** полностью перепрошивает Флиппер по USB. То же самое, что Full Repair в
  qFlipper, — для устройства, которое уже не загружается.
- **Уведомления о релизах** включаются по желанию, у dev-канала отдельный переключатель.

## Устройство {#device}

- **Информация об устройстве**: версия и дата сборки прошивки, батарея, память.
- **GPS и раздача интернета**: телефон отдаёт свои координаты приложениям на Флиппере и пропускает через
  себя сетевой трафик Флиппера. Нужна прошивка с RPC-расширением GPS/сеть.
- **Удалённый экран**: экран Флиппера в реальном времени на телефоне или ПК, кнопки — на экране. На
  компьютере можно управлять обычной клавиатурой. Скриншоты сохраняются, экран пишется в GIF.
- **Командная строка**: полноценный CLI Флиппера. Только по USB, то есть не на iOS.

## Архив {#archive}

Копия ваших ключей хранится на телефоне, отдельный архив для каждого Флиппера. У каждого файла есть
состояние: **synced**, **remote-only**, **local-only** или **deleted** — сразу видно, что где лежит, а
удалённый файл можно восстановить. Файлы можно помечать избранными.

Категории: Sub-GHz, Wardriving (включая автосохранения), RFID 125, NFC, Infrared, iButton, Bad USB,
JavaScript.

Файл можно запустить прямо из приложения. NFC, RFID и iButton эмулируются через RPC; Sub-GHz, Infrared,
Bad USB и JavaScript открываются в соответствующем приложении на Флиппере.

Ещё есть текстовый редактор с подсветкой форматов файлов Флиппера, так что поправить `.sub` или `.ir`
можно без компьютера.

## Файловый менеджер {#file-manager}

Показывает `/ext` (SD-карта) и `/int` (внутренняя память). Создание, переименование, удаление, скачивание,
загрузка и правка текстовых файлов.

## Приложения {#apps}

Каталог приложений с поиском, категориями, сортировкой, описанием и скриншотами. Установка, обновление и
удаление. Приложение видит и то, что уже стоит на Флиппере, включая предустановленное.

## Инструменты {#tools}

- **Pixel Draw**: редактор пиксельной графики с менеджером проектов и многокадровой анимацией. Умеет
  импортировать анимации дельфина и показывать превью прямо на Флиппере.
- **Extract MIFARE Keys**: считает Mfkey32 на телефоне по нонсам, собранным Флиппером. Полный процесс —
  на странице [Быстрое вскрытие ключей с qUnleashed](/ru/nfc/qunleashed).
- **Remotes Library**: ИК-пульты из официального источника и из публичного репозитория
  [Lucaslhm/Flipper-IRDB](https://github.com/Lucaslhm/Flipper-IRDB). Листать, искать, править `.ir` и
  сохранять в архив или сразу в `/ext/infrared`.
- **Pulse Plotter**: рисует сырые импульсные записи Sub-GHz, ИК и RFID.
- **Saved Locations**: метки на карте по координатам, которые лежат в файлах архива.

## Восстановление Seed по захватам Sub-GHz {#seed-recovery}

Часть пультов на основе KeeLoq (FAAC SLH, Genius, Erreka, старые BFT Mitto) использует секретный **Seed**, без
которого их не раскодировать. Флиппер только собирает данные приложением [Seed Capturer](/ru/subghz/seed-capturer),
а сам поиск — это перебор (brute force), и его делает qUnleashed, а не Флиппер.

1. Снимите пульт через `Apps → Sub-GHz → Seed Capturer`: нажимайте **одну и ту же кнопку** много раз, по одному
   ровному нажатию, и следите, чтобы счётчик `Hops` рос на каждом нажатии.
2. Подключите Флиппер к **qUnleashed** и откройте инструмент **восстановления Seed** (Seed recovery).
3. Выберите свой захват из списка. qUnleashed сам читает захваты из папки `subghz_seed_captures` на Флиппере;
   производитель, частота, значения `Fix` и `Hop` уже есть в файле. **Ничего копировать, перемещать, переименовывать
   или править не нужно.**
4. Запустите поиск и ждите.
5. Если Seed найден, qUnleashed выдаёт Seed и счётчик и может **сохранить готовый клон пульта** в файл `.sub` (в `Fix`
   уже есть серийник и кнопка). Закиньте его обратно на Флиппер и отправляйте — вводить что-то через `Add Manually`
   не нужно.
6. Если ничего не найдено, скорее всего в захвате был пропуск. Снимите заново, держа пульт вплотную к Флипперу, и если
   нажатие не засчиталось, начните заново кнопкой `Reset` (<kbd>←</kbd>).

::: warning Seed принадлежит установке
У FAAC SLH и Genius Seed **разный для каждой кнопки**, поэтому снимайте ту кнопку, которой собираетесь пользоваться.
У Erreka Seed свой для каждого пульта (иногда для всей установки). У BFT Mitto — свой для пульта, и захват нужен только
старым пультам с уникальным Seed.
:::

Полная процедура, включая прописывание клона в приёмник, — в
[Программировании пультов с плавающим кодом](/ru/subghz/remote-prog) и [KeeLoq](/ru/subghz/keeloq).

Используйте это только для своих пультов и ворот.
