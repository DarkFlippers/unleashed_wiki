# Мобильное приложение Flipper

Официальное **Flipper Mobile App** ([App Store](https://apps.apple.com/us/app/flipper-mobile-app/id1534655259),
[Google Play](https://play.google.com/store/apps/details?id=com.flipperdevices.app)) подключается к Флипперу по
Bluetooth. С ним можно обновлять прошивку, просматривать и делиться сохранёнными ключами, ставить приложения из
каталога, управлять Флиппером удалённо и делать бэкап данных.

::: tip Unleashed
Официальное мобильное приложение работает с Unleashed. Оно умеет ставить `.tgz` от Unleashed как **Custom**-обновление
(см. ниже). Если после установки Unleashed или смены имени Флиппера приложение перестало подключаться — сопрягите
их заново, см. раздел «Проблемы с подключением» ниже.
:::

## Подключение к Флипперу

1. На Флиппере: `Main Menu → Settings → Bluetooth`, установите **Bluetooth** в **ON**.
2. В приложении нажмите **Connect**, затем **Connect** рядом с именем вашего Флиппера.
3. Введите **код сопряжения**, показанный на экране Флиппера, и нажмите **Pair**.
4. Дождитесь, пока приложение закончит синхронизацию.

## Что есть в приложении

- **Main Menu** (вкладка устройства): обновление по Bluetooth, **Device Info** (подробности о железе и прошивке),
  **Options** (бэкап, логи, файловый менеджер, перезагрузка, баг-репорт; набор зависит от iOS/Android), ручная
  синхронизация, звуковой сигнал, чтобы найти Флиппер.
- **Archive**: все сохранённые файлы Sub-GHz, RFID 125, NFC, Infrared и iButton. Избранное, поиск и восстановление
  удалённых. Нажмите на ключ, чтобы открыть **Key Info**: эмуляция или отправка, в избранное, переименовать, добавить
  заметку, подробности, удалить, поделиться.
- **Apps**: официальный каталог приложений, установка по Bluetooth LE, см. [Приложения на SD-карте](/ru/apps/sd-card-apps).
- **Tools**: **Mfkey32** (Extract MF Keys) для вычисления ключей MIFARE Classic по собранным nonce и **Remotes Library** —
  библиотека ИК-пультов (см. [ИК с телефона](/ru/infrared/mobile)).
- **Виджет**: эмуляция сохранённых пультов и карт с домашнего экрана телефона без открытия приложения (iOS: Today View
  → Изменить → Добавить виджет → Flipper; на Android добавьте его как обычный виджет и нажмите, чтобы настроить).

## Установка Unleashed с телефона

::: warning Первая установка
Если это ваша первая кастомная прошивка, сначала обновитесь до последнего **официального** релиза и проверьте, что
SD-карта вставлена. Уже стоит Unleashed? Ставьте новую версию поверх.
:::

### iOS

1. Откройте [последний релиз Unleashed](https://github.com/DarkFlippers/unleashed-firmware/releases/latest) и скачайте
   `flipper-z-f7-update-(version).tgz`.
2. В приложении **Файлы** выберите скачанный `.tgz`, нажмите **Поделиться** и выберите приложение **Flipper**.
3. В приложении Flipper проверьте, что в Update Channel указано `Custom flipper-z-f7-update...`, и нажмите зелёную
   кнопку **Update**.
4. Дождитесь окончания обновления. В конце приложение на iOS может показать ошибку, но Флиппер при этом обновится.

### Android, через файл `.tgz`

1. Скачайте `flipper-z-f7-update-(version).tgz` со страницы релиза.
2. В приложении Flipper нажмите **Update channel** → **Custom** и выберите скачанный файл.
3. Нажмите **Update** и ждите.

### Android, через ссылку на веб-апдейтер

1. На странице релиза нажмите **Install via Web Updater**.
2. Когда Android спросит, чем открыть ссылку, выберите приложение **Flipper**.
3. Продолжите установку и ждите.

Обновление по Bluetooth может занять около 10 минут. Другие способы: [Установка Unleashed](/ru/start/install).

### Если обновление не удалось

- Проверьте, что Флиппер включён и всё ещё подключён по Bluetooth.
- Перезагрузите Флиппер (<kbd>←</kbd> + <kbd>Back</kbd>) и запустите обновление заново.
- Если ошибка повторяется, возможно, внутренняя память переполнена или повреждена: установите прошивку через
  [qFlipper](/ru/mobile/qflipper) или [Web Installer](/ru/mobile/web-tools#unleashed-web-installer), см.
  [Восстановление](/ru/start/recovery).

## Бэкап ключей

1. На вкладке устройства нажмите **Options → Backup Keys**.
2. Выберите, куда сохранить или кому отправить `.zip` с вашими ключами, картами и пультами.

Чтобы восстановить, распакуйте архив и загрузите файлы на Флиппер через [qFlipper](/ru/mobile/qflipper). Для полного
бэкапа SD-карты скачайте всю карту во вкладке **File manager** qFlipper.

## Проблемы с подключением

**После установки Unleashed или смены имени Флиппера приложение не подключается:**

1. В приложении нажмите **Forget flipper**.
2. В настройках Bluetooth телефона найдите Флиппер, откройте его параметры и выберите **Забыть устройство**.
3. На Флиппере: `Settings → Bluetooth → Unpair All Devices` и подтвердите кнопкой **Unpair**.
4. Убедитесь, что Bluetooth на Флиппере включён (ON), и снова выполните сопряжение из приложения.

**Флиппер не находится:** проверьте, что Bluetooth включён на обоих устройствах, отключите Флиппер от других
устройств (например, от хоста [Bluetooth-пульта](/ru/apps/controllers)), обновите приложение и прошивку,
перезагрузите Флиппер.

**Не проходит синхронизация:** удалите сопряжение и сопрягите заново, перезагрузите оба устройства и попробуйте на
Флиппере `Settings → System → Sleep Method → Legacy`.

## Сообщить об ошибке в приложении

Ошибки официального приложения: **Options → Report Bug**, заполните заголовок и шаги воспроизведения, оставьте
прикреплённые логи, нажмите **Submit** и при желании опубликуйте ID обращения на
[forum.flipperzero.one](https://forum.flipperzero.one/) (раздел Mobile App). Чтобы снять логи Флиппера для отчёта:
установите `Settings → System → Log Level` в **Debug**, подключитесь по USB, откройте serial-терминал на скорости
**230400** бод (или [lab.flipper.net/cli](https://lab.flipper.net/cli)), выполните `info device`, затем `log`,
повторите ошибку и перед публикацией удалите строки `hardware.uid` и `hardware.name`.
