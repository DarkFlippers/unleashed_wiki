# Приложения на SD-карте (.fap)

Почти всё, что вы запускаете из `Main Menu → Apps`, — это **FAP** (Flipper App Package): исполняемый файл `.elf` с
дополнительными метаданными (название, иконка, категория, требуемая версия API) и, при необходимости, встроенными
ресурсами. FAP лежат на microSD-карте, поэтому **без SD-карты приложения не запускаются**.

## Где лежат приложения

| Путь | Что там |
|---|---|
| `/ext/apps/<Category>/*.fap` | установленные приложения, по папке на категорию (`Sub-GHz`, `NFC`, `RFID`, `GPIO`, `USB`, `Bluetooth`, `Games`, `Tools`, ...) |
| `/ext/apps_data/<appid>/` | данные и настройки, которые приложение сохраняет для себя |
| `/ext/apps_data/loader/plugins/` | плагины загрузчика, например [стили главного меню](/ru/apps/menu-styles) |

`Main Menu → Apps` просто показывает папки внутри `/ext/apps`. Вкладка **Apps** в [Archive](/ru/apps/archive)
показывает ту же папку, а заодно и скрипты `.js`.

## Как Flipper запускает FAP

Микроконтроллер не умеет выполнять код прямо с внешнего носителя. При запуске приложения **App Loader** (загрузчик):

1. читает FAP с SD-карты и проверяет его целостность и манифест;
2. проверяет, что **мажорная версия API** приложения совпадает с мажорной версией API прошивки;
3. копирует секции кода и данных в RAM и пересчитывает адреса под новое расположение (релокация);
4. находит все импортируемые приложением функции через **таблицу символов** (symbol table) прошивки;
5. запускает приложение.

Так как приложение работает из RAM, большое приложение оставляет меньше кучи (heap) для всего остального. В память
загружаются только код и данные, поэтому занятый объём RAM меньше размера файла `.fap`.

::: tip Unleashed
Unleashed сохраняет официальный API (текущая версия API указана в начале каждого changelog, например
`Current API: 88.27`), поэтому большинство приложений из официального каталога работают как есть. Если мажорная версия
API отличается, Unleashed не отказывает сразу: он показывает **App Too Old** или **App Too New** с обеими версиями
(например `APP:86 < FW:88`) и кнопкой **Continue**, так что приложение можно попробовать запустить всё равно. См.
[Проблемы с приложениями](/ru/apps/troubleshoot).
:::

## Установка приложений

### Из паков приложений

Проще всего выбрать сборку прошивки, в которую пак уже включён (сборка по умолчанию или `e`), см.
[Приложения в комплекте Unleashed](/ru/apps/catalog).

Оба пака лежат в репозитории [xMasterX/all-the-plugins](https://github.com/xMasterX/all-the-plugins). Чтобы поставить пак вручную:

1. Скачайте `.zip` со [страницы релизов](https://github.com/xMasterX/all-the-plugins/releases/latest).
2. Распакуйте архив.
3. Скопируйте папки приложений в папку `apps` на SD-карте (`/ext/apps/`), сохранив папки-категории.
4. Проверьте, что версия API пака совпадает с версией прошивки (`Current API:` в начале changelog).

### Из официального каталога {#installing-from-the-official-catalog}

Официальный каталог приложений есть во [Flipper Lab](https://lab.flipper.net/apps) (Chrome, Edge и другие браузеры
на Chromium с поддержкой Web Serial) и на вкладке **Apps** в [мобильном приложении Flipper](/ru/mobile/mobile-app).

1. Закройте qFlipper и другие вкладки Flipper Lab (USB-последовательный порт может занимать только одна программа).
2. Подключите Flipper по USB (Flipper Lab) или по Bluetooth (мобильное приложение).
3. Откройте **Apps**, найдите приложение по категории или через поиск.
4. Нажмите **Install** на карточке приложения или на его странице и дождитесь окончания загрузки.
5. На Flipper откройте `Main Menu → Apps → <категория> → <приложение>`.

Чтобы обновить или удалить приложения из каталога, откройте **Apps → Installed** и нажмите **Update** или значок
удаления (корзину).

Если установка не удалась: проверьте подключение, освободите место на SD-карте (удалите файлы в
[Archive](/ru/apps/archive)) и убедитесь, что прошивка свежая.

### Вручную (любой `.fap`)

1. Скачайте `.fap`, собранный под вашу прошивку (сборку под Unleashed или сборку под OFW с совпадающей версией API).
2. Скопируйте его в `/ext/apps/<Category>/` через [qFlipper](/ru/mobile/qflipper), файловый менеджер мобильного
   приложения или кардридер.
3. Запустите его из `Main Menu → Apps` или откройте файл в [Archive](/ru/apps/archive) и выберите **Run**.

::: warning
Приложения, собранные под другой форк прошивки, могут импортировать функции, которых Unleashed не экспортирует, и
тогда падают с ошибкой **Missing Imports**. Берите приложения из паков Unleashed или пересобирайте их под SDK Unleashed.
:::

## Сборка своего FAP

FAP разрабатываются точно так же, как встроенные приложения. Коротко:

1. Положите папку своего приложения в `applications_user/` в чекауте прошивки.
2. В его `application.fam` укажите `apptype=FlipperAppType.EXTERNAL` (см. [Манифесты приложений](/ru/dev/app-manifests)).
3. Соберите одной из команд:

```bash
./fbt fap_{APPID}                                     # собрать одно приложение
./fbt launch APPSRC=applications_user/path/to/app     # собрать, загрузить по USB и запустить
./fbt build APPSRC=applications_user/path/to/app      # собрать без загрузки
./fbt faps                                            # собрать все FAP (или ./fbt fap_dist)
```

В стандартном профиле VS Code команда `launch` — это действие **Launch App on Flipper**
(<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd>).

**Ассеты.** Положите картинки в подпапку приложения и укажите её в `fap_icon_assets`; затем
`#include "{APPID}_icons.h"` и используйте их так же, как иконки из `assets_icons.h`.

**Версионирование API.** Приложениям доступны не все функции прошивки: экспортируемый набор перечислен в
`api_symbols.csv` аппаратной платформы. Мажорная версия растёт при несовместимых изменениях (удалена функция или
переменная, изменена сигнатура), минорная — при добавлениях. `fbt` управляет этим автоматически: новые символы
появляются с отметкой `?`, и каждый нужно пометить `+` (экспортируется) или `-` (скрыт), иначе прошивка не соберётся.

**Отладка.** `fbt` загружает в gdb скрипт `debug/flipperapps.py`, так что FAP можно отлаживать как код прошивки.
Соберите и прошейте прошивку (`./fbt`, `./fbt flash`), запустите свой FAP, затем подключитесь через `./fbt debug`.
Сразу после загрузки FAP прошивка останавливается на точке останова, и в нём можно расставить breakpoints. Тип сборки
прошивки и приложения (debug/release) должен совпадать, а соответствующая сборка должна быть слинкована как
`build/latest`.

Подробнее: [Сборка прошивки](/ru/dev/build), [fbt](/ru/dev/fbt) и [Первое приложение на C](/ru/dev/first-app-c).
