# Часы (Clock)

Прикроватные часы: крупное время, дата и заряд батареи, регулировка яркости экрана с красным ночником на светодиоде,
секундомер и ежедневный будильник. Основано на FlipperNightStand от @nymda, при участии @Willy-JL, @mishamyte и
@xMasterX (версия приложения 1.3).

`Main Menu → Clock`

![Clock: дата над крупным временем и заряд батареи под ним](/screens/apps/clock.png)

::: tip Unleashed
В Unleashed часы — приложение главного меню с будильником и ночником. Если нужно просто время на рабочем столе,
включите `Settings → Desktop → Show Clock`.
:::

## Кнопки на экране часов

| Кнопка | Действие |
|---|---|
| <kbd>↑</kbd> / <kbd>↓</kbd> | яркость экрана выше / ниже (появляется шкала, она скрывается через 3 с после последнего нажатия) |
| <kbd>↓</kbd> при яркости 0 | включить / выключить тусклый красный ночник (светодиод) |
| <kbd>OK</kbd> | секундомер Start / Stop |
| <kbd>←</kbd> | сбросить секундомер |
| <kbd>→</kbd> | настройка будильника |
| <kbd>Back</kbd> | выход |

Время отображается в системном формате: 12-часовом с AM/PM или 24-часовом, как задано в
`Settings → System → Time Format`.

## Секундомер

1. Нажмите <kbd>OK</kbd> для запуска; идущее время показывается как `MM:SS`.
2. Нажмите <kbd>OK</kbd> ещё раз, чтобы остановить, и снова — чтобы продолжить.
3. Нажмите <kbd>←</kbd> (**Reset**), чтобы сбросить.

## Ежедневный будильник

1. На экране часов нажмите <kbd>→</kbd>.
2. Переключите **Alarm** в **ON** кнопками <kbd>←</kbd> / <kbd>→</kbd>.
3. Выберите **Set time** и нажмите <kbd>OK</kbd>.
4. В окне выбора `Alarm time`: <kbd>←</kbd> / <kbd>→</kbd> выбирают часы, минуты (и AM/PM в 12-часовом режиме),
   <kbd>↑</kbd> / <kbd>↓</kbd> меняют значение (удержание — автоповтор). <kbd>OK</kbd> или <kbd>Back</kbd> сохраняют.
5. Нажмите <kbd>Back</kbd>, чтобы вернуться к часам. Время будильника отображается на экране часов.

Когда срабатывает будильник, экран мигает надписью `! ALARM !` с подсказкой `Press any key to stop`, играет мелодия
с вибрацией и красным светодиодом. Нажмите любую кнопку, чтобы его остановить. Будильник остаётся включённым и
сработает снова на следующий день в то же время.

::: warning
Будильник звонит только пока открыто приложение Clock. Оставьте Флиппер на зарядке с запущенными часами на ночь.
:::

Будильник и уровень яркости сохраняются в `/ext/apps_data/clock/` и восстанавливаются при следующем запуске приложения.
