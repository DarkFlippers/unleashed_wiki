# Змейка (Snake)

Классическая «Змейка» из официальной прошивки, в Unleashed поставляется как системное приложение.

`Main Menu → Apps → Games → Snake Game`

![Snake в начале игры: змейка слева на игровом поле и фрукт в центре](/screens/apps/snake.png)

## Как играть

1. Запустите игру. Змейка движется сама.
2. Управляйте кнопками <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd>. Ешьте фрукты, чтобы расти; каждый фрукт
   добавляет очки.
3. Не врезайтесь в стену и в собственный хвост. По мере роста змейка ускоряется.
4. При `Game Over` на экране показывается ваш `Score` (счёт). Нажмите <kbd>OK</kbd>, чтобы начать новую игру.
5. <kbd>Back</kbd> — выход в любой момент.

::: tip Unleashed
Больше игр есть в [паках приложений](/ru/apps/catalog), а у Dummy Mode на рабочем столе есть свои мини-игры: нажмите
или удерживайте любую кнопку-стрелку (см. [Рабочий стол](/ru/start/desktop)).
:::
