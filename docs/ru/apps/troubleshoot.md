# Проблемы с приложениями

Когда приложение не запускается, Флиппер показывает `Error: <name>` с короткой подсказкой и ссылкой
`r.flipper.net/err_0X`. Ниже — каждое сообщение в том виде, в каком его показывает Unleashed.

::: tip Unleashed
Unleashed не блокирует приложения, собранные под другую версию API. Вместо стоковых ошибок **Outdated App** /
**Outdated Firmware** он показывает предупреждение и даёт решить самому, см.
[App Too Old / App Too New](#app-too-old-app-too-new).
:::

## App Too Old / App Too New

```
App Too Old
APP:86 < FW:88
This app might not work
Continue anyways?
```

**Мажорная версия API** приложения отличается от версии прошивки: **App Too Old** — приложение собрано под более
старый API, **App Too New** — под более новый.

- Нажмите **Continue** (<kbd>→</kbd>), чтобы всё равно попробовать. Многие приложения работают, но приложение,
  вызывающее изменённую функцию, может упасть.
- Нажмите <kbd>Back</kbd> для отмены.
- Настоящее решение: обновить приложение (взять из актуального пака Unleashed или пересобрать под текущий SDK), а
  для **App Too New** — обновить прошивку.

## Error: App Not Found (err_01)

`Update firmware or app`

| Причина | Решение |
|---|---|
| файл приложения удалён с SD-карты | переустановите приложение или переустановите прошивку (для системных приложений) |
| старое или бета-мобильное приложение открыло приложение из каталога, которого нет на карте | установите официальное мобильное приложение Flipper из App Store / Google Play и переустановите приложение |

Родственное сообщение **SD card needed** / `Install SD card to run this app` означает, что приложение из меню лежит
на SD-карте, а карта не вставлена. **Update needed** / `Update firmware to run this app` — карта есть, но файла
приложения нет: переустановите прошивку со вставленной картой.

## Error: Invalid File (err_02)

`Update the app`. Файл `.fap` повреждён: испорчен ELF-заголовок, файл неполный (прерванное копирование) или секции
не удаётся загрузить. Скопируйте или установите приложение заново.

## Error: Invalid Manifest (err_03)

`Update firmware or app`. Не удаётся прочитать манифест (специальную секцию ELF с версией API и сведениями о
приложении). Файл повреждён, либо приложение и прошивка слишком сильно расходятся. Обновите приложение; если оно
новее вашей прошивки — обновите прошивку.

## Error: Missing Imports (err_04)

`Update firmware or app`. Приложение вызывает функции, которые ваша прошивка не экспортирует.

| Причина | Решение |
|---|---|
| приложение собрано под более новую прошивку | обновите Unleashed |
| приложение собрано под другой форк (использует его собственные функции) | найдите сборку приложения для Unleashed или пересоберите его с Unleashed SDK |

## Error: HW Target Mismatch (err_05)

`App not supported`. Приложение собрано под другую аппаратную платформу Флиппера. На этом устройстве оно работать
не может.

## Error: Out of Memory

`Not enough RAM to run the app. Please reboot the device`. FAP загружается в оперативную память; если куча
фрагментирована или запущено слишком много всего (например, фоновый BLE-маячок или большое приложение), оно не
помещается. Нажмите **Reboot** и запустите приложение сразу после загрузки.

## Всё равно не работает

1. Обновитесь до последнего релиза Unleashed, см. [Обновление](/ru/start/updating).
2. Переустановите приложение из актуального [пака приложений](/ru/apps/catalog) или из каталога
   ([Приложения на SD-карте](/ru/apps/sd-card-apps)).
3. Если приложение роняет Флиппер, перезагрузите его комбинацией <kbd>←</kbd> + <kbd>Back</kbd>; если он перестал
   загружаться, см. [Восстановление](/ru/start/recovery).
4. Спросите в чатах сообщества, см. [FAQ](/ru/start/faq).
