# Archive (файловый менеджер)

**Archive** — файловый менеджер Flipper. Он показывает сохранённые ключи, карты, пульты и скрипты, запускает их на
месте и делает базовые операции с файлами: закрепить в избранном, переименовать, скопировать, переместить, создать
папку, удалить.

**Как открыть:** на рабочем столе нажмите <kbd>↓</kbd>.

![Archive на вкладке Sub-GHz: папка Garage и сохранённые сигналы .sub, выбран Barrier](/screens/apps/archive.png)

## Вкладки

Вкладки переключаются кнопками <kbd>←</kbd> / <kbd>→</kbd>. Каждая вкладка показывает одну папку с фильтром по типу файлов:

| Вкладка | Папка | Какие файлы видны |
|---|---|---|
| Favorites | закреплённые файлы | всё, что вы закрепили (`/ext/favorites.txt`) |
| Sub-GHz | `/ext/subghz` | `.sub` |
| SubRem | `/ext/subghz_remote` | `.txt` (раскладки [Sub-GHz Remote](/ru/subghz/remote)) |
| RFID LF | `/ext/lfrfid` | `.rfid` и дампы T5577 |
| NFC | `/ext/nfc` | `.nfc` |
| Infrared | `/ext/infrared` | `.ir` |
| iButton | `/ext/ibutton` | `.ibtn` |
| Bad USB | `/ext/badusb` | `.txt` |
| Phone | `/ext/phonebook` | `.phone` (телефонная книга [SIM800](/ru/gpio/sim800)) |
| U2F | внутренняя | пункт приложения U2F |
| Apps | `/ext/apps` | `.fap` и `.js` |
| Internal | внутренняя флеш-память | всё (только при включённом режиме Debug) |
| Browser | вся SD-карта | всё |

Archive открывается на вкладке **Favorites**.

::: tip Unleashed
Unleashed добавляет вкладку **SubRem** для раскладок Sub-GHz Remote, вкладку **Phone** для телефонной книги SIM800
(файл `.phone` открывается сразу в приложении SIM800), показывает дампы T5577 рядом с ключами на вкладке **RFID LF** и
выводит скрипты `.js` на вкладке **Apps**.
:::

## Кнопки в списке

| Кнопка | Действие |
|---|---|
| <kbd>↑</kbd> / <kbd>↓</kbd> | перемещение по списку (удержание — быстрая прокрутка) |
| <kbd>←</kbd> / <kbd>→</kbd> | предыдущая / следующая вкладка |
| <kbd>OK</kbd> на файле | открыть его меню |
| <kbd>OK</kbd> на папке | войти в папку |
| удержание <kbd>OK</kbd> на папке | открыть меню папки |
| <kbd>OK</kbd> в Favorites | сразу запустить файл |
| удержание <kbd>OK</kbd> в Favorites | открыть меню |
| удержание <kbd>OK</kbd> в пустой папке | открыть меню (Paste / NewDir) |
| <kbd>Back</kbd> | на папку выше или выход |

## Меню файла: Actions и Manage

У меню две страницы, его заголовок показывает, какая открыта: **Actions** (действия) или **Manage** (управление).
Внутри меню кнопки <kbd>←</kbd> или <kbd>→</kbd> переключают страницы (кроме вкладки Favorites). <kbd>↑</kbd> /
<kbd>↓</kbd> выбирают пункт, <kbd>OK</kbd> выполняет его, <kbd>Back</kbd> закрывает меню.

**Actions** (для файлов, которые прошивка умеет открывать):

- **Run**: открыть файл в его приложении (эмулировать ключ, отправить сигнал, запустить скрипт...).
- **Pin** / **Unpin**: добавить в избранное / убрать из избранного.
- **Info**: имя и размер файла.
- **Show**: показать файл как текст (для текстовых форматов).

Для неизвестного типа файла в Actions есть только **Info** и, для текстовых файлов, **Show**.

**Manage:**

- **Cut** / **Copy**, затем **Paste** в целевой папке.
- **NewDir**: создать папку.
- **Rename**: ввести новое имя.
- **Delete**: сначала спрашивает подтверждение.

На вкладке **Favorites** меню состоит из **Run**, **Unpin**, **Show** (если применимо) и **Move**. Move меняет порядок
избранного: <kbd>↑</kbd> / <kbd>↓</kbd> сдвигают элемент, <kbd>OK</kbd> сохраняет новое место (<kbd>Back</kbd> — отмена).

## Типовые задачи

### Закрепить файл в Favorites

1. Рабочий стол → <kbd>↓</kbd>, чтобы открыть Archive.
2. Перейдите на нужную вкладку кнопками <kbd>←</kbd> / <kbd>→</kbd> и выберите файл.
3. Нажмите <kbd>OK</kbd> → **Pin**. Теперь файл появится на вкладке Favorites.

### Переименовать сохранённый ключ или сигнал

1. Выберите файл и нажмите <kbd>OK</kbd>.
2. Нажмите <kbd>→</kbd>, чтобы переключить меню на **Manage**.
3. Выберите **Rename**, введите имя, подтвердите.

### Удалить файлы, чтобы освободить место

1. Выберите файл, <kbd>OK</kbd>, <kbd>→</kbd> на **Manage**.
2. Выберите **Delete** и подтвердите.

Чтобы очистить целую папку, используйте вкладку **Browser**: выберите папку, удерживайте <kbd>OK</kbd>,
**Manage → Delete**.

### Переместить файл в другую папку

1. Выберите файл, <kbd>OK</kbd>, **Manage → Cut**.
2. Перейдите в целевую папку (вкладка **Browser** даёт доступ к любой папке на карте).
3. Нажмите <kbd>OK</kbd> на любом файле (или удерживайте <kbd>OK</kbd> в пустой папке) → **Paste**.

## Проблемы

- **"Empty"** означает, что в папке нет файлов типа этой вкладки. Проверьте расширение: файл `.ir` в `/ext/nfc` не
  появится ни в одной из этих вкладок, но во вкладке Browser он виден.
- **Нет вкладки Internal**: она видна, только если `Settings → System → Debug` включён (ON).
- **Пропал файл из избранного**: избранное, чей файл больше не существует (перемещён, переименован или удалён не через
  Archive), удаляется из списка. Закрепите файл заново на новом месте.
- **Delete** всегда спрашивает `Delete <name>?` с кнопками **Cancel** / **Delete**, так что одним случайным нажатием
  ничего не удалится.
