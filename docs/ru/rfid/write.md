# Запись 125 кГц ключей на заготовки

Оригинальные 125 кГц карты и брелоки почти всегда только для чтения. Чтобы сделать физическую копию, нужна
**перезаписываемая заготовка** (болванка) — «магический» чип, который можно запрограммировать вести себя как карта
другого протокола. Flipper Zero пишет на такие заготовки любой прочитанный, сохранённый или добавленный вручную ключ.

## На какие заготовки можно писать

| Чип (как на экране) | Названия в продаже | Что пишет | По умолчанию |
|---|---|---|---|
| **T5577** | T5577, ATA5577, «5577» — карты, брелоки, наклейки | все протоколы | ON |
| **EM4305** | заготовки EM4305 / EM4205 | семейство EM4100, Electra, FDX-B, Gallagher, GProxII, Jablotron, Radio Key (Securakey), Viking | ON |
| **8265** | ID8265 / H5 (клон Hitag Micro, пароль по умолчанию) | семейство EM4100 | ON |
| **8210** | ID8210 (тот же чип, пароль клонера FURUI) | семейство EM4100 | ON |
| **H5.5** | H5.5 от iKey (тот же чип, пароль iKey) | семейство EM4100 | ON |
| **8268** | ID8268 (магический Hitag S) | только EM4100 на RF/64 | **OFF** |

::: tip Unleashed
В официальной документации речь только о T5577. Поддержку записи Hitag Micro — **8265/H5, H5.5 и 8210** — добавил в
Unleashed **@gromovyna**: чипы отличаются только паролем входа, поэтому Флиппер по очереди пробует все известные
пароли и не спрашивает вас. Предыстория: [T5577 и Hitag Micro](/ru/rfid/t5577-hitag).
:::

::: warning 8268 — только по желанию
Цель **8268** (Hitag S) по умолчанию выключена. В отличие от остальных, она выбирает любую ответившую метку Hitag S, а
у настоящего Hitag S на страницах 4 и 5 лежат прикладные данные — отличить оригинал от клона Флиппер не может.
Включайте, только если точно знаете, что на катушке заготовка 8268.
:::

## Как записать ключ

1. Прочитайте метку (`Read` → **More** → **Write**) или откройте сохранённую (`Saved` → ключ → **Write**).
2. Приложите заготовку к задней стороне Флиппера и **не двигайте**. Светодиод мигает пурпурным.
3. На экране **Writing**, протокол в скобках, имя файла (или *Unsaved Tag*) и в круглых скобках **чип, который сейчас
   пробуется**, например:

   ```text
   Writing
   [EM4100]
   Office
   (T5577)
   ```

   ![Экран записи: протокол [EM4100], имя ключа и в круглых скобках пробуемый чип (T5577)](/screens/lfrfid/write.png)

4. Флиппер по очереди пишет каждый включённый тип чипа и после каждой попытки **читает метку обратно**. Как только
   прочитанное совпало — запись завершена.
5. При успехе — **Success!** и название чипа, на который реально записалось (например `T5577`, `EM4305`, `H5.5`);
   затем приложение возвращается в меню ключа.

![Запись: видно, какой чип пробуется](/img/remote/34b72cbd8417d74e.png)

![Результат записи с названием чипа](/img/remote/3ca59457a78dad5b.png)

::: tip Зачем название чипа?
Когда типов чипов несколько (а у Hitag Micro ещё и три пароля), запись идёт заметно дольше, и было непонятно, чем
записалось. Показ текущего и итогового чипа — UX-правка от @gromovyna: технически это не протокол, а рыночное название
вариации метки.
:::

## Settings → Write Chips

`Main Menu → 125 kHz RFID → Settings → Write Chips` — список всех целей: **T5577**, **EM4305**, **8265**, **8210**,
**H5.5**, **8268**, у каждой **ON** / **OFF**.

- <kbd>OK</kbd>, <kbd>←</kbd> или <kbd>→</kbd> переключают выделенный чип.
- Выбор сохраняется при выходе со страницы (<kbd>Back</kbd>) в `/ext/lfrfid/.lfrfid.settings`.
- Отключите неиспользуемые чипы — запись станет быстрее (каждый включённый, но не подошедший чип — это одна запись и
  одна проверка).
- CLI-команда `rfid write` учитывает ту же настройку.

Если страница не открывается и пишет *Settings plugin failed to load* — обновите ресурсы на SD (страница вынесена в
отдельный плагин). Запись при этом продолжает использовать то, что сохранено в файле настроек.

## Write and set password

`Saved` → ключ → **Write and set password** записывает ключ на **T5577** и включает защиту паролем, чтобы метку
нельзя было перезаписать без пароля.

1. Введите пароль — 4 байта в hex. Если пароль ещё не задавался, поле заполнено случайным словом из словаря T5577.
2. Держите заготовку неподвижно. На экране **Writing with password**, `[Протокол]` и текущий шаг.
3. Сначала пишется и проверяется ключ, затем пароль уходит в блок 7 и проверяется, и только потом в блоке 0 включается
   бит пароля. **Запишите пароль** — T5577, закрытую неизвестным паролем, повторно использовать не получится.

Возможные результаты:

| Экран | Что значит |
|---|---|
| **Success!** | Ключ записан, пароль сохранён, защита включена |
| **Error** — *This protocol cannot be written with a password* | Протоколу нужны все 7 блоков данных, в блоке 7 нет места для пароля |
| **Has a password** — *Clear it first: the T5577 app, Clear Password* | Метка уже защищена |
| **Cannot read it** | На катушке что-то есть, но блоки не читаются — сначала очистите метку или снимите пароль |
| **Not written** | Блок не принял ключ: на метке часть ключа и пароля нет |
| **Not protected** | Пароль не лёг в блок 7 или метка отказалась включать защиту |
| **Not confirmed** | Пароль на метке, но включилась ли защита — прочитать не удалось |
| **Still trying to write...** | Метка не отвечает — проверьте, что это перезаписываемая T5577 |

## Ошибки обычной записи

| Сообщение | Что делать |
|---|---|
| *This protocol cannot be written* | Для протокола нет кодирования ни под один чип |
| *No write chips enabled. Enable one in Settings* | Все цели выключены |
| *No enabled chip can write this protocol* | Например, включён только EM4305, а ключ HID — включите T5577 |
| **Still Trying to Write...** *Make sure this card is writable and not protected* | Появляется через ~10 с или после нескольких неудачных проверок. Метка только для чтения, под паролем, неподдерживаемый чип или плохо лежит. Флиппер продолжает пытаться, пока вы не нажмёте <kbd>Back</kbd>. |

## Если не получается

- **На заготовке пароль.** Многие дешёвые копировщики «запароливают» T5577. Используйте
  [приложение T5577](/ru/rfid/t5577-app) → **Clear Password** (пробует ваш пароль, затем словарь).
- **T5577 получила мусорную конфигурацию** (ни как что не читается). Приложение T5577 → **Wipe Tag**.
- **Hitag Micro (8265/8210/H5.5) требует хорошего позиционирования.** Запись идёт дольше и чувствительна к положению; у
  Флиппера на LF есть только TX, поэтому успех подтверждается только обратным чтением.
- **«Success» на неперезаписываемой карте.** Если на метке только для чтения уже тот же ID, обратное чтение совпадает и
  запись считается успешной.
- **Брелоки в толстом / металлическом корпусе.** Пробуйте разные места — катушка в брелоке часто смещена от центра.
