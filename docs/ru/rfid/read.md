# Чтение, сохранение и эмуляция 125 кГц меток

125 кГц метка — это транспондер, который, получив питание от поля считывателя, передаёт фиксированный ID. Если метка
использует один из [поддерживаемых протоколов](/ru/rfid/protocols), Flipper Zero декодирует ID, показывает его и может
сохранить на SD-карту, эмулировать перед считывателем или [записать на заготовку](/ru/rfid/write).

**Когда пригодится:** нужна копия своего пропуска / брелока во Флиппере, нужно понять, что за метка у вас, или узнать
ID для СКУД, которой вы управляете.

::: tip Нужна SD-карта
Сохранённые ключи, словари и настройки лежат на microSD (`/ext/lfrfid/`). Ставьте прошивку со вставленной картой,
чтобы ресурсы приложения были на месте.
:::

## Чтение метки

1. Откройте `Main Menu → 125 kHz RFID → Read`.
2. Приложите метку к **задней** стороне Флиппера, ближе к центру, и не двигайте. На экране — *Don't move card*.
3. Флиппер по кругу перебирает три прохода примерно по 2 секунды и показывает текущий как **Reading 1/3 … 3/3**:
   **ASK** (125 кГц), **PSK** (125 кГц) и **134kHz** (ASK на 134,2 кГц, для чипов животных).

   ![Чтение 1/3: активен проход ASK, ниже PSK и 134 кГц, внизу надпись «Don't move card»](/screens/lfrfid/read.png)

4. Следите за светодиодом: при чтении он мигает **голубым**, становится **жёлтым**, когда что-то слышно, и **зелёным**,
   когда начинают декодироваться кадры метки — так удобно искать лучшее положение.
5. Когда метка прочитана, Флиппер пищит и показывает экран результата:
   - заголовок: производитель и протокол, например **EM-Micro EM4100**;
   - `Hex:` — сырые данные ключа (первые 7 байт, у длинных ключей в конце `...`);
   - расшифрованные поля (код объекта / facility code, номер карты и т. п. — см. [протоколы](/ru/rfid/protocols)).

   ![Результат чтения: EM-Micro EM4100, hex-данные, код объекта, номер карты, DEZ 8 и DEZ 10, внизу Retry и More](/screens/lfrfid/read_success.png)

6. Кнопки: <kbd>←</kbd> **Retry** (спросит *Retry Reading? All unsaved data will be lost*), <kbd>→</kbd> **More**,
   <kbd>Back</kbd> предложит выйти, потеряв несохранённое чтение.

::: tip Unleashed
В стоковой документации описано только переключение ASK/PSK. В Unleashed есть третий проход **134 кГц** (метки
FDX-A/FDX-B настроены на 134,2 кГц, и слабые отвечают только там), а для EM4100 дополнительно показываются **DEZ 8** и
**DEZ 10** — десятичные формы, которые печатают на брелоках. Если EM4100 подходит под пропуск Casi-Rusco C10106,
появляется строка `or C10106: …`, а ключ Generic HIDProx сверяется с известными форматами HID (H10304, H10302, S10401,
H10306, Corp1000-35) и для них выводятся FC/номер карты.
:::

## После чтения: More

<kbd>→</kbd> **More** открывает:

| Пункт | Действие |
|---|---|
| **Save** | Ввести имя (по умолчанию с префиксом `RFID`), сохраняется как `/ext/lfrfid/<имя>.rfid` |
| **Emulate** | Сразу эмулировать ключ без сохранения |
| **Write** | Записать ключ на заготовку — см. [Запись](/ru/rfid/write) |

## Чтение с фиксированной модуляцией

Некоторым меткам не хватает одного двухсекундного прохода или они надёжно находятся только конкретным демодулятором.
`Main Menu → 125 kHz RFID → Extra Actions`:

| Пункт | Что читает |
|---|---|
| **Read ASK (Regular)** | Только ASK на 125 кГц, пока метка не найдётся: EM4100, HID, AWID, Viking, Paradox… |
| **Read PSK (Indala)** | Только PSK: Indala, Keri, Nexwatch, Idteck… |
| **Read FDX-B (Animals)** | Только ASK на 134,2 кГц — чипы животных, см. [Чипы животных](/ru/rfid/animal-microchips) |

В режиме Debug в этом же меню появляются **Read RAW RFID data** и **Emulate RAW RFID data** — см. [RAW](/ru/rfid/raw).

## Сохранённые ключи

`Main Menu → 125 kHz RFID → Saved` открывает файловый браузер в `/ext/lfrfid/`. Меню ключа `.rfid`:

![Меню сохранённого ключа: Emulate, Write, Write and set password и Edit](/screens/lfrfid/saved_menu.png)

| Пункт | Действие |
|---|---|
| **Emulate** | Эмулировать ключ перед считывателем |
| **Write** | Записать на заготовку ([Запись](/ru/rfid/write)) |
| **Write and set password** | Записать на T5577 и защитить паролем ([Запись](/ru/rfid/write#write-and-set-password)) |
| **Edit** | Изменить данные в hex; сохраняется под тем же именем |
| **Rename** | Переименовать файл |
| **Delete** | Удалить файл (с подтверждением) |
| **Info** | Имя, протокол, полный hex и все расшифрованные поля |

::: tip Unleashed
В браузере видны и дампы блоков **`.t5577`** (со значком T5577). При выборе такого файла запускается
[приложение T5577](/ru/rfid/t5577-app) с этим дампом. Если приложения нет — *No T5577 app — It comes with the firmware - install
its resources to get it*.
:::

## Эмуляция

1. Откройте сохранённый ключ (или свежее чтение через **More**) и выберите **Emulate**.
2. На экране *Emulating*, `[Протокол]` и имя ключа (или *Unsaved Tag*); светодиод мигает пурпурным.

   ![Экран эмуляции: надпись «Emulating», протокол [EM4100] и имя ключа](/screens/lfrfid/emulate.png)

3. Приложите Флиппер задней стороной плашмя к считывателю. <kbd>Back</kbd> — остановить.

## CLI

Через USB/serial CLI (команда `rfid`):

```text
rfid read <optional: normal | indala | ask134>   - read in ASK/PSK mode
rfid <write | emulate> <key_type> <key_data>      - write or emulate a card
rfid raw_read <ask | ask134 | psk> <filename>     - read and save raw data to a file
rfid raw_emulate <filename>
rfid raw_analyze <filename>
```

`key_type` — имя протокола, как в файлах `.rfid` (например `EM4100`, `H10301`), `key_data` — hex.

## Если не получается

- **Ничего не находится.** Возможно, это карта 13,56 МГц — попробуйте [NFC](/ru/nfc/read). Многие «двойные» карты
  содержат оба чипа.
- **Чтение крутится по кругу.** Попробуйте фиксированный режим в **Extra Actions** — двухсекундного прохода может не
  хватать.
- **Слабые метки / маленькие брелоки.** Медленно водите меткой по задней стороне, ориентируйтесь на жёлтый/зелёный
  светодиод. Не держите метку над металлом.
- **Неизвестный протокол.** Сделайте [RAW-запись](/ru/rfid/raw) и отправьте разработчикам.
- **Считыватель не принимает эмуляцию.** Некоторые считыватели капризны к расстоянию и ориентации — держите Флиппер
  плашмя, попробуйте разные положения. Считыватели, проверяющие что-то кроме ID (например, крипто-карты), эмуляцией
  не обмануть.
