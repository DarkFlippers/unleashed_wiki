# Приложение T5577

Приложение **T5577** (автор @mishamyte, входит в Unleashed) работает с заготовкой T5577 / ATA5577 **на уровне
блоков** — с самим кристаллом, а не с картой, которую он изображает. Оно умеет читать и сохранять блоки чипа,
редактировать любой блок или собирать слово конфигурации, записывать сохранённый дамп обратно, проверять, какие блоки
принимают запись, очищать метку, снимать пароль и перехватывать пароль из эфира, слушая считыватель или копировщик.

Запуск: `Main Menu → Apps → RFID → T5577` (файл `/ext/apps/RFID/t5577.fap`). Приложение 125 kHz RFID тоже запускает
его, если открыть файл `.t5577` из **Saved**.

::: tip Unleashed
В стоковой прошивке такого приложения нет. Clear Password и очистка T5577 раньше были в **Extra Actions** приложения
125 kHz RFID — теперь они здесь.
:::

## Немного теории: что внутри T5577

| Страница / блок | Содержимое |
|---|---|
| Страница 0, блок 0 | **Конфигурация**: модуляция, скорость, сколько блоков данных отдаётся (max block), бит пароля и прочие флаги |
| Страница 0, блоки 1–6 | Данные — кадр эмулируемой карты |
| Страница 0, блок 7 | Хранилище пароля (или обычные данные, если пароль не включён) |
| Страница 1, блок 0 | Копия конфигурации |
| Страница 1, блоки 1–3 | Заводские данные прослеживаемости (у оригинальных чипов блоки 1–2 заблокированы) |

## Главное меню

| Пункт | Что делает |
|---|---|
| **Read Tag** | Прочитать все блоки в дамп |
| **Test Tag** | Выяснить, какие блоки принимают запись (сначала бэкап, потом всё возвращается) |
| **Saved** | Открыть сохранённый дамп `.t5577` |
| **Wipe Tag** | Сбросить чип в чистое состояние |
| **Clear Password** | Снять пароль: сначала ваше слово, потом словарь |
| **Sniff Password** | Слушать считыватель / копировщик и декодировать его команды |
| **Passwords** | Словари и управление своими паролями |

## Read Tag

1. `T5577 → Read Tag`. Приложите метку к задней стороне и не двигайте (*Finding tag*, затем `P0 block N…`).
2. Экран результата **T5577 read** показывает `Block 0: XXXXXXXX` и сводку вида `RF/64, password set, inverted`.
   Кнопки: **Save**, **Info**, **Retry**.
   - **Info** — расшифровка конфигурации (Modulation, Bit rate, Max block, флаги PWD/AOR/ST/XM/POR, Password) и все
     блоки страниц 0 и 1; непрочитанные блоки показаны прочерками.
   - **Save** спросит *Name the dump* и сохранит `/ext/lfrfid/<имя>.t5577`.
3. **Read in part** — метка перестала отвечать на середине, указан блок, на котором это случилось. Положите получше и
   повторите.
4. **Nothing found** — *Hold the tag still, or it needs a password*. Кнопки **No pass** (повтор без пароля) и
   **Password**.

::: danger Чтение с паролем может испортить открытую метку
При выборе **Password** появится *Only if it is protected — A password read writes block 0 of a tag that has no
password set*. Кадр чтения с паролем той же длины, что и запись: если у метки пароля **нет**, ваш «пароль» запишется в
блок 0, и метка перестанет читаться как что-либо. Плохо приложенная метка выглядит в точности как защищённая, поэтому
всегда сначала повторяйте чтение без пароля. Если потом выяснится, что пароль метке был не нужен, приложение
предупредит: *Tag wants no password — That frame wrote block 0. Check it below, and wipe the tag if it reads wrong*.
:::

## Сохранённые дампы

`T5577 → Saved` — список файлов `.t5577`. Меню дампа:

| Пункт | Действие |
|---|---|
| **Info** | Расшифровка конфигурации и все блоки |
| **Write to Tag** | Записать дамп обратно (спросит *Write to tag* с количеством блоков) |
| **Edit** | Редактировать блоки |
| **Rename** / **Delete** | Управление файлом (в дампе может храниться пароль метки — удалите его, если он не должен оставаться на карте) |

### Write to Tag

Пишутся только реально прочитанные блоки, в порядке Proxmark3: страница 0 блоки 1–7, страница 1 блоки 1–3,
**блок 0 последним**. Нулевой блок 0 не пишется никогда. После записи каждый блок читается обратно. Возможные
результаты: **Written!**, **Not written**, *Lost the tag at P0 block N*, *P0 block N differs*, *Tag wants a password
this dump has not* или *P1 trace unchanged* (оригинальные чипы не дают менять блоки прослеживаемости — это нормально).

Если блок 0 описывает конфигурацию, которую Флиппер не умеет декодировать, перед записью предупредят: *Nothing will read
back*.

### Edit

**Edit blocks** — список всех блоков со значениями. Выберите блок, чтобы ввести новое 32-битное слово. **Блок 0**
открывает редактор конфигурации с именованными полями:

- **Modulation**: Direct, PSK1, PSK2, PSK3, FSK1, FSK2, FSK1a, FSK2a, ASK/MC, Biphase, Diphase
- **Bit rate**: RF/8, RF/16, RF/32, RF/40, RF/50, RF/64, RF/100, RF/128
- **Data blocks** (max block), **Password bit** и **Word** — сырое hex-значение.

При выходе *Save changes — Write the edited blocks back to the file* спросит, сохранять ли. Отказ заодно отменяет правку
в памяти, чтобы она случайно не попала на метку.

## Test Tag

Определяет, какие блоки 1–7 страницы 0 действительно принимают запись. Спросит *Do not move the tag — A backup is
saved, then every block is written and put back*.

- Перед первой записью весь дамп читается и сохраняется как `/ext/lfrfid/t5577/T5577_before_test.t5577`.
- В каждом блоке инвертируется один бит, блок читается обратно, затем оригинал записывается назад и проверяется.
- Результаты: **Full T5577** (всё записывается), **Nothing writeable**, *Stopped at block N*, *Lost tag at block N —
  Check it, then retry*, *Block N is not back* (восстановите из бэкапа), **Tag has a password — Not supported yet**.
- Если прошлый тест оставил метку изменённой, перед перезаписью бэкапа будет предупреждение *Unfinished test*.

## Wipe Tag

Подтвердите *Wipe T5577 — Erases all data. The tag stops working as a key. Hold still while running* → **Wipe**. Блоки
данных обнуляются, пишется стандартная конфигурация, результат проверяется чтением.

- **Wiped!** — готово, записывайте новый ключ из приложения 125 kHz RFID.
- **Not wiped** — *No answer. Protected? Try Clear Password*, *The tag answered, but not as wiped* или *Could not check
  what the tag holds*.

Очистка **не** снимает пароль.

## Clear Password

1. `Clear Password` спросит *Password to try first* — введите пароль метки, если знаете (или оставьте как есть).
2. Подтвердите *Apply tag to Flipper's back and don't move it while it runs* → **Start**.
3. Приложение сначала проверяет, защищена ли метка вообще, затем пробует ваш пароль, потом **пользовательский словарь**,
   потом **системный** (`Pass N of M`). Пишется только блок 0 со сброшенным битом пароля — та же одиночная запись, что
   и в Proxmark3.
4. Результаты: **Cleared!** (*Opened by this password* — с кнопкой **Save**, чтобы добавить слово в свой список),
   *The tag was asking for no password*, **Not cleared** (*No password matched, or no tag answered*) или ошибки словаря /
   SD-карты.

После снятия пароля в блоке 7 остаётся старое значение — убирается только бит защиты.

## Sniff Password

Перехватывает пароль, **слушая**, как считыватель или копировщик общается с меткой. Флиппер ничего не передаёт и не
включает поле — можно спокойно прикладывать к чужому оборудованию.

1. `Sniff Password`. На экране *Listening* / *Hold on the cloner* и живая осциллограмма.
2. Приложите Флиппер задней стороной к копировщику или считывателю — туда, где должна лежать метка, — и дайте
   устройству выполнить запись/чтение.
3. Захват заканчивается после полной команды и паузы; экран результата покажет, что было услышано:
   - **Password** — *The cloner sent it* (услышано чтение/запись с паролем);
   - **New password** — *Written to block 7* (копировщик устанавливал пароль);
   - **Maybe a password** — 38-битный кадр может быть и чтением с паролем, и записью; оба варианта — в **More**;
   - **No password** / **Commands heard** — *None of them carried a password*;
   - **Too much noise**, **Can't decode**, **Nothing heard**.
4. **More** — список всех декодированных команд (Reset, Read/Write с паролем и без, с блоком и данными). **Save**
   сохраняет найденный пароль в пользовательский словарь (для варианта, выведенного по соседним кадрам, сначала
   спросит *Save a deduction?*).

## Passwords

`T5577 Passwords` показывает **System dict: N** и **User dict: N**, кнопки **Add** и **List** (выберите слово, чтобы
удалить).

| Файл | Содержимое |
|---|---|
| `/ext/lfrfid/assets/t5577_dict.lfrfid` | Системный список (пароли из Proxmark3, перезаписывается при обновлении прошивки) |
| `/ext/lfrfid/assets/t5577_dict_user.lfrfid` | Ваши пароли — Clear Password пробует их первыми, при обновлении не теряются |
