# Чипы животных (FDX-B, FDX-A)

Чип животного — RFID-транспондер размером с рисовое зерно, который вживляют под кожу. При считывании он передаёт ID,
по которому можно найти владельца в базах поиска животных. Flipper Zero читает два распространённых LF-типа:

| Тип | Имя во Флиппере | Описание |
|---|---|---|
| **FDX-B** | `FDX-B` (ISO) | ISO 11784/11785, 15-значный ID; самый распространённый; некоторые чипы ещё и передают температуру тела |
| **FDX-A** | `FDX-A` (FECAVA) | Старые 10-значные чипы, не соответствуют ISO |

Большинство чипов животных работают на **134,2 кГц**, а антенна Флиппера настроена на 125 кГц, поэтому дальность
маленькая — около **1 см**. Чипы диапазона 110–140 кГц читаются, но ближе.

::: tip Unleashed
Официальная документация советует *Read ASK*. Unleashed генерирует для таких чипов настоящее поле **134,2 кГц**:
- **Read** выполняет третий проход **134kHz** после ASK и PSK;
- `Extra Actions → Read FDX-B (Animals)` всё время работает на 134,2 кГц — лучший вариант для слабых чипов;
- название страны для FDX-B берётся из `/ext/lfrfid/assets/iso3166.lfrfid`.
:::

## Как прочитать чип питомца

1. Откройте `Main Menu → 125 kHz RFID → Extra Actions → Read FDX-B (Animals)`. На экране — *Reading FDX-B*.
2. Найдите чип:
   - у собак и кошек он обычно под кожей **между лопатками**; в континентальной Европе часто **посередине левой стороны
     шеи**. Чип может немного мигрировать;
   - аккуратно прощупайте пальцами твёрдый предмет размером с рисовое зерно и положите центр задней стороны Флиппера
     прямо над ним.
3. Держите Флиппер неподвижно около **3 секунд** в каждой точке. Если не нашлось — двигайте маленькими шагами по
   области, затем поверните Флиппер на 90° и повторите.
4. Следите за светодиодом: жёлтый/зелёный — сигнал ловится, оставайтесь на месте.
5. После декодирования появится экран результата. <kbd>→</kbd> **More → Save** — сохранить.

## Что показывает Флиппер для FDX-B

| Поле | Значение |
|---|---|
| `ID: CCC-NNNNNNNNNNNN` | 3-значный код страны (ISO 3166-1 numeric) или производителя + 12-значный национальный ID — 15-значный номер для поиска |
| Country Code / Country | Код и название страны из таблицы ISO 3166 |
| Temperature | У термочипов, в °C и °F; `---`, если нет |
| Animal | Флаг применения для животных |
| Visual Start Digit, Replacement Number, User Info, RFU | Поля заголовка ISO-кадра |
| Data Block | Present / Absent — дополнительный блок данных (например, температура) |
| RUDI Bit | Yes / No |

FDX-A показывает `ID` из 10 hex-цифр и `Parity`.

::: warning
Температура с чипа не заменяет нормальный градусник.
:::

## Поиск по ID

Введите 15-значный ID в базе поиска животных, например:
- [AAHA Pet Microchip Lookup](https://www.aaha.org/petmicrochiplookup) — США и Канада
- [Europetnet](https://www.europetnet.com/) — Европа
- [PETMAXX](http://www.petmaxx.com/) — весь мир

Или обратитесь в местную ветклинику / реестр животных.

## Если чип не находится

- Слишком далеко — шаги меньше, держите дольше в каждой точке.
- Чип мигрировал — сканируйте бо́льшую область.
- Рядом металл или электроника — отойдите от них.
- У животного может быть чип 13,56 МГц — попробуйте [NFC](/ru/nfc/read).
- Неподдерживаемый чип — попросите ветеринара просканировать.

Ключи FDX-B можно [эмулировать или записать](/ru/rfid/write) (заготовки T5577 и EM4305, бывают и в стеклянном
корпусе) — например, чтобы проверить дверцу для питомца.
