# Модуль Math

Математические функции и константы. Сначала подключите модуль:

```js
let math = require("math");
```

::: tip
`math` — самый большой JS-модуль: после загрузки он занимает около 21 КБ ОЗУ. Если нужно только округлить неотрицательное число вниз, `x | 0` даёт тот же результат, что `math.floor(x)`, без загрузки модуля.
:::

## Константы

| Константа | Значение |
|---|---|
| `PI` | π = 3.14159265358979323846264338327950288 |
| `E` | e (число Эйлера) = 2.71828182845904523536028747135266250 |
| `EPSILON` | Наименьшее число, при котором 1.0 + EPSILON != 1.0; EPSILON = 2.2204460492503131e-16 |

## Методы

### abs()
`abs(x)` — модуль числа. Для отрицательного `x` (включая -0) возвращает `-x`, иначе `x`. Результат всегда положительный или 0.

```js
math.abs(-5); // 5
```

### acos()
`acos(x)` — арккосинус в радианах. `x` от -1 до 1 включительно (косинус угла). Возвращает угол от 0 до π включительно. Если `x` меньше -1 или больше 1, возвращает `NaN`.

```js
math.acos(-1); // 3.141592653589793
```

### acosh()
`acosh(x)` — обратный гиперболический косинус. `x` ≥ 1.

```js
math.acosh(1); // 0
```

### asin()
`asin(x)` — арксинус в радианах. `x` от -1 до 1 включительно. Возвращает угол от -π/2 до π/2 включительно.

```js
math.asin(0.5); // 0.5235987755982989
```

### asinh()
`asinh(x)` — обратный гиперболический синус.

```js
math.asinh(1); // 0.881373587019543
```

### atan()
`atan(x)` — арктангенс в радианах, от -π/2 до π/2 включительно.

```js
math.atan(1); // 0.7853981633974483
```

### atan2()
`atan2(y, x)` — угол в радианах (от -π до π включительно) между положительной осью x и лучом из (0, 0) в точку (x, y).

- `y` — координата y точки;
- `x` — координата x точки.

```js
math.atan2(90, 15); // 1.4056476493802699
```

### atanh()
`atanh(x)` — обратный гиперболический тангенс. `x` от -1 до 1 включительно.

```js
math.atanh(0.5); // 0.5493061443340548
```

### cbrt()
`cbrt(x)` — кубический корень.

```js
math.cbrt(2); // 1.2599210498948732
```

### ceil()
`ceil(x)` — округление вверх: наименьшее целое, большее или равное `x`. То же, что `-math.floor(-x)`.

```js
math.ceil(-7.004); // -7
math.ceil(7.004);  // 8
```

### clz32()
`clz32(x)` — количество ведущих нулевых битов в 32-битном двоичном представлении `x`.

```js
math.clz32(1);    // 31
math.clz32(1000); // 22
```

### cos()
`cos(x)` — косинус угла в радианах, от -1 до 1 включительно.

```js
math.cos(math.PI); // -1
```

### exp()
`exp(x)` — e в степени `x` (неотрицательный результат).

```js
math.exp(0); // 1
math.exp(1); // 2.718281828459045
```

### floor()
`floor(x)` — округление вниз: наибольшее целое, меньшее или равное `x`. То же, что `-math.ceil(-x)`.

```js
math.floor(-45.95); // -46
math.floor(-45.05); // -46
math.floor(-0); // -0
math.floor(0); // 0
math.floor(45.05); // 45
math.floor(45.95); // 45
```

### log()
`log(x)` — натуральный логарифм ln(x).

```js
math.log(1); // 0
math.log(3); // 1.0986122886681098
```

### isEqual()
`isEqual(a, b, tolerance)` — `true`, если разница между `a` и `b` меньше `tolerance`, иначе `false`.

```js
math.isEqual(1.4, 1.6, 0.2);      // false
math.isEqual(3.556, 3.555, 0.01); // true
```

### max()
`max(a, b)` — большее из двух чисел.

```js
math.max(10, 20);   // 20
math.max(-10, -20); // -10
```

### min()
`min(a, b)` — меньшее из двух чисел.

```js
math.min(10, 20);   // 10
math.min(-10, -20); // -20
```

### pow()
`pow(base, exponent)` — `base` в степени `exponent`.

```js
math.pow(7, 2);  // 49
math.pow(7, 3);  // 343
math.pow(2, 10); // 1024
```

### random()
`random()` — псевдослучайное число с плавающей точкой от 0 (включительно) до 1 (не включая), распределённое примерно равномерно. Масштабируйте его под нужный диапазон.

```js
let num = math.random();
```

### sign()
`sign(x)` — -1, если `x` меньше 0, иначе 1.

```js
math.sign(3);  // 1
math.sign(0);  // 1
math.sign(-3); // -1
```

### sin()
`sin(x)` — синус угла в радианах, от -1 до 1 включительно.

```js
math.sin(math.PI / 2); // 1
```

### sqrt()
`sqrt(x)` — квадратный корень, `x` ≥ 0. Если `x` < 0, скрипт **завершится с ошибкой**.

```js
math.sqrt(25); // 5
```

### trunc()
`trunc(x)` — целая часть `x` без дробных разрядов.

```js
math.trunc(-1.123); // -1
math.trunc(0.123);  // 0
math.trunc(13.37);  // 13
math.trunc(42.84);  // 42
```
