# Первое приложение на JavaScript

Напишем маленький скрипт, который выводит числа с задержкой, и запустим его двумя способами: из меню Flipper и с компьютера через CLI. Понадобятся Flipper Zero, ПК и USB-кабель.

## Шаг 1. Создайте скрипт

Создайте текстовый файл `first_app.js` с таким содержимым:

```js
print("start");
delay(1000);
print("1");
delay(500);
print("2");
delay(500);
print("3");
delay(500);
print("end");
```

Что он делает:

- выводит **start** и ждёт 1 секунду;
- выводит **1**, **2** и **3** с паузой 0,5 секунды после каждого;
- выводит **end**.

`print()` выводит текст, а `delay()` делает паузу на заданное число миллисекунд (1000 мс = 1 с). Обе функции **встроенные**, подключать модули для них не нужно. Полный список см. в [Встроенные функции](/ru/dev/js-builtin).

## Шаг 2. Скопируйте файл на Flipper Zero

1. Подключите Flipper Zero к ПК по USB.
2. Откройте [qFlipper](/ru/mobile/qflipper).
3. Перейдите на вкладку **File manager** и откройте `SD Card/apps/Scripts/`.
4. Перетащите `first_app.js` в окно qFlipper.

Можно скопировать файл и через картридер. Главное, чтобы он оказался в `/ext/apps/Scripts/`.

## Шаг 3. Запустите скрипт

### Из меню Flipper

1. Откройте `Main Menu → Apps → Scripts`. В списке будут скрипты из `SD Card/apps/Scripts/`.
2. Выберите `first_app`.
3. Нажмите <kbd>OK</kbd>.

![Скрипт на экране Flipper Zero](/img/dev/js_first_app_on_fz.jpg)

Строки появятся на экране Flipper с заданными в скрипте паузами.

### Из CLI

Запуск из [CLI](/ru/dev/cli) удобен при отладке: правите и проверяете скрипт, не трогая само устройство.

1. Подключите Flipper Zero по USB.
2. Откройте CLI (например, вкладка CLI в qFlipper, любой терминал последовательного порта или `./fbt cli`).
3. Введите `js` и путь к скрипту:

```sh
js /ext/apps/Scripts/first_app.js
```

![Вывод скрипта в CLI](/img/dev/js_first_app_on_cli.jpg)

При запуске из CLI всё, что выводит `print()`, уходит в CLI, а не на экран Flipper.

## Возможные проблемы

- **Скрипта нет в списке.** Проверьте расширение `.js` и что файл лежит в `/ext/apps/Scripts/` (подпапки допустимы, в них можно зайти).
- **Скрипт падает с ошибкой.** mJS поддерживает только часть JavaScript (нет замыканий, стрелочных функций, классов). Запустите скрипт из CLI, чтобы увидеть текст ошибки и строку.
