# Приложение Nice O-Code

**Nice O-Code** (автор @xMasterX) восстанавливает 16-битный **код инсталлятора (IC)** пульта Nice O-Code и сохраняет пульт в `.sub` — либо как обычный клон, либо как **новый пульт** той же инсталляции, который можно привязать к приёмнику.

## Немного теории

Nice O-Code — это Nice FloR-S, зашифрованный кодом инсталлятора: одно значение на все пульты инсталляции. Приёмник принимает только пульт со своим IC. Одного нажатия недостаточно, но **четыре и больше нажатий** одного пульта — достаточно: только правильный код даёт один и тот же серийник во всех посылках. Приложение собирает нажатия и перебирает все 65 536 кодов прямо на Флиппере.

Некоторые пульты O-Code ещё передают **сертификат** приёмника (длинный пакет 112 бит, только первые двадцать использований пульта). Если приложение его увидит, то после нахождения IC расшифрует и покажет как `Cert`.

::: tip Unleashed
Nice O-Code — встроенное системное приложение Unleashed, а приложение Sub-GHz умеет декодировать и отправлять O-Code, если в файле есть IC. В `Add Manually` есть пункты `Nice O-Code`, `Nice O-Code One` и `Nice O-Code+Crt` — см. [Add manually](/ru/subghz/add-manually) и [Привязка нового пульта](/ru/subghz/remote-prog).
:::

::: warning
Используйте только со своей инсталляцией. Клон делит счётчик с оригиналом, и они будут конфликтовать (см. [Динамические коды](/ru/subghz/rolling-codes)).
:::

## Что нужно

- Файл ключей Nice FloR-S `/ext/subghz/assets/nice_flor_s` на SD-карте (идёт с прошивкой). Без него приложение пишет `No rainbow table`.
- Рабочий пульт O-Code этой инсталляции. Приложение слушает **433.92 МГц AM650** через встроенное или [внешнее](/ru/subghz/external-cc1101) радио (`Int` / `Ext` в заголовке).

## Захват пульта

1. Откройте `Main Menu → Apps → Sub-GHz → Nice O-Code`.
2. Выберите `Capture remote`. В статусе — `Listening 433.92`.
3. Нажмите кнопку пульта **4 и более раз — короткими нажатиями, не удерживая**. Каждое новое нажатие показывается как `Press N: …`, строка `Presses n/4  Xpkt` и полоска заполняются. Если у пульта есть сертификат, в конце строки будет `+Crt`.
4. Когда набралось 4 нажатия, появится `Solve` — нажмите <kbd>OK</kbd>.
5. Экран `Trying installer codes` со счётчиком до 65536. <kbd>←</kbd> (`Cancel`) — отмена.
6. При успехе: `IC XXXX`, `Serial XXXXXXX` и, если есть, `Cert XXXXXX`.

Возможные статусы:

| Статус | Значение |
|---|---|
| `Not O-Code, ignored` | пакет не O-Code (например, обычный FloR-S) |
| `Same press, ignored` | повтор уже сохранённого нажатия |
| `Need 4+ packets` | мало нажатий для решения |
| `Ambiguous, capture more` | подходит несколько кодов — нажмите пульт ещё несколько раз и решите снова |
| `No code fits, not O-Code?` | ни один код не подошёл — скорее всего это не O-Code или смешались нажатия разных пультов |

## Сохранение

На экране результата:

- <kbd>OK</kbd> (`Save`) — **клон** захваченного пульта (имя по умолчанию `NiceO`). Для тестов, но он будет конфликтовать с оригиналом по счётчику.
- <kbd>→</kbd> (`New`) — **новый пульт**: тот же IC, кнопка и сертификат, но свой серийник и счётчик (имя `NiceO_new`). Именно его привязывают к приёмнику. Счётчик ставится близко к значению рабочего пульта, чуть ниже.

Оба файла после ввода имени (`Name the .sub file`) пишутся в `/ext/subghz/` и открываются через `Sub-GHz → Saved`.

Для привязки нового пульта используйте процедуру Nice FloR-S со страницы [Привязка нового пульта](/ru/subghz/remote-prog). Пульт с сертификатом привязывается сам: нажимайте кнопку примерно раз в секунду, **10–15 раз подряд** — ворота откроются где-то на десятом нажатии.

## Decode RAW file

`Decode RAW file` делает то же самое по RAW-файлу `.sub`, записанному ранее через [Read RAW](/ru/subghz/read-raw) (запишите 4+ отдельных нажатия). Файл с ключом отклоняется с сообщением `Not a RAW capture`. Полоска показывает прогресс по файлу.

## Проблемы и решения

- **`No rainbow table`** — нет `/ext/subghz/assets/nice_flor_s`; переустановите прошивку с картой памяти или восстановите папку assets.
- **Нажатия не засчитываются** — делайте отдельные короткие нажатия; удержание повторяет одну и ту же посылку.
- **Новый приёмник с завода игнорирует O-Code** — в нетронутом приёмнике нет кода инсталлятора; привяжите кнопкой обычный `Nice One` / `Nice FloR-S` (см. [Привязка нового пульта](/ru/subghz/remote-prog)).
- **Приёмник не принимает новый пульт** — держите счётчик рядом со значением рабочего пульта, не сбрасывайте в ноль.
