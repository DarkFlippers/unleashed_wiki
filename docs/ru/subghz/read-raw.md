# Read RAW (запись сырого сигнала)

**Read RAW** записывает демодулированный сигнал «как есть», без декодирования — как диктофон. Запись можно
воспроизвести, сохранить, позже декодировать или отредактировать. Пригодится, когда:

- **Read** не распознаёт пульт (неизвестный протокол);
- нужно снять сигнал для анализа или для запроса нового протокола разработчикам;
- нужен точный повтор статического сигнала, протокол которого Флиппер не знает.

Запись производится с выбранными **частотой и модуляцией** — Флиппер не SDR. С неправильной частотой или модуляцией
вы запишете только шум.

::: warning Динамические коды
Повтор RAW-записи пульта с динамическим кодом — то же самое, что клон: он сдвигает счётчик приёмника и может
рассинхронизировать оригинал. **Никогда не делайте так с ключом от машины** — ключ могут заблокировать. Подробнее:
[Динамические коды](/ru/subghz/rolling-codes).
:::

## Запись

1. Если частота неизвестна — определите её [анализатором](/ru/subghz/frequency-analyzer).
2. Откройте `Main Menu → Sub-GHz → Read RAW`.
3. Нажмите <kbd>←</kbd> **Config** и задайте `Frequency`, `Modulation` и `RSSI Threshold:` (см. ниже).
   <kbd>Back</kbd> — назад.

   ![Read RAW готов к записи: пустая осциллограмма, кнопки Config и REC](/screens/subghz/read_raw.png)

4. Нажмите <kbd>OK</kbd> **REC**. Пойдёт осциллограмма, справа — уровень RSSI.
5. Нажмите кнопку пульта (держите 1–2 с).

   ![Идёт запись RAW: две посылки на осциллограмме, счётчик сэмплов и кнопка Stop](/screens/subghz/read_raw_recording.png)

6. Нажмите <kbd>OK</kbd> **Stop**.
7. Дальше три варианта:
   - <kbd>←</kbd> **Erase** — стереть и начать заново;
   - <kbd>OK</kbd> **Send** — воспроизвести запись (удержание — повтор);
   - <kbd>→</kbd> **Save** — ввести имя (по умолчанию `RAW_<дата-время>`) и сохранить в `/ext/subghz/`.

## Config в Read RAW

Меню настроек в RAW короче, чем в Read:

| Пункт | Значения | Что значит |
|---|---|---|
| `Frequency` | список частот | Частота приёма |
| `Modulation` | `AM270`, `AM650`, `FM238`, `FM476`, `FM12K` + свои | Пресет демодуляции |
| `Sound` | `OFF` / `ON` | Выводить принимаемый сигнал в динамик |
| `RSSI Threshold:` | `-----`, `-85.0` … `-40.0` | Запись идёт только пока сигнал выше порога. `-----` — писать всё |

::: tip Зачем порог
С порогом в файл попадают только посылки пульта, а не секунды шума между нажатиями — файлы намного меньше и чище.
Для записей, которые отправляете разработчикам, оставляйте `-----` (полная запись).
:::

## Воспроизведение сохранённого RAW {#playback}

1. `Main Menu → Sub-GHz → Saved` и выберите RAW-файл — он откроется в экране Read RAW.
2. <kbd>OK</kbd> **Send** — отправить запись один раз; держите <kbd>OK</kbd>, чтобы повторять (**Hold to repeat**).
3. <kbd>←</kbd> **New** — новая запись.
4. <kbd>→</kbd> **More**:
   - `Decode` — прогнать запись через все декодеры Sub-GHz; найденные сигналы можно сохранить обычными ключами;
   - `Edit` — открыть файл в приложении [Sub-GHz RAW Edit](/ru/subghz/raw-editor) (пункт виден, только если
     приложение установлено в совместимой версии); после выхода из редактора снова откроется Sub-GHz;
   - `Rename`, `Delete`.

::: tip Unleashed
`More → Decode` и `More → Edit` — дополнительный функционал Unleashed. В `Edit` можно найти реальный сигнал в зашумлённой записи,
обрезать его, склеить файлы и декодировать только выделенный участок.
:::

Длинные «плотные» RAW-файлы при отправке читаются с SD-карты на лету. Если в них очень короткие импульсы (менее 10 мкс),
а карта медленная, передача может оборваться до конца файла — используйте хорошую карту.

## Как записать пульт для запроса нового протокола

Провести такую процедуру просят разработчики Unleashed в случае, когда необходимо собрать образцы неизвестного сигнала для дальнейшей расшифровки и добавления в список поддерживаемых протоколов:

1. Определите частоту анализатором. В Read попробуйте `AM650`, `FM238`, `FM476`, `FM12K` — если ничего не
   декодируется, продолжайте.
2. В Read RAW выставьте эту частоту и **`RSSI Threshold: -----`**.
3. Сделайте **по одной записи на каждую модуляцию**: `AM650`, `FM238`, `FM476`, `FM12K`.
4. Для каждой записи: **REC**, затем нажмите одну кнопку пульта **5 раз, удерживая 1–2 с**, потом **5 раз, удерживая
   ~5 с**. Stop и Save.
5. Если кнопок несколько — запишите каждую так же. Назовите файлы по кнопкам.
6. Скопируйте файлы на ПК, упакуйте в архив и создайте issue в
   [репозитории прошивки](https://github.com/DarkFlippers/unleashed-firmware/issues) или передайте запрос команде
   любым удобным способом ([Официальные ссылки](/ru/community/links) — чаты в Telegram, [Discord](https://discord.unleashedflip.com)).
   Приложите хорошие фото пульта (по возможности и в разобранном виде), модель и производителя.

## Частые проблемы

- **В записи только шум / ровная линия** — не та частота или модуляция, либо пульт далеко. Поднесите ближе.
- **Огромные файлы** — задайте `RSSI Threshold`.
- **Повтор не срабатывает** — у пульта динамический код (приёмник отвергает старые счётчики), модуляция была неверной
  или записалась только часть сигнала. Записывайте более долгие нажатия.
- **Передача обрывается посередине** — медленная SD-карта и длинный файл. Обрежьте файл в
  [RAW Edit](/ru/subghz/raw-editor) или возьмите карту быстрее.
- **Нет пункта `Edit` в `More`** — приложение Sub-GHz RAW Edit не установлено или устарело.
