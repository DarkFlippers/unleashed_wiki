# Remote Analyzer

**Remote Analyzer** (автор @xMasterX) декодирует по одному пульту за раз на встроенном CC1101 и показывает все поля, которые удалось разобрать. В отличие от `Sub-GHz → Read` здесь **нет истории** — на экране только последний сигнал — и приложение **никогда не сохраняет** `.sub`. Это инструмент, чтобы ответить на вопрос «что это за пульт?».

::: tip Unleashed
Remote Analyzer — встроенное системное приложение Unleashed. Помимо всех протоколов приложения Sub-GHz у него есть собственные (только декодирование): **Crypt**, **Crypt Lite**, **Hormann BiSecur**, **KCE6xxx**, **Life Fido**, **Nero Intro II** и **PC4**.
:::

**Когда использовать:** быстро опознать неизвестный пульт, понять, статика это или динамика, проверить пульт, который основное приложение не декодирует. Для записи и повтора — [Read](/ru/subghz/read) или [Read RAW](/ru/subghz/read-raw).

## Главное меню

`Main Menu → Apps → Sub-GHz → Remote Analyzer`:

- `Read` — декодирование в реальном времени
- `Decode RAW File` — прогнать сохранённую RAW-запись через те же декодеры
- `Frequency Analyzer` — определить частоту пульта
- `How to use` — встроенная инструкция

## Чтение пульта

1. Откройте `Read`. На экране `Waiting for a signal`.
2. Нажмите <kbd>←</kbd> (`Config`) и задайте **Frequency** и **Modulation** (или включите **Hopping**).
3. Поднесите пульт к Флипперу и нажмите кнопку.
4. Появится результат:
   - иконка слева вверху — **статический** или **динамический** код;
   - строка под названием протокола и числом бит — знает ли этот протокол приложение Sub-GHz или он **только в анализаторе**;
   - `xN` справа вверху — сколько раз принят этот код;
   - полоска под линией — уровень сигнала.
5. <kbd>↑</kbd> / <kbd>↓</kbd> прокручивают длинный результат, <kbd>→</kbd> (`Reset`) очищает экран.

**Светодиод:** фиолетовый — слушает; жёлтый — в эфире что-то есть, но не декодировалось; зелёный — код принят.

## Config

| Пункт | Что делает |
|---|---|
| Frequency | частота приёма (игнорируется при включённом Hopping) |
| Modulation | пресет: AM270, AM650, FM238, FM476, FM12K и пользовательские |
| Hopping | `OFF` или порог от `-90dB` до `-40dB` |
| Sound | выводить демодулированный сигнал на динамик |
| Mod. sweep | перебирать другие модуляции, если ничего не декодируется |
| Notify | вибро один раз на код, отличающийся от предыдущего |
| Reset to default | сбросить настройки |

**Hopping.** При заданном пороге приложение перебирает **315, 390, 430.5, 433.92, 434.42 и 868.35 МГц**, пока в эфире тихо, и останавливается на первой частоте, где несущая достигла порога. После декодирования частота удерживается две секунды, затем перебор продолжается. Выбор частоты в Frequency Analyzer отключает hopping. Этот же порог используют sweep и светодиод как признак «есть сигнал», поэтому он важен и при `OFF`.

**Mod. sweep.** Если пульт явно передаёт, но ничего не декодируется, приложение перебирает модуляции примерно по секунде. `~` рядом с модуляцией — ещё пробует, **держите кнопку пульта**. Первое удачное декодирование фиксирует модуляцию, `~` пропадает; после двух секунд без декодирования перебор начинается заново с неё. `Unknown remote` — за весь круг ничего не нашлось; пока кнопка зажата, идёт следующий круг.

**Notify.** Зажатый пульт повторяет один код — тогда только мигает светодиод; новый код ещё и вибрирует.

## Decode RAW File

1. Выберите `Decode RAW File` и RAW-файл `.sub` из `/ext/subghz`.
2. Полоска показывает прогресс по файлу.
3. Выводится список всех различных найденных кодов; <kbd>OK</kbd> на строке — полный разбор.

Сэмплы есть только в RAW-записи — файл с ключом отклоняется. Если ничего не декодировалось (или файл отклонён) — звук ошибки и красный светодиод.

## Frequency Analyzer

Держите кнопку пульта рядом с Флиппером, затем **удерживайте** <kbd>OK</kbd>, чтобы перенести найденную частоту в `Read`. <kbd>←</kbd> / <kbd>→</kbd> двигают порог триггера. Работает так же, как [анализатор основного приложения](/ru/subghz/frequency-analyzer).

## Проблемы и решения

- **Всё время `Waiting for a signal`** — не та частота; запустите Frequency Analyzer или включите Hopping.
- **Жёлтый светодиод, но нет декода** — включите `Mod. sweep` и держите кнопку, либо запишите сигнал через [Read RAW](/ru/subghz/read-raw) и попробуйте `Decode RAW File`.
- **Протокол «только в анализаторе»** — основное приложение не может его сохранить или отправить, анализатор лишь опознаёт.
- **Нужно сохранить сигнал** — используйте [Read](/ru/subghz/read); это приложение файлы не пишет.
