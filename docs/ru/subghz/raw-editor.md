# Sub-GHz RAW Edit

**Sub-GHz RAW Edit** (автор Lechnio) — небольшой редактор формы сигнала для RAW-файлов `.sub` прямо на Флиппере. Запись [Read RAW](/ru/subghz/read-raw) обычно содержит секунды шума вокруг короткой нужной посылки. В RAW Edit вы находите настоящий сигнал, отмечаете его и сохраняете только эту часть, а также можете склеивать файлы, вырезать куски и декодировать выделенный фрагмент декодерами прошивки.

::: tip Unleashed
RAW Edit входит в Unleashed как системное приложение, и Sub-GHz открывает его напрямую: `Sub-GHz → Read RAW` (или `Saved`) → открыть RAW-файл → <kbd>→</kbd> `More` → `Edit`. Пункт `Edit` виден, только если RAW Edit установлен. После выхода из редактора вы возвращаетесь в Sub-GHz.
:::

**Когда использовать:** обрезать длинную RAW-запись перед отправкой или публикацией, разделить запись на отдельные кнопки, склеить несколько записей, выяснить, какой протокол спрятан в RAW-файле.

## Главное меню

`Main Menu → Apps → Sub-GHz → Sub-GHz RAW Edit`:

- `Select .sub file` — открыть файл из `/ext/subghz` в редакторе
- `Merge .sub files` — склеить несколько файлов в один
- `Config` — параметры загрузки и склейки
- `About` — версия и ссылка на проект

Кроме RAW, приложение загружает любой сигнал, который прошивка умеет кодировать (он переводится в RAW встроенным энкодером). Для протоколов с custom buttons сначала предлагается выбрать кнопку.

## Редактор

На экране — форма сигнала, сверху полоса обзора, снизу две строки: `View:` (масштаб) и `Marked:` (длина выделения A..B). Выделенный диапазон подчёркнут пунктиром, метки по краям показывают, что сигнал продолжается за экраном.

| Кнопка | Действие |
|---|---|
| <kbd>←</kbd> / <kbd>→</kbd> | двигать активный маркер (A или B); удержание — быстрее |
| <kbd>↑</kbd> / <kbd>↓</kbd> | приблизить / отдалить |
| <kbd>OK</kbd> | переключить активный маркер A ↔ B |
| удержание <kbd>OK</kbd> | меню действий |
| <kbd>Back</kbd> | закрыть редактор |

Меню действий (<kbd>↑</kbd> / <kbd>↓</kbd>, <kbd>OK</kbd> — выполнить, <kbd>Back</kbd> — закрыть):

- **Save** — записать только диапазон A..B в новый RAW-файл. Имя предлагается как `<имя>_edit1`, `_edit2`, … При совпадении имени спросит `Name exists, overwrite?`; открытый файл никогда не перезаписывается.
- **Decode** — декодировать диапазон A..B декодерами Sub-GHz, сгруппировать одинаковые пакеты (`Decoded: N`) и сохранить выбранный как файл ключа; по умолчанию имя из протокола и производителя (например, `KeeLoq_Verex`). `No known protocol` — ничего не распознано.
- **Cut** — вырезать диапазон A..B из сигнала (не даст, если сигнал станет пустым).
- **Undo** — отменить последний вырез (зачёркнут, если отменять нечего).

## Обрезка записи — по шагам

1. Запишите пульт через [Read RAW](/ru/subghz/read-raw) и сохраните.
2. Откройте файл в RAW Edit (через `More → Edit` или `Select .sub file`).
3. Отдалите <kbd>↓</kbd>, чтобы увидеть, где посылки.
4. Поставьте маркер **A** перед посылкой (<kbd>←</kbd>/<kbd>→</kbd>), нажмите <kbd>OK</kbd>, поставьте маркер **B** после неё.
5. Удержите <kbd>OK</kbd> → `Save`, примите или измените имя.
6. Проверьте сохранённый файл через `Sub-GHz → Saved`.

## Склейка файлов

1. `Merge .sub files` → выберите файл; диалог показывает `Added N file(s)` и число сэмплов. Дальше `Add more` или `Done`.
2. Все файлы должны быть на одной частоте, иначе — `Frequency mismatch`.
3. Результат открывается в редакторе как `merged`; сохраните его через меню действий.

## Config

| Пункт | Что делает |
|---|---|
| Normalize jitter | `OFF`/`ON` — выравнивать дрожание и дрейф таймингов при загрузке |
| Merge gap | пауза между склеиваемыми файлами, 0–1000 мс (по умолчанию 100); <kbd>OK</kbd> — ввод числа |
| Repeat | повторить каждый загружаемый / склеиваемый сигнал 1–64 раза |

## Ограничения и проблемы

- В файл помещается до **24 000 сэмплов**; при нехватке RAM — меньше. `Out of memory` / `Not enough free RAM to load this capture` — перезагрузите Флиппер и запустите приложение первым.
- `Unsupported protocol or file is empty` — в файле пусто или протокол, который прошивка не умеет кодировать.
- `Nothing in A..B` / `Range too small` — раздвиньте маркеры.
- Длинные паузы сохраняются в файле в реальную длину.
