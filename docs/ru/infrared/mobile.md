# ИК-пульты во Flipper Mobile App

Во Flipper Mobile App (iOS / Android) есть **Remotes Library** — онлайн-база ИК-пультов. Вы выбираете тип
устройства и бренд, приложение подбирает нужный пульт, проверяя несколько сигналов, загружает его во Флиппер и
показывает на экране телефона нормальную раскладку пульта. Передаёт сигналы при этом сам Флиппер.

В отличие от [универсальных пультов](/ru/infrared/universal-remotes), которые при каждом нажатии гонят всю
библиотеку, пульт из Remotes Library подбирается **один раз** и дальше срабатывает мгновенно. Кнопок у него больше,
и типов устройств тоже.

## Что там есть

В библиотеке, среди прочего, пульты для телевизоров, проекторов, ТВ-приставок, вентиляторов, очистителей воздуха,
DVD-плееров, фотокамер и AV-ресиверов. База открытая: [flipperdevices/IRDB](https://github.com/flipperdevices/IRDB);
свой пульт можно добавить по [инструкции для контрибьюторов](https://github.com/flipperdevices/IRDB/blob/dev/docs/adding_remote.md).

::: tip Unleashed
С Unleashed мобильное приложение работает так же, как со стоковой прошивкой: оно управляет приложением Infrared
по RPC. Пока телефон управляет Флиппером, на экране **«Infrared – RPC mode»**. Пульты, загруженные из приложения, —
обычные `.ir`-файлы в `/ext/infrared/`, их можно использовать, редактировать и переименовывать на Флиппере, как
любой записанный пульт. Подробнее о самом приложении: [Flipper Mobile App](/ru/mobile/mobile-app).
:::

## Подобрать пульт для устройства

1. Подключите Флиппер к приложению по Bluetooth.
2. В приложении зайдите в `Tools → Remotes Library`.
3. Выберите **тип устройства**, затем **бренд**.
4. У многих брендов несколько пультов, поэтому приложение проверяет сигналы по одному: направьте Флиппер на
   устройство, нажмите кнопку отправки и ответьте, отреагировало ли устройство.
5. Когда пульт найден, приложение покажет его раскладку. Пользоваться можно сразу.
6. Нажмите **Save** (вверху справа) и задайте имя пульта. Он запишется во Флиппер.
7. *(По желанию)* **⋯ → Add to Favorites** — чтобы пульт был под рукой во вкладке Archive.

## Пользоваться сохранённым пультом

**С телефона.** В приложении откройте `Archive → Infrared` (или Favorites), выберите пульт, направьте Флиппер на
устройство и нажимайте кнопки на экране телефона. Приложение говорит Флипперу, какой сигнал отправить.

![Раскладка пульта в приложении](/img/remote/7387cb59433e202d.jpg)

**Только с Флиппера.** `Main Menu → Infrared → Saved Remotes`, откройте пульт, выберите кнопку <kbd>↑</kbd> /
<kbd>↓</kbd> и нажмите <kbd>OK</kbd>. См. [Запись и отправка сигналов](/ru/infrared/read#отправить-сохранённую-кнопку).

## Решение проблем

| Проблема | Что попробовать |
|---|---|
| Приложение не отправляет / ничего не происходит | Проверьте, что Флиппер подключён и не занят другим приложением. Закройте запущенное на Флиппере приложение и попробуйте снова. |
| Для вашего бренда пульт не нашёлся | Запишите родной пульт на Флиппер ([как](/ru/infrared/read)) или попробуйте [универсальные пульты](/ru/infrared/universal-remotes). |
| Устройство реагирует только вплотную | Используйте [внешний ИК-модуль](/ru/infrared/external-ir): приложение использует передатчик, выбранный в GPIO Settings приложения Infrared. |
