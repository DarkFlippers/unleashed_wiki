# Универсальные пульты

С универсальным пультом вы управляете устройством, **не записывая заранее его пульт**. Когда вы нажимаете,
например, *Power*, Флиппер по очереди отправляет код Power для каждой модели из библиотеки. Как только попадается
код, понятный вашему устройству, оно реагирует. Поэтому универсальная кнопка срабатывает не мгновенно, а через
несколько секунд.

Откройте `Main Menu → Infrared → Universal Remotes`.

![Список категорий Universal Remotes: TVs, Audio, Projectors, LEDs](/screens/infrared/universal_remotes.png)

::: tip Unleashed
В официальной прошивке есть библиотеки для ТВ, аудио, проекторов и кондиционеров. Unleashed добавляет **LEDs** и
**Fans** и держит все библиотеки гораздо более полными и регулярно перепроверенными командой (ИК-ассеты — @amec0e).
ТВ-библиотека пересобрана так, что работают **все** кнопки, а не только Power.
:::

## Категории

Пункты меню и имена кнопок ниже взяты из прошивки; число сигналов — из библиотек текущей сборки `dev`
(`/ext/infrared/assets/`, обновлены в октябре 2024, кондиционеры — в феврале 2024).

| Пункт меню | Файл библиотеки | Кнопки | Сигналов в библиотеке |
|---|---|---|---|
| **TVs** | `tv.ir` | Power, Mute, Vol_up, Vol_dn, Ch_next, Ch_prev | 613 (из них 295 — Power) |
| **Audio** | `audio.ir` | Power, Mute, Play, Pause, Prev, Next, Vol_dn, Vol_up | 851 |
| **Projectors** | `projectors.ir` | Power, Mute, Vol_up, Vol_dn, Play, Pause | 302 |
| **LEDs** | `leds.ir` | Power_on, Power_off, Brightness_up, Brightness_dn, Red, Green, Blue, White | 489 |
| **Fans** | `fans.ir` | Power, Mode, Speed_up, Speed_dn, Rotate, Timer | 421 |
| **ACs** | `ac.ir` | Off, Dh, Cool_hi, Cool_lo, Heat_hi, Heat_lo | 182 |

«Audio» — это саундбары, AV-ресиверы, музыкальные центры и т. п. «LEDs» — LED-ленты и лампы с ИК-пультом.

### Кондиционеры

Пульт кондиционера сам хранит состояние и при каждом нажатии передаёт его целиком, поэтому в библиотеке AC лежат
готовые «сцены», а не отдельные кнопки:

| Кнопка | Значение |
|---|---|
| **Off** | Выключить кондиционер. Это *единственная* кнопка, которая его выключает. |
| **Dh** | Режим осушения (Dry). |
| **Cool_hi** | Охлаждение на минимальной температуре, доступной на пульте (максимальный холод). |
| **Cool_lo** | Охлаждение на 23 °C. |
| **Heat_hi** | Обогрев на максимальной температуре, доступной на пульте (максимальное тепло). |
| **Heat_lo** | Обогрев на 23 °C. |

Чтобы **включить** кондиционер, нажмите любую кнопку, кроме Off. Кнопки температуры показывают °C или °F в
зависимости от `Settings → System → Units`.

## Как пользоваться

1. Зайдите в `Main Menu → Infrared → Universal Remotes` и выберите категорию.
2. Направьте верхний торец Флиппера на устройство. Держитесь поближе и в прямой видимости.
3. Выберите кнопку стрелками и нажмите <kbd>OK</kbd>.

   ![Универсальный ТВ-пульт на вертикальном экране: сверху Power и Mute, ниже переключение каналов и громкость](/screens/infrared/universal_tv.png)

4. Окно **«Sending...»** показывает прогресс `текущий/всего` и полоску. Продолжайте держать Флиппер направленным на
   устройство.
5. Когда устройство отреагировало, нажмите <kbd>OK</kbd> — **пауза**, или дождитесь конца библиотеки.

![Универсальный пульт в работе](/img/remote/bdb3541a3f2e88fe.png)

### Управление во время отправки

| Состояние | Кнопка | Действие |
|---|---|---|
| Отправка | <kbd>OK</kbd> | **pause** — пауза |
| Отправка | <kbd>Back</kbd> | **stop** — остановить |
| Пауза | <kbd>Back</kbd> | **resume** — продолжить с того же места |
| Пауза | <kbd>OK</kbd> | **send 1** — отправить только выбранный сигнал |
| Пауза | <kbd>←</kbd> / <kbd>→</kbd> | **select** — предыдущий / следующий сигнал библиотеки |
| Пауза | <kbd>↓</kbd> | **save** — сохранить выбранный сигнал |

## Найти точный код и сохранить его

Главная фишка экрана паузы: можно найти тот единственный код, который подходит, и сохранить его — в следующий раз
кнопка сработает мгновенно.

1. Запустите универсальную кнопку. Как только устройство отреагировало, нажмите <kbd>OK</kbd> (пауза). Счётчик
   указывает на последний отправленный сигнал.
2. Мгновенно нажать всё равно не получится, поэтому отступите стрелкой влево и нажимайте **send 1** (<kbd>OK</kbd>)
   на каждом сигнале, пока не найдёте тот, на который реагирует устройство. Стрелкой вправо — обратно вперёд.
3. Нажмите <kbd>↓</kbd> **save**. В заголовке меню — имя кнопки (например, `Power`), под этим же именем сигнал и
   сохранится:
   - **Save as New Remote** — ввести имя пульта в **«Name the remote»**; в `/ext/infrared/` создаётся новый `.ir`;
   - **Add to Existing Remote** — выбрать существующий `.ir`-файл; сигнал допишется в него.
4. **«Saved»** подтверждает сохранение. Пульт появится в `Infrared → Saved Remotes`.

Повторите для Vol_up, Mute и т. д., добавляя всё в один пульт, — получится личный мгновенный пульт, собранный из
универсальной библиотеки.

![Сохранённый пульт на вертикальном экране: список кнопок Power, Vol_up, Vol_dn, Mute, Ch_next, Ch_prev](/screens/infrared/remote.png)

## Из командной строки

Те же библиотеки можно запускать через [CLI](/ru/dev/cli):

```text
ir universal list tv        # список имён сигналов в tv.ir
ir universal tv Power       # отправить все сигналы "Power" из tv.ir
```

`ir universal` без аргументов выводит список доступных библиотек (все `.ir` в `/ext/infrared/assets/`).
Остановить — <kbd>Ctrl</kbd>+<kbd>C</kbd> в терминале.

## Решение проблем

| Проблема | Что попробовать |
|---|---|
| *«Function requires SD card with fresh databases.»* | Нет файлов библиотек. Вставьте microSD и переустановите / обновите прошивку со вставленной картой, см. [Обновление](/ru/start/updating). |
| Ничего не реагирует после всей библиотеки | Вашей модели нет в библиотеке. [Запишите](/ru/infrared/read) родной пульт, попробуйте [Remotes Library в приложении](/ru/infrared/mobile) и подумайте о том, чтобы [прислать свои записи](/ru/infrared/captures). |
| Устройство отреагировало, но поставить паузу не успели | Стрелкой влево + **send 1** вернитесь к нужному сигналу, см. выше. |
| Работает только вплотную | Встроенные светодиоды слабоваты для больших комнат. Используйте [внешний ИК-модуль](/ru/infrared/external-ir). |
| Кондиционер не включается кнопкой Off | Так и задумано: Off только выключает. Включайте через Cool/Heat/Dh. |
