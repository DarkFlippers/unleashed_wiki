# Как добавить свои ИК-записи в универсальные пульты

Если [универсальный пульт](/ru/infrared/universal-remotes) не работает с вашим устройством, можно записать родной
пульт и добавить его в библиотеку — тогда он заработает у всех. Запись должна быть **чистой**: короткой, по
возможности распознанной и с именем ровно таким, какое ждёт универсальный пульт.

Методика — из гайда Unleashed от **@amec0e** (он ведёт ИК-ассеты Unleashed), который основан на оригинальной
документации *UniversalRemotes* от @gsurkov, @skotopes, @knrn-ai, @DrZlo13 и @ahumeniy.

## Имена кнопок для каждой библиотеки

Универсальный пульт использует только сигналы, у которых `name:` точно совпадает с одной из его кнопок (регистр
важен). Любую кнопку можно пропустить, если её нет на вашем устройстве.

| Библиотека | Файл | Имена сигналов |
|---|---|---|
| TVs | `tv.ir` | `Power`, `Mute`, `Vol_up`, `Vol_dn`, `Ch_next`, `Ch_prev` |
| Audio | `audio.ir` | `Power`, `Mute`, `Play`, `Pause`, `Prev`, `Next`, `Vol_up`, `Vol_dn` |
| Projectors | `projectors.ir` | `Power`, `Mute`, `Vol_up`, `Vol_dn`, `Play`, `Pause` |
| LEDs | `leds.ir` | `Power_on`, `Power_off`, `Brightness_up`, `Brightness_dn`, `Red`, `Green`, `Blue`, `White` |
| Fans | `fans.ir` | `Power`, `Mode`, `Speed_up`, `Speed_dn`, `Rotate`, `Timer` |
| ACs | `ac.ir` | `Off`, `Dh`, `Cool_hi`, `Cool_lo`, `Heat_hi`, `Heat_lo` |

На многих аудиопультах `Play` и `Pause` — одна кнопка: записывайте её как `Play`, а `Pause` пропускайте.

## Телевизоры, аудио, проекторы, вентиляторы, LED

1. Направьте пульт на ИК-приёмник Флиппера.
2. Для первой кнопки запустите `Infrared → Learn New Remote`, для следующих — `+` в пульте.
3. **Коротко** нажмите кнопку пульта и сохраните под соответствующим именем из таблицы.
4. Повторите шаги 2-3 для всех кнопок.
5. Проверьте каждую сохранённую кнопку на реальном устройстве: она должна делать ровно то, что написано в имени.

::: warning Не удерживайте кнопку
При удержании кнопки получаются длинные записи с множеством повторов. Они дольше передаются и замедляют весь
универсальный пульт для всех пользователей.
:::

### Parsed или RAW

**Parsed** — лучший результат: протокол распознан, сохраняются только протокол, адрес и команда.

```text
name: EXAMPLE
type: parsed
protocol: NEC
address: 07 00 00 00
command: 02 00 00 00
```

Помехи от устройств вокруг (лампы, подсветка ТВ, другие пульты) могут превратить запись в **RAW**, даже если
протокол известен. Если обычный пульт записался в RAW, нажмите на Флиппере **Retry** несколько раз, пока не
получите чистый parsed-сигнал.

**RAW** нормален, если пульт действительно использует неизвестный протокол. Стремитесь к *минимальному числу
отсчётов*, при котором устройство ещё срабатывает: короткое нажатие, обычно **около 100 отсчётов**. Идеальная
запись одного нажатия выглядит так:

```text
name: EXAMPLE
type: raw
frequency: 38000
duty_cycle: 0.330000
data: 2410 597 1189 599 592 600 1186 602 589 603 1183 606 595 597 593 598 1208 605 596 596 594 597 593 599 592 25604 2403 604 1182 606 595 597 1189 599 591 601 1185 603 618 573 617 575 1211 602 588 603 588 605 596 596 594 25605 2402 604 1192 596 594 597 1189 599 592 601 1185 628 593 598 593 600 1186 602 589 603 588 604 597 595 596
```

## Кондиционеры

С кондиционерами всё иначе: пульт хранит состояние (режим, температуру, обдув, жалюзи) на своём дисплее и при
каждом нажатии передаёт **всё состояние** сразу. Поэтому каждая «кнопка» кондиционера — это полное состояние,
которое нужно записать целиком.

Для каждого сигнала **кроме `Off`**:

1. Нажмите **Power** на пульте, чтобы на дисплее кондиционер был ВКЛЮЧЁН.
2. Выставьте режим и температуру из таблицы ниже. Всё остальное (скорость вентилятора, жалюзи) по возможности
   оставьте на **AUTO**.
3. Нажмите **Power** на пульте, чтобы ВЫКЛЮЧИТЬ.
4. На Флиппере начните запись (`Learn New Remote` для первой, `+` для остальных).
5. Направьте пульт на Флиппер и нажмите **Power** ещё раз (это кадр «включиться в этом режиме»).
6. Сохраните сигнал под именем из таблицы.
7. Повторите для каждой строки.

| Сигнал | Режим | Температура | Примечание |
|:---:|:---:|:---:|---|
| `Dh` | Осушение | — | |
| `Cool_hi` | Охлаждение | минимальная | минимальная температура в режиме охлаждения |
| `Cool_lo` | Охлаждение | 23 °C | |
| `Heat_hi` | Обогрев | максимальная | максимальная температура в режиме обогрева |
| `Heat_lo` | Обогрев | 23 °C | |

Потом запишите **`Off`**:

1. Убедитесь, что на дисплее пульта кондиционер ВКЛЮЧЁН.
2. Начните запись на Флиппере и направьте на него пульт.
3. Нажмите **Power**, чтобы пульт показал ВЫКЛ.
4. Сохраните сигнал как `Off`.

Получится до 6 сигналов. Проверьте все на реальном кондиционере.

## Подготовить файл и отправить

1. Скопируйте `.ir`-файл из `/ext/infrared/` на компьютер через [qFlipper](/ru/mobile/qflipper) (или мобильное
   приложение) и откройте в текстовом редакторе.
2. Перед своими сигналами поставьте комментарий с моделью, чтобы в библиотеке был порядок:
   ```text
   # Model: <бренд и модель>
   ```
   Порядок сигналов внутри блока не важен.
3. Сделайте форк [репозитория Unleashed](https://github.com/DarkFlippers/unleashed-firmware) и **допишите** свой блок
   **в конец** нужного файла в `applications/main/infrared/resources/infrared/assets/`.
4. Откройте pull request с изменённым файлом. После ревью запись попадёт в следующую сборку для всех.

Формат файлов описан в [Формат ИК-файлов](/ru/infrared/file-format#файлы-библиотек). Большие коллекции готовых
пультов от сообщества: [Flipper-IRDB](https://github.com/Lucaslhm/Flipper-IRDB) и официальная
[flipperdevices/IRDB](https://github.com/flipperdevices/IRDB), которую использует [мобильное приложение](/ru/infrared/mobile).
