# Инфракрасный порт (Infrared)

У Flipper Zero есть встроенный ИК-модуль. Он умеет **запоминать** кнопки почти любого ИК-пульта, **сохранять** их
как виртуальный пульт на microSD-карте, **отправлять** их обратно и работать **универсальным пультом**, перебирая
библиотеку известных кодов для телевизоров, аудиотехники, проекторов, LED-лент, вентиляторов и кондиционеров.

![Infrared на Flipper Zero](/img/remote/133011d2bd3dc44c.png)

## Железо

- Прозрачное для ИК-излучения окошко на верхнем торце Флиппера.
- **Три ИК-светодиода** для передачи.
- **ИК-приёмник**, который сам демодулирует несущую (рассчитан на распространённую несущую 38 кГц). Обучение
  всегда идёт через этот встроенный приёмник.
- По желанию — **внешний ИК-передатчик** на GPIO-пине 2 (A7) для большей дальности, см.
  [Внешние ИК-модули](/ru/infrared/external-ir).

## Меню Infrared

Откройте `Main Menu → Infrared`. Пункты меню взяты прямо из прошивки:

![Меню Infrared: Universal Remotes, Learn New Remote, Saved Remotes и GPIO Settings](/screens/infrared/menu.png)

| Пункт | Что делает |
|---|---|
| **Universal Remotes** | Отправляет целую библиотеку кодов для одной кнопки (Power, Vol+…), пока устройство не отреагирует. См. [Универсальные пульты](/ru/infrared/universal-remotes). |
| **Learn New Remote** | Считывает кнопки физического пульта и сохраняет их как новый пульт. См. [Запись и отправка сигналов](/ru/infrared/read). |
| **Saved Remotes** | Открывает файловый браузер в `/ext/infrared/`: отправка, редактирование, переименование и удаление пультов. |
| **GPIO Settings** | Выбор передатчика (встроенный, пин 2 (A7) или автоопределение) и 5 В на GPIO. См. [Внешние ИК-модули](/ru/infrared/external-ir). |
| **Learn New Remote RAW** | Только при включённом `Settings → System → Debug`. Как Learn, но без декодера: всё сохраняется в RAW. |
| **Debug RX** | Только в режиме Debug. Экран «INFRARED monitor» с тем, что сейчас ловит приёмник. |

::: tip Unleashed
Приложение Infrared, его декодеры протоколов и механика универсальных пультов — из официальной прошивки.
Unleashed добавляет:
- ИК-протокол **RCA** (см. [Протоколы](/ru/infrared/protocols));
- дополнительные библиотеки универсальных пультов (**LEDs**, **Fans**) и гораздо более полные, регулярно
  перепроверяемые библиотеки для ТВ, аудио, проекторов и кондиционеров от команды Unleashed (ИК-ассеты — @amec0e).
  ТВ-библиотека пересобрана так, что работают **все** её кнопки;
- поддержка внешних ИК-модулей с автоопределением (перенесена из официальной прошивки).
:::

## Где лежат файлы

| Путь | Содержимое |
|---|---|
| `/ext/infrared/*.ir` | Ваши сохранённые пульты (`Filetype: IR signals file`). |
| `/ext/infrared/assets/*.ir` | Библиотеки универсальных пультов: `tv.ir`, `audio.ir`, `projectors.ir`, `leds.ir`, `fans.ir`, `ac.ir` (`Filetype: IR library file`). Ставятся и обновляются вместе с прошивкой. |
| `/ext/infrared/.infrared.settings` | Настройки GPIO (пин вывода, 5 В). |

Формат `.ir`-файлов описан на странице [Формат ИК-файлов](/ru/infrared/file-format).

## Командная строка

Команда `ir` доступна в [CLI](/ru/dev/cli) (например, через qFlipper или терминал по последовательному порту):

```text
ir rx [raw]                                  приём и вывод сигналов (raw = без декодирования)
ir tx <protocol> <address> <command>         отправка распознанного сигнала, адрес/команда в hex
ir tx RAW F:<frequency> DC:<duty_cycle> <sample0> <sample1>...
                                             частота 10000-1000000 Гц, коэфф. заполнения 0-100, до 512 отсчётов
ir decode <input_file> [<output_file>]       попытаться декодировать RAW-сигналы файла в parsed
ir universal <remote_name> <signal_name>     запустить универсальную библиотеку, напр. ir universal tv Power
ir universal list <remote_name>              список имён сигналов в библиотеке
```
