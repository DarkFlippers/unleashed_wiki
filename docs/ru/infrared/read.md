# Запись и отправка ИК-сигналов

Flipper Zero может по одной скопировать кнопки ИК-пульта и хранить их как **виртуальный пульт** — файл `.ir`
в `/ext/infrared/`. Пригодится, если родной пульт потерялся, сломался или просто лежит в другой комнате, или если
универсальный пульт не находит ваше устройство.

Сигналы [известных протоколов](/ru/infrared/protocols) декодируются и сохраняются компактно, в виде *parsed*
(протокол + адрес + команда). Всё остальное сохраняется как **RAW**-тайминги — их тоже можно воспроизводить.

## Запись нового пульта

1. Зайдите в `Main Menu → Infrared → Learn New Remote`.
2. На экране надпись **«Point the remote at IR port and push the button»**. Поднесите пульт на несколько сантиметров
   к верхнему торцу Флиппера, в прямой видимости ИК-окошка.

   ![Экран записи пульта в ожидании сигнала: «Point the remote at IR port and push the button»](/screens/infrared/learn.png)

3. **Коротко** нажмите кнопку на пульте. Не удерживайте: при удержании получается длинная запись с кучей повторов.
4. Появляется экран с результатом:
   - распознанный сигнал показывает имя протокола и адрес/команду, например `NECext`, `A: 0x87EE`, `C: 0xA05D`;
   - неизвестный сигнал показывает **Unknown** и число отсчётов, например `150 samples`.

   ![Экран пойманного сигнала: распознанный протокол NEC с адресом и командой, внизу Retry, Send и Save](/screens/infrared/learn_success.png)

5. Выберите действие:
   - <kbd>OK</kbd> **Send** — отправляет пойманный сигнал, пока кнопка удерживается, чтобы сразу проверить;
   - <kbd>←</kbd> **Retry** — спрашивает *«Retry Reading? All unsaved data will be lost!»*, затем <kbd>←</kbd> Exit
     выбрасывает запись и слушает заново, <kbd>→</kbd> Stay возвращает назад;
   - <kbd>→</kbd> **Save** — перейти к вводу имени.
6. Введите имя кнопки в **«Name the button»** (до 23 символов) и подтвердите. Имя по умолчанию генерируется из
   сигнала: первые 4 буквы протокола и команда (например, `NECe_A05D`) или `RAW_<число отсчётов>` для RAW.
7. Появляется **«Success!»** и открывается новый пульт. Первый пульт сохраняется как `/ext/infrared/Remote.ir`, если
   имя занято — `Remote1.ir`, `Remote2.ir` и т. д.

![Пойманный сигнал на экране](/img/remote/a62fc8f9d738534b.png)

::: tip Переименуйте пульт
Новый пульт всегда называется `Remote`. Переименуйте его сразу через `Edit → Rename Remote` (см. ниже), иначе
получится зоопарк `Remote`, `Remote1`, `Remote2`…
:::

### Добавить кнопки

В списке кнопок пульта пролистайте в самый низ и выберите **`+`**. Снова откроется экран записи. Поймайте сигнал,
нажмите **Save**, назовите кнопку — появится **«Saved»**: кнопка дописана в тот же файл.

<kbd>Back</kbd> на экране записи спрашивает *«Exit to Infrared Menu?»* (или *«Exit to Remote Menu?»*, если вы добавляете
кнопку к существующему пульту): при выборе Exit несохранённое пропадёт.

## Отправить сохранённую кнопку

1. Зайдите в `Main Menu → Infrared → Saved Remotes` и выберите `.ir`-файл.
2. Направьте верхний торец Флиппера на устройство.
3. Выберите кнопку <kbd>↑</kbd> / <kbd>↓</kbd> и нажмите <kbd>OK</kbd>.

Сигнал передаётся, **пока удерживается** <kbd>OK</kbd>: короткое нажатие — одна команда, удержание — для действий
«нажать и держать», вроде плавной регулировки громкости. Во время передачи мигает светодиод.

![Отправка сохранённого сигнала](/img/remote/d20ed673954c3711.png)

::: tip Избранное и Archive
Сохранённые пульты видны и в **Archive** (`Main Menu → Archive → Infrared`), оттуда их можно добавить в избранное.
Во Flipper Mobile App они находятся в **Archive → Infrared**, см. [Пульты в мобильном приложении](/ru/infrared/mobile).
:::

## Редактирование пульта

Откройте пульт и выберите **Edit** в самом низу списка кнопок. В меню Edit:

| Пункт | Что делает |
|---|---|
| **Add Button** | Записать ещё одну кнопку (то же, что `+`). |
| **Rename Button** | Выбрать кнопку и ввести новое имя. |
| **Move Button** | Экран *«Select a Button to Move»*: выберите кнопку, <kbd>OK</kbd> — «взять» её (она сдвигается вправо), двигайте <kbd>↑</kbd> / <kbd>↓</kbd>, снова <kbd>OK</kbd> — «положить». |
| **Delete Button** | Выбрать кнопку. Подтверждение *«Delete Button?»* показывает имя и протокол / адрес / команду (или `RAW` и число отсчётов). <kbd>←</kbd> Cancel, <kbd>→</kbd> Delete. |
| **Rename Remote** | Переименовывает пульт и файл. Если имя занято, добавляется номер. |
| **Delete Remote** | Подтверждение *«Delete Remote?»* с числом кнопок. Удаляет `.ir`-файл. |

Имена кнопок и пультов ограничены **23 символами**. Крупные правки (слияние файлов, удаление множества кнопок)
удобнее делать на ПК: скачайте файл через [qFlipper](/ru/mobile/qflipper) и редактируйте как текст, см.
[Формат ИК-файлов](/ru/infrared/file-format).

::: warning Библиотеки — это не пульты
Если открыть через Saved Remotes файл из `/ext/infrared/assets/`, будет ошибка *«Library file … can't be opened as a
remote»*. Файлы библиотек (`Filetype: IR library file`) используются только [универсальными пультами](/ru/infrared/universal-remotes).
:::

## Дополнительно в режиме Debug

При включённом `Settings → System → Debug` в меню Infrared появляются ещё два пункта:

- **Learn New Remote RAW** — тот же сценарий, что и Learn, но декодер выключен и всё сохраняется в RAW. Полезно,
  когда протокол распознаётся, но расшифрованный сигнал на вашем устройстве не срабатывает.
- **Debug RX** — экран *«INFRARED monitor»*, показывающий, что принимает приёмник в реальном времени.

## Решение проблем

| Проблема | Что попробовать |
|---|---|
| Флиппер не реагирует на пульт | Проверьте батарейки пульта (посмотрите на его светодиод через камеру телефона). Поднесите ближе и направьте точно в верхний торец. Уберите прямое солнце и люминесцентные / LED-лампы рядом. |
| Обычный пульт записывается как **Unknown / RAW** | Помехи могут превратить запись в RAW. Нажмите **Retry** несколько раз, пока не получите распознанный сигнал. Если протокол действительно неизвестный, RAW — это нормально. |
| Огромные RAW-записи (сотни отсчётов) | Вы удерживали кнопку. Нажимайте коротко: для одного нажатия типично около 100 отсчётов. Длинные записи медленно воспроизводятся. RAW-сигнал вмещает максимум 1024 тайминга. |
| Устройство не реагирует на сохранённую кнопку | Подойдите ближе, целиться прямо в ИК-окошко устройства. Отправьте несколько раз или подержите <kbd>OK</kbd> дольше. Для больших расстояний — [внешний ИК-модуль](/ru/infrared/external-ir). |
| Кондиционер реагирует не так | Пульты кондиционеров при каждом нажатии передают всё состояние (режим, температуру, обдув). Каждое нужное состояние записывайте отдельной кнопкой, см. [Как прислать свои записи](/ru/infrared/captures#кондиционеры). |
| «Failed to load …» при отправке | `.ir`-файл повреждён или неправильно отредактирован вручную. Сверьтесь с [форматом файла](/ru/infrared/file-format). |
