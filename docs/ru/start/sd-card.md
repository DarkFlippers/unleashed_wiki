# microSD-карта

MicroSD-карта не опциональна. На ней хранятся сохранённые ключи, карты и пульты, все `.fap`-приложения (включая
встроенные приложения Unleashed), базы, пакет обновления и, в текущих прошивках, даже **внутреннее хранилище**.

## Выбор карты

- **Объём:** 16–32 ГБ более чем достаточно. Поддерживается до 256 ГБ, но большие карты дольше монтируются.
- **Файловая система:** FAT12, FAT16, FAT32 или exFAT.
- **Качество:** берите **брендовую** карту (SanDisk, Kingston…). Флиппер работает с картой по **SPI**, а не в быстром
  режиме SDIO, как телефоны и ПК. Не каждая карта нормально работает по SPI, даже если в других устройствах всё
  отлично. Плохая карта тормозит Флиппер, быстрее разряжает батарею (до ~50 мА вместо ~30 мА) и может портить данные.
- По SPI чтение идёт почти на 600 КиБ/с — для задач Флиппера этого хватает.

## Установка

1. Слот находится на нижнем торце Флиппера.
2. Держите карту **контактами вверх** и вставьте до щелчка.
3. В строке состояния появится значок SD.

## Если карта не распознаётся

Появляется сообщение о SD-карте или перечёркнутый значок в строке состояния. Возможные причины:

| Причина | Решение |
|---|---|
| Нет файловой системы или она не та | Отформатируйте карту (см. ниже) |
| Пыль в слоте | Аккуратно продуйте сжатым воздухом |
| Карта не поддерживает SPI | Возьмите другую карту |
| Карта повреждена | Возьмите другую карту |

## Settings → Storage

**Main Menu → Settings → Storage**

| Пункт | Что делает |
|---|---|
| **About Internal Storage** | Имя, тип `Virtual (/.int on SD)`, общий и свободный объём, свободная flash-память |
| **About SD Card** | Метка, файловая система, общий и свободный объём, производитель и серийный номер |
| **Unmount SD Card** / **Mount SD Card** | Безопасное извлечение / повторное монтирование. При монтировании может ненадолго пропасть питание внешних модулей |
| **Format SD Card** | Форматирование. **Все данные будут удалены!** |
| **Benchmark SD Card** | Тест скорости записи и чтения в режиме SPI |
| **Factory Reset** | Стирает внутреннее хранилище (настройки, сопряжения, дельфин). См. [Восстановление](/ru/start/recovery#factory-reset) |

### Форматирование

1. **Settings → Storage → Format SD Card**.
2. Подтвердите <kbd>→</kbd> **Format**.
3. Дождитесь `Formatted` и нажмите **Finish**.

Если на Флиппере отформатировать не получилось (`Cannot Format SD Card`), отформатируйте карту на ПК в FAT32/exFAT
или возьмите другую.

### Безопасное извлечение

1. **Settings → Storage → Unmount SD Card** → <kbd>→</kbd> **Unmount**.
2. Когда появится `SD Card Unmounted` / `You can remove SD card now.`, нажмите на карту, чтобы она вышла, и достаньте её.

Если вытащить карту во время записи, можно повредить файлы или файловую систему.

### Бенчмарк

Тест пишет временный файл `/ext/rwfiletest.bin` и показывает строки вида `4096b : W 300K R 600K`: размер блока,
затем скорость записи и чтения в КиБ/с. Для нормальной работы карта должна писать **не медленнее ~260 КиБ/с**.
Результаты отличаются от тестов на ПК, потому что проверка идёт в режиме SPI. Для честной картины прогоните тест
несколько раз.

## Структура папок

`/ext` — корень карты. Основные папки:

| Папка | Содержимое |
|---|---|
| `/ext/subghz/` | Файлы Sub-GHz `.sub`. В `assets/` лежат `dangerous_settings`, `setting_user.example` (шаблон своего списка частот), хранилище ключей KeeLoq `keeloq_mfcodes` |
| `/ext/subghz_remote/` | Карты Sub-GHz Remote |
| `/ext/nfc/` | Файлы NFC `.nfc`. В `assets/` — словари ключей |
| `/ext/lfrfid/` | Файлы 125 кГц RFID `.rfid` |
| `/ext/ibutton/` | Файлы iButton `.ibtn` |
| `/ext/infrared/` | ИК-пульты `.ir`. В `assets/` — библиотеки универсальных пультов |
| `/ext/badusb/` | Скрипты Bad USB (`.txt`). В `assets/layouts/` — раскладки клавиатуры (`.kl`) |
| `/ext/apps/` | `.fap`-приложения по категориям (встроенные и из наборов) |
| `/ext/apps_data/` | Данные и настройки приложений |
| `/ext/dolphin/` | `name.settings` (своё имя) и анимации |
| `/ext/update/` | Распакованные пакеты обновления |
| `/ext/.int/` | Хранилище для внутреннего хранилища (`/int`). Вручную не редактировать |

::: tip
Время от времени делайте копию всей карты (через qFlipper или на ПК). Ваши ключи и пульты существуют только на ней.
:::

## macOS: скрытые файлы и сортировка {#macos-hidden-files-and-sorting}

macOS оставляет на карте файлы `._*` и `.DS_Store`. Удалить их можно так:

```bash
sudo dot_clean -mn /Volumes/Flipper\ SD
```

Замените `Flipper\ SD` на имя своей карты.

Файловый браузер работает быстрее, если каталоги FAT отсортированы. На macOS (через [Homebrew](https://brew.sh)):

```bash
brew install fatsort
diskutil list                         # найдите карту, например disk4s1
diskutil unmount /Volumes/Flipper\ SD
sudo fatsort -n /dev/disk4s1          # подставьте свой идентификатор
```

`fatsort` есть и для Linux.
