# Опасные настройки: расширенный диапазон Sub-GHz

Unleashed умеет заставить радиочип CC1101 работать **за пределами его официального диапазона частот**.

::: danger Прочитайте сначала
1. Не делайте этого, если не понимаете точно, что делаете.
2. Расширенный диапазон не нужен почти ни для одной задачи.
3. Передача за пределами аппаратной спецификации **может повредить железо**.
4. Ни команда Flipper Devices, ни разработчики Unleashed не несут ответственности за повреждения, вызванные
   кастомной прошивкой или расширением диапазона частот.
:::

## Скорее всего, вам это не нужно: региональных блокировок нет

::: tip Unleashed
В Unleashed **все региональные ограничения на передачу сняты по умолчанию**. Передача работает на всех частотах в
пределах поддерживаемого чипом диапазона без каких-либо действий. Не используйте опасную настройку, чтобы «разлочить
регион» — для этого она не нужна.
:::

Если передача на какой-то частоте блокируется, сначала проверьте, что частота входит в обычный TX-диапазон (см. ниже).
Вне его прошивка пишет в лог `Frequency blocked - outside default range`.

## Диапазоны частот

| | Диапазоны |
|---|---|
| Даташит CC1101 | 300–348 МГц, 386–464 МГц, 778–928 МГц |
| **TX-диапазон** Unleashed по умолчанию | ≈ 300–350 МГц, 387–467,75 МГц, 779–928 МГц (расширен, чтобы включить 350 и 467 МГц) |
| TX с включённым `dangerous_settings` | **281–361 МГц, 378–481 МГц, 749–962 МГц** |

Расширенный диапазон соответствует расширенному диапазону YARD Stick One (согласно исходникам прошивки). За пределами
диапазонов из даташита чип работает вне спецификации, и передача там может его повредить.

## Как включить

1. Достаньте microSD-карту или подключитесь через qFlipper / любой удобный файловый менеджер.
2. Откройте файл **`/ext/subghz/assets/dangerous_settings`**. Он выглядит так:
   ```text
   # Do you want to damage your flipper CC1101 radio chip by using Frequencies that outside HW specs?
   # CC1101 Frequency range specs: 300-348 MHz, 386-464 MHz, and 778-928 MHz
   # This setting will extend to: 281-361 MHz, 378-481 MHz, and 749-962 MHz
   yes_i_want_to_destroy_my_flipper: false
   ```
   («Хотите повредить радиочип CC1101 своего Флиппера, используя частоты вне аппаратной спецификации?»)
3. Прочитайте комментарии и замените `false` на `true`:
   ```text
   yes_i_want_to_destroy_my_flipper: true
   ```
4. Сохраните файл и перезагрузите Флиппер — настройка читается при старте.

Чтобы вернуть как было, поставьте `false` и перезагрузитесь.

::: warning Обновления
Файл входит в ресурсы прошивки, и обновление может перезаписать его значением по умолчанию `false`. Если вы
пользуетесь этой настройкой, проверяйте файл после обновления.
:::
