# Восстановление

Что делать, если Флиппер завис, не обновляется, ничего не показывает или вы забыли PIN. Идите по шагам по порядку —
от самых мягких мер к самым радикальным.

## 1. Сначала перезагрузка

- **Завис:** зажмите <kbd>←</kbd> + <kbd>BACK</kbd> примерно на 5 секунд.
- **Всё ещё завис:** отключите USB и зажмите <kbd>BACK</kbd> на 30 секунд (сброс питания).
- **Сел аккумулятор:** зарядите несколько минут (или час) и попробуйте снова.
- На рабочем Флиппере: **Settings → Power → Reboot → Reboot Flipper**.

Все комбинации: [Комбинации кнопок](/ru/start/key-combos).

## 2. Восстановление прошивки из режима DFU {#firmware-recovery}

Нужно, если прошивка повреждена: обновление не проходит, на экране мусор или пусто, кнопки не реагируют. Загрузчик
USB DFU прошивает устройство в обход его собственной ОС.

### Шаг 1: переведите Флиппер в режим DFU (восстановления)

**Если Флиппер работает, но не обновляется нормально:**
1. **Main Menu → Settings → Power → Reboot → Firmware Upgrade**.
2. Подтвердите `Reboot to DFU Mode?` кнопкой <kbd>→</kbd> **Reboot**.

*или:* зажмите <kbd>←</kbd> + <kbd>BACK</kbd> на 5 с, отпустите <kbd>BACK</kbd> и держите <kbd>←</kbd>, пока не
загорится **синий светодиод**.

**Если на экране ничего нет и кнопки не реагируют:**
1. **Отключите USB-кабель.**
2. Зажмите <kbd>OK</kbd> + <kbd>BACK</kbd> на **30 секунд**. Пустой экран здесь — это нормально.

Затем подключите Флиппер к компьютеру USB-кабелем.

### Шаг 2: проверьте, что компьютер видит DFU-устройство

| ОС | Где смотреть | Название |
|---|---|---|
| Windows | Диспетчер устройств | **DFU in FS Mode** |
| macOS | Меню Apple → Об этом Mac → Отчёт о системе → Аппаратные средства → USB (или `system_profiler SPUSBDataType`) | **DFU in FS Mode** |
| Linux | `lsusb` | **STMicroelectronics STM Device in DFU Mode** |

Не определяется? Попробуйте другой кабель. Подключите напрямую к USB-порту материнской платы, без хабов и
переходников. Или выньте SD-карту, зарядите устройство час и подключите без карты.

### Шаг 3: восстановление

Подойдёт любое из двух приложений — оба полностью перепрошивают Флиппер по USB.

**[qUnleashed](/ru/mobile/qunleashed-app)** — Android, Windows, macOS и Linux (на iOS USB нет):

1. Подключите Флиппер в режиме DFU по USB.
2. Откройте **Repair from DFU mode** и запустите восстановление.

**qFlipper** — Windows, macOS и Linux:

1. Запустите **qFlipper** — он сам обнаружит DFU-устройство.
2. Нажмите **Repair**. qFlipper полностью установит **официальную** прошивку.

Затем снова поставьте Unleashed: [Установка Unleashed](/ru/start/install).

::: tip Unleashed
**Repair** в qFlipper всегда возвращает официальную прошивку. Это нормально: получается чистая база. После
восстановления поставьте Unleashed заново через qUnleashed, Web Installer или **Install from file**. Файлы на
SD-карте при восстановлении не затрагиваются.
:::

### Если qFlipper не может восстановить

- Проверьте, что qFlipper установлен правильно (на Windows — разберитесь с драйверами).
- Отключите USB, перезагрузите <kbd>←</kbd> + <kbd>BACK</kbd> и повторите.
- Сделайте сброс питания (<kbd>BACK</kbd> 30 с, USB отключён) и повторите.
- Запустите qFlipper от имени администратора.
- Используйте USB-порт прямо на материнской плате.
- Крайний вариант — прошить по SWD через ST-Link (см. [Комбинации кнопок](/ru/start/key-combos#if-nothing-helps)).

## 3. Восстановление внутреннего хранилища / сброс к заводским настройкам {#factory-reset}

Если обновления не проходят из-за переполненного или повреждённого внутреннего хранилища, сбросьте Флиппер к
заводскому состоянию. Сброс стирает **внутреннее хранилище**: настройки, Bluetooth-сопряжения, PIN, уровень
дельфина. **Файлы на SD-карте остаются.**

::: info Внутреннее хранилище в текущих прошивках
В текущих прошивках внутреннее хранилище (`/int`) **виртуальное** и находится в скрытой папке `/ext/.int/` на SD-карте.
**Settings → Storage → About Internal Storage** показывает `Type: Virtual (/.int on SD)`.
:::

### Сначала резервная копия (по желанию)

qFlipper → **Advanced controls** → **BACKUP** → выберите папку → **BACKUP**. Внутреннее хранилище сохранится в `.tgz`.
SD-карта в копию не входит — её копируйте отдельно.

### Сброс на устройстве

1. **Main Menu → Settings → Storage → Factory Reset**.
2. Экран спросит `Confirm Factory Reset?`: *«Internal storage will be erased, data and settings will be lost!»*
   («Внутреннее хранилище будет стёрто, данные и настройки потеряны»).
3. Нажмите <kbd>→</kbd> **Erase** **5 раз** (на экране счётчик оставшихся нажатий).
4. Флиппер перезагрузится и отформатирует внутреннее хранилище.

### Сброс через qFlipper

**Advanced controls** → **ERASE** → **ERASE** → по окончании **CONTINUE**.

### Восстановление из копии

qFlipper → **Advanced controls** → **RESTORE** → выберите `.tgz` копии → **RESTORE** → **CONTINUE**.

Если после сброса обновление всё равно не проходит, сбросьте ещё раз **без** восстановления копии или выполните
[восстановление прошивки](#firmware-recovery).

## 4. Сброс забытого PIN {#reset-pin}

Если Флиппер заблокирован PIN-кодом, который вы не помните:

1. **Отключите USB-кабель.**
2. Выключите Флиппер: зажмите <kbd>BACK</kbd> → **Power Off**. Если не получается, выполните следующий шаг, но держите
   кнопки 30–40 секунд.
3. Зажмите <kbd>↑</kbd> + <kbd>BACK</kbd> примерно на 5 секунд. Флиппер загрузится с зажатой <kbd>↑</kbd> и покажет
   **экран сброса PIN**.
4. **Держите <kbd>→</kbd>**, пока полоса прогресса не заполнится, — это подтверждение сброса. <kbd>↓</kbd> — выйти без
   сброса.
5. Флиппер перезагрузится.

Пользовательская конфигурация (регистры RTC, внутреннее хранилище с настройками и PIN) сбрасывается к заводской.
**Файлы на microSD остаются.**

## 5. Всё равно не работает?

- Зарядите час и попробуйте снова.
- Отключите и подключите аккумулятор (нужно разобрать корпус).
- Прошейте по SWD через ST-Link или другой программатор.

Если ничего не помогло — проблема в железе, а не в прошивке.
