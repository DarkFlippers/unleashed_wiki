# Управление

У Flipper Zero пятипозиционный джойстик и отдельная кнопка <kbd>BACK</kbd>.

| Кнопка | Действие |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | Перемещение по меню и экранной клавиатуре. <kbd>←</kbd>/<kbd>→</kbd> меняют значение выбранной опции |
| <kbd>OK</kbd> | Запуск приложения, подтверждение. Долгое нажатие часто открывает дополнительные действия |
| <kbd>BACK</kbd> | Назад / выход из приложения. Долгое нажатие на рабочем столе открывает экран выключения |

В списке стрелки двигают рамку по пунктам, а <kbd>OK</kbd> открывает выбранный:

![Главное меню, рамка на пункте Sub-GHz](/screens/mainmenu/subghz.png)

В этой вики «зажать» или «долгое нажатие» значит удерживать кнопку около секунды. Подсказки внизу экрана (например,
`◀ Cancel` или `Save ▶`) показывают, что делают <kbd>←</kbd>, <kbd>OK</kbd> и <kbd>→</kbd> на текущем экране.

## Режим для левши

**Main Menu → Settings → System → Hand Orient → `Lefty`**

Экран переворачивается на 180°, а кнопки переназначаются, чтобы Флиппер было удобно держать в левой руке.

## Горячие клавиши

| Действие | Как |
|---|---|
| Включить | Зажать <kbd>BACK</kbd> ~3 с |
| Выключить | Зажать <kbd>BACK</kbd> на рабочем столе → **Power Off** (<kbd>→</kbd>) |
| Перезагрузить (если завис) | Зажать <kbd>←</kbd> + <kbd>BACK</kbd> ~5 с |
| Жёсткая перезагрузка (сброс питания) | Отключить USB, зажать <kbd>BACK</kbd> ~30 с |
| Перезагрузка в DFU (режим восстановления) | Зажать <kbd>←</kbd> + <kbd>BACK</kbd>, отпустить <kbd>BACK</kbd>, держать <kbd>←</kbd>, пока не загорится синий светодиод |

Все комбинации сброса и входа в DFU, а также случаи, когда они не сработают, собраны на странице
[Комбинации кнопок](/ru/start/key-combos).

## Ярлыки рабочего стола

| Кнопка | Короткое нажатие | Долгое нажатие |
|---|---|---|
| <kbd>OK</kbd> | Main Menu | Избранное приложение (Ok Long) |
| <kbd>↑</kbd> | Lock Menu | **Заблокировать Флиппер** (с PIN, если задан) |
| <kbd>↓</kbd> | Archive | Информация об устройстве / отладочный экран |
| <kbd>←</kbd> | Избранное (Left Short), по умолчанию меню Apps | Избранное (Left Long) |
| <kbd>→</kbd> | Passport (или назначенное приложение) | Избранное (Right Long) |
| <kbd>BACK</kbd> | — | Экран выключения |

Приложения назначаются в **Settings → Desktop → Favorite App - …**. Подробнее — на странице [Рабочий стол](/ru/start/desktop).

::: tip Unleashed
Удержание <kbd>↑</kbd> на рабочем столе сразу блокирует устройство (с PIN, если он задан). В стоковой прошивке
блокировка делается через Lock Menu.
:::

Короткое нажатие <kbd>↑</kbd> открывает Lock Menu:

![Lock Menu: выбран пункт Turn Bluetooth On, ниже Mute и Dummy Mode](/screens/desktop/lock_menu.png)

Если задан PIN, Флиппер спросит его перед разблокировкой. Код набирается стрелками, <kbd>BACK</kbd> стирает его,
<kbd>OK</kbd> подтверждает:

![Enter PIN: четыре введённые цифры показаны звёздочками, пятая ячейка пустая, подсказки очистки и кнопка OK](/screens/desktop/pin_input.png)

Долгое нажатие <kbd>↓</kbd> открывает экран сведений об устройстве — время работы, ревизия железа, имя Флиппера, версия
и дата сборки прошивки, коммит, версия API и флаг Debug. Долгое нажатие <kbd>OK</kbd> на этом экране включает и
выключает Debug:

![Экран сведений: Uptime 1h23m45s, железо 13.F7B9C6 R00, прошивка unlshd-080 от 21-11-2026 и D:ON](/screens/desktop/debug.png)

## Отклик кнопок

**Main Menu → Settings → Input**

| Пункт | Значения | Смысл |
|---|---|---|
| Buttons Vibro | `OFF`, `1`…`9` | Короткая вибрация на нажатие. Чем больше число, тем длиннее импульс |
| Vibro Trigger | `Press`, `Release`, `Both` | Когда срабатывает вибрация: при нажатии, отпускании или в обоих случаях |

## Ввод текста

На экранной клавиатуре перемещайтесь стрелками, <kbd>OK</kbd> вводит выбранный символ. Удержание <kbd>OK</kbd> на букве
вводит заглавную. Для подтверждения выберите клавишу `⏎` / **Save**. <kbd>BACK</kbd> стирает последний символ или
выходит из клавиатуры.

::: tip Unleashed
В текстовом вводе есть **курсор**, так что можно править текст в середине. В шестнадцатеричном **вводе байтов**
(например, при ручном добавлении ключа) нажмите <kbd>↑</kbd> несколько раз — появится **мини-редактор полубайтов**,
который правит байт по половинкам.
:::
