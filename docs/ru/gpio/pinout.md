# Распиновка GPIO

На верхнем торце Flipper Zero — 18-контактный разъём с шагом 2,54 мм. На нём выходы питания, земля, 13 линий
ввода-вывода микроконтроллера STM32WB55, линии отладки SWD и линия 1-Wire, общая с iButton.

![Функции пинов GPIO Flipper Zero](/img/remote/b75cf29833cf8de8.jpg)

## Таблица пинов

Нумерация начинается с **пина 1 (+5 В)**. Имена портов (`PA7`, `PC0`, …) — те, что прошивка показывает на экране и в
CLI.

| Пин | Имя | Основные функции | Примечание |
|---|---|---|---|
| 1 | +5V | Выход 5 В | От батареи выключен, пока не включите (см. ниже) |
| 2 | PA7 | SPI MOSI, ШИМ (TIM1), АЦП | MOSI внешнего CC1101 / NRF24 |
| 3 | PA6 | SPI MISO, АЦП | MISO внешнего CC1101 / NRF24 |
| 4 | PA4 | SPI CS, ШИМ (LPTIM2), АЦП | CS внешнего CC1101 / NRF24; пин DE/RE в USB-UART |
| 5 | PB3 | SPI SCK | SCK внешнего CC1101 / NRF24 |
| 6 | PB2 | GPIO | GDO0 внешнего CC1101, CE у NRF24 |
| 7 | PC3 | GPIO, АЦП | Управление усилителем внешнего CC1101 |
| 8 | GND | Земля | |
| 9 | 3V3 | Выход 3,3 В | Включён по умолчанию |
| 10 | PA14 | SWCLK | Отладка (SWD) |
| 11 | GND | Земля | |
| 12 | PA13 | SWDIO | Отладка (SWD) |
| 13 | PB6 | USART TX | UART по умолчанию: USB-UART мост, логи, expansion-модули |
| 14 | PB7 | USART RX | |
| 15 | PC1 | LPUART TX, I2C SDA, АЦП | Второй UART; данные внешней шины I2C |
| 16 | PC0 | LPUART RX, I2C SCL, АЦП | Второй UART; тактирование внешней I2C |
| 17 | PB14 | 1-Wire | Линия iButton |
| 18 | GND | Земля | |

Прошивка помечает пины 10, 12, 13, 14 и 17 как **отладочные**: их нет в `GPIO Manual Control`, а команда CLI `gpio`
показывает их только при включённом режиме Debug (и спрашивает подтверждение перед изменением).

![Подробная распиновка GPIO Flipper Zero](/img/remote/e77df2d4499cbbbc.jpg)

PDF с распиновкой для печати есть на [официальной странице GPIO](https://docs.flipper.net/zero/gpio-and-modules).

## Электрические ограничения

- **Логические уровни:** 3,3 В КМОП. Каждый пин идёт к МК через резистор 51 Ом и защищён от ЭСР.
- **Ток на пин:** до 20 мА.
- **Суммарно с пинов I/O:** не более 5 Вт, иначе может сработать защита батареи и Flipper выключится.
- **Толерантность к 5 В:** только у пина, настроенного на **вход**. Пин в режиме выхода 5 В не выдерживает. Не
  подключайте периферию с 5-вольтовой логикой без преобразователя уровней. Подробности — в аппноуте ST
  [AN4899](https://www.st.com/resource/en/application_note/dm00315319-stm32-gpio-configuration-for-hardware-settings-and-lowpower-consumption-stmicroelectronics.pdf).

### +3,3 В (пин 9)

- Включён по умолчанию, максимальная нагрузка **1,2 А**.
- От этой же линии питается microSD. Во время обновления прошивки и монтирования карты пин 9 ненадолго отключается.

::: warning
Модули с большой ёмкостной нагрузкой подключайте только к выключенному Flipper, иначе можно повредить данные на
microSD.
:::

### +5 В (пин 1)

- От USB: при подключённом кабеле пин 1 питается напрямую от USB. Не превышайте **1,2 А**.
- От батареи: выход **выключен по умолчанию**. Повышающий преобразователь (OTG) после включения даёт до **1,2 А**.

Как включить 5 В при работе от батареи:

1. Откройте `Main Menu → GPIO`.
2. Выберите `5V on GPIO` и переключите на `ON` кнопкой <kbd>→</kbd>.

Другие способы:

- CLI: `power 5v 1` / `power 5v 0` (см. [CLI](/ru/dev/cli)).
- `Infrared → GPIO Settings → 5V on GPIO` — для внешних ИК-модулей.
- Приложения вроде Sub-GHz (внешний CC1101) и [SIM800](/ru/gpio/sim800) включают его сами, а
  [expansion-модуль](/ru/gpio/expansion-modules) может запросить его по своему протоколу.

::: tip Как прошивка обращается с 5 В
Если запросить 5 В при подключённом питании USB, сервис питания откладывает включение преобразователя и сам включит его,
когда USB отключат. Если зарядный контроллер сообщает об ошибке OTG (перегрузка или КЗ), 5 В отключается и запрос
сбрасывается — включать придётся заново.
:::

## Пины в режиме DFU

В режиме DFU (загрузчик) пины I/O, кроме пина 17, меняют состояние согласно аппноуту STMicroelectronics
[AN2606](https://www.st.com/resource/en/application_note/cd00167594-stm32-microcontroller-system-memory-boot-mode-stmicroelectronics.pdf)
(таблица «STM32WB30xx/35xx/50xx/55xx configuration in system memory boot mode»). Учитывайте это, если модуль реагирует
на уровни пинов, пока вы [восстанавливаете](/ru/start/recovery) Flipper.

## Как вставлять модуль

- **Без силиконового чехла:** вставляйте до упора, чтобы между Flipper и модулем не было видно пинов. Может
  понадобиться усилие.
- **В силиконовом чехле:** вставляйте, пока не исчезнет зазор посередине между чехлом и модулем.
