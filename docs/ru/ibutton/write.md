# Запись ключей iButton на болванки

У оригинальных ключей iButton заводской ID, который нельзя изменить. Чтобы сделать копию, нужна **болванка** —
перезаписываемый ключ, ID которого можно запрограммировать. У Flipper Zero два режима записи:

- **Write ID** — пишет ID (ROM / код) на болванку. Это обычное «сделать копию домофонного ключа».
- **Full Write on Same Type** — только для DS1992, DS1996 и DS1971: копирует **память** на другой оригинальный ключ
  того же типа (DS1992 → DS1992). ID у целевого ключа остаётся свой.

## Поддерживаемые болванки

| Болванка (как в Settings) | Что пишет | Примечание |
|---|---|---|
| **RW1990.1** | ID DS1990, DS1420 | Болванки типа RW1990; этот вариант пишет биты инвертированными |
| **RW1990.2** | ID DS1990, DS1420 | Болванки типа RW1990, неинвертированный вариант |
| **TM2004** | ID DS1990, DS1420, DS1992, DS1996, DS1971 и generic 1-Wire | Болванки RW2004/TM2004; пишется только ID, хотя память у болванки есть |
| **TM01x** | ID DS1990, **Cyfral**, **Metakom** | Болванки TM01/TM01x |

Болванки, продаваемые как RW1990, TM1990 или TM08v2, обслуживаются вариантами RW1990; Флиппер пробует оба, так что
знать, какая именно у вас, не нужно.

::: tip Unleashed
- **Settings → Write Blanks** — включить или выключить типы болванок (по умолчанию включены все).
- При записи видно, какая болванка пробуется, а экран успеха пишет *Written to TM2004!* и т. п.
- **Cyfral и Metakom** можно записать на болванки **TM01x**.
:::

::: warning TM01x для Cyfral / Metakom — необратимо
Для Cyfral и Metakom болванка TM01x записывается, читается обратно, сравнивается и затем **финализируется** в режим
Cyfral или Metakom. Финализацию отменить нельзя: болванка перестаёт отвечать как устройство 1-Wire и больше не
перезаписывается — даже как ключ Dallas. Если проверка не прошла, болванка не финализируется и остаётся
перезаписываемой. ID Dallas, записанный на TM01x, не финализируется.

Ключи Metakom с неверной чётностью не пишутся (*Refusing to write a key with odd parity*).
:::

## Write ID

1. Откройте ключ: `Saved` → ключ → **Write ID** (или **More → Write ID** после чтения).

   ![Меню сохранённого ключа: Emulate, Write ID, Edit и Rename](/screens/ibutton/saved_menu.png)

2. На экране **Writing ID**, `[Протокол]`, имя ключа (или *Unsaved Key*) и в скобках тип болванки, который сейчас
   пробуется, например `(RW1990.1)`.

   ![Экран записи ID: протокол [DS1990], имя ключа и в скобках пробуемая болванка (RW1990.1)](/screens/ibutton/write.png)

3. Приложите болванку к **плоской части** площадки (левый пин данных + средняя земля), как при чтении. Не двигайте.
4. Флиппер пробует каждую включённую болванку, которая может нести этот протокол, и читает результат обратно.
5. **Written to RW1990.2!** (или *Successfully written!*) — готово.

## Full Write on Same Type

1. `Saved` → ключ DS1992 / DS1996 / DS1971 → **Full Write on Same Type**.
2. На экране **Full Writing**. Приложите оригинальный ключ **того же** типа.
3. Память записывается, собственный ID целевого ключа остаётся. Этот режим не использует настройку Write Blanks.

## Settings → Write Blanks

`Main Menu → iButton → Settings → Write Blanks` — список **RW1990.1**, **RW1990.2**, **TM2004**, **TM01x** с
**ON**/**OFF**. Переключение — <kbd>OK</kbd>/<kbd>←</kbd>/<kbd>→</kbd>; сохраняется при выходе в
`/ext/ibutton/.ibutton.settings`. CLI-команда `ikey write` использует ту же настройку.

Если страница пишет *Settings page missing. Update the SD resources* — переустановите прошивку со вставленной SD-картой.

## Ошибки

| Экран | Что значит |
|---|---|
| **Cannot Write** — *No blanks enabled. Enable one in Settings* | Все типы болванок выключены |
| **Cannot Write** — *No enabled blank can write this key* | Например, включены только RW1990, а ключ Metakom |
| **Cannot Write** — *This key cannot be written* (или причина от протокола) | Данные ключа непригодны для записи |
| Экран записи висит, мигает светодиод | Болванка пока не обнаружена — проверьте контакт, или тип болванки не поддерживается |

## Если не получается

- **Контакт.** Центр болванки должен касаться пина данных, ободок — пина земли.
- **Неизвестный тип болванки.** Включите все типы. Некоторые дешёвые болванки Флиппер программировать не умеет.
- **«Успех», но считыватель копию не принимает.** Некоторые считыватели фильтруют болванки — тут Флиппер ничего не
  сделает.
- **Использованная TM01x.** TM01x, финализированную как Cyfral/Metakom, повторно не использовать.
