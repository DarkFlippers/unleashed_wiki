# Приложение MFKey (MFKey 4.1)

**MFKey** (автор [@noproto](https://github.com/noproto)) восстанавливает ключи MIFARE Classic **на самом Флиппере**
из нонсов, собранных NFC-приложением: нонсов считывателя (MFKey32) и нонсов метки из nested-атак. Это инструмент на
случай, когда под рукой нет телефона или ПК: медленнее, чем [qUnleashed](/ru/nfc/qunleashed), зато работает где
угодно, хоть в кармане.

| | |
|---|---|
| Где | `Main Menu → Apps → NFC → MFKey` (`/ext/apps/NFC/mfkey.fap`) |
| Версия в Unleashed | **4.1** |
| Входные данные | `/ext/nfc/.mfkey32.log` (нонсы считывателя), `/ext/nfc/.nested.log` (нонсы метки) |
| Результат | `/ext/nfc/assets/mf_classic_dict_user.nfc` (ключи), `/ext/nfc/assets/mf_classic_dict_<UID>.nfc` (кандидаты SEN) |

## Использование

1. Сначала соберите нонсы:
   - со считывателя — [MFKey32](/ru/nfc/mfkey) (`Extract MFC Keys`);
   - с метки — [nested-атаки](/ru/nfc/nested-fudan) во время `NFC → Read`.
2. Откройте `Main Menu → Apps → NFC → MFKey` или нажмите **Run** на экране *«Now run Mfkey32 to extract keys»* в
   NFC-приложении (он появляется после `Extract MFC Keys` и после `Crack nonces in MFKey32`).
3. На экране **Ready**. <kbd>→</kbd> **Help** покажет *«Collect nonces by reading tag or reader in NFC app»*.
   Нажмите <kbd>OK</kbd> **Start**.
4. Сначала MFKey сверяет нонсы с имеющимися словарями: **Dict solves: N (in progress)**, **Keys in dict: N**. Нонсы,
   ключ к которым уже известен, пропускаются.
5. Затем идёт атака с тремя прогресс-барами: **Cracking: X/Y**, **Round: X/Y – ETA NN Sec** и **Total ETA NNN Sec**.
   Строка **RAM** вверху показывает свободную память.
6. По окончании — звуковой сигнал и **Complete**, **Keys added to user dict: N**, а для static encrypted нонсов —
   **SEN key candidates: N**.
7. Вернитесь в NFC и прочитайте метку снова (или `Saved → <метка> → Unlock with Dictionary`).

<kbd>←</kbd> останавливает работу и выходит (поток завершается корректно, найденные к этому моменту ключи
записываются).

### Ошибки

| Экран | Что значит |
|---|---|
| **No nonces found** | Нет ни `.mfkey32.log`, ни `.nested.log`. Сначала соберите нонсы. Так же выглядит случай меток только с HardNested — их нонсы на Флиппере не взламываются. |
| **Nonces already cracked** | Все нонсы из логов уже решены ключами из ваших словарей. |
| **No free RAM** | Не хватает памяти. Перезагрузите Флиппер и попробуйте снова; закройте другие приложения. |

## Что изменилось в MFKey 4.x

По статье @gromovyna «MFKey 4.1 — быстрее, выше, сильнее!»: новая мажорная версия прошла довольно незаметно, хотя
производительность заметно выросла. Изменение доступно в **дев-билдах Unleashed начиная с 1251**. (На момент статьи
в официальной прошивке изменения приложения были вмерджены, а изменения в самой прошивке, нужные для работы аппки, —
нет.) Спасибо за изменения @noproto и команде.

Ниже **SEN** — static encrypted nonce (подробнее — в [статье про Nested](/ru/nfc/nested-fudan)).

**4.0**

- Поддержка нового формата SEN-словаря — скорость восстановления ключей выросла **в 10 раз**.
- Поддержка старого формата SEN-словаря убрана.

**4.1**

- Восстановление ключей ускорено ещё **на 40%**; улучшена эффективность использования памяти.
- Монолитный `mfkey.c` разбит на специализированные модули: `mfkey_batch_prelude`, `mfkey_state_expansion`,
  `mfkey_bs_verify`, `mfkey_recovery`, `mfkey_dedup`.
- Параллельная проверка 32 кандидатов одновременно через SWAR (битовые операции вместо поштучной проверки).
- Предвычисленная 2 KB Super-LUT таблица для раундов 0–3 — один индексированный load на раунд вместо вычислений.
- Сортировка радиксом O(n) вместо quicksort; дедупликация через хэш Фибоначчи вместо наивного сканирования.
- FPU-регистры M4 используются как дополнительный scratch-буфер (`vmov`), снижая давление на регистры.
- 8-кратно развёрнутый цикл по методу Даффа в сканировании дубликатов.

### Тесты

Для тестов автор выбрал самую тяжёлую метку — со **static encrypted nonce**. В такой метке просчитанные ключи не
проверяются на ходу и не попадают в словарь юзера сразу, а строится словарь **предположений**, который потом
необходимо проверить на метке. Значит, из нонсов будут добыты **все** ключи, которые могут «дать» этот нонс — самый
большой словарь и самый длинный сценарий. Во время всех тестов не было ни одного *Out Of Memory*.

| Тест | Условия | Результат |
|---|---|---|
| Ключ от Iron Logic | Метка зашифрована картой объекта [Iron Logic](/ru/nfc/iron-logic); в словаре ни одного ключа, атака через бэкдор; **18 уникальных ключей на 32 сектора** | Полный цикл **6 ч 8 мин**, более **1,2 млн кандидатов**; затем ещё несколько часов проверки кандидатов на метке. (Первый раз автор запустил тест на ночь и не знал, когда закончился перебор, — знал точно, что быстрее, чем его сон. Поэтому подчистил всё и запустил ещё раз.) |
| 1 сектор — 2 ключа | Та же метка (очищенная), сектор 0 зашифрован случайными разными ключами A и B | **17 минут**; проход по одному сектору тоже был довольно быстрый. |

Для сравнения: полная расшифровка ключа из первого теста на Proxmark3 заняла 24 секунды — с этим Флиппер, очевидно,
не сравнится. Но если вы едете куда-то в отель или просто есть время на фоновые операции, Флиппер в кармане будет
полезен: можно восстановить ключи и эмулировать метку. А с учётом того, что диверсификацию любят в основном Iron Logic
и подобные СКД, шанс пойти по самому длинному сценарию относительно мал.

::: tip Unleashed
В Unleashed MFKey 4.1 идёт вместе с нужными изменениями в прошивке (CUID-словарь в `Read` с прогресс-баром при
загрузке). После того как MFKey отработал по SEN-метке и метка полностью прочитана, используйте **Save Keys to
Dictionary** в меню дампа, чтобы скопировать ключи в пользовательский словарь — см.
[MIFARE Classic](/ru/nfc/mifare-classic#save-keys-to-dictionary).
:::

## Советы

- Чистите `/ext/nfc/.nested.log` и `/ext/nfc/.mfkey32.log` после успешного восстановления: старые нонсы
  перепроверяются при каждом запуске.
- Если ставили приложения отдельно, убедитесь, что старый `mfkey.fap` не перетёр версию из прошивки.
- Гораздо быстрее: [qUnleashed](/ru/nfc/qunleashed) на телефоне/ПК или проект
  [mfkey_desktop_cli](https://github.com/phntm-lab/mfkey_desktop_cli).
