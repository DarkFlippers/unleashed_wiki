# App T5577

La app **T5577** (de @mishamyte, incluida con Unleashed) trabaja con un chip virgen T5577 / ATA5577 a **nivel de
bloque** — con el silicio, no con la tarjeta que finge ser. Puede leer los bloques del chip y guardarlos, editar
cualquier bloque o componer su palabra de configuración, volver a escribir un volcado guardado, comprobar qué bloques
aceptan escrituras, borrar el tag por completo, limpiar su contraseña y recuperar una contraseña por el aire
escuchando a un lector o un clonador mientras escribe un tag.

Ábrela desde `Main Menu → Apps → RFID → T5577` (se instala como `/ext/apps/RFID/t5577.fap`). La app de RFID de
125 kHz también la lanza cuando abres un archivo `.t5577` desde **Saved**.

::: tip Unleashed
Esta app no existe en el firmware de fábrica. Clear Password y el borrado del T5577 estaban antes en **Extra Actions**
de la app de RFID de 125 kHz; ahora viven aquí.
:::

## Contexto: qué hay dentro de un T5577

| Página / bloque | Contenido |
|---|---|
| Página 0, bloque 0 | **Configuración**: modulación, tasa de bits, número de bloques de datos enviados (max block), bit de contraseña y otros indicadores |
| Página 0, bloques 1–6 | Datos — la trama de la tarjeta emulada |
| Página 0, bloque 7 | Almacén de la contraseña (o datos normales si no hay contraseña activada) |
| Página 1, bloque 0 | Copia de la configuración |
| Página 1, bloques 1–3 | Datos de trazabilidad de fábrica (los bloques 1–2 están bloqueados en los chips auténticos) |

## Menú principal

| Elemento | Qué hace |
|---|---|
| **Read Tag** | Leer todos los bloques en un volcado |
| **Test Tag** | Averiguar qué bloques aceptan escrituras (primero copia de seguridad, después restauración) |
| **Saved** | Abrir un volcado `.t5577` guardado |
| **Wipe Tag** | Devolver el chip al estado virgen |
| **Clear Password** | Eliminar una contraseña: primero tu palabra, después el diccionario |
| **Sniff Password** | Escuchar a un lector o clonador y decodificar los comandos que envía |
| **Passwords** | Ver los diccionarios y gestionar tus propias palabras |

## Read Tag

1. `T5577 → Read Tag`. Coloca el tag en la parte trasera del Flipper y mantenlo quieto (*Finding tag*, después
   `P0 block N…`).
2. La pantalla de resultado **T5577 read** muestra `Block 0: XXXXXXXX` y un resumen del tipo `RF/64, password set,
   inverted`. Botones: **Save**, **Info**, **Retry**.
   - **Info** muestra la configuración decodificada (Modulation, Bit rate, Max block, los indicadores
     PWD/AOR/ST/XM/POR y Password) y todos los bloques de la página 0 y de la página 1; los bloques que no se han
     leído aparecen como guiones.
   - **Save** pregunta *Name the dump* y guarda `/ext/lfrfid/<name>.t5577`.
3. **Read in part** significa que el tag dejó de responder a mitad del proceso — se indica el bloque en el que se
   quedó mudo. Sujétalo mejor y vuelve a intentarlo.
4. **Nothing found** — *Hold the tag still, or it needs a password*. Botones **No pass** (reintentar en claro) y
   **Password**.

::: danger Las lecturas con contraseña pueden dañar un tag sin proteger
Al elegir **Password** aparece *Only if it is protected — A password read writes block 0 of a tag that has no password
set*. La trama de lectura con contraseña tiene la misma longitud que una escritura: enviada a un tag que **no** tiene
contraseña, escribe tu «contraseña» en el bloque 0 y el tag deja de leerse como nada. Un tag mal sujetado parece
exactamente igual que uno protegido, así que reintenta siempre primero en claro. Si la app descubre después que el tag
no quería contraseña, avisa con *Tag wants no password — That frame wrote block 0. Check it below, and wipe the tag if
it reads wrong*.
:::

## Volcados guardados

`T5577 → Saved` lista los archivos `.t5577`. Un volcado abre un menú:

| Elemento | Acción |
|---|---|
| **Info** | Configuración decodificada y todos los bloques |
| **Write to Tag** | Volver a escribir el volcado (pregunta *Write to tag* con el número de bloques) |
| **Edit** | Editar bloques |
| **Rename** / **Delete** | Gestionar el archivo (un volcado puede contener la contraseña del tag — bórralo si no debe quedarse en la tarjeta) |

### Write to Tag

Escribe solo los bloques que el volcado leyó realmente, en el orden que usa Proxmark3: bloques 1–7 de la página 0,
bloques 1–3 de la página 1 y el **bloque 0 al final**. Un bloque 0 a cero nunca se escribe. Después se relee cada
bloque. Entre los resultados están **Written!**, **Not written**, *Lost the tag at P0 block N*, *P0 block N differs*,
*Tag wants a password this dump has not* o *P1 trace unchanged* (los chips auténticos se niegan a cambiar sus bloques
de trazabilidad — es lo esperado).

Si el bloque 0 describe una configuración que el Flipper no puede decodificar, se te advierte antes de escribir de que
*Nothing will read back*.

### Edit

**Edit blocks** lista todos los bloques con su valor. Elige un bloque para escribir una nueva palabra de 32 bits. El
**bloque 0** abre un editor de configuración con campos con nombre:

- **Modulation**: Direct, PSK1, PSK2, PSK3, FSK1, FSK2, FSK1a, FSK2a, ASK/MC, Biphase, Diphase
- **Bit rate**: RF/8, RF/16, RF/32, RF/40, RF/50, RF/64, RF/100, RF/128
- **Data blocks** (max block), **Password bit** (On/Off) y **Word** — el hexadecimal en bruto.

Al salir, *Save changes — Write the edited blocks back to the file* pregunta si quieres guardar. Rechazar descarta
también la edición de memoria, así que no puede llegar a un tag por accidente.

## Test Tag

Averigua cuáles de los bloques 1–7 de la página 0 aceptan realmente una escritura. Pregunta *Do not move the tag — A
backup is saved, then every block is written and put back*.

- Se lee el volcado completo y se guarda como `/ext/lfrfid/t5577/T5577_before_test.t5577` antes de cualquier
  escritura.
- A cada bloque se le invierte un bit, se relee, y después se vuelve a escribir el original y se verifica.
- Resultados: **Full T5577** (todo escribible), **Nothing writeable**, *Stopped at block N*, *Lost tag at block N —
  Check it, then retry*, *Block N is not back* (restáuralo desde la copia de seguridad), **Tag has a password — Not
  supported yet**.
- Si una prueba anterior dejó un tag modificado, la app avisa con *Unfinished test* antes de sobrescribir la copia de
  seguridad.

## Wipe Tag

Confirma *Wipe T5577 — Erases all data. The tag stops working as a key. Hold still while running* → **Wipe**. Los
bloques de datos se ponen a cero y se escribe una configuración por defecto; después el resultado se verifica
releyendo.

- **Wiped!** — listo; escribe una llave nueva desde la app de RFID de 125 kHz.
- **Not wiped** — *No answer. Protected? Try Clear Password*, *The tag answered, but not as wiped* o *Could not check
  what the tag holds*.

El borrado **no** elimina una contraseña.

## Clear Password

1. `Clear Password` pregunta *Password to try first* — introduce la contraseña del tag si la conoces (o deja el valor
   por defecto).
2. Confirma *Apply tag to Flipper's back and don't move it while it runs* → **Start**.
3. La app comprueba primero si el tag está siquiera protegido, después prueba tu contraseña, después tu **diccionario
   de usuario** y después el **diccionario del sistema** (`Pass N of M`). Solo se escribe el bloque 0, con el bit de
   contraseña a cero — la misma escritura única que usa Proxmark3.
4. Resultados: **Cleared!** (*Opened by this password* — con **Save** para añadir la palabra a tu lista), *The tag was
   asking for no password*, **Not cleared** (*No password matched, or no tag answered*) o errores de diccionario o de
   tarjeta SD.

El bloque 7 conserva el valor de la contraseña antigua después de limpiarla — solo se elimina el bit de protección.

## Sniff Password

Recupera una contraseña **escuchando** mientras un lector o un clonador habla con un tag. El Flipper no envía nada y
no energiza el campo — es seguro apuntarlo a hardware que no sea tuyo.

1. `Sniff Password`. La pantalla muestra *Listening* / *Hold on the cloner* y una traza en vivo.
2. Coloca la parte trasera del Flipper sobre el clonador o el lector, donde iría el tag, y deja que el aparato haga su
   escritura o lectura.
3. La captura termina tras un comando completo y un silencio; la pantalla de resultado muestra lo que se ha oído:
   - **Password** — *The cloner sent it* (se ha oído una lectura o escritura protegida por contraseña);
   - **New password** — *Written to block 7* (el clonador estaba instalando una contraseña);
   - **Maybe a password** — la trama de 38 bits podría ser una lectura con contraseña o una escritura; ambas
     interpretaciones están en **More**;
   - **No password** / **Commands heard** — *None of them carried a password*;
   - **Too much noise**, **Can't decode**, **Nothing heard**.
4. **More** lista todos los comandos decodificados (Reset, Read/Write con o sin contraseña, con bloque y datos).
   **Save** guarda una contraseña encontrada en tu diccionario de usuario (una interpretación deducida de tramas
   vecinas pregunta primero *Save a deduction?*).

## Passwords

`T5577 Passwords` muestra **System dict: N** y **User dict: N** con **Add** y **List** (selecciona una palabra para
borrarla).

| Archivo | Contenido |
|---|---|
| `/ext/lfrfid/assets/t5577_dict.lfrfid` | Lista del sistema (contraseñas de Proxmark3; se sobrescribe al actualizar el firmware) |
| `/ext/lfrfid/assets/t5577_dict_user.lfrfid` | Tus palabras — Clear Password las prueba primero y se conservan entre actualizaciones |
