# Comunidad

El firmware Unleashed y esta wiki existen gracias a una gran comunidad de desarrolladores, investigadores y
entusiastas. Esta sección es la parte «humana» de la wiki: quién ha hecho todo esto, dónde están los recursos
oficiales del proyecto y cómo puedes ayudar a mejorar las páginas que estás leyendo.

## Sobre esta wiki

Este es un proyecto comunitario. **No está afiliado a Flipper Devices** y **no** es un recurso oficial de
Unleashed: es una wiki de guías escrita leyendo el código fuente del firmware, la documentación oficial y los
artículos de investigación de las personas acreditadas aquí.

La wiki está **orientada a Unleashed**: allí donde el fork Unleashed se comporta de forma distinta al firmware de
serie (protocolos extra, menús extra, aplicaciones extra), la diferencia se señala de forma explícita. El
conocimiento sobre el Flipper Zero de serie se cubre igualmente por completo.

::: tip Cada página acredita sus fuentes
Toda página elaborada a partir del artículo, la publicación de un canal, la documentación o el código del firmware
de alguien lleva al final un bloque de créditos con los originales exactos. Si crees que algo está mal acreditado
o falta, consulta [Contribuir](/es/community/contributing).
:::

::: warning Solo para uso lícito
Todo lo que hay aquí es para trabajar con **tus propios** dispositivos y para investigación lícita. El control de
accesos, los códigos rodantes y las llaves de coche se tratan como materia técnica, no como una invitación a
atacar sistemas que no te pertenecen.
:::
